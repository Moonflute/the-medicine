- 공통 좌표와 원본 정체성 유지, 계통별 지연 로딩, 회전·절개·분해·선택·indication·복원 동작 검증.

- 기기 모델 저장: 해시 검증, 재사용, 취소, 삭제. 전신 6계통 저장 후 네트워크 차단 상태의 추가 계통 로딩 검증. 웹앱 전체 오프라인 기능은 아니다.
- 0.13.0 실제 Pages 배포 및 공개 사이트 저장/재사용 성공: Actions 34753264555.
- 이번 교정: 경부·왼쪽 상지 보기의 일부 양측 횡격신경 표면을 반영한 명칭, 5개 구조의 구현 범위 설명. 원본 ID·좌표·형상 변경 없음.

## 후속 보완으로 남기는 사항
- Z-Anatomy의 별도 명명 표면 기준 양측 횡격신경·하둔신경 누락, 척수신경 뿌리의 개별 분절 미구현.
- 동맥 2개와 정맥 1개의 미확인 원본 명칭은 미확인 상태로 유지. 추정 명칭을 부여하지 않는다.
- 일부 혈관·신경의 분지 연결과 근육 부착면은 추가 주행·표면 검수가 필요하다. 근접한 표면만으로 정확한 연결을 단정하지 않는다.
- 서로 다른 표본을 임의로 합치지 않는다. BodyParts3D 지역 보기와 Z-Anatomy 전신 보기는 별도의 원본 좌표계다.
- 병태 표현은 교육용 개념 표현이며 환자별 구조나 실제 질환 정도의 재현이 아니다.
- 브라우저 저장 데이터는 브라우저 정리/용량 정책으로 삭제될 수 있다. 저사양 실기기 검증은 사용자 지시에 따라 최적화 및 브라우저 검증으로 대체했다.

치명적 실행 오류나 이번 교정에서 발생한 좌표 회귀는 발견하지 못했다. 이 범위로 배포를 마치며 세부 확장은 다음 작업으로 넘긴다.

- 별도 명명 표면이 없는 횡격신경·하둔신경, 개별 척수신경 뿌리, 미확인 혈관 명칭과 절개면 채움은 후속 사항으로 유지한다.
