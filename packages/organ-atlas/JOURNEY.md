# 1인칭 내부 탐험

Atlas 모델 화면의 **내부 탐험**에서 진입한다. 심장 모델에서는 심장·혈관 탐험을 바로 연다. 기존 Atlas의 시점·선택·절개 상태를 유지한 채 렌더링을 중단하고, 탐험을 닫으면 그대로 재개한다. 탐험 코드와 해당 영역의 표면·충돌 데이터만 지연 로드한다.

## 범위와 의학적 한계

- 구강 → 구인두·후두인두 → 식도 → 위 → 십이지장 → 공장·회장 → 맹장·상행결장 → 횡행결장 → 하행·구불결장 → 원위부 대장.
- 인두에서 전방의 후두 입구 → 기관 → 좌·우주기관지로 분기.
- 입·소화관·기도 36구간을 하나의 표면·충돌 필드로 제공한다. 기관 → 좌우 주기관지 → 엽기관지·중간기관지 → 분절기관지까지 장면 전환 없이 연결한다. 좌하엽 기저부는 원본의 공통 줄기와 분절 형상이 여러 이름에 걸쳐 있으므로 다섯 원본 메시를 `Left basal bronchi`로 묶는다. 개별 B7–B10 경계를 임의로 새로 만들지 않는다.
- 동맥 32구간: 상행대동맥 → 대동맥활 → 흉부·복부대동맥, 머리·상지의 주요 분지, 복강동맥 → 총간·고유간·위십이지장·비장·좌위동맥, 장간막동맥 근위부, 양쪽 신동맥과 앞·뒤 가지, 양쪽 총·내·외장골동맥. 우관상동맥·좌관상동맥·앞심실사이동맥(LAD)을 추가했다. 좌관상동맥 원본 안에서 좌주간부와 회선동맥의 경계를 임의로 나누지 않는다.
- 정맥 11구간: 하대정맥의 상부·하부 원본 구간, 양쪽 신정맥, 총·내·외장골정맥, 간정맥 합류부. 심장과 함께 하나의 `circulation` 영역으로 지연 로드한다. 간정맥 원본은 짧은 합류부이며 간내 세부 분지나 좌·중·우 간정맥 전체를 뜻하지 않는다.
- 상체 정맥 9구간: 상대정맥, 양쪽 팔머리·쇄골하·내경·액와정맥. 상·하대정맥 모두 우심방으로 이어지며 별도 모델 전환 없이 이동한다.
- 소화관과 혈관 사이에 통로를 만들지 않는다. 심장·혈관 영역에 처음 진입하면 우심방에서 시작한다. 상단 부위 이동에서 좌심장과 다른 혈관을 직접 선택할 수 있다. 이전 위치를 누르면 이동 전 위치·시선·크기·위치도 방향을 복원한다. 두 공간의 실제 관강이 연결되었다는 표현은 하지 않는다.
- 과거 HRA 기관지 상세는 다른 표본이라 기본 영역 선택에서 제외했다. 연구용 원본과 생성 파일은 보존하되 배포·전체 저장 목록에서는 제외한다. 기존 Atlas의 HRA 폐 모델에는 영향이 없다. `coordinateFrame` 검사는 유지해 향후 다른 표본이 같은 몸의 근접 좌표로 잘못 전환되지 않게 한다.
- 세기관지·폐포, 장간막동맥의 원위부 혈관궁, 모세혈관과 전신의 모든 정맥을 포함한 완전한 폐쇄 순환은 제공하지 않는다. 원위부 대장의 정확한 직장–항문관 경계와 외부 개구도 분할 자료가 아니다. 범위 끝의 폐쇄면은 데이터 제공 경계이며, 가까워지면 범위 안내와 지나온 통로 방향을 표시한다.

기존 Z-Anatomy의 원본 공통 좌표를 사용한다(+X 인체 좌측, +Y 위, +Z 앞; m). 상세 기관지는 공식 Z-Anatomy Unity 앱의 `VisceralSystem100.fbx`에서 재사용한다. 평가된 월드 좌표에 cm→m 단위 변환만 적용하며 회전·평행 이동·비균일 변형은 없다. 식도는 원본 내·외벽 교차 중 내강을 사용한다. 위·십이지장·기관지·혈관은 원본 표면에서 **탐색용 내부 공간을 재구성**한다. 구강·인두·후두 입구는 기존 혀·식도·기관의 위치를 참고한 모식 보강이다.

혀는 기존 Z-Anatomy 표면을 공통 좌표 그대로 사용한다. 후두개는 기존 BodyParts3D 후두 자산에서 재사용하며, 갑상연골·윤상연골의 중심으로 평행 이동을 구하고 양쪽 피열연골 표면으로 별도 점검한다. 회전·비균일 확대는 하지 않는다. 네 연골의 원본 표면 간 RMS는 0.46–0.74 mm, 95백분위 거리는 0.77–1.62 mm 미만이다. 변환·원본 해시·개별 오차를 `landmarkRegistration`에 기록하고 RMS 1 mm 또는 95백분위 2 mm 초과 시 생성을 중단한다. 이 수치는 연골 정합 검사이며 후두개 점막이나 임상 내강의 정확도를 검증한 값이 아니다. 서로 다른 출처를 같은 원본 좌표라고 간주하지 않는다.

혀·후두개의 체적을 탐색 공간에서 제외하고 같은 mask로 표면과 충돌 필드를 만든다. 따라서 표지만 띄운 관통 가능한 물체가 아니며, 원본 표면은 voxel 재구성과 평활화 범위에서 근사된다. 런타임에 별도 고해상도 장기 메시를 추가로 로드하지 않는다.

### 장관 원본의 범위와 이름

Z-Anatomy의 `Jejunum`은 십이지장 인접 끝에서 맹장 인접 끝까지 이어지는 1,153개의 12정점 단면으로 된 하나의 관이다. 이 단면의 순서·중심을 그대로 추출하고 외형 안쪽으로 1.5 mm 줄여 탐색 공간을 만든다. 이 수치는 재구성을 위한 여유이며 실제 벽 두께가 아니다. 공장·회장 사이에 측정된 구분점이 없어 `Jejunum and ileum`으로 표시한다. 원본의 경로 길이는 약 2.03 m이며 사람의 실제 장 길이를 주장하는 값이 아니다.

`Ascending colon`은 하부 맹장 주머니를 포함하며, `Descending colon`은 하행부와 하부 내측 회전을 포함한다. 각각 묶음 이름으로 표시한다. 원본 이름이 `Sigmoid colon`인 맨 아래 골반 중앙 구간은 정확한 직장·항문관 경계를 정하지 않고 `Distal colorectal segment`로 표시한다. 원본 라벨을 검증된 세부 경계로 취급하지 않는다. 각 설명은 생성 명세의 `scopeNote`에도 기록한다.

소장의 서로 인접한 회전은 원본 경로 순서를 사용해 분리한다. 다른 장관과 겹친 재구성 영역은 소장 중심 경로를 보존하고 벽을 분리한다. 조정 voxel 수를 명세에 남긴다. 십이지장–소장 및 회맹부 연결은 원본 끝점 주위의 제한된 창에서만 허용한다. 소장 전체 원본 중심 경로의 통과성과 양 끝 사이 최단 경로 길이도 검사한다.

이는 임상 내시경 영상이나 CT에서 분할한 실제 내강 자료가 아니다. 점막 주름·성대·후두개 개폐·괄약근·벽 두께·팽창 및 생리적 변형은 검증된 재현 범위가 아니다. 내부 표면의 작은 다각형이나 요철을 실제 조직학적 구조로 해석하면 안 된다. 원본의 상대 위치와 연결 방향을 재사용한 탐험 프로토타입이다.

## 연속 기관지의 원본 대조

`node prepare-journey-continuity.mjs`는 [공식 Z-Anatomy Unity 원본](https://github.com/LluisV/Z-Anatomy/tree/PC-Version)을 받아 Git blob `355770ae46123044c85deca03de3fb880b8f7301`을 검증한다. 기관·좌우 주기관지·혀·두 폐엽을 현재 자산과 양방향 표면 대조했다. 최대 좌표 차이는 0.000239 mm이며, 이는 같은 좌표 자료임을 확인하는 수치로 실제 환자 해부학의 정확도 수치가 아니다. 단위 변환과 개별 검사, 원본 해시를 `journey-continuity-source-audit.json` 및 생성 manifest의 `sourceContinuity`에 기록한다.

새 22개 기관지 묶음의 부모 표면과 자식 표면 간 최소 간격은 모두 0.454 mm 이하이다. 좌하엽 B8/B10의 이름만 따라 부모에 직접 연결하면 각각 5.75/20.76 mm 간격이 생기므로 그렇게 연결하지 않는다. 해당 원본의 공통 줄기 형상을 포함한 기저기관지 묶음을 사용한다. 가지가 좁으면 ¼× 크기가 필요하며 관을 임의로 굵게 만들지 않는다.

`node prepare-journey-context.mjs`는 같은 좌표의 기존 경량 뼈·장기 표면을 두 방향으로 투영한다. 정수 양자화된 좌표는 먼저 부동소수로 해석한 뒤 월드 변환을 적용한다. 위치도는 방향·위치 참고용 투영이며 단면이나 검증된 외형 피부 모델이 아니다. 두 PNG의 합은 106,123 bytes이며 추가 고해상도 3D 모델을 로드하지 않는다.

## 심장–대혈관–전신 분지 연속 탐험

`circulation`은 64개 구조와 62개 연결을 같은 표면·충돌 필드로 제공한다. 기존 대동맥·하대정맥·상대정맥 영역의 중복 근위부를 하나로 합쳐, 접합면의 뚜껑이나 모델 로드 전환 없이 이동한다. 양쪽 방향의 탐험은 가능하지만 설명과 표지는 생리적인 혈류 방향을 따로 표시한다.

- 상·하대정맥 및 관상정맥동 → 우심방 → 삼첨판 통과부 → 우심실 → 폐동맥판 통과부 → 폐동맥줄기 → 좌우 폐동맥.
- 네 폐정맥 → 좌심방 → 승모판 통과부 → 좌심실 → 대동맥판 통과부 → 기존 대동맥·관상동맥·전신 주요 분지.
- 우·좌 경로는 **분리된 두 연결 성분**이다. 폐 모세혈관망 없이 폐동맥과 폐정맥을 직접 붙이거나, 심장 중격을 관통하거나, 전신 동맥과 정맥을 직접 연결하지 않는다. 완전한 폐쇄 순환이나 환자별 심장 분할 자료가 아니다.

`node prepare-journey-cardiac.mjs`는 공식 Z-Anatomy Unity `CardioVascular41.fbx`의 Git blob `aa5bbcb63ae6e9ace8051111b3a85ea87f00c4f3`을 검증하고 평가된 월드 좌표의 cm→m 변환만 적용한다. 기존 4방 원본과 양방향 표면 대조한 최대 차이는 0.492 mm 이내, 95백분위 최대 차이는 0.156 mm 이내다. 이 수치는 같은 좌표의 자산 대조이며 실제 환자 해부학의 정확도 수치가 아니다. 심장 4방은 현재 고해상도 원본을, 추가 폐혈관은 동일 좌표의 공식 FBX를 사용한다. 다른 HRA 심장을 임의 정합하지 않는다.

0.6 mm 격자에서 내·외벽의 교차 방향을 구별하고 세 직교 축 중 둘 이상이 일치하는 혈액 공간을 재구성한다. 심근으로 판별한 공간을 제외하고, 심장에는 일반적인 구멍 채우기를 적용하지 않는다. 다만 같은 원본에서 분할한 혈관 내부는 심근 근사 마스크보다 우선한다. 심근 안을 주행하는 관상동맥을 벽으로 막지 않으며, 이 겹침은 `sourceVesselWallOverlapVoxels`로 기록하고 별도 연결 허용 목록으로 잘못된 지름길을 차단한다. 원본 혈관과 심방 근사 공간이 맞닿는 곳은 심방 쪽에만 분리 벽을 남겨 좁은 관상동맥을 깎지 않는다. 짧고 검토된 혈관 접합부에도 같은 원칙을 적용한다. `audit-journey-cardiac.mjs` / `.py`, `journey-cardiac-cavity-audit.json`과 PNG는 원본과 재구성의 단면 검토를 재현한다. 심장 내벽의 작은 주름은 복셀·평활화 오차 범위에서 근사된다.

네 판막은 원본 방실륜·유출로 위치에서 **열린 탐험용 통과부**로 보강한다. 모든 판막이 동시에 열리는 생리적 단계나 완전한 판엽·건삭·유두근의 박동 모델을 뜻하지 않는다. 공식 FBX의 판엽 일부는 누락되거나 계층 이름이 맞지 않으므로 완성된 동적 판막으로 재사용하지 않는다. 통과부의 중심·반경·보강 범위·원본 간격은 `valvePassages`, `junctionWindows`, `junctions`에 남긴다.

`node verify-journey-circulation.mjs`는 배포할 희소 필드에서 64개 시작점과 모든 허용 접촉, 두 독립 혈류 경로, 판막 표지·방향, 모든 목적지까지 실제 충돌 컨트롤러의 왕복 이동, 화면 벽과 충돌 공간의 여유 및 리소스 예산을 검사한다. 심장 단독 단면 자료는 `python verify-journey.py cardiac`로 네 판막을 기본 크기로 통과하는지와 표면이 닫혀 있는지도 검사한다. 신뢰 범위는 재구성 모델의 기하·연결 정합성이다.

연결 참고: [OpenStax Heart anatomy](https://openstax.org/books/anatomy-and-physiology-2e/pages/19-1-heart-anatomy), [OpenStax Circulatory pathways](https://openstax.org/books/anatomy-and-physiology-2e/pages/20-5-circulatory-pathways).

## 생성 및 검증

`node build-journey.mjs` (Python: numpy, scipy, scikit-image 필요). `upper` 또는 `circulation` 인자로 한 영역만 다시 만들 수 있다. 브라우저에는 이 빌드 의존성을 추가하지 않는다.

기존 분리 자료는 `vessels`, `veins`, `thoracic-veins` 인자로, 심장만의 검토 자료는 `cardiac` 인자로 재생성한다. 이들은 중복 배포하지 않는다. 과거 별도 HRA 연구 자료는 `airways` 인자로 재생성할 수 있으나 기본 배포에는 포함하지 않는다. `node audit-journey-expansion.mjs`는 재사용한 파일 해시, 원본 삼각형 간 연결 거리, 기관의 내·외벽 교차, 심장 4방·4판막의 경계 모서리와 중심 단면 교차를 `journey-expansion-audit.json`에 기록한다. 기관지와 상체 정맥 연결은 재구성 시 원본 표면 간격을 4 mm 이내로 제한한다. 우하엽 B9/B10은 원본 접촉점을 기준으로 접합부를 찾으며, 먼 곳에서 서로 겹친 딸가지 조각을 부모 기시부로 오인하지 않도록 한다.

통합 입·소화관·기관지는 0.8 mm, 관상동맥을 포함한 동맥은 0.6 mm 격자로 샘플링한다. 동맥의 작은 기시부를 더 굵게 만드는 대신 원본을 세밀하게 샘플링한다. 원본 동맥 내부의 작은 표면 틈 보정은 이전 0.8 mm 격자에서의 2칸, 즉 1.6 mm 기준을 유지하며 새 격자에 올림해 적용한다. 생성 도구의 거리 계산은 저장 가능한 거리보다 넓은 여유를 둔 구간으로 나누고, 분지 계산은 부모 구조 주변으로 제한해 전체 격자의 대형 임시 배열을 줄인다. 브라우저에서 사용하는 희소 블록·표면 단순화 방식은 유지한다.

1. 기존 압축 GLB와 원본 mesh identity를 읽고 3방향 내부 교차를 결합한다. 대장 내·외벽은 한 관을 이루는 네 교차를 구분하고 두 방향 이상이 일치한 공간을 사용해 관 사이의 외부 공간이 채워지지 않게 한다. 원본 파일은 변경하지 않는다.
2. 장기별 작은 열린 표면 틈을 보완한다. 허용한 연결부만 내부 중심 사이를 잇는다. 각 연결의 원본 표면 간격·재구성 길이·반경·좌표를 manifest에 기록한다.
3. 분지 기시부는 부모 관강에 속하도록 처리한다. 원본 딸가지가 중복 포함하는 공통 줄기는 부모 영역으로 분류하고 `sharedBranchVoxels`로 기록한다. 혈관 연결은 원본 접촉점 주변에서 찾으며, 먼 곳의 넓은 단면을 연결점으로 고르지 않는다. 분할 끝면의 작은 틈은 허용된 연결부의 양쪽에서 모두 2.4 mm 이내인 빈 공간만 보완하고 연결별 `seamRepairVoxels`를 남긴다. 그 외 서로 인접한 식도와 기관 등의 벽 접촉은 연결로 취급하지 않는다.
4. 같은 voxel mask에서 화면 표면과 보수적인 거리 필드를 생성한다. 평활화 이동을 0.18 mm, 표면 단순화 오차를 0.12 mm로 제한한다. 단순화 중 모서리가 찝히면 해당 위치의 원본 이웃 정점만 보호하고 다시 단순화한다. 그래도 닫힌 표면 조건을 만족하지 못하면 원래 표면을 유지한다.
5. 필요한 영역 하나만 로드한다. 충돌 필드는 빈 공간을 제외한 8³ 블록을 `bricks-v1` 형식으로 압축 저장한다. 브라우저는 전체 인체 격자를 만들지 않고 압축 해제한 블록을 직접 참조한다. 기존 `dense-v1` 데이터도 읽을 수 있다. WebGL은 한 표면·공유 재질, 그림자와 후처리 없이 변경 때만 그린다. 통로 폭에 맞춘 조명·깊이 안개로 구부러진 방향을 구별한다.

`python verify-journey.py`: 장기 간 허용 연결, 최소 탐험 크기에서 모든 목적지 연결, 닫힌 표면, 소장 양 끝 사이에 비정상적인 지름길이 없는지 검사.

`node verify-journey.mjs`: 실제 거리 필드와 화면 벽 간 여유, 전후 왕복, 분기 이동, 벽을 따라 미끄러짐, 큰 프레임 이동의 관통 방지, 각 목적지까지 실제 격자 경로의 왕복 통과 검사. 혀·후두개의 장애물 처리, 정합 보고서, 입구 표지의 앞뒤 관계와 벽 너머 표지 차단도 검사한다.

검사의 의미는 **구현된 모델의 연결·충돌 정합성**이다. 의학적 내강 모양이나 개인의 해부학을 임상 검증했다는 뜻이 아니다. 큰 탐험 크기는 좁은 구간을 통과하지 못할 수 있다. 그 자리에서 크기를 늘릴 공간이 없으면 위치를 강제로 옮기지 않고 거절한다.

## 입력·수명 주기

- W/A/S/D 이동, Q/E 수직 이동, Shift 가속. PC는 화면을 한 번 클릭하면 버튼을 누르지 않은 마우스 움직임으로 시선을 조작한다. Esc는 먼저 시선 조작만 해제한다. 방향키도 사용할 수 있다. Pointer Lock을 지원하지 않거나 거부하면 캔버스 안의 마우스 이동으로 동작하며, 터치·펜은 드래그 방식을 유지한다.
- 이동은 모두 카메라 기준이다. W/S는 시선 방향 전진·후진, A/D는 화면 좌우, Q/E는 화면 아래·위다. 모바일 조이스틱과 ↑↓도 같은 기준을 사용한다. 인체의 S/I/A/P/L/R 방향은 별도의 작은 시선 표시로 안내한다.
- 크기 1×/½×/¼×에서 이동 속도는 몸 크기에 비례하고 수직 시야각은 76°/86°/96°로 변한다. 약 0.45초 동안 시야만 보간하고 위치·회전·해부모형 좌표는 유지한다. 동작 줄이기 설정에서는 즉시 적용한다. 근거리 절단면도 크기에 맞춰 줄이며, 좁은 곳에서 크기를 늘리는 동작은 충돌 공간이 허용할 때만 적용한다. 공간 배율은 탐험자 몸 크기에 대한 상대값이며 해부학 모델의 실제 크기를 바꾸지 않는다.
- 카메라 반경을 고려하는 세분화된 swept sphere와 벽 접선 이동. 레일 이동이나 충돌 시 텔레포트는 없다.
- 경사·곡면 접촉에서는 실제 거리 보간식의 국소 기울기로 남은 이동을 벽 접선에 투영한다. 작은 곡면 보정도 이동 거리 안으로 제한하고 경로 전체의 여유를 검사한다. 구조물·카메라 크기를 바꾸지 않으며, 이동이 계속되는 접촉과 실제 정지를 구분한다. 정지가 0.18초 지속될 때만 안내하고 입력을 놓으면 지운다.
- 마우스·터치 시선 감도는 0.0048 rad/px, 방향키는 약 91°/초다. 충돌 보정은 위치에만 적용하고 시선을 돌리지 않는다.
- 포커스 상실·탭 숨김에서 입력을 비운다. 도움말을 펼치면 움직임을 멈춘다. 크기 변경·위치 지도 토글은 시점을 바꾸지 않는다.
- 가까운 인두·식도/후두 입구·좌우주기관지 및 혀·후두개에 영어 표지를 표시한다. 실제 시야와 거리 필드의 시선 검사를 통과한 표지만 보이고, 안내에서 끌 수 있다. 표지는 클릭·자동 이동을 일으키지 않는다. 사용자가 인두를 시작 위치로 직접 고른 경우에만 두 입구의 중간으로 초기 시선을 잡는다.
- 위치도는 원본 뼈·주요 장기의 앞/옆 투영을 현재 탐험과 같은 좌표로 겹친다. 두 PNG만 로드하며 3D 모델을 추가 로드하지 않는다. 데스크톱에서는 기본으로 열고 모바일은 기존 위치 버튼에서 연다. 확대 버튼은 현재 영역으로 전환하며, 짧은 이동 흔적과 시선 방향을 표시한다. 명시적 시작 위치 변경 때 흔적을 초기화하고 시점이 같으면 다시 그리지 않는다.
- 영역 교체 중에는 현재 화면·시점을 유지하고 입력을 멈춘다. 다음 데이터가 준비되면 교체하고 이전 geometry/material/listener를 해제한다. 로드 실패 시 현재 영역을 계속 사용할 수 있다. 닫힌 뒤 늦게 도착한 데이터도 해제한다. 구간 경계의 조명·안개는 약 0.2초 응답으로 보간하며 안정되면 추가 렌더링을 멈춘다.
- 두 영역의 6개 `journey-*` 파일과 앞/옆 위치도 두 장을 기존 전체 모델 저장 목록에 포함한다. 별도 원본 FBX와 중간 기관지 GLB는 브라우저에서 받지 않는다.
- 끝지점 안내는 모델 범위에서만 표시한다. 최근 이동 경로를 기준으로 돌아갈 방향을 알려 주며 자동 시선 회전·텔레포트를 일으키지 않는다. 좁은 혈관을 시작 위치로 직접 고르면 그 위치에 맞는 탐험 크기를 적용한다.

## 구조 설명과 국소 병태

상단의 현재 구조 이름을 누르면 설명·연결 구조·관련 문서 검색·출처가 펼쳐진다. 100개 구간 전체에 설명을 제공한다. 부위 이동 목록은 계통·부위 및 폐엽으로 묶으며 한글·영문 이름으로 검색한다. 연결 구조를 누르면 해당 연결 위치를 시야에 표시하며 카메라를 회전하거나 이동시키지 않는다. 동맥의 기시·분지, 정맥의 유입·유출, 기관지의 상위 구조·분지를 구분한다. 사용자가 시작 위치를 명시적으로 바꿀 때는 동맥·기관지는 하위 가지, 정맥은 유출 방향을 초기 시선 기준으로 삼는다.

병태 예시는 진단용 모델이나 측정된 병변이 아니다. 기존 장기 표면을 재사용하고, 해당 구간에서 현재 볼 수 있는 벽에 작은 교육용 형상을 놓는다. 크기 슬라이더는 임상 중증도·협착률이 아니다. 해부학적 발생 빈도나 환자별 병변 위치를 주장하지 않는다.

- 동맥 플라크, 정맥 혈전, 대장 용종, 기관지 점액 축적: 저해상도 타원체 조합으로 국소 돌출을 표시한다. 같은 타원체의 보수적 거리 함수를 카메라 충돌에 적용한다. 현재 카메라를 덮는 크기 변경은 거부하며 시점을 강제로 옮기지 않는다.
- 위·십이지장 궤양: 기존 벽 위의 국소 색·음영 표시이다. 실제 벽 결손 깊이, 천공 또는 새로운 통로를 만들지 않는다.
- 정상으로 전환하면 표시와 병변 충돌을 함께 해제한다. 명시적으로 시작 위치를 바꾸거나 영역을 바꿀 때도 예시를 해제한다. 시선만 돌리거나 걷는 동안에는 같은 위치에 유지한다.
- 병태는 선택 때만 갱신하며 별도 상시 애니메이션·텍스처 다운로드를 추가하지 않는다. 변경이 없을 때 WebGL을 다시 그리지 않는다.
- 새 기관지 가지에도 점액 축적, 관상동맥에는 플라크, 상체 정맥에는 혈전 예시를 적용한다. 예시는 같은 표면을 재사용하며 실제 진단이나 협착률을 뜻하지 않는다.

심장에는 장관·혈관의 숫자 ID에 의존한 병태 예시를 적용하지 않는다. 현재 심장 내부 병변·완성된 판막 운동·관상 미세순환은 제공하지 않는다.

`node verify-journey-clinical.mjs`: 전체 구간의 설명·묶음 목록·연결 대상, 실제 모델 위의 병변 배치, 시점 유지, 큰 이동의 병변 관통 방지, 카메라를 덮는 변경 거부, 정상 상태 복원을 검사한다.

## v0.13.148 분기 이동·입구 안내·심장 공간감

- 두 벽이 만나는 좁은 모서리에서 한 면 보정으로 진행하지 못하면 두 면의 공통 접선으로 남은 이동을 계산한다. 각 후보는 같은 충돌 필드에서 경로 전체를 확인한다. 60°·90°·120°·150°의 두 접촉면에서 왕복 진행을 확인했고 기존 실제 혈관 벽 재현 사례도 유지한다. 위치만 보정하며 시선·반경·해부 좌표를 바꾸거나 분지를 자동 선택하지 않는다.
- 입구 이름은 현재 구조에 연결된 항목 중 가까운 3개(좁은 화면) 또는 4개를 우선한다. 위치도·조작부·다른 라벨을 피해서 배치한다. 시야 가장자리 밖의 입구는 실제 관강 안에서 가리지 않고 보이는 경우에만 방향 화살표로 표시한다. 선택한 입구가 뒤쪽에 있어도 카메라는 유지하며, 벽 뒤에 있으면 표식을 표시하지 않는다. 소화관·중심 기도의 돌아가는 입구도 표시한다.
- 네 판막 통과부는 검토된 원본 좌표에 표시하며, 통과부 이름과 반대편 심방·심실 또는 혈관을 함께 보여 준다. 유입·유출 표기는 `flowConnections`를 사용하여 폐동맥·폐정맥도 정확한 방향으로 구분한다. 연결 관계와 용어는 [NHLBI 혈류 설명](https://www.nhlbi.nih.gov/health/heart/blood-flow), [University of Minnesota 심장판막 해부](https://www.vhlab.umn.edu/atlas/anatomy-tutorial/cardiac-valve-nomenclature.shtml)와 대조했다. 표시는 탐험용 열린 통과부이며 판막엽의 운동이나 실제 혈류 시뮬레이션을 추가한 것이 아니다.
- 심방·심실에서는 깊이 안개를 줄이고 조명 도달 거리를 늘린다. 한 개의 비스듬한 보조광으로 벽의 요철을 구별하며, 경계에서는 조명을 부드럽게 전환한다. 기존 상단 작은 제목에 좌·우심장 및 심방·심실을 표시한다. 새 메시·텍스처·그림자맵·후처리를 사용하지 않는다.
- 124개 심혈관 입구마다 라벨·선·점을 만들던 방식 대신 4개의 표시 묶음을 재사용한다. 현재 구간의 입구만 가림을 계산하고 정지 시 결과를 재사용한다. 모델·충돌 자산 용량은 그대로다. 로컬 WebGL에서 정상 장면 1 draw call, 소화관·기도 375,338 triangles, 정지 후 추가 draw call 없음(500 ms 관찰)을 확인했다.
- 검증: 심장·혈관 63,160단계와 소화관·기도 58,428단계 왕복 통과, 기존 표면·충돌 여유 유지. 로컬 Chromium에서 네 판막 통과부를 실제 컨트롤러로 통과하고 선택 시 시선을 유지했다. 390×844 터치 화면에서 양쪽 기관지 가장자리 표시, 터치 회전·조이스틱 이동, 조작 해제 및 가림을 확인했다. 실제 저사양 기기 전수 검증을 뜻하지 않는다.
- `verify-journey-guidance.mjs`는 62개 해부 연결, 판막 양방향 이름·혈류 관계, 모바일·가로·데스크톱 라벨 배치 및 벽 뒤 가림을 검사한다. 생성 모델을 다시 만들지 않고 기존 자료를 재사용한다.


## 부위 이동과 현재 제공 범위

상단 **부위 이동**에서 두 영역의 100개 내부 구간을 한 번에 검색한다. 기존 안내 안의 시작 위치 선택과 영역 선택을 통합했다. 전체 / 입·소화관 / 기도·기관지 / 심장 / 동맥 / 정맥으로 좁히며 원본 manifest의 한글·영문 이름과 묶음을 사용한다. 현재 위치는 목록에서 표시한다.

| 분류 | 내부 구간 | 구현 범위 |
|---|---:|---|
| 입·소화관 | 10 | 구강·인두, 식도, 위, 십이지장, 공장·회장, 맹장·상행·횡행·하행·구불결장, 원위부 대장 |
| 기도·기관지 | 26 | 후두·기관, 좌우 주기관지, 중간·엽·분절기관지와 좌하엽 기저기관지군 |
| 심장 | 4 | 우심방·우심실·좌심방·좌심실, 네 판막의 열린 통과부 |
| 동맥 | 35 | 폐동맥줄기·좌우 폐동맥, 대동맥, 관상·머리·상지·복강·장간막·신장·골반의 제공 분지 |
| 정맥 | 25 | 네 폐정맥, 상·하대정맥, 관상정맥동, 팔머리·내경·쇄골하·액와·신장·장골정맥 및 간정맥 합류부 |

이 표는 **1인칭 내부 공간**의 제공 범위다. Atlas에 있는 다른 장기의 외형 모델까지 내부 탐험이 구현되었다는 뜻은 아니다. 간·신장으로 검색되는 동정맥은 해당 혈관 내부이며 간 실질·담관·네프론·요관 내부는 아니다. 세기관지·폐포·미세혈관망, 심장의 생리적 판막 운동과 완전한 폐쇄 순환은 아직 제공하지 않는다. 원본이 묶은 장관·기관지 구간은 세부 경계를 임의로 나누지 않는다.

- 선택한 부위의 기존 검토 지점을 실제 충돌 필드로 검사한 뒤 위치를 바꾼다. 해당 구간 ID와 여유를 함께 확인하며 좁은 곳에서는 허용된 작은 탐험 크기로 줄인다. 관을 넓히거나 벽을 뚫지 않는다.
- 부위 이동은 명시적인 위치 전환이다. 소화관과 혈관, 서로 분리된 좌·우 심장 경로 사이를 직선으로 비행하거나 새 관강으로 이어 붙이지 않는다. 일반 구조 표지 클릭·검색·필터 변경은 시선을 돌리지 않는다.
- **이전 위치**는 이동 전의 정확한 위치·시선·크기·위치도 방향을 복원한다. 병태 예시는 위치 이동 때 해제한다. 영역 다운로드 실패 시 기존 모델과 위치를 유지하고 선택한 목적지로 다시 시도할 수 있다.
- 메뉴를 열 때는 두 manifest만 읽고(합계 118,835 bytes, 현재 영역 목록 재사용) 표면·충돌 파일을 미리 받지 않는다. 같은 영역 안에서는 모델 재다운로드가 없다. 다른 영역은 선택 시 로드하고 교체 후 이전 GPU 자원을 해제한다. 원본·표면·충돌 자산은 변경하지 않았다.
- `node verify-journey-destinations.mjs`: 100구간 × 3크기의 실제 필드 착지, 좁은 구간 축소, 양 언어 검색, 정확한 위치 복원, 잘못된 위치·다른 표본 복원 거부를 검사한다.
- 배포 전 확인: 로컬 Chrome에서 위·좌심실 직접 이동, 같은 영역과 다른 영역의 이전 위치 복원, 다운로드 실패 후 기존 시점 유지와 목적지 재시도, 터치 선택을 확인했다. 390×844·844×390·1365×900에서 조작부와 목록이 화면 안에 들어오며 목록만 스크롤한다. 메뉴 열기로 표면·충돌 파일을 추가 요청하지 않았고, 이동 후 안정된 화면에서 300 ms 동안 추가 WebGL draw call은 0이었다. Atlas 프로덕션 빌드와 이동·입구 안내 검사를 통과했다.


## v0.13.153 경로 안내·미세순환 전환·전체 화면

- **부위 이동 → 경로 안내**는 현재 구간에서 다음 입구를 표시한다. 다른 가지로 이동하면 기존 연결 그래프에서 다시 안내하며, 시점·위치·크기를 자동으로 바꾸지 않는다. 도착 상태는 새 목적지를 고를 때까지 유지한다. 알려지지 않은 경계 ID를 잠깐 지날 때도 안내를 잃지 않는다.
- 물리적으로 연결된 관강 안에서는 기존 입구·판막 통과부를 재사용한다. 벽에 가린 입구는 벽 너머로 표시하지 않는다. 일반 구조 표시를 꺼도 선택한 경로의 다음 입구는 유지한다. 안내를 취소하면 경로 표시를 해제한다.
- 서로 분리된 좌·우 혈류 공간 사이에는 **명시적인 미세순환 생략 전환**을 안내할 수 있다. 실제 관강 연결과 별도 데이터로 관리하며 충돌/표면/생성 manifest를 수정하지 않는다. 유도 경로는 동맥→생략 구간→정맥 순서를 사용한다. 정맥 쪽의 역방향 전환은 사용자가 직접 고르는 탐험 기능이며 생리적인 역혈류를 의미하지 않는다.

| 전환 영역 | 동맥 쪽 | 정맥 쪽 | 대응 경로 |
|---|---|---|---:|
| 좌우 폐 | 좌우 폐동맥 | 같은 쪽 상·하폐정맥 | 4 |
| 좌우 신장 | 신동맥 전·후분지 | 같은 쪽 신정맥 | 4 |
| 좌우 골반·하지 | 내·외장골동맥 | 같은 쪽 내·외장골정맥 | 4 |
| 좌우 상지 | 쇄골하동맥 | 같은 쪽 액와정맥 | 2 |

전환은 해당 혈관의 기존 탐험 끝 근처에서만 실행한다. 생략 범위는 모세혈관뿐 아니라 아직 모델이 없는 말초 동맥·정맥 분지를 포함한다. 이는 영역 단위의 연결 관계다. 폐동맥 주간을 특정 폐엽/분절의 실제 말단과 동일시하거나, 전·후 신동맥의 영역별 미세혈관망을 새로 표현한 것은 아니다. 신장에서는 사구체와 세뇨관 주위/직혈관 모세혈관계를 함께 생략한다. 골반·상지는 해당 정맥으로 돌아오는 대표 경로이며 모든 측부 정맥 배출을 재현하지 않는다. 장간막·비장·위 영역은 필요한 문맥계 모델이 없으므로 대정맥으로 바로 보내는 전환을 제공하지 않는다. 관상동맥·머리 혈관 등 대응 미세순환을 정하지 않은 곳은 기존 범위 끝 안내를 유지한다.

전환 순간 짧게 생략 구간을 표시하고 수신 혈관의 기존 충돌 필드 안에 착지한다. v0.14.0부터 선택한 크기·인체 기준 시선·위치도 방향을 유지하며, 같은 크기의 안전한 착지와 안쪽 이동 여유가 없으면 현재 위치를 보존하고 직접 크기를 줄이도록 안내한다. 중간 빈 공간을 비행하지 않는다. 경로 안내는 수신 혈관부터 계속되고 **이전 위치**로 전환 전 시점·크기를 복원할 수 있다. 전환/착지에 새 3D 자산이나 다운로드는 없다. 병태 예시는 다른 명시적 위치 이동과 동일하게 해제한다.

해부 대응 참고: [NHLBI 혈류](https://www.nhlbi.nih.gov/health/heart/blood-flow), [폐정맥](https://www.ncbi.nlm.nih.gov/books/NBK545205/), [신장 혈관](https://www.ncbi.nlm.nih.gov/books/NBK482385/), [골반 정맥](https://www.ncbi.nlm.nih.gov/books/NBK554574/), [상지 동정맥](https://www.ncbi.nlm.nih.gov/books/NBK507841/), [소화기 문맥 순환](https://www.ncbi.nlm.nih.gov/books/NBK53099/).

- 탐험 캔버스는 화면 전체를 채우고 이름·복귀·부위 이동·크기 조절을 위에 띄운다. Atlas 호스트는 같은 출처의 자기 iframe에서 받은 진입/종료 메시지만 받아 바깥 헤더와 Flow를 숨기고 복귀 시 복원한다. 브라우저 전체 화면 권한을 요청하지 않는다. 이름 길이와 화면 크기에 맞춰 조작부 높이를 측정하고 입구 이름·위치도·경계 안내가 피하도록 한다.
- 계산은 구간 변경/메뉴 선택 때만 경로를 갱신한다. 기존 표시 묶음을 재사용하며, 새 메시·텍스처·후처리를 추가하지 않았다. 로컬 통합 화면에서 정지 상태 400 ms 동안 추가 WebGL draw call 0, 안내/전환으로 추가 모델 다운로드 0을 확인했다.
- 검증: 기존 물리 연결 3,416쌍과 분리 1,976쌍, 양방향 입구 194개; 14개 전환 × 양방향 × 3크기 = 84개 실제 충돌 필드 착지; 문맥 생략 오연결 거부 및 생리적 순환 방향 검사. 로컬 Chrome에서 폐동맥→폐정맥, 역방향 전환, 경로 연속 갱신·취소, 이전 위치 복귀를 확인했다. 390×844·844×390·1365×900에서 캔버스가 전체 높이를 사용하고 조작부가 화면 안에 표시된다. 웹앱 통합 상태에서 진입 시 외부 헤더 제거와 복귀 시 복원, Atlas 프로덕션 빌드 및 변경된 호스트 컴포넌트 lint를 확인했다.
- 재현 명령: `node verify-journey-routes.mjs`, `node verify-journey-transfers.mjs`. GitHub 배포 전 검증 단계에도 포함한다.


## v0.13.154 심방 벽의 가짜 틈 수정

우심방을 안에서 볼 때 길게 찢어진 격자와 입구 옆의 작은 창처럼 보이던 부분은 원본 심방의 근육 구조가 아니었다. 분리되어야 하는 혈액 공간을 하나의 이진 마스크로 평활화하면서 얇은 경계가 연결되었다. 원래 충돌 필드는 분리되어 있었지만 렌더 표면의 주된 연결 성분은 하나로 합쳐져 있었다. 같은 우심장 계통 안에서도 우심방 옆 우폐동맥과의 얇은 벽이 사라지는 경우를 재현했다.

- 혈류 공간별로 표면을 생성하고, 같은 계통 안에서도 벽으로 분류된 격자점은 표면 보간에서 외부로 유지한다. 작은 양의 여유만 두는 방식은 대각선 셀에서 창을 남기므로 벽의 스칼라 값을 0으로 보존한다. 혈관과 심방의 색도 각 혈류 공간의 소속 안에서만 결정한다.
- 기존 원본 GLB, 해부 좌표, 분지·입구 연결, 내비게이션 충돌 필드를 바꾸지 않았다. `node build-journey.mjs circulation --surface-only`는 원본 해시를 확인한 후 기존 희소 필드로 표면만 다시 만든다. 전체 생성 경로도 같은 `journey_mesh.py`를 사용한다. 소화관·기도의 표면 생성 방식은 기존대로 유지한다.
- 366,050 → 366,706 triangles (+0.18%). 압축 표면은 5,727,876 → 5,620,128 bytes (107,748 bytes 감소). 런타임 충돌 필드 메모리는 14,342,012 bytes로 동일하다. 모델 해시를 갱신하여 로컬 저장본도 수정된 표면을 받는다.
- 회귀 검사 `verify-journey-cardiac-walls.mjs`: 좌·우 렌더 공간 분리, 원본 우심방 벽과 대조한 고정 시선 4개, 우폐동맥 앞 얇은 벽의 시선 418개를 확인한다. 고정 시선에서 원본보다 0.916–2.212 mm 안쪽인 보수적 재구성 벽을 확인했다. 이는 원본 표면과의 국소 대조이며 임상 측정 정확도 인증이 아니다.
- 64구조·62연결·네 판막 통과부의 실제 충돌 이동 63,160단계, 표면과 충돌 필드 4,233지점(최소 여유 0.154 mm), 100구간 설명과 병태 예시 11개 검사를 통과했다. 로컬 Chrome에서 신고 위치를 재현하고 원본 심방 표면과 같은 시점으로 비교한 뒤 격자 틈 및 작은 창의 제거를 확인했다. 실제 혈관 입구는 유지했다.

## v0.14.0 연결부 점검·접촉 이동·전환 시점 유지

- 네 심장 방과 네 판막 양쪽의 12지점에서 구면 방향 3,072개를 검사했다. 실제 입구를 통과하는 시선은 허용하고, 충돌 마스크에 연속된 벽이 있는 곳은 렌더 표면이 가리도록 검증한다. 기존 우심방 원본 대조와 얇은 벽 검사도 유지한다. 추가 벽 누락은 발견되지 않아 원본·파생 모델·연결 좌표를 변경하지 않았다. 이는 재구성 표면의 오류 검사이며 임상 측정 정확도 인증이 아니다.
- 대동맥판 통과부의 경사진 격자 접점에서 진행률 1.25%의 멈춤을 재현했다. 진행이 거의 막힐 때만 기존 이동 예산 안에서 최대 0.1 voxel의 내강 쪽 여유를 주고, 후보 경로 전체를 같은 충돌 필드로 검사한다. 같은 입력의 진행률은 97.36%이며 원래 벽·몸 크기·시선은 유지한다. 실제로 좁거나 막힌 곳을 뚫고 지나가게 하지 않는다.
- 반복 충돌 표본에서 좌표·가중치 배열 생성을 제거하고 표본 배열 하나를 재사용한다. 막힌 벽에 이동 키를 계속 눌러도 카메라가 그대로면 추가 WebGL 렌더를 요청하지 않는다. 새 물리 엔진·메시·텍스처·상시 효과는 없다. 심혈관 표면 366,706 triangles, 충돌 메모리 14,342,012 bytes와 모든 모델 파일은 동일하다.
- 14개 미세순환 생략 전환은 시선·크기·위치도 방향을 보존한다. 끝·복귀 지점·기존 시작점 범위에서 착지를 찾고, 안쪽으로 몸 반경 두 배의 이동을 요청했을 때 75% 이상 진행할 수 있는지 확인한다. 자동 축소나 자동 시선 회전을 하지 않는다. 84개 방향·크기 조건 중 79개는 같은 크기로 착지하고, 좁은 1× 조건 5개는 현재 시점을 유지한 채 거부한다. 모든 14개 경로의 양방향 이동은 ¼×에서 가능하다.
- 전환 거부·성공 안내는 끝지점 안내 카드의 기존 설명 자리에 표시한다. 매 프레임 사라지거나 다른 안내에 겹치지 않는다. 도착 직후에는 `안쪽 통로`의 화면 기준 방향을 알려 주고, 실제 이동 기록이 생기면 `지나온 통로`로 바뀐다. 이전 위치 복귀는 정확한 위치·시선·크기를 복원한다.
- 배포 전 확인: 심혈관 63,160단계와 입·소화관·기도 58,428단계 왕복, 표면/충돌 여유, 기존 병태 11사례, 세 크기 조작·충돌·얇은 벽 보호 검사를 통과했다. 로컬 Chrome에서 네 판막 양방향 통과, 전환 시 시선/크기 보존, 좁은 착지 거부 후 수동 축소, 정확한 복귀를 확인했다. 데스크톱 1280×900과 터치 390×844에서 전체 화면 탐험과 전환을 확인했고 정지 상태 추가 렌더는 0회, 정상 장면은 1 draw call이었다. 실제 저사양 단말기 전수 검증을 뜻하지 않는다.
