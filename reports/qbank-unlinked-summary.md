# MedQA 미연결 질환 태그 요약

집계 기준: 질환 문서 슬러그가 없는 MedQA 문항. 증상·검사·약물명만 있는 태그는 별도 질환 미연결 집계에서 제외한다.

## 현재 상태

- 미연결 문항: 24개
- 정규화된 태그: 8개
- 모든 태그는 1~2문항에서만 등장한다.

## 남은 태그

| 태그 | 문항 수 | 처리 방향 |
| --- | ---: | --- |
| 칸나비스 구토 증후군 | 2 | 향후 소화기/중독 감별 문서 보강 시 연결 |
| 47,XYY 증후군 | 1 | 소아 유전질환 대표 문서의 희귀 하위 질환 |
| Conn syndrome | 1 | 원발성 알도스테론증 동의어 검토 대상 |
| burn infection | 1 | 화상/상처 감염의 상황 태그 |
| coronary artery disease evaluation | 1 | 관상동맥질환 검사·평가 태그 |
| pinworm infection | 1 | 기생충 감염의 하위 질환 |
| post-traumatic infection | 1 | 외상 후 감염의 상황 태그 |
| 임신 중 피부질환 | 1 | 산과와 피부과를 가로지르는 상황 태그 |

이 목록은 독립 질환 문서를 무한히 늘리는 대신, 반복 출현하거나 개별 학습 가치가 확인될 때만 정본 문서로 승격하기 위한 보류 목록이다.
