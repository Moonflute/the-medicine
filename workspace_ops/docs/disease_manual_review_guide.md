# 질병 문서 교재 대조 기준

[질병 문서 가독성 정리 기준](disease_readability_guide.md)을 적용한다.

## 검토 순서

- *SNUH Manual of Medicine* 6판(2022)을 인쇄 쪽수 기준으로 처음부터 읽는다. 본문과 표, 흐름도의 분기 조건을 함께 확인한다.
- 주제와 직접 대응하는 `source_notes/02 Diseases` 원본을 찾아 문서 끝까지 읽는다. 주증상이나 술기가 독립 주제면 직접 대응하는 원본도 확인한다.
- 책에서 보완할 지점이 확인되면 기존 목차 안에 넣는다. 충분한 문서와 대응 원본이 없는 주제도 검토 기록에 표시한다.
- 부·장, 인쇄 쪽수, 검토 문서, 수정 여부, 주요 변경, 다음 검토 위치를 남긴다. 같은 문서를 여러 장에서 확인한 경우 전체 문서 수는 중복 없이 집계한다.

## 본문 보완

- 개요는 기존 형식에 맞춰 **정의**, **원인**, **기전**을 구분한다. 임상 양상에는 **증상**, **진찰**을 사용한다.
- 검사에는 검사 선택, 시점, 해석을 적는다. 진단은 확인 가능한 핵심 기준을 먼저 쓰고 감별·분류·병기를 뒤에 둔다. 비교가 중심인 분류에는 필요에 따라 표를 쓴다.
- 치료에는 환자 상태와 적응증에 따른 약제·수액·시술 선택을 먼저 제시한다. 약제는 한글과 영문 일반명을 병기한다. 확인된 용량·기간·재평가·중단 기준, 주요 금기와 예외를 해당 항목에 묶는다.
- 위험인자, 병력·진찰 단서, 검사 함정, 예방·추적, 합병증 등 다른 섹션에도 빠진 내용을 검토한다.
- 책의 내용을 문서에 맞게 요약한다. 진단 기준·처방·시술 등 실제 판단에 영향을 주는 내용은 최신 공식 지침이나 허가사항을 확인해 적용 대상과 수치를 구분한다. 출처는 문서 맨 아래에 책의 쪽수·표·그림 번호와 함께 기록한다.
- 술기 원본의 출처는 기존 `sources` 목록에 넣는다. 앱에서 본문 뒤에 표시한다.

## 흐름도

- 앞 단계의 결과에 따라 다음 검사나 처치가 달라질 때 흐름도를 쓴다. 분기 조건은 그 결과로 이어지는 상자에 적는다.
- 질병 라이브러리에서는 `flowchart` 코드 블록을 텍스트와 화살표가 있는 HTML로 표시한다. 첫 줄은 제목, 그 뒤는 `>` 하나로 시작하는 시작 상자 한 개와 `>` 개수로 단계가 깊어지는 하위 상자다. 이웃 분기는 같은 깊이로 쓴다.

````markdown
```flowchart
검사 선택
> 첫 검사와 중증도 확인
>> 소견 A → 검사 A
>> 소견 B → 검사 B
>>> 결과 양성 → 상태별 처치
>>> 결과 음성 → 감별 재평가
```
````

- 바탕색과 글자색은 본문 테마를 따른다. 상자 텍스트는 짧게 쓰고, 상세 근거와 용량은 해당 본문에 둔다.
