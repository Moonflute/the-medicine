# 질병 문서 가독성 정리 기준

2026-11-18 사용자와 본문 전후 예시를 비교해 합의한 편집 기준이다.

## 편집 범위

- 원본인 `source_notes/02 Diseases`의 각 문서를 처음부터 끝까지 읽고 판단한다. 문서 수와 실제 수정 수를 구분해 기록한다.
- 기존 정의·증상·검사·진단·치료·예후 등 상위 섹션, 분류 정보, 문서 연결은 유지한다. 목차와 템플릿에 본문 편집을 일괄 적용하지 않는다.
- 수치, 단위, 비교 연산자, AND/OR 관계, 대상 환자, 금기, 예외, 조건부 권고와 추적 시점을 보존한다. 문체 정리로 의학적 주장을 추가하거나 강화하지 않는다.
- 지침·의학적 내용 갱신이 필요하면 서식 변경과 구분하고 원문 근거를 확인한다. 기존 출처는 보존하되 긴 URL을 본문 중간에 새로 삽입하지 않는다.

## 문장과 불릿

- `**항목명**: 핵심 내용`을 기본으로 하되, 이미 짧고 읽기 좋은 문장은 유지한다.
- 한 항목의 적응증·조건·소견·선택지·예외는 하위 불릿으로 묶는다. 서로 독립적인 내용은 같은 수준에 둔다.
- 단순히 불릿을 긴 문단으로 합치거나 모든 문장을 한 줄씩 쪼개지 않는다. 일괄 번호 매기기, 한 줄짜리 소제목 남발, 동일한 틀 강제 적용을 피한다.
- 조건이 여러 개이면 `모두 충족`과 `다음 중 하나`를 명확히 구분한다. 설명·주의 문구를 조건 목록의 또 다른 선택지처럼 배치하지 않는다.
- 일반적으로 하위 불릿 한 단계면 충분하다. 실제 판단 순서가 필요할 때만 더 깊게 구성한다.
- 용량·빈도·대상 조건처럼 함께 읽어야 하는 정보는 가까이 둔다. 짧은 설명을 위해 불필요하게 항목을 늘리지 않는다.
- 비교가 핵심인 병기·분류·치료 조건은 표를 사용하되 기존 표를 불필요하게 바꾸지 않는다. 병기·분류 기준은 기존 진단 섹션에 둔다.
- 항목명과 핵심 기준을 선택적으로 강조한다. `**항목명**: 내용`처럼 강조 기호를 완결하고, 문장 전체를 과도하게 굵게 만들지 않는다.

## 합의된 예시

급성 췌장염의 검사:

- **혈액 검사**: 아밀라아제·리파아제가 정상 상한치의 3배 이상 상승 (리파아제가 더 특이적)
- **영상 검사**: 조영증강 CT 또는 MRI
  - **적응증**: 진단이 불명확하거나 48–72시간 내 임상 호전 없음
  - **소견**: 췌장 부종, 췌장 주위 액체 저류, 췌장 괴사
  - 초기 경증이면서 전형적 증상·효소 상승으로 진단이 명확하면 필수적이지 않음

위궤양의 제균 성공 확인:

- **제균 성공 확인**: 다음 두 조건을 **모두 충족한 시점**에 적절한 검사 시행
  - 항생제 종료 후 최소 4주
  - PPI/P-CAB 중단 후 최소 2주

이 예시는 편집 형태를 보여주는 것이며, 모든 질환을 같은 형식으로 바꾸라는 뜻은 아니다.

## 검토와 게시

- 문서별 검토 기록에 수정 여부와 실제 변경 지점을 남긴다. 전수 작업에서는 100개 검토마다 검토 수·수정 수를 별도로 보고한다.
- 편집 전 원본과 비교하여 내용 누락, 수치·조건 변화, 강조 기호와 표 손상, 다른 섹션으로의 잘못된 이동을 확인한다.
- 원본의 하위 불릿이 웹 데이터 변환과 화면 출력에서도 유지되는지 배포 전에 확인한다.
- 이미 존재하던 미커밋 변경은 별도로 보존한다. 배포·원격 동기화·임시 산출물 정리는 루트 `AGENTS.md`를 따른다.
