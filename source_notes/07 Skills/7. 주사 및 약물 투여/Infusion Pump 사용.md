# Infusion Pump 사용

> [!summary]
> infusion pump 사고는 약물 농도, dose 단위, rate와 VTBI 입력을 혼동하거나 다른 환자·line에 연결할 때 발생합니다.
> 처방에서 환자까지 line을 손으로 끝까지 추적하고 약물·농도·단위·속도·VTBI를 독립 이중 확인한 뒤, 시작 직후 실제 점적과 환자 반응을 확인합니다.

## Indications
- 정확한 속도의 지속 수액, 고위험 약물, 소량 또는 체중 기반 주입이 필요할 때 사용합니다.
- 승압제, insulin, heparin, 진정제, 항암제 등은 기관 smart pump drug library와 이중 확인 절차를 따릅니다.
- 단순 중력 주입보다 정확성과 알람 감시가 필요한 상황에서 적용합니다.

## Supplies
- 충전·전원 상태가 정상인 pump와 장비에 맞는 전용 infusion set를 준비합니다.
- 환자 라벨이 붙은 약물 bag·syringe, 처방과 표준 농도 정보를 준비합니다.
- 연결·고정용 extension, needleless connector와 line label을 준비합니다.
- 고위험 약물에는 독립 이중 확인자와 필요한 모니터링·구조 약물을 준비합니다.

## Precautions
- mL/h, mg/h, mcg/kg/min, units/h 등 dose 단위를 끝까지 확인하고 계산값과 pump 표시 단위를 맞춥니다.
- drug library의 hard limit를 우회하거나 임의 basic mode로 전환하지 않습니다.
- door를 열기 전 clamp해 free flow를 방지하고 set가 pump channel에 정확히 장착됐는지 확인합니다.
- 여러 line이 있으면 bag에서 환자까지 손으로 trace하며 stopcock·lumen·호환성을 확인합니다.
- occlusion alarm을 단순 재시작하지 말고 clamp, kink, closed stopcock, infiltration과 고압 축적을 확인합니다.

## Complications
- 과량·급속 주입 — 즉시 pump를 정지하고 line을 clamp한 뒤 환자와 약물을 확인해 상급자에게 보고합니다.
- 주입 중단 — battery, bag 잔량, occlusion, line 이탈을 확인하고 고위험 약물 중단 시간을 즉시 보고합니다.
- infiltration·extravasation — 부종·통증·누출이 있으면 주입을 중단하고 약물별 처치를 시행합니다.
- air-in-line — 환자 쪽을 clamp하고 공기를 제거한 뒤 원인을 교정하며 알람을 무시하지 않습니다.
- 잘못된 line 연결 — 해당 투여를 중단하고 환자 위해를 평가해 약물오류 보고 절차를 따릅니다.

## Steps

### 1. 처방과 약물 이중 확인
환자, 약물, 농도, 총량, 경로, dose 단위, 속도와 VTBI를 처방·라벨에서 대조합니다. 고위험 약물은 독립적으로 계산·확인합니다.

### 2. Set priming
무균적으로 set를 연결하고 환자에게 연결하기 전 약물로 tubing을 완전히 prime해 공기를 제거합니다. 약물 bolus가 문제가 되는 경우 기존 line 교체 방법을 기관 지침에서 확인합니다.

### 3. Pump 장착과 library 선택
Set를 pump 방향에 맞게 장착하고 door·clamp를 확인합니다. 정확한 care area, 약물명, 표준 농도와 dosing unit을 drug library에서 선택합니다.

Warning: pump에 표시된 농도와 실제 bag 라벨이 다르면 속도가 맞아 보여도 치명적 용량 오류가 되므로 시작하지 않습니다.

### 4. Rate·VTBI 입력과 line trace
처방된 rate와 VTBI를 입력하고 예상 완료 시간을 확인합니다. Bag에서 pump, stopcock, 환자 lumen까지 손으로 trace해 올바른 정맥로에 연결합니다.

### 5. 시작 직후 확인
주입을 시작하고 pump가 실제 작동하는지, drip chamber·syringe plunger가 움직이는지, line과 삽입부에 누출·부종이 없는지 확인합니다. 활력징후와 약물별 반응을 재평가합니다.

### 6. 알람 대응
알람 문구를 읽고 환자부터 확인한 뒤 bag 잔량, door, battery, air, clamp, kink, stopcock, downstream occlusion을 순서대로 봅니다. 원인을 해결하지 않은 채 반복 silence·restart하지 않습니다.

### 7. 교대·변경·기록
교대와 bag 교체 때 환자·약물·농도·속도·잔량·line을 함께 확인합니다. 시작·변경·중단 시각, pump 설정, 이중 확인자, 환자 반응과 알람·오류 조치를 기록합니다.
