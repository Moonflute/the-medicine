# 항암제 투여

> [!summary]
> 항암제는 환자와 투여자 모두에게 고위험 약물입니다.
> 약물 확인, PPE, line 안정성, 유출 대응 경로를 투여 전부터 준비해야 합니다.

## Indications
- 정주 항암치료
- 세포독성 또는 고위험 항암제 투여

## Supplies
- PPE
- 항암용 세트
- 신뢰 가능한 혈관 접근
- 유출 대응 키트
- 투여 확인 문서

## Precautions
- 가능하면 안정적인 중심정맥 접근을 우선 고려합니다.
- 항암제는 일반 약물보다 line patency 확인을 더 엄격히 합니다.
- 유출 의심 시 즉시 주입을 멈추고 약제별 프로토콜을 따릅니다.

## Complications
- 혈관외유출
- 아나필락시스 또는 과민반응
- 투여자 노출
- line failure

## Steps

### 1. 투여 전 이중 삼중 확인
환자, 약명, 용량, 체표면적, 주기, 동의 여부를 확인합니다.

### 2. PPE와 line 확인
보호구를 착용하고 line 역류와 flush를 확인합니다.

### 3. 투여 중 관찰
주입 부위 통증, 부종, 발적, 환자 전신 반응을 지속 관찰합니다.

### 4. 종료 후 정리
line flush, 폐기물 처리, 이상반응 기록을 마무리합니다.
