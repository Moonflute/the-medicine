# 항암제 투여

## 개요·원리

항암제는 자격을 갖춘 교육 이수자가 기관 프로토콜에 따라 투여하는 고위험 업무이며, 인턴은 독립 투여보다 처방·환자 상태 확인, 응급 대응과 보고를 보조합니다.

투여 전 protocol·cycle·체표면적·검사·line·vesicant 여부를 독립 이중 확인하고, 통증·부종이 생기면 extravasation 가능성으로 즉시 주입을 중단합니다.

## 적응증·금기증

- 종양 protocol에 따라 경구·정주·피하·강내 항암제와 면역치료제를 투여할 때 적용합니다.
- 처방 승인, informed consent, cycle·day와 사전 검사 기준을 충족한 경우에만 진행합니다.
- 미교육 인턴은 항암제 연결·투여·폐기 또는 spill 처리를 독립 수행하지 않고 항암 전문 인력 지시를 따릅니다.

## 시행

### 준비물
- 약제부 조제·라벨링된 항암제, protocol과 환자별 treatment sheet를 준비합니다.
- 항암제용 장갑·가운·보안경 등 hazardous drug PPE와 전용 폐기용기를 준비합니다.
- 적절한 central 또는 peripheral access, compatible tubing과 closed-system device를 기관 기준에 따라 준비합니다.
- spill kit, extravasation kit·해독제와 anaphylaxis 응급약물을 가까이 둡니다.
- 활력징후·SpO2 감시와 필요한 premedication을 확인합니다.

### 주의사항
- 환자, regimen, cycle/day, 약명, dose, BSA·체중, 장기기능, route, sequence, rate와 expiry를 두 명이 독립 확인합니다.
- ANC, platelet, 신·간기능, 감염·발열, 임신 가능성과 protocol hold criterion을 확인합니다.
- vesicant·irritant 여부와 central line 필요성, blood return과 개통성을 투여 전·중 확인합니다.
- tablet을 분쇄하거나 capsule을 열지 않고 경구 항암제도 PPE와 투여·반납 절차를 따릅니다.
- 체액과 폐기물은 약제별 기간 동안 hazardous drug precautions가 필요할 수 있어 기관 지침을 적용합니다.

### 자격과 protocol 확인
본인이 독립 투여 자격이 있는지 확인하고, 인턴은 항암 전문 간호사·종양팀과 역할을 명확히 합니다. Consent, regimen, cycle/day와 약제부 승인을 확인합니다.

### 환자와 hold criterion 평가
두 가지 식별자로 환자를 확인하고 체중·BSA, 최근 CBC·신·간기능, 발열·감염, performance와 protocol hold 기준을 검토합니다.

### 약물·순서·응급 준비 이중 확인
두 명이 약명·dose·농도·route·sequence·rate·expiry와 premedication을 독립 확인합니다. Vesicant, reaction, extravasation kit와 spill kit 위치를 확인합니다.

Warning: 투여 중 통증·작열감·부종 또는 blood return 소실이 생기면 flush하지 말고 즉시 주입을 멈춘 뒤 line을 유지해 extravasation protocol을 시행합니다.

### Line 개통과 보호구 확인
PPE를 착용하고 line 종류·tip 위치, blood return, saline flush와 삽입부를 확인합니다. 약물별로 central access 필요 여부와 다른 수액 호환성을 확인합니다.

### 투여와 지속 관찰
자격 있는 투여자가 protocol 속도로 시작하고 초기 활력징후, 피부, 호흡, 오한·통증과 IV 부위를 관찰합니다. 이상반응은 즉시 중단하고 ABC와 약물별 처치를 시행합니다.

## 결과

계획한 약물·순서·속도와 실제 투여를 대조하고 투여 부위·활력·환자 반응을 확인합니다. 주입 완료만으로 지연 독성이나 혈관외유출을 배제하지 않으며 추적 계획을 설명합니다.

## 합병증·사후 관리

### 합병증
- extravasation — 통증·작열감·부종·blood return 소실 시 주입을 중단하되 line은 흡인·해독제 투여를 위해 유지하고 전문팀을 호출합니다.
- infusion reaction·anaphylaxis — 발열, 오한, 발진, 호흡곤란, 저혈압 시 즉시 중단하고 약물별 응급 알고리즘을 시행합니다.
- 골수억제·감염 — 발열과 호중구감소 가능성은 응급으로 평가하고 배양·항생제 경로를 시작합니다.
- tumor lysis syndrome — 고위험 regimen에서 전해질·요산·신기능, 소변량과 부정맥을 감시합니다.
- hazardous drug exposure — 피부·눈·spill 노출 시 즉시 세척하고 산업안전·노출 보고 절차를 따릅니다.

### 혈관외유출의 초기 대응
- Doxorubicin(Adriamycin) 등 vesicant는 혈관외유출 시 심한 조직 손상을 일으킬 수 있습니다. 약물 종류·농도·유출량과 부위를 신속히 확인합니다.
- 주입을 즉시 멈추고 도움을 요청합니다. 처음에는 도관을 남겨 잔여 약물을 흡인하며 **flush하거나 유출 부위를 강하게 누르지 않습니다**.
- 흡인 뒤 말초·중심 도관별 처치, 해독제·냉/온찜질을 약물별 프로토콜로 정합니다. 모든 항암제에 같은 찜질을 적용하지 않습니다.
- 범위를 표시·촬영하고 통증·감각·혈류·피부 변화와 지연 손상을 추적합니다. 항암제 유발 말초신경병증은 국소 유출과 다른 독성으로 [[Oxaliplatin]] 등 해당 약물에서 확인합니다.

### 종료·폐기·추적
Protocol에 따른 flush 후 line을 관리하고 모든 오염 물품을 전용 폐기합니다. 실제 투여량·시각·rate, 이중 확인자, 반응·조치, 추적 CBC·전해질과 발열 시 연락법을 기록·교육합니다.
