# 연명의료결정제도 대응

> [!summary]
> 연명의료 유보·중단은 가족의 구두 요청이나 인턴 개인 판단으로 시행하지 않고, 환자의 의사와 임종과정 판단, 법정 서식과 의료기관윤리위원회 절차가 확인된 뒤 담당 전문의 지시에 따라 이행합니다.
> 연명의료를 시행하지 않더라도 통증·호흡곤란·불안 완화, 기본 돌봄과 가족 의사소통은 계속합니다.

## Indications
- 말기 또는 임종과정 환자가 연명의료계획을 논의하거나 사전연명의료의향서 확인이 필요할 때 대응합니다.
- 환자가 의사결정 능력이 있는 경우 본인의 이해와 자발적 의사를 중심으로 공식 절차를 진행합니다.
- 환자 의사 확인이 불가능한 경우 현행 법률이 정한 가족 진술·합의 요건과 기관 절차를 담당 전문의·윤리위원회가 확인합니다.
- 단순 DNAR 메모와 법정 연명의료결정 서식의 범위가 다를 수 있으므로 기관 문서를 확인합니다.

## Supplies
- 환자 신원과 의무기록, 사전연명의료의향서 등록 조회 경로를 준비합니다.
- 연명의료계획서, 임종과정 판단서와 이행 관련 현행 법정 서식을 기관 시스템에서 확인합니다.
- 담당 전문의, 해당과 전공의, 의료기관윤리위원회 또는 연명의료지원팀 연락처를 확인합니다.
- 가족관계 확인과 의사소통 기록에 필요한 기관 양식을 준비합니다.
- 증상 완화, 산소·진통·진정과 기본 돌봄 처방을 별도로 확인합니다.

## Precautions
- `가족이 원한다`는 말만으로 CPR, ventilator, dialysis, vasopressor 등을 중단하지 않습니다.
- 환자가 의사표현 가능하면 가족보다 환자 본인의 의사를 우선 확인하고 강요·오해 가능성을 평가합니다.
- 임종과정 판단과 법정 요건 충족은 권한 있는 담당 의사들이 확인하며 인턴이 단독 결정하지 않습니다.
- 적용할 연명의료 항목과 유지할 치료·돌봄을 구체적으로 확인해 모든 치료 중단으로 확대 해석하지 않습니다.
- 교대·검사·병동 이동 전 유효 문서와 code status가 EMR·오더·인계에서 일치하는지 확인합니다.
- 응급 상황에서 문서가 불명확하면 임의로 제한하지 말고 즉시 담당 전문의와 응급대응팀에 확인합니다.

## Complications
- 비공식 결정 이행 — 법적·윤리적 문제와 환자 위해가 생길 수 있어 즉시 중단하고 공식 절차를 확인합니다.
- 문서 간 불일치 — 의향서, 계획서, code status, 처방이 다르면 담당 전문의와 지원팀에 즉시 알립니다.
- 치료 범위 오해 — DNAR를 항생제·영양·진통 등 모든 치료 거부로 확대하지 않습니다.
- 증상 조절 소홀 — 연명의료 제한 후에도 통증, 호흡곤란, 불안·분비물과 가족 지원을 적극 관리합니다.
- 가족 갈등 — 인턴이 결론을 중재하려 하지 말고 담당 전문의·윤리위원회와 구조화된 면담을 요청합니다.

## Steps

### 1. 환자 상태와 의사결정 능력 확인
현재 응급도, 임종과정 판단 여부와 환자가 정보를 이해·표현할 수 있는지 확인합니다. 즉시 증상 완화가 필요한 문제는 절차 확인과 병행해 치료합니다.

### 2. 기존 문서 조회
두 가지 식별자로 사전연명의료의향서, 연명의료계획서, DNAR, 임종과정 판단과 code status 처방을 확인합니다. 문서의 환자·작성자·유효성과 적용 범위를 봅니다.

Warning: 가족의 구두 요청이나 확인되지 않은 메모만으로 CPR 등 연명의료를 유보·중단하지 말고 즉시 담당 전문의와 공식 지원체계에 확인합니다.

### 3. 담당 팀과 공식 절차 연결
담당 전문의·전공의와 연명의료지원팀 또는 의료기관윤리위원회에 연락해 필요한 판단자, 가족 요건과 법정 서식을 확인합니다. 인턴은 자료 준비와 연락·기록을 지원합니다.

### 4. 항목별 치료계획 확인
CPR, ventilator, dialysis, 항암제, vasopressor 등 유보·중단할 항목과 계속할 산소·진통·수액·항생제·돌봄 범위를 구체적으로 처방에서 확인합니다.

### 5. 이행 전 팀 공유
간호사와 당직팀, 관련 부서에 유효한 code status와 이행 계획을 공유하고 EMR banner·오더·인계가 일치하는지 확인합니다. 불일치하면 이행 전 정정합니다.

### 6. 증상 완화와 가족 지원
통증, 호흡곤란, 불안, 섬망, 분비물과 피부·구강 돌봄을 적극 관리합니다. 가족에게 담당 팀의 일관된 설명과 연락 창구를 제공하고 갑작스러운 상태 변화를 알립니다.

### 7. 이행·기록·재확인
법정 서식, 판단·면담 참여자, 시각, 환자·가족 의사, 항목별 결정, 시행한 완화치료와 상태 변화를 기록합니다. 전동·교대 시 원문 문서와 계획을 직접 인계합니다.
