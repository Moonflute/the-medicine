# 심전도 (EKG)

> [!summary]
> 12유도 심전도는 흉통, 실신, 부정맥, 전해질 이상 평가의 기본 검사입니다.
> 붙이는 위치가 틀리면 해석이 완전히 달라질 수 있어 전극 위치 정확도가 중요합니다.

## Indications
- 흉통
- 부정맥 의심
- 실신
- 전해질 이상 또는 약물 영향 평가

## Supplies
- EKG 기계
- 전극 패드
- 면도기 또는 알코올 솜
- 환자 정보 입력 장치

## Precautions
- 전극 위치를 외우기보다 매번 landmarks를 다시 확인합니다.
- 움직임, 떨림, 전기 간섭은 artifact를 만듭니다.
- 흉통 환자에서 STEMI 소견이 보이면 지체 없이 보고합니다.

## Complications
- 피부 자극
- 유도 위치 오류로 인한 해석 오류

## Steps

### 1. 환자 준비
상체를 노출하고 피부 기름기와 땀을 닦아 전극 접촉을 좋게 만듭니다.

### 2. 전극 부착
사지 유도와 흉부 유도를 정확한 위치에 붙입니다.

### 3. 기록
환자가 움직이지 않게 하고 baseline artifact가 적은 상태에서 기록합니다.

### 4. 즉시 확인
리듬, ST 변화, 심박수, artifact 여부를 먼저 보고 이상 시 바로 전달합니다.
