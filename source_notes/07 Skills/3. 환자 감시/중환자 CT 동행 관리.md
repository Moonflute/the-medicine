# 중환자 CT 동행 관리

> [!summary]
> 중환자 이동은 ICU 수준의 기도·호흡·순환 치료와 감시를 복도와 CT실에서도 끊기지 않게 옮기는 과정입니다.
> 출발 전 검사 결과가 치료를 바꿀지와 환자가 이동을 견딜 수 있는지 확인하고, 산소 잔량·battery·약물 여유분·line·drain을 체크리스트로 점검합니다.

## Indications
- CT 결과가 응급 진단·시술·수술 결정을 바꾸며 bedside 검사로 대체할 수 없을 때 이동합니다.
- 불안정 환자는 소생·기도 안정화 후 이동하고, 이동 위험이 검사 이득보다 큰지 담당 전문의가 판단합니다.
- 필요한 인력은 airway, vasoactive infusion, 격리와 환자 중증도에 맞춥니다.

## Supplies
- 이동용 monitor, defibrillator, pulse oximeter와 충분히 충전된 battery를 준비합니다.
- 예상 이동·대기·촬영 시간에 여유분을 더한 oxygen cylinder와 ventilator·bag-valve-mask를 준비합니다.
- suction, airway kit, 응급약물과 필요한 sedation·analgesia를 준비합니다.
- 충분한 양의 infusion, pump battery, extension line과 line·drain 고정 물품을 준비합니다.
- 조영제·신기능·IV gauge, 격리 PPE와 transport checklist를 확인합니다.

## Precautions
- ETT 깊이·cuff, ventilator setting과 분비물을 이동 전 확인하고 portable ventilator 연결 후 환기 상태를 재평가합니다.
- 산소는 cylinder pressure만 보지 말고 현재 flow에서 예상 사용 시간을 계산해 reserve를 확보합니다.
- 승압제·진정제 bag이 이동 중 소진되지 않게 하고 MRI가 아닌 CT라도 장비·전원·pump 배치를 사전 확인합니다.
- chest tube, EVD, sheath와 drain의 clamp·level·suction 이동 규칙을 각 전문팀에 확인합니다.
- CT table 이동 때 line이 당겨지거나 환자 몸 아래 눌리지 않게 한 사람이 line만 전담합니다.

## Complications
- 기도 이탈·ventilator 문제 — 즉시 이동을 멈추고 100% oxygen·bagging과 airway 위치를 확인합니다.
- 저혈압·부정맥 — 촬영을 중단하고 원인, infusion·line과 pulse를 확인해 소생합니다.
- 산소 고갈·battery 방전 — 출발 전 계산과 여유 장비로 예방하고 즉시 대체합니다.
- line·drain 이탈 — 출혈·공기유입·배액 문제를 통제하고 해당 전문팀에 보고합니다.
- 검사 지연 — CT실 준비와 조영제·IV 확인을 출발 전에 완료해 불필요한 대기를 줄입니다.

## Steps

### 1. Go/no-go와 역할 확인
검사 목적·응급도·결과가 바꿀 치료를 확인하고 담당 의사가 이동 가능성을 판단합니다. 동행자 중 airway, monitor, pump·line, 이동 리더 역할을 정합니다.

### 2. ABC 안정화와 baseline
ETT·기도, ventilator setting·ABGA, 혈압·리듬·관류와 neuro status를 확인합니다. 필요한 suction, 수액·승압제 조정 후 출발 baseline을 기록합니다.

Warning: 기도·혈압이 안정되지 않았거나 산소·battery·응급장비가 준비되지 않으면 긴급성을 재논의하고 무리하게 출발하지 않습니다.

### 3. 장비·약물·line 체크
산소 예상 시간, monitor·ventilator·pump battery, 약물 잔량과 emergency kit를 확인합니다. 모든 line·tube·drain을 환자에서 장비까지 trace하고 고정합니다.

### 4. 이동 중 연속 감시
ECG, SpO2, 혈압과 ventilator alarm을 감시하고 환자의 얼굴·흉곽을 직접 봅니다. 문턱·엘리베이터·침대 이동 전 tubing 여유와 장비를 확인합니다.

### 5. CT table 이전과 촬영
CT 팀에 airway, 감염, 조영제, line·drain과 불안정 위험을 인계합니다. Table 이동 때 한 명이 airway, 한 명이 line을 관리하고 촬영 중에도 monitor를 볼 수 있게 합니다.

### 6. 복귀 후 재평가·기록
ICU 장비로 다시 연결한 뒤 ETT 깊이, ventilator, 활력징후, neuro status, 삽입부·drain과 약물 rate를 출발 전과 비교합니다. 이동 중 사건·처치와 CT 결과 전달을 기록·인계합니다.
