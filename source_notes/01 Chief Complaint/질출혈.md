# 질출혈

## Concept
‘부인과’, 거의근종?

## 감별진단
종양 : 자궁경부암, 자궁내막암 / 자궁내막증, 자궁근종, 자궁선근증
산과적 : 자궁 외 임신, 유산
내분비 : 호르몬 제제, 경구피임약, 갑상샘저하증

## Hx

### O / L / D / Co / Ex (Onset, Location, Duration, Course, Experienced)

### C (Character)
#### CC-specific
- 양, 색, 양상, 냄새, 정도
- 월경력 : 월경 중 여부, 주기, LMP, 임신 가능성
- 산과력 : 결혼 여부, 아이 수, 출산 방법
- 성관계 : 성교통, 전후 증상 악화, 파트너 수 / 피임 여부, 출혈

### A (Associated symptoms)
#### CC-specific
- General : Weight loss, Fatigue, Fever, Chill, Edema
- 출혈 경향 : 코피, 출혈 후 잘 안 멎음, 멍이 잘 듦, 생리량 증가
- 탈수 평가 : 두근거림, 호흡곤란, 어지럼, 소변량 감소
- FUND (Frequency, Urgency, Nocturia, Dysuria)-HIR (Hematuria, Incontinence, Retention) + 변비, 복부 덩이
- 추위불내성, 변비

## 환자교육
검사 : 골반초음파, biopsy
치료 : 종양 - 수술
교육 : 정기적인 검진, 위생 교육, 피임

질출혈 + 월경 과다 +월경통
= 자궁근종 / 골반초음파, 자궁난관조영술 / GnRH agonist, 절제술

성교 후 질출혈 + 체중 감소
= 자궁경부암 / pap smear, biopsy / 수술, RTx, CTx

폐경 후 질출혈 + 폐경 전에 월경 과다
= 자궁내막암 / endometrial aspiration, pap smear / 수술, RTx

복통 + 무월경 + 질출혈 + 임신 가능성 (+)
= 자궁 외 임신 / 임신반응검사, 질초음파, 복강경 / salpingectomy, MTX

임신 충 질출혈
= 유산 / 태아 초음파 / 침대안정, D&C,

호르몬 제제 사용 중 불규칙적 복용
= 호르몬 제제, 경구피임약에 의한 출혈 / 혈액검사 / 규칙적으로 복용

월경 이상 + 월경량 이상 + 전신 질환
= 기능성 자궁 출혈 / 임신반응검사, 호르몬 검사 / NSAIDs, 호르몬, 체중

월경 과다 + 만성 피로 + 추위불내성 + 변비 + 체중 증가
= 갑상샘저하증 / TFT / levothyroxine
