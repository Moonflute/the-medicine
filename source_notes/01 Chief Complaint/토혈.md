# 토혈

## Concept
'출혈’, 토혈 상황 확인, 음주 관련 체크

## 감별진단
식도 : 역류성 식도염, 식도암, 식도정맥류
위 : 말로리-바이스 증후군, 위/십이지장궤양, 소화성 궤양 천공, 위암

응고장애

## Hx
O L D Co Ex
Character
	음식물/거품/색깔/피떡 (↔ 객혈), 출혈량
Associated Sx 
	General  : Weight loss, Fatigue, Fever
출혈 증상 : 어지럼증, 호흡곤란, 소변량 감소
출혈 경향 : 코피, 출혈 후 잘 안 멎음, 멍이 잘 듦, 생리량 증가
AVNCD-B SSP, 황달
Factor
	식사, 음주 관련 (과음 여부)
E 
외과약사가여 : 출혈 관련 약물 확인 (NSAIDs, 항응고제)

## PEx
V/S 눈 코 입 목(림프절)
손 (긴장도, Palmar erythema, Flapping tremor)
흉부 : 시진
복부 : 시 – 청 – 타 – 촉
DRE (필요 시 시행)

## 환자교육
검사 : 혈액검사, 내시경, 요소날숨검사, CXR, AXR..
치료 : 수액 치료 (수혈 가능)
교육 : 병원으로 오셔야 합니다

소량 토혈 + 신물 + 속쓰림
= 역류 식도염 / 위내시경, 24hr 식도 pH / PPI, 제산제, 생활 습관

토혈 + 체중감소 + 연하곤란 + 고령 + 흡연
= 식도암 / 위내시경, 흉부 CT / 수술, RTx

다량 토혈 + 황달 + 복부 팽만 + 간경변 + erythema, tremor, angioma
= 식도정맥류 / 위내시경, 간기능검사 / 수액 정주, 정맥류결찰술, BB

음주 후 구토 중 토혈
= 말로리-바이스 증후군 / 위내시경 / 수액 정주, 안정

다량 토혈 + 속쓰림 + 소화불량 + 상복부 압통
= 위궤양, 십이지장궤양 / 위내시경, 신속요소분해효소검사 			/ 내시경지혈, PPI, 제균, 교육

다량 토혈 + 속쓰림 + 소화불량 + 발열 + 오한 + 복통 + 복부 전체 압통
= 소화성 궤양 천공 / 흉부 X-ray, 복부 CT / 응급 개복 수술

토혈 + 체중 감소 + 소화불량
= 위암 / 위내시경, 복부 CT / 위절제술, EMR, 항암치료

출혈 경향 + 출혈성 약제 복용
= 응고장애 / … / …

* 약물에 의해서 위염 발생 가능 (NSAIDs)
