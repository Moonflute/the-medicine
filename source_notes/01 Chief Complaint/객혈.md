# 객혈

## Concept
객혈은 비출혈·구강출혈·토혈과 출처를 구분하고, 원인 감별보다 기도 위협과 출혈 중증도 판단이 우선이다.

## 감별진단
감염 : 폐렴, 폐결핵, 폐흡충증
염증 : 만성 기관지염, 기관지확장증
기타 : 폐색전증, 폐암, 단순 구강 출혈, 혈액응고장애

## 환자교육
검사 : CXR, 기관지내시경, 혈액검사, 객담검사
치료 : 안정, 진해제 등
교육 : 금연, 독감 예방접종, 응급 상황 교육, 손위생

객혈 + 기침 + 가래 + 발열 + 흉통 + 수포음 청진 + 성음진탕 증가
= 폐렴 / CXR, 객담 배양, 혈액 배양, CBC / 경험적 항생제, 수액

객혈 + 기침 + 가래 + 피로 + 체중감소 + 야간 발한
= 폐결핵 / Tb 검사, AFB / 항결핵제

대량 객혈 + 가래 + 민물게장 섭취력
= 폐흡충증 / ELISA / Praziquantel

소량 객혈 + 양치 중 출혈 + 구강 시진에서 피
= 상기도, 단순 구강 출혈 / 불필요 / 경과 관찰

소량 객혈 + 기침 + 가래 
= 만성 기관지염 / CBC, CXR, 객담배양 / 항생제, 진해제

대량 객혈 + 가래 + 잦은 상기도 감염력 + 수포음 청진
= 기관지확장증 / CXR, CT / 기관지동맥색전술, 폐절제술

객혈 + 호흡곤란 + 흉통 + 누워지냄 + 수포음 청진 + 목정맥 확장 + 부종
= 폐색전증 / CT angio, EKG / heparin, 혈전용해제, IVC filter

객혈 + 체중 감소 + 오랜 흡연력
= 폐암 / 기관지내시경, 경피적 미세침습 / 폐절제술, 방사선 치료, 항암제

## 접근
- 양과 속도, 산소 요구량을 확인하고 hematemesis·epistaxis 흡인을 구분한다. 최근 기관지경·biopsy, anticoagulant, 폐암·결핵·기관지확장증과 PE 위험을 확인한다.
- 계속되는 출혈, 저산소증·저혈압, 분비물 배출 불가는 대량 기준 숫자를 기다리지 말고 기도 응급으로 판단한다. 출혈 폐가 추정되면 해당 쪽을 아래로 눕히고 ICU·호흡기·중재시술팀을 호출한다.
## 검사
- CBC·serial Hb, coagulation, type and screen, renal function과 흉부 X선을 시행한다. 안정 시 contrast chest CT/CT angiography, 지속 출혈에서는 bronchoscopy와 bronchial artery embolization을 준비한다.
- 산소·호흡수·출혈량·Hb를 반복하고 anticoagulant의 마지막 투여시각과 신기능을 확인한다.
## 치료
- 산소와 suction을 준비하고 NPO, large-bore IV를 확보한다. 출혈 관련 anticoagulant·antiplatelet은 적응증과 혈전위험을 함께 검토해 보류·reversal한다.
- 불안정하거나 지속 출혈이면 병실에서 진정·검사를 반복하지 말고 definitive airway, bronchoscopy 또는 embolization이 가능한 장소로 이동한다. 기침억제제는 분비물 배출을 막을 수 있어 대량 객혈에 일률적으로 사용하지 않는다.

## ER

### 1. 즉시 평가 및 안정화
- 출혈량보다 기도 위협, 산소화·환기 장애와 혈역학적 불안정을 우선 평가한다.
- 대량 또는 지속 출혈이면 출혈 폐를 아래로 향하게 하고 흡인 준비, 산소화, 굵은 정맥로와 조기 기도·기관지내시경 협진을 진행한다.
- 비출혈·구강출혈·토혈이 기침으로 배출된 것인지 구분한다.

### 2. 놓치면 안 되는 질환
- 폐암·결핵·기관지확장증·괴사성 폐렴 : 반복 또는 다량 객혈
- [[폐색전증 (Pulmonary Embolism)]] : 급성 호흡곤란, 흉막통, 혈전 위험인자
- 미만성 폐포출혈 : 빈혈, 저산소증, 양측 침윤, 신장·자가면역 소견
- 대동맥-기관지 누공 또는 혈관성 병변 : 수술·스텐트 병력, 전조 출혈 후 대량 출혈
- 항응고 관련 출혈 : 약물·신기능·응고 이상 확인

### 3. 초기 검사
- CBC, 응고검사, 신장기능, 혈액형·교차시험을 중증도와 출혈 가능성에 맞춰 시행한다.
- 흉부 X선 후 안정 환자에서는 조영증강 흉부 CT 또는 CT angiography로 원인과 출혈 혈관을 평가한다.
- 기관지내시경은 기도 확보, 출혈 위치 확인과 치료에 사용하며 불안정 환자에서는 조기에 준비한다.
- 감염·결핵 위험에 따라 객담검사와 격리를 적용한다.

### 4. 초기 처치 및 재평가
- 산소화와 기도를 유지하고 항응고·응고장애를 적절히 교정한다.
- 지속 출혈은 기관지동맥 색전술, 기관지내시경 치료 또는 수술팀과 조기에 협의한다.
- 출혈 빈도, 산소 요구량, 혈색소와 활력징후 변화를 반복 평가한다.

### 5. Disposition
- 기도 위험, 지속 출혈, 산소화 장애, 혈역학 불안정 또는 중증 기저 폐질환은 중환자실 또는 시술 가능 기관 입원이 필요하다.
- 소량으로 멈췄더라도 원인 불명, 영상 이상, 암 위험이 있으면 신속한 전문 평가를 연결한다.
- 명확한 양성 원인과 안정성이 확인된 경우에만 재출혈 시 즉시 내원 기준을 교육하고 퇴원을 고려한다.

### 6. ER 함정
- 환자가 말한 출혈량은 부정확할 수 있으므로 생리적 영향과 출혈 지속 여부를 함께 본다.
- 정상 흉부 X선만으로 악성종양이나 중요한 기도 병변을 배제하지 않는다.
