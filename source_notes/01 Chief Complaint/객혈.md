# 객혈

## Concept
'출혈’, 토혈은 아닌지 확인

## 감별진단
감염 : 폐렴, 폐결핵, 폐흡충증
염증 : 만성 기관지염, 기관지확장증
기타 : 폐색전증, 폐암, 단순 구강 출혈, 혈액응고장애

## Hx
O L D Co Ex
Character
	양, 색, 양상, 거품, 음식물 (종이컵 반 이상 = 대량)
Associated Sx 
	General  : Weight loss, Fatigue, Fever, Chill, Edema
	출혈 경향 : 코피, 출혈 후 잘 안 멎음, 멍이 잘 듦, 생리량 증가
	출혈 증상 : Hemoptysis, Melena, Hematochezia 
	탈수 증상 : 목마름, 호흡곤란, 두근거림, 소변량 감소
	FCCSR + 흉통, 호흡곤란, 야간 발한
FE 
외과약사가여 : 민물게장, 감기에 자주 걸리는가?

## PEx
V/S 눈 입 코 목(림프절)
흉부 : 시 – 촉 – 타 – 청
복부 : 시 – 청 – 타 – 촉 (혈액응고 의심 시)
사지 (출혈, 부종, 곤봉지, 청색증)
PTE 의심 시 Homan’s

## 환자교육
검사 : CXR, 기관지내시경, 혈액검사, 객담검사
치료 : 안정, 진해제 등
교육 : 금연, 독감 예방접종, 응급 상황 교육, 손위생

객혈 + 기침 + 가래 + 발열 + 흉통 + 수포음 청진 + 성음진탕 증가
= 폐렴 / CXR, 객담 배양, 혈액 배양, CBC / 경험적 항생제, 수액

객혈 + 기침 + 가래 + 피로 + 체중감소 + 야간 발한
= 폐결핵 / Tb 검사, AFB / 항결핵제

대량 객혈 + 가래 + 민물게장 섭취력
= 폐흡충증 / ELISA / Praziquantel

소량 객혈 + 양치 중 출혈 + 구강 시진에서 피
= 상기도, 단순 구강 출혈 / 불필요 / 경과 관찰

소량 객혈 + 기침 + 가래 
= 만성 기관지염 / CBC, CXR, 객담배양 / 항생제, 진해제

대량 객혈 + 가래 + 잦은 상기도 감염력 + 수포음 청진
= 기관지확장증 / CXR, CT / 기관지동맥색전술, 폐절제술

객혈 + 호흡곤란 + 흉통 + 누워지냄 + 수포음 청진 + 목정맥 확장 + 부종
= 폐색전증 / CT angio, EKG / heparin, 혈전용해제, IVC filter

객혈 + 체중 감소 + 오랜 흡연력
= 폐암 / 기관지내시경, 경피적 미세침습 / 폐절제술, 방사선 치료, 항암제
