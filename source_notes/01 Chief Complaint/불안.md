# 불안

## Concept
불안은 공황발작과 지속성 불안을 구분하면서 약물·물질, 갑상샘·심폐 질환 같은 의학적 원인과 자살 위험을 함께 평가한다.

## 감별진단
원발성 : 공황장애, 광장공포증, 범불안장애, 사회불안장애 / 강박장애 / PTSD, 급성 스트레스 장애, 적응장애
속발성 : 허혈 심장병, 부정맥 / 천식 / 갑상샘항진증, 크롬친화세포종 / 기타 : 뇌전증, 약물

## 환자교육
검사 : 정신상태검사, 우울척도검사, 혈액검사, EKG
치료 : 약물, 인지 행동 치료
교육 : 안심시키기, 꾸준한 치료 필요 설명

반복적인 공황 발작 + 예기불안 + 발작에 대한 걱정 + 행동 변화
= 공황장애 / … / BZD, SSRI, 인지 행동 치료

대중교통, 공개된 공간, 폐쇄된 장소, 군중, 야외에 있는 것을 매우 불안
= 광장공포증 / … / SSRI, 인지 행동 치료

일상생활 중의 일에 대한 걱정과 불안 + 6개월 이상
= 범불안장애 / … / buspirone, BZD, SSRI, 인지 행동 치료

타인의 시선에 대한 불안
= 사회불안장애 / … / BB, SSRI, BZD, 인지 행동 치료, 집단 치료

강박 사고나 행동이 생활에 지장을 줌
= 강박장애 / … / SSRI, 행동 치료

심각한 사건을 접한 후 발생 + 침습증상 + 1개월 이상
= 외상 후 스트레스 장애 / … / SSRI, TCA, 인지 행동 치료

심각한 사건을 접한 후 발생 + 침습증상 + 1개월 이내
= 급성 스트레스 장애 / … / SSRI, TCA, 인지 행동 치료

일상에서 겪는 스트레스에 대한 불안 + 3개월 이내
= 적응장애 / 나머지 배제 / BZD, 인지 행동 치료, 단기 정신 치료

치료 : 약물, 인지 행동 치료
교육 : 안심시키기, 꾸준한 치료 필요 설명

불안 + 흉통 + 호흡곤란 + 운동 시 악화
= 허혈 심장병 / EKG, 운동부하 심전도 / aspirin, 재개통술

불안 + 두근거림 + 심장쿵 + 맥박
= 빠른 부정맥 / EKG, 24hr holter / 항부정맥제

불안 + 기침 + 호흡곤란 + 쌕쌕거림 + 계절성
= 천식 / PFT / SABA, ICS

불안 + 두근거림 + 체중 감소 + 더위불내성 + 갑상샘 비대
= 갑상샘 항진증 / TFT / PTU, 방사성 요오드

불안 + 두통 + 안면홍조 + 식은땀 + 두근거림
= 크롬친화세포종 / 24hr meta, CT / propranolol, 부신절제술

불안 + 발작 + 신경학적 이상 소견
= 뇌전증 / EEG, MRI, 항뇌전증제

약물 남용력
= 약물 금단 증상 / … / haloperidol, BZD

## 접근
- hypoxia, hypoglycemia, delirium, withdrawal, pain·dyspnea, arrhythmia와 steroid·bronchodilator 부작용을 먼저 배제하고 자살사고를 확인한다.
## 검사
- 활력징후·SpO2·glucose, ECG와 약물검토를 단서에 따라 시행한다. 4AT 양성이면 anxiety보다 delirium을 우선 관리한다.
## 치료
- 원인 증상과 환경 자극을 교정한다. benzodiazepine은 withdrawal·catatonia 등 명확한 적응증 외에는 섬망·낙상·호흡억제 때문에 일률적으로 사용하지 않는다.
