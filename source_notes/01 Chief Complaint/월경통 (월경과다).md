# 월경통 (월경과다)

## Concept
월경통과 과다월경은 통증과 출혈 문제를 분리해 평가하고, 새로 심해진 증상이나 주기 외 증상에서는 이차성 원인을 찾는다.

## 감별진단
원발성 월경통
이차성 월경통
자궁내막증, 자궁근종, 자궁샘근육증
자궁내 장치, 골반 감염 등

## 환자교육
검사 : 골반초음파
치료 : 월경과다 시 수액 정주 등
교육 : 자궁경부암 정기검진 받을 것

월경통이 초경 후 1~2년 후부터 지속 + 오심 + 구토 + 하복부 압통
= 원발 월경통 / 임상적 진단 / 진통제, 운동, 경구피임제

월경통 + 월경과다 + 성교통 + 자궁 후굴 + 운동성 감소 + 25~35세
= 자궁내막증 / 자궁난관조영술, CA-125, 골반초음파 / 수술, progestin

월경통 + 월경과다 + 성교통 + 30~45세 + 빈뇨
= 자궁근종 / 골반 US, 자궁난관조영술 / GnRH agonist, 자궁근종절제술

월경통 + 월경과다 + 성교통 + 40세~
= 자궁샘근육증 / 골반초음파 / 임신 계획중이면 약물, 아니면 자궁절제술

## 접근
- pad 수·clot, hemodynamic change와 pregnancy, anticoagulant, fibroid·adenomyosis, coagulopathy를 확인한다. 저혈압·실신·빠른 Hb 감소는 acute abnormal uterine bleeding으로 산부인과를 호출한다.
## 검사
- β-hCG, CBC·serial Hb, ferritin, coagulation과 type and screen을 중증도에 따라 시행하고 pelvic ultrasound를 선택한다.
## 치료
- 안정된 heavy bleeding은 금기가 없으면 Tranexamic acid (트란사민캡슐/주 등) 1 g PO TID 또는 원내 IV protocol을 단기간 고려하되 active/historical thrombosis와 renal function을 확인한다.
- 불안정 출혈은 IV access·혈액제제와 산부인과의 hormonal, tamponade·수술 치료로 전환한다. 진통 NSAID는 AKI·출혈위험을 확인한다.
