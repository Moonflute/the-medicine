# 피부 발진

## Concept
‘DM’, 전신 증상 질환과 피부 국한 질환으로 나눠 생각, 약물도

## 감별진단
전신 : 감염 : 바이러스 (홍역, 수두), 매독, 대상포진 / 자가면역 : 전신홍반루푸스, 베체트, 피부근염
피부 : 감염 : 옴, 어루러기, 결절홍반 / 피부질환 : 건선, 접촉피부염, 아토피 피부염
약물 발진

## Hx

### O / L / D / Co / Ex (Onset, Location, Duration, Course, Experienced)

### C (Character)
#### CC-specific
- 모양 (과녁, 수, 색, 딱지, 물집, 흰비늘, 여러개 합쳐짐, 경계 분명) 동반 (소양증, 따가움, 압통, 열감), 정도

### A (Associated symptoms)
#### CC-specific
- General : Weight loss, Fatigue, Fever, Chill, Edema
- 감염 증상 확인
- 호흡곤란/마른기침 (류마티스)
- 피부 발진, 햇빛 알러지 (루푸스)
- 구강/성기 궤양, 안구 충혈/통증 (베체트)
- 입술 부종

### F (Factor)
#### CC-specific
- 악화 요인 (접촉, 음식, 찬물, 땀), 성관계력

## 환자교육
검사 : 첩포 검사, 혈액 검사, 미생물 검사
치료 : 약물 중단, 항히스타민
교육 : 병변 자극하지 말 것, 보습제 사용

전신 발진 + 발열 + 감기 증상 (+ 홍역 3C, 수두 다양한 형태로)
= 바이러스 발진 (홍역, 수두) / CBC, 혈청검사 / 대증 치료, 항바이러스제

무릎 앞 발진 + 여러 개의 큰 홍반
= 결절 홍반 / 바이러스 등 검사 / NSAIDs, 소실될 것 교육

dermatome 위치 발진 + 통증 뒤따름 + 노인, 면역억제자
= 대상포진 / … / 항바이러스제, 스테로이드, 통증 조절

malar rash, discoid rash + 광과민성 + 구강 궤양 + 관절염 + 거품뇨
= 전신홍반 루푸스 / CBC, 항핵항체, anti-dsDNA / 국소 스테로이드

구강 궤양 + 생식기 궤양 + 포도막염 + 관절염
= 베체트병 / pathery test, 결절 홍반 / 콜히친, glucocorticoid

gottron papule, heliotrope rash + 머리빗기/계단오르기 어려움
= 피부근염 / EMG, CK, 근육조직검사 / 스테로이드, 면역억제제

사타구니, 하복부, 겨드랑이 가려움 + 잘 때 더 가려움 + 가족 유사 증상
= 옴 / 병변 부위 현미경 검사, 굴 확인 / 가족도 치료, 연고

땀이 나는 부위 반점 + 경한 소양증
= 어루러기 / 우드등검사, KOH 도말검사, 진균배양검사 / 건조, 시원하게

구진과 판 + 은백색 비늘 + 손발톱 변화
= 건선 / 피부조직검사 / 보습, 스테로이드, 광선 치료, retinoid

비누/샴푸/세제/화장품/벨트/목걸이 등에 접촉한 부위에 발진
= 접촉피부염 / 첩포검사, 유발검사 / 냉습포, 스테로이드, 항히스타민제

가려움 + 피부 건조 + 피부염
= 아토피 피부염 / 피부바늘따끔검사, IgE / 피부 보습, 국소 스테로이드 

전신 발진 + 약물 복용력 + 동일 약물에는 동일 부위
= 약물 발진 / 의심되는 약 사용 금지 / steroid, 항히스타민제
