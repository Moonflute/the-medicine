# 피부 발진

## Concept
‘DM’, 전신 증상 질환과 피부 국한 질환으로 나눠 생각, 약물도

## 감별진단
전신 : 감염 : 바이러스 (홍역, 수두), 매독, 대상포진 / 자가면역 : 전신홍반루푸스, 베체트, 피부근염
피부 : 감염 : 옴, 어루러기, 결절홍반 / 피부질환 : 건선, 접촉피부염, 아토피 피부염
약물 발진

## 환자교육
검사 : 첩포 검사, 혈액 검사, 미생물 검사
치료 : 약물 중단, 항히스타민
교육 : 병변 자극하지 말 것, 보습제 사용

전신 발진 + 발열 + 감기 증상 (+ 홍역 3C, 수두 다양한 형태로)
= 바이러스 발진 (홍역, 수두) / CBC, 혈청검사 / 대증 치료, 항바이러스제

무릎 앞 발진 + 여러 개의 큰 홍반
= 결절 홍반 / 바이러스 등 검사 / NSAIDs, 소실될 것 교육

dermatome 위치 발진 + 통증 뒤따름 + 노인, 면역억제자
= 대상포진 / … / 항바이러스제, 스테로이드, 통증 조절

malar rash, discoid rash + 광과민성 + 구강 궤양 + 관절염 + 거품뇨
= 전신홍반 루푸스 / CBC, 항핵항체, anti-dsDNA / 국소 스테로이드

구강 궤양 + 생식기 궤양 + 포도막염 + 관절염
= 베체트병 / pathery test, 결절 홍반 / 콜히친, glucocorticoid

gottron papule, heliotrope rash + 머리빗기/계단오르기 어려움
= 피부근염 / EMG, CK, 근육조직검사 / 스테로이드, 면역억제제

사타구니, 하복부, 겨드랑이 가려움 + 잘 때 더 가려움 + 가족 유사 증상
= 옴 / 병변 부위 현미경 검사, 굴 확인 / 가족도 치료, 연고

땀이 나는 부위 반점 + 경한 소양증
= 어루러기 / 우드등검사, KOH 도말검사, 진균배양검사 / 건조, 시원하게

구진과 판 + 은백색 비늘 + 손발톱 변화
= 건선 / 피부조직검사 / 보습, 스테로이드, 광선 치료, retinoid

비누/샴푸/세제/화장품/벨트/목걸이 등에 접촉한 부위에 발진
= 접촉피부염 / 첩포검사, 유발검사 / 냉습포, 스테로이드, 항히스타민제

가려움 + 피부 건조 + 피부염
= 아토피 피부염 / 피부바늘따끔검사, IgE / 피부 보습, 국소 스테로이드 

전신 발진 + 약물 복용력 + 동일 약물에는 동일 부위
= 약물 발진 / 의심되는 약 사용 금지 / steroid, 항히스타민제

## ER

### 1. 즉시 평가 및 안정화
- 기도·호흡·순환, 점막 침범, 발열·전신독성, 통증, 자반의 압박 소실 여부와 빠른 진행을 먼저 평가한다.
- 호흡곤란, 저혈압, 혀·인두 부종이 있으면 [[아나필락시스 (Anaphylaxis)]] 치료를 즉시 시작한다.
- 점상출혈·자반과 쇼크가 있으면 격리와 중증 감염 치료를 지연하지 않는다.

### 2. 놓치면 안 되는 질환
- [[아나필락시스 (Anaphylaxis)]]·혈관부종
- Stevens-Johnson syndrome/TEN : 새 약물, 피부통증, 수포·박리, 다발 점막 침범
- 수막구균혈증·패혈증 : 비창백성 자반, 발열, 쇼크
- 괴사성 연조직감염 : 진찰보다 심한 통증, 빠른 부종·수포·피부색 변화
- 독성쇼크·DRESS : 발열, 저혈압, 장기침범과 약물 노출
- 대상포진 안구침범 : 이마·코끝 수포와 안구 증상

### 3. 초기 검사
- 안정적인 국소 발진은 임상진단이 중심이며 일률적 검사가 필요하지 않다.
- 전신독성·자반·점막 침범이 있으면 CBC, 대사·간·신장기능, 응고, 배양과 원인별 검사를 시행한다.
- 괴사성 감염은 영상이나 점수 때문에 외과 평가를 지연하지 않는다.
- 약물 목록과 시작시점을 정확히 재구성한다.

### 4. 초기 처치 및 재평가
- 아나필락시스, 중증 감염, 중증 약물이상반응의 시간 민감 치료를 시작하고 원인 약물을 중단한다.
- 발진 범위, 통증, 점막·안구 침범, 활력징후와 장기기능을 반복 평가한다.
- 전파 가능 감염은 적절한 격리를 적용한다.

### 5. Disposition
- 기도·순환 침범, 비창백성 자반, 광범위 수포·박리, 점막·안구 침범, 괴사성 감염 의심은 입원한다.
- 안정적인 양성 발진으로 판단되며 위험 약물·전신 증상이 없을 때 퇴원을 고려한다.

### 6. ER 함정
- 두드러기가 없어도 아나필락시스가 가능하다.
- 초기 SJS/TEN이나 괴사성 감염은 피부 소견이 작아 보일 수 있으므로 통증과 진행속도를 중시한다.
