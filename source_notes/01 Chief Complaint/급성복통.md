교육 : 입원 가능성 설명, 수술 가능성 있는 경우 잘 설명

명치부 통증 + 식후 악화 + 메스꺼움 + 구토 + 속쓰림 + 복부 압통
= 위염, 위궤양 / 위내시경, 요소날숨검사, RUT / PPI, 제산제, 제균치료

명치부 통증 + 공복 악화 + 메스꺼움 + 구토 + 속쓰림 + 복부 압통
= 십이지장궤양 / 위내시경 / PPI, 제산제

위궤양 증상 + 두근거림 + 어지럼 + 복부 전반적 압통 + 반발 압통
= 소화 천공 궤양 / AXR, CT / 응급 수술

찌르는 통증 + 식후 악화 + 구역 + 구토 + 굽히면 완화 + 과음 + 압통
= 급성 췌장염 / amylase, lipase, CT / 수분 공급, 진통제, 비위관 삽입

RUQ 통증 + 황달 + 발열 + Murphy (+)
= 급성 담낭염, 담석증, 담관염 / CT, US, LFT / 담낭절제술, 항생제

RUQ 불쾌감 + 황달 + 메스꺼움 + 피로 + 근골격계 통증 + 간비대
= 급성 간염 / US, LFT / 황달 치료

극심한 찢어지는 통증 + 호흡곤란 + 복부 박동성 종괴
= 복부 대동맥류 파열 / CT / 응급개복수술

명치에서 RLQ로 이동 + 구역구토 + 압통 + Rovsing, Obturator, Psoas (+)
= 급성 충수염 / US, CT / 충수절제술, 항생제

복통 + 혈변 + 설사 + 체중감소 + 항문통증 + DRE 혈변
= 크론병 / 대장내시경 / 설파살라진, steroid, infliximab, 영양 공급

배꼽 주위 통증 + 복부 수술력 + 장음 항진
= 장폐색증 / AXR / 비위관 삽입

## ER

### 1. 즉시 평가 및 안정화
- ABC, 활력징후, 의식, 통증 정도와 복막자극징후를 평가하고 쇼크가 있으면 정맥로·검사·소생을 동시에 진행한다.
- 임신 가능 연령에서는 임신 관련 응급질환을 항상 고려한다.
- 진통과 항구토는 평가를 방해한다는 이유로 지연하지 않되 반복 진찰로 변화를 추적한다.

### 2. 놓치면 안 되는 질환
- [[복부 대동맥류 (Abdominal Aortic Aneurysm)]]·대동맥박리 : 갑작스러운 복통·요통, 실신, 저혈압, 맥박성 종괴
- 장간막허혈 : 진찰 소견에 비해 심한 통증, 심방세동·혈관질환
- 천공·복막염·[[장폐색]] : 복막자극, 지속 구토, 복부팽만, 이전 수술력
- [[급성 충수염 (Acute Appendicitis)]]·담낭염·[[급성 췌장염 (Acute Pancreatitis)]] : 위치와 경과에 맞는 염증성 복통
- 자궁외임신·난소염전 : 임신 가능성, 질출혈, 편측 골반통
- 요로결석·신우신염 : 옆구리 통증, 혈뇨, 발열 또는 패혈증

### 3. 초기 검사
- CBC, 전해질·신장·간기능, lipase, 소변검사와 임신반응검사를 임상 가설에 따라 선택한다.
- lactate 정상만으로 초기 장간막허혈을 배제하지 않는다.
- bedside ultrasound는 AAA, 담낭, 수신증, 복강내 액체와 임신 위치 평가에 유용하다.
- CT는 비임신 성인의 중증·불명확 복통에서 유용하지만 불안정 환자의 수술·혈관중재를 지연하지 않는다.

### 4. 초기 처치 및 재평가
- 금식, 적절한 진통·항구토, 수액을 시행하고 감염·천공·허혈이 의심되면 조기 항균치료와 외과 협진을 진행한다.
- 시간 경과에 따른 통증 위치, 복막자극, 활력징후와 검사 변화를 반복 평가한다.
- 출혈성 쇼크가 의심되면 혈액제제와 출혈 조절 경로를 조기에 활성화한다.

### 5. Disposition
- 쇼크, 복막자극, 혈관성 응급, 천공·폐색·허혈·염전 의심은 응급 수술 또는 입원이 필요하다.
- 진단이 불명확하고 통증이 지속되거나 검사 추세가 변하면 관찰과 재진찰을 시행한다.
- 퇴원은 활력징후가 안정되고 경구섭취가 가능하며 중증 원인이 합리적으로 배제되고 재내원 기준이 명확할 때만 고려한다.

### 6. ER 함정
- 고령자·면역저하자·임신부는 복막자극과 발열이 뚜렷하지 않을 수 있다.
- 진통 후 호전이나 정상 단일 검사만으로 혈관성·초기 염증성 질환을 배제하지 않는다.
