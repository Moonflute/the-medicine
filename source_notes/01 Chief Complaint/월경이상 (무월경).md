# 월경이상 (무월경)

## Concept
무월경은 임신을 먼저 배제한 뒤 초경 여부와 이차성징을 기준으로 시상하부·뇌하수체, 난소, 자궁·유출로 원인을 나눈다.

## 감별진단
임신
난소 이상 : 원발성 난소 기능 부족증 (조기폐경), 터너 증후군
뇌하수체, 시상하부 이상 : 종양, 시한 증후군 / 신경성 식욕부진증, 과한 운동, 스트레스
내분비 : 고프로락틴혈증 / 갑상샘항진증 / PCOS, 쿠싱증후군, 비만

## 환자교육
검사 : 혈액검사, 골반초음파검사, 소변임신검사
치료 : 병바병
교육 : 생활 습관 개선, 경구피임약 복용 교육, 과격 운동 주의, 검진 권유

임신 가능성 있음 + 기타 소견 정상
= 임신 / 소변 hCG 검사 / 임신 교육

이차성 무월경 + 안면홍조 + 화끈거림 + 열감 + 두근거림
= 조기 폐경 / 혈중 FSH LH / 호르몬 대체요법

원발성 무월경 + 작은 키 + 작은 턱 + 기형
= 터너 증후군 / 혈중 FSH LH / E, P 공급

무월경 + 유즙 분비 + 두통 + 시야장애
= 뇌하수체 질환 (종양, 뇌하수체저하증) / 혈중 프로락틴 / bromocriptine, cabergoline

식사 적게 함 + 젊은 여성 + 체중에 대한 부정적 인식 + 3회 이상 무월경
= 신경성 식욕부진증 / 전해질검사 / 입원 치료, 영양 공급, 정신 치료

과한 운동 or 스트레스 많이 받은 상황
= HPO 저하로 인한 무월경 / … / 상황 개선

두근거림 + 더위불내성 + 체중 감소 + 피로 + 설사 + Goiter
= 갑상샘항진증 / TFT, ECG / 항갑상샘제, BB, 방사성 요오드 치료

다모증 + 여드름 + 월경 불규칙
= 다낭성난소증후군 / 골반 U, FST, LH / 체중 감량, 클로미펜, 메트포민

자색선조 + 둥근 얼굴 + steroid 복용 + 복부 비만
= 쿠싱 증후군 / 24hr 소변 cortisol 농도 / 부신절제술, 뇌수술

자궁소파술력
= 자궁내막유착증 / 자궁난관조영술 / 소파술, E+P 고용량

## 접근
- 마지막 월경과 임신 가능성을 먼저 확인하고 급성질환·체중변화, hyperprolactinemia 유발약, thyroid, PCOS와 menopause를 구분한다.
## 검사
- β-hCG를 우선하고 TSH, prolactin, FSH/LH와 pelvic ultrasound는 지속성과 임상 단서에 따라 선택한다.
## 치료
- 임신이면 산과 경로로 전환하고 원인 약물·영양·endocrine disorder를 교정한다. 급성 입원 중 진단 없이 hormonal therapy를 시작하지 않고 3개월 이상 지속 시 추적계획을 남긴다.
