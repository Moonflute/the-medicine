# 근력/감각이상

## Concept
근력·감각이상은 중추신경, 말초신경, 신경근접합부, 근육 수준으로 병변을 국소화하며 갑작스러운 편측 증상은 중추성 원인을 우선한다.

## 감별진단
CNS : 뇌출혈/뇌경색/뇌종양, 일과성 허혈발작 / 척수염, 다발경화증
PNS : 추간판탈출증, GBS, 당뇨병 신경병증, 수근관증후군, 노신경마비
NMJ, M : 중증근무력증, 염증성 근병증
기타 : 갑상샘 독성 주기 마비, Vit B 결핍

## 환자교육
검사 : 뇌 CT, MRI + angio
치료 : 혈전용해제, 항응고제, 항혈소판제, 뇌동맥류결찰술
교육 : 생활습관 개선 필요 (금연, 금주), 규칙적인 운동

급성 국소 신경학적 이상 + HTN, DM, HL + 심질환
= 뇌경색증, 일과성 허혈발작 / CT, MRI, angio / 혈전용해제, 항응고제

국소 신경학적 이상 + 두통 + 오심 + 구토 + 고혈압 + 수막 자극 징후
= 거미막밑출혈, 뇌내출혈 / brain CT, MRI, angio / 뇌압, 혈압 조절, 수술

체중 감소 + 두통 + 구토 + 경련 + 의식변화 + 시야 이상 + 유두 부종
= 뇌종양 / brain CT, MRI / glucocorticoid, 수술, RTx

특정 분절 아래 감각, 근력 변화 + 배변, 배뇨장애 + DTR 증가
= 척수염 / whole spine MRI, CSF검사 / glucocorticoid, 면역억제제

시력 저하 + 시야 이상 + 감각, 운동이상 + 배변, 배뇨장애
= 다발경화증 / MRI, CSF / high dose glucocorticoid, b-IF

편측 상하지 통증, 감각이상 + 목/허리 통증 + 근위약
= 추간판탈출증 / x-ray, CT, MRI, 근전도 / 진통제, 안정, 수술

대칭성 상행 사지마비 + 감각이상 + 최근 감염/접종력 + DTR 감소
= 길랑바레 증후군 / CSF, 근전도, NST / 입원, IVIG, 혈장교환

대칭성 상행 사지마비 + 김긱이상 + 당뇨 + 발끝 감각 저하 + DTR 감소
= 당뇨병성 신경병증 / 혈당검사, 신경전도속도 / 혈당 조절, TCA

손 저림, 통증 + 손 많이 쓰는 직업 + Tinel / Phalen (+)
= 수근관증후군 / 신경전도속도, 근전도, US / 진통제, steroid 주사, 수술

손팔 저림 + 팔이 오래 눌리는 자세 + wrist drop
= 노신경 마비 / 신경 전도 속도, 근전도 / 안심, 경과 관찰

## 접근
- 마지막 정상시각, 갑작스러운 편측 여부와 얼굴·언어·시야·보행을 확인하고 glucose를 즉시 측정한다. 수술 자세·압박신경, epidural·spinal procedure, 항응고, 전해질 이상과 약물성 weakness도 확인한다.
- 새 편측결손, aphasia, spinal cord compression·cauda equina 의심은 병동 관찰 없이 stroke/spine pathway를 활성화한다.
## 검사
- NIHSS 또는 신경학적 baseline 비교, glucose·electrolytes·Ca·Mg, CBC와 ECG를 시행한다. stroke이면 즉시 noncontrast CT와 vascular imaging, 척수압박이면 urgent MRI를 선택한다.
## 치료
- 저혈당은 Glucose 50% (대한포도당주사액 50% 등) 50 mL, 25 g IV 후 15분 재측정한다. 급성 허혈성뇌졸중의 thrombolysis·thrombectomy는 항응고·수술·출혈위험과 시간창을 확인해 stroke team이 결정한다.
- epidural hematoma·cord compression 의심 시 anticoagulant를 보류하고 신경외과·마취통증팀에 즉시 연락한다. 원인 확정 전 진정제나 단순 근이완제로 가리지 않는다.

## ER

### 1. 즉시 평가 및 안정화
- 증상 시작시각과 마지막 정상시각을 확인하고 혈당, ABC, 활력징후와 신경학적 중증도를 즉시 평가한다.
- 갑작스러운 편측 약화·감각저하·언어장애는 뇌졸중 경로를 활성화한다.
- 진행성 사지약화, 호흡근 약화, 연하장애가 있으면 환기능과 기도 보호를 조기에 평가한다.

### 2. 놓치면 안 되는 질환
- [[허혈성 뇌졸중 (Ischemic stroke)]]·뇌출혈 : 갑작스러운 국소 결손
- 척수압박·척수경색 : 양측 증상, 감각수준, 배뇨장애, 심한 경부·요통
- Guillain-Barre syndrome·중증근무력 위기 : 상행성 또는 변동성 약화, 호흡·연하 침범
- 저칼륨혈증 등 전해질 이상·저혈당·주기성 마비
- 대동맥박리·급성 사지허혈 : 통증, 맥박 소실, 혈압 차이와 신경학적 이상

### 3. 초기 검사
- 혈당, 전해질, 심전도와 원인별 혈액검사를 시행한다.
- 뇌졸중 의심은 비조영 CT와 혈관영상을 재관류 치료 판단에 맞춰 신속히 시행한다.
- 척수압박은 응급 MRI가 필요하며 영상 때문에 신경외과 협진을 지연하지 않는다.
- 호흡근 약화는 serial vital capacity 등 객관적 환기능으로 추적한다.

### 4. 초기 처치 및 재평가
- 재관류 치료, 척수압박 감압, 전해질 교정 등 시간 민감 원인 치료를 시작한다.
- 신경학적 결손 범위, 호흡·연하 기능과 보행 안전성을 반복 평가한다.
- 기능성 증상이 의심되어도 구조적·대사성 응급을 먼저 평가한다.

### 5. Disposition
- 급성 뇌졸중, 진행 결손, 호흡·연하 침범, 척수압박 또는 보행 불가는 입원한다.
- 일과성 증상도 TIA 고위험 평가와 신속한 뇌졸중 예방 경로가 필요하다.
- 명확한 말초신경 원인이고 진행 위험이 없으며 추적이 보장될 때만 퇴원을 고려한다.

### 6. ER 함정
- 증상이 호전되었다고 TIA·뇌졸중 위험이 사라지는 것은 아니다.
- CT 정상은 초기 허혈성 뇌졸중이나 척수질환을 배제하지 않는다.
