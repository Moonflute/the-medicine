# 혈변

## Concept
혈변은 색과 양상만으로 하부 출혈로 단정하지 않고 혈역학적 영향과 급속 상부위장관 출혈 가능성을 함께 판단한다.

## 감별진단
소장, 대장 : 메켈 게실, 게실 출혈 / 허혈 결장염, 감염성 대장염, 염증성 장질환 / 결장암, 직장암 (게실, 염증, 암)
직장항문 : 치핵, 항문 열창
기타 : 소아 폴립, 소화성 궤양

## 환자교육
검사 : 혈액검사, 대장내시경, 복부 CT
치료 : 수액공급 (수혈)
교육 : 빈혈 소견 나타나면 수혈 필요, 생활 습관 교정

무통성 선홍색 혈변 + 학동전기 소아
= 소아 폴립 / 대장내시경 / 내시경 폴립절제술

무통성 대량 혈변 + 기타 정상
= 메켈 게실 / 99mTc 적혈구 스캔, 대장내시경 / 수액, 게실절제술

대량 혈변 + 흑색변 + 변 굵기 변화 + 변비 + 체중 감소 + 종괴 촉진
= 결장암, 직장암 / 대장내시경, CT, MRI / 대장절제술, RTx, 수술

혈변 + 발열 + 복통 + 변비 + RLQ Td (or 무증상 혈변)
= 게실 출혈 / 대장내시경, 복부 CT / 경과관찰, 수액, 항생제, 소작술

혈변 + 복통 + 심혈관계 기저질환 + LQ Td
= 허혈 결장염 / 대장내시경, AXR / 수액, 항생제, 금식

혈변 + 설사 + 복통 + 상한 음식 섭취력 + 복부 Td
= 감염성 대장염 / 대장내시경, 대변배양, AXR / 수액, 항생제, 금식

혈변 + 복통 + 체중 감소 + 탈수 + 복부 압통 + DRE 혈변
= 염증 장질환 / 대장내시경, 대장조영술, CT / 설파살라진, steroid, 영양

묻어나오는 피 + 변비 + 항문 통증 + DRE 치핵/열상
= 치핵, 항문 열창 / 대장내시경 / 보존적 치료, 치핵절제술, 좌욕

혈변 + 소화불량 + 속쓰림 + 상복부 압통
= 소화성 궤양 출혈 / 위내시경 / PPI, NSAID, 제균치료, 금주

## 관련질환
[[게실 출혈 (Diverticular Bleeding)]], [[결장직장암 (Colorectal Cancer)]], [[메켈 게실 (Meckel's Diverticulum)]]

## 접근
- 선홍색·암적색·melena, 양과 hemodynamic change를 확인한다. 대량 hematochezia는 upper GI source도 고려하고 anticoagulant, 최근 colonoscopy·수술, ischemia·infectious diarrhea를 확인한다.
## 검사
- CBC·serial Hb, coagulation, BMP, lactate, type and cross를 시행한다. 불안정이면 upper source 평가와 CT angiography를 우선하고, 안정 후 bowel preparation·colonoscopy를 계획한다.
## 치료
- NPO, IV access와 수혈전략은 출혈 정도에 맞춘다. anticoagulant 관련 중증 출혈은 원내 reversal protocol을 적용한다.
- 지속 active bleeding은 CTA 후 IR embolization 또는 endoscopy로 전환한다. ischemic colitis·C. difficile·post-polypectomy bleeding은 원인별 치료를 병행하고 지사제를 자동 투여하지 않는다.

## ER

### 1. 즉시 평가 및 안정화
- ABC, 활력징후, 말초관류와 출혈 지속 여부를 평가하고 불안정하면 정맥로·교차시험·수혈 경로를 활성화한다.
- 빠른 혈변은 대량 상부 위장관 출혈일 수 있으므로 토혈·간질환·BUN 상승 등 단서를 함께 확인한다.
- 항응고제, 허혈 위험인자, 최근 시술과 감염 노출을 확인한다.

### 2. 놓치면 안 되는 질환
- [[하부 위장관 출혈 (Lower Gastrointestinal Tract)]] : 게실출혈, 혈관이형성, 종양
- 대량 상부 위장관 출혈 : 혈역학 불안정과 빠른 혈변
- 허혈성 대장염·장간막허혈 : 심한 통증, 혈관질환, 저관류
- 감염성 대장염·염증성 장질환 중증악화 : 발열, 독성 전신상태, 빈번한 혈성 설사
- 치핵·항문열상은 흔하지만 중증 원인을 배제한 뒤 판단한다.

### 3. 초기 검사
- CBC, 응고검사, 전해질·신장기능, 혈액형과 교차시험을 시행하고 추세를 본다.
- 불안정한 지속 출혈은 CT angiography로 출혈 위치를 찾고 중재영상 또는 수술과 연결할 수 있다.
- 안정 환자의 내시경 시점과 전처치는 위험도와 출혈 경과에 따라 결정한다.
- 감염성 설사가 의심될 때만 적절한 대변검사를 선택한다.

### 4. 초기 처치 및 재평가
- 출혈성 쇼크를 교정하고 항응고 관련 중증 출혈은 적절히 역전한다.
- 허혈·천공·독성 거대결장이 의심되면 항균치료와 외과·소화기 협진을 지연하지 않는다.
- 출혈 횟수, 활력징후, 복통·복막자극과 혈색소 변화를 반복 평가한다.

### 5. Disposition
- 불안정, 지속 출혈, 수혈 필요, 허혈·중증 대장염 의심은 입원 또는 중환자 치료가 필요하다.
- 경미한 출혈이 멈추고 안정적이며 고위험 동반질환이 없을 때만 신속 외래 평가와 재내원 기준을 전제로 퇴원을 고려한다.

### 6. ER 함정
- 선홍색 혈변을 모두 치핵으로 단정하지 않는다.
- 출혈이 일시적으로 멈춘 상태에서도 항응고, 고령, 동반질환과 재출혈 위험을 따로 평가한다.
