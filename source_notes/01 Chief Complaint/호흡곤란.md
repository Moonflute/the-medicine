# 호흡곤란

## Concept
호흡곤란은 주관적 정도보다 산소화와 호흡노력으로 중증도를 판단하고 심장성, 폐성, 대사성, 기능성 원인을 나눈다.

## 감별진단
순환기 : 울혈 심부전, 빈혈
호흡기 : 천식, 만성 폐쇄성질환, 기흉, 기관지확장증, 폐색전증, 폐렴, ILD
내분비 : 갑상샘항진증
정신 : 공황장애, 과다환기증후군

## 환자교육
검사 : CXR, ABGA, CBC, PFT, EKG (의심 시) 천식 유발검사
치료 : 병바병
교육 : 원인 인자 피하기, 금연

호흡곤란 + 피로 + 부종 + 누우면 악화 + 기저 심질환 + 경정맥 확장
= 울혈 심부전 / echo, EKG / ACEi, BB, spironolactone

호흡곤란 + 어지럼 + 피로 (+ 소화기 수술력) + 결막 창백
= 빈혈 / CBC, PBS, ferritin / 철분 보충 등

호흡곤란 + 쌕쌕거림 + 봄/야간 악화 / 알레르기력
= 천식 / PFT, 객담검사, skin prick test / ICS + formoterol

호흡곤란 + 가래 + 기침 + 흡연력 + 고령
= 만성 폐쇄성 폐질환 / PFT, CXR, ABGA / SABA, LABA

호흡곤란 + 찌르는 통증 + 호흡 시 악화 + 젊은 남성 + 공명음 감소
= 기흉 / CXR / 산소마스크, 흉관 삽입, 수술

호흡곤란 + 가래 + 객혈 + 감염력 + 수포음 청진
= 기관지 확장증 / CXR, CT / 기관지동맥색전술, 폐절제술

호흡곤란 + 누워 지냄 + 수포음 청진 + 목정맥 확장 + 부종
= 폐색전증 / CT, EKG / heparin, 혈전용해제, IVC filter

호흡곤란 + 발열 + 기침 + 가래 + 흉통 + 수포음 청진
= 폐렴 / CXR, CBC, 객담 배양 / 경험적 항생제

호흡곤란 + 만성 마른기침 + 피로 + 수포음 + 곤봉지
= 사이질 폐질환 / CT, PFT / steroid, pirfenidone, 산소 치료

호흡곤란 + 두근거림 + 더위불내성 + 설사 + 피로
= 갑상샘항진증 / TFT / PTU, 방사성 요오드 치료

호흡곤란 + 예기불안 + 발작에 대한 걱정
= 공황장애 / … / BZD, BB, 인지 행동 치료

호흡곤란 + 빈호흡 + 어지럼 + 기타 정상
= 과다환기증후군 / ABGA, 전해질검사 / 비닐봉지

## 접근

- 입원 당시 산소 요구량·호흡수와 현재 상태를 비교하고 증상 발생시각을 수액·수혈, 수술·진정, opioid 투여, 중심정맥관 삽입, 흡인, 부동·항응고 중단 시점과 맞춘다.
- 산소공급장치와 실제 유량, SpO2 waveform, 기도 분비물·tube 문제를 먼저 확인한다. 폐부종, atelectasis·mucus plugging, 폐렴·흡인, PE, 기흉, 기관지수축, opioid 호흡억제와 metabolic acidosis를 병렬로 평가한다.
- 말하기 어려움, 보조근 사용, silent chest, 새 의식저하, 저혈압, 빠르게 증가하는 산소 요구량은 병동 치료 실패 신호다. 즉시 신속대응팀을 호출하고 NIV·삽관이 가능한 장소로 이동한다.

## 검사

- ECG와 흉부 X선을 기본 가설에 맞춰 시행하고, bedside ultrasound로 B-line, 흉수, lung sliding, 심실기능·우심실 부담과 IVC를 확인한다.
- CBC, 전해질·Cr, glucose를 확인하고 감염이면 lactate·배양, 심부전이면 BNP/NT-proBNP·troponin, PE이면 사전확률에 따른 D-dimer 또는 CTPA를 선택한다.
- hypercapnia, 심한 호흡곤란, 의식 변화 또는 NIV 고려 시 ABGA/VBGA를 시행한다. COPD 악화에서 산소를 조정하거나 NIV를 시작한 뒤에는 pH·PaCO2를 반복 확인한다.
- 치료 시작 15–30분 후 호흡수, SpO2, 산소 유량, 보조근 사용, 의식과 청진을 재평가한다. 산소 요구량이 증가하거나 gas가 악화하면 중환자 치료로 전환한다.

## 치료

### 산소와 기관지확장
- 산소는 SpO2 94–98%를 목표로 적정한다. COPD, 비만저환기 등 hypercapnic respiratory failure 위험이 있으면 88–92%로 시작하고 blood gas로 조정한다.
- 기관지수축이면 Salbutamol (벤토린네뷸 2.5 mg 등) 2.5–5 mg nebulization q20min × 3회 후 반응에 따라 q1–4h. 중증이면 Ipratropium (아트로벤트흡입액유디비 500 mcg 등) 500 mcg nebulization q20min × 3회를 병용한다. 빈맥, 떨림, K 감소와 lactate 상승을 확인한다.
- COPD 악화에서 지속되는 hypercapnic acidosis는 최적 약물치료 후 NIV를 우선 고려한다. NIV 시작 시 실패 시 삽관 여부와 치료 상한을 함께 정한다.

### 폐울혈·약물 관련 원인
- 임상적으로 체액과다·급성 폐부종이면 Furosemide (라식스주 20 mg/2 mL) 20–40 mg IV를 시작한다. 기존 loop diuretic 복용자는 평소 1일 경구량과 신기능을 반영해 더 높은 IV 용량이 필요할 수 있으며, 1–2시간 내 소변량·호흡·혈압·Cr·K를 재평가한다.
- opioid 투여 후 호흡저하·축동·의식저하가 있으면 투여를 중단하고 Naloxone (한림날록손염산염주사 등) 0.04 mg IV부터 2–3분 간격으로 0.04–0.4 mg씩 환기가 회복될 때까지 적정한다. 누적 2 mg에도 반응이 없으면 다른 원인을 재평가하고, 장시간 작용 opioid에서는 재진정에 대비한다.
- 폐렴·흡인, PE, 기흉, 수혈관련 폐손상·순환과부하는 각각의 원인 치료를 즉시 병행한다. 호흡곤란을 불안으로 단정하거나 진정제부터 투여하지 않는다.

## ER

### 1. 즉시 평가 및 안정화
- 기도 개방성, 호흡 노력, 산소포화도, 순환과 의식상태를 동시에 평가한다.
- 말하기 어려움, 청색증, silent chest, 피로·의식저하, 저혈압은 임박한 호흡부전 신호다.
- 저산소증을 교정하고 환기부전이 의심되면 혈액가스와 비침습·침습 환기 필요성을 즉시 판단한다.

### 2. 놓치면 안 되는 질환
- [[긴장성 기흉 (Tension Pneumothorax)]] : 급격한 악화, 편측 호흡음 감소, 쇼크
- [[폐색전증 (Pulmonary Embolism)]] : 설명되지 않는 급성 호흡곤란, 흉통, 실신, 저산소증
- 급성심부전·폐부종 : 기좌호흡, 수포음, 경정맥 팽창, 말초부종
- 중증 천식/COPD 악화 : 호흡음 감소, 이산화탄소 상승, 피로
- [[아나필락시스 (Anaphylaxis)]]·상기도폐쇄 : stridor, 쉰목소리, 혀·인두 부종
- 중증 폐렴·[[패혈증 (Sepsis)]] : 감염 증상과 저혈압, 의식 변화, 장기관류 저하

### 3. 초기 검사
- 심전도, 흉부 X선, 혈액검사와 혈액가스는 임상 가설에 따라 선택한다.
- bedside ultrasound로 폐슬라이딩, B-line, 흉수, 심실기능과 우심실 부담을 확인할 수 있다.
- 폐색전증은 임상 사전확률에 따라 D-dimer 또는 CT pulmonary angiography를 선택한다.
- 검사 때문에 긴장성 기흉, 심한 기관지수축, 아나필락시스의 즉시 처치를 지연하지 않는다.

### 4. 초기 처치 및 재평가
- 원인에 맞춰 산소, 기관지확장, 양압환기, 이뇨·혈관확장, 항균치료 또는 응급 감압을 시행한다.
- 호흡수, 산소 요구량, 의식, 보조근 사용, 혈액가스와 피로 징후를 반복 평가한다.
- 초기 치료에 반응하지 않으면 진단 오류, 복합 원인과 기도 확보 필요성을 다시 평가한다.

### 5. Disposition
- 호흡부전, 지속 저산소증·고탄산혈증, 쇼크, 빠른 산소 요구량 증가는 중환자 치료 대상이다.
- 산소 없이 안정되고 원인이 확인되며 치료 반응과 안전한 추적계획이 있을 때만 퇴원을 고려한다.
- 재발 위험이 높은 천식, 심부전, 폐색전증 의심 환자는 관찰 또는 입원 기준을 질환별로 적용한다.

### 6. ER 함정
- 정상 산소포화도만으로 환기부전이나 초기 폐색전증을 배제할 수 없다.
- 불안으로 보이는 과호흡도 대사성 산증, 폐색전증, 패혈증 등 유기적 원인을 먼저 평가한다.
