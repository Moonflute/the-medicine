# 의식장애

## Concept
의식장애는 기도·호흡·순환과 혈당을 즉시 확인하고, 기존 상태와 비교해 독성·대사성 원인과 구조적 뇌병변을 구분한다.

## 감별진단

| 가능성 | 단서 |
| --- | --- |
| 구조적 중추질환 | 갑작스러운 국소결손·동공 비대칭·새 심한 두통·두부외상 → 뇌졸중·뇌출혈·경막하출혈 |
| 감염·염증 | 발열/저체온·수막자극·발진·쇼크 → 중추신경계 감염 또는 패혈증 |
| 발작 | 경련 또는 설명되지 않는 지속 의식장애·안구 편위 → 발작 후 상태 및 비경련성 간질지속상태 |
| 호흡·대사·장기부전 | 저산소·고탄산, 저혈당, DKA/HHS, Na/Ca 이상, 간성·요독성 뇌병증, 저체온 |
| 독성·금단·영양 | 투약 변경·저환기·동공 변화, 음주·금단·티아민 결핍, 밀폐공간 일산화탄소 노출 |

## 환자교육
- 동반자에게 평소 기능·마지막 정상 시각, 발병 상황, 낙상·복용 약의 변화를 확인하는 이유를 설명한다.
- 원인·재발 위험·도움 요청 기준을 공유한다. 의식·삼킴이 회복되기 전에는 음식·물·약을 입으로 주지 않는다.

**의식 기록(GCS)**

| 항목 | 반응과 점수 |
| --- | --- |
| 눈뜨기 | 자발 4, 음성 3, 압박자극 2, 없음 1 |
| 언어 | 지남력 5, 혼돈 4, 단어 3, 소리 2, 없음 1 |
| 운동 | 지시 수행 6, 통증 부위 국소화 5, 정상 굴곡/회피 4, 비정상 굴곡 3, 신전 2, 없음 1 |

삽관·마비처럼 평가 불가 항목은 이유와 함께 따로 기록한다. 한 번의 총점보다 구성 점수의 변화를 추적한다.

## 관련질환
[[고혈압 (Hypertension)]], [[뇌내 출혈 (Intracerebral hemorrhage)]], [[뇌수막염 (Meningoencephalitis)]], [[당뇨병 (Diabetes Mellitus)]], [[저혈당 (Hypoglycemia)]], [[지주막하 출혈 (Subarachnoid hemorrhage)]]

## 콜 접수
- 마지막 정상시각·평소 인지기능, 의식 변화 속도, 기도/호흡·SpO2·동공·체온과 최근 opioid·진정제 투여를 확인한다.
- 급성 발병·하루 중 변동·주의력 저하는 섬망을 시사하고, 만성 인지저하만으로 새 변화를 설명하지 않는다. 최근 방 이동, 안경/보청기 부재, 통증·요저류·변비, 금주/진정제 중단, 수술·마취 이력을 확인한다.

## 위험 판단
- 기도 보호 불가, 급격한 GCS 하강, 새 국소결손·지속 경련 또는 쇼크: 신속대응팀·중환자팀 즉시 호출.
- 발열·수막자극/새 두통, 낙상·항응고 후 새 혼돈, 알코올 금단 징후(진전·발한·빈맥·환각), 동공 비대칭은 감시 병상에서 긴급 원인 평가가 필요하다.

## 원인 감별·추가검사
- **Bedside 혈당**, **ABGA/VBGA**, **CBC·BMP·Ca·Mg·간/신기능**, **ECG**와 약물 검토. 단서에 따라 **뇌 CT/CTA·EEG·배양·lactate·ammonia·독성검사**를 선택한다.
- 저산소/고탄산혈증, 패혈증, 뇌졸중·경련, Na/Ca 이상, 장기부전과 약물 독성을 병렬 평가한다.
- 새 편측 신경징후·동공 차이·낙상력이 있으면 경막하출혈 등 구조적 병변을 우선 배제한다. 기면과 저환기는 opioid/진정제 축적·CO2 저류, 발열/수막징후는 중추신경계 감염을 고려한다.

## 처치
### 즉시 조치
- 저혈당이면 **Glucose 50% (대한포도당주사액 50% 등)** 50 mL(25 g) IV 후 15분 재측정. Opioid 호흡억제는 환기 보조와 함께 **Naloxone (한림날록손염산염주사 등)** 0.04 mg IV부터 환기 회복까지 적정.
### 원인 치료
- 알코올 사용장애·영양실조가 의심되면 **Thiamine hydrochloride (제일티아민염산염주사액 50 mg/2 mL 등)** 100–200 mg IV를 glucose와 함께 투여하되 저혈당 교정을 지연하지 않는다. 원인 불명에서 flumazenil을 일률 사용하지 않는다.
- 알코올/benzodiazepine 금단 의심 시 **Benzodiazepine** 기반 치료를 원내 금단 프로토콜과 감시하에 시작한다. 섬망은 원인 교정과 통증·수면·감각 보조기 조정이 우선이며 진정제만 반복하지 않는다.

## 경과관찰
- 의식 수준·호흡수·SpO2·동공·혈당을 반복 확인한다. Opioid 길항 후 재진정 또는 새 신경결손·경련은 즉시 재평가한다.

## ER

### 1. 즉시 평가 및 안정화
- 기도 보호, 호흡·순환, 산소포화도, 체온과 현장 혈당을 즉시 확인한다.
- 저산소증·저혈당·쇼크·경련·opioid toxidrome처럼 즉시 교정 가능한 원인을 검사 결과 전에 치료한다.
- 외상 가능성과 경추 손상을 고려하고, 의식수준과 동공·편측 신경학적 소견을 반복 기록한다.

### 2. 놓치면 안 되는 질환
- [[허혈성 뇌졸중 (Ischemic stroke)]]·뇌출혈·[[지주막하 출혈 (Subarachnoid hemorrhage)]] : 갑작스러운 신경학적 변화
- [[세균성 뇌수막염 (Bacterial Meningitis)]]·뇌염·[[패혈증 (Sepsis)]] : 발열, 경부강직, 발진, 쇼크
- 저혈당·DKA/HHS·전해질 이상·간성 또는 요독성 뇌병증
- [[중독 (Poisoning)]] : 약물 접근성, toxidrome, 비정상 체온·동공·호흡
- 비경련성 간질지속상태 : 설명되지 않는 지속 혼돈, 미세한 안구·안면 운동
- 일산화탄소 노출 : 동시 다발 환자, 밀폐공간·연소기구 노출

### 3. 초기 검사
- 혈당, 심전도, CBC, 전해질·신장·간기능, 혈액가스와 독성검사를 임상 단서에 맞춰 시행한다.
- 급성 국소신경학적 이상, 두부외상, 출혈 위험 또는 원인 불명 깊은 의식저하는 응급 뇌영상이 필요하다.
- 감염이 의심되면 배양과 항균치료를 준비하며, 요추천자 전 영상 필요성을 판단하되 치료를 지연하지 않는다.
- 원인 불명 지속 의식장애는 EEG를 포함해 비경련성 발작을 평가한다.

### 4. 초기 처치 및 재평가
- 교정 가능한 원인을 치료하고, 원인 불명 혼수는 기도·환기·혈역학을 유지하며 병렬 평가한다.
- 진정제 투여 전 가능한 신경학적 기준선을 기록하고 체온·소변량·검사 추세를 재평가한다.
- 중독 의심 시 독극물정보센터 또는 임상독성 전문가와 조기에 상의한다.

### 5. Disposition
- 기도 보호 불가, 지속 의식저하, 뇌졸중·감염·대사·중독 응급은 입원 또는 중환자 치료가 필요하다.
- 일시적 원인이 완전히 교정되고 재발 위험과 안전한 보호 환경이 확인된 경우에만 퇴원을 고려한다.

### 6. ER 함정
- 알코올 냄새나 정신과 병력이 있어도 구조적·대사성 원인을 먼저 배제한다.
- 정상 활력징후와 정상 단일 CT만으로 중독, 감염, 발작 후 상태를 배제할 수 없다.
