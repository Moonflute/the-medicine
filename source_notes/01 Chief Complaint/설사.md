# 설사

## Concept
설사는 급성·지속성 경과와 수양성·염증성 양상을 구분하고 탈수, 혈변, 면역저하, 최근 항생제·여행 노출을 함께 본다.

## 감별진단
소화기 : 식중독, 급성 위장염, 염증성 장질환, 허혈 결장염 (염증) / 단장증후군, 과민성 대장증후군, 젖당불내성 (생리적) / 결장암, 직장암 (암)
기타 : 갑상샘 항진증, 약물 유발 (PMC)

## 환자교육
검사 : 직장항문기능검사, 혈액검사, 내시경
치료
교육 : 지사제를 사주 사용하면 악영향 있을 수 있음
	탈수 증상, 고열, 복통 발생 시 병원 내원, 생활습관 개선

설사 + 구토 + 복통 + 발열 + 탈수 + 음식섭취 관련 + 복부 압통
= 식중독, 급성 위장염 / 대변배양검사 / 수액, 항생제

설사 + 혈변 + 복통 + 체중 감소 + 탈수 + 복부 압통 + 장음 감소
= 염증성 장질환 / 대장내시경, 대장조영술, CT / steroid, 영양공급

혈변 + 복통 + 심혈관계 기저질환 + LQ Td
= 허혈 결장염 / 대장내시경, AXR / 수액, 항생제, 금식

설사 + 변비 + 혈변 + 대변 가늘어짐 + 체중 감소 + 피로 + DRE 종괴
= 결장암, 직장암 / 대장내시경, US, CT, MRI / 수술, RTx, CTx

설사 + 장절제 수술력 + 기타 정상
= 단장증후군 / US, AXR / TPN, 지사제, cholestyramine

설사 + 변비 + 복부 팽만 + 소화불량 + 배변 후 호전 + 점액질 변
= 과민 대장증후군 / 대변검사, 대장내시경, CBC / 생활 습관 교정, 완하제

설사 + 우유 마시면 속이 불편
= 젖당불내성 / 수소날숨검사, 젖당부하검사 / 유당회피요법

설사 + 체중감소 + 심계항진 + 더위불내성
= 갑상샘항진증 / TFT / propylthiouracil, methimazole

설사 + 항생제/제산제/변비약
= 약물 유발 설사 / 대변검사, 독소검사 / 약물 중단 및 교체

## 관련질환
[[결장직장암 (Colorectal Cancer)]], [[중독 (Poisoning)]]

## 접근
- 횟수·혈액, 복통·발열과 최근 항생제·tube feeding·laxative를 확인하고 C. difficile, medication-induced diarrhea, overflow와 neutropenic enterocolitis를 구분한다.
## 검사
- laxative를 중단하고 CBC·BMP를 중증도에 따라 시행한다. 새 설명되지 않는 3회 이상 unformed stool이면 contact precaution과 C. difficile 검사를 적용한다.
## 치료
- 수분·K·Mg를 보충한다. 감염성·염증성 설사, ileus에서는 Loperamide를 피하고, 위험 원인이 배제된 수양성 설사에만 Loperamide (로페라미드 제품) 4 mg 후 매 묽은 변마다 2 mg, 최대 16 mg/day를 단기간 사용한다.

## ER

### 1. 즉시 평가 및 안정화
- 탈수·쇼크, 의식, 소변량과 전해질 이상을 평가하고 수액·격리 필요성을 판단한다.
- 혈성 설사, 고열, 심한 복통·복막자극, 면역저하, 고령·영아는 고위험이다.

### 2. 놓치면 안 되는 질환
- 패혈증·침습성 세균감염
- C. difficile 중증 대장염·독성 거대결장
- 장간막허혈·허혈성 대장염
- 용혈요독증후군
- 염증성 장질환 중증악화와 약물·중독

### 3. 초기 검사
- CBC, 전해질·신장기능과 lactate는 중증·탈수 환자에서 시행한다.
- 혈성·중증·지속 설사, 면역저하 또는 공중보건 필요성이 있을 때 대변검사를 선택한다.
- 복막자극·팽만·허혈이 의심되면 영상검사를 시행한다.

### 4. 초기 처치 및 재평가
- 경구 또는 정맥 재수화와 전해질 교정이 중심이다.
- 항균제와 지사제는 원인·중증도와 금기를 확인해 선택하며 혈성 설사·독성 대장염에서 일률적으로 사용하지 않는다.
- 활력징후, 소변량과 경구섭취를 재평가한다.

### 5. Disposition
- 쇼크, 중증 탈수·AKI, 독성 대장염·허혈·HUS 의심은 입원한다.
- 재수화 후 안정되고 경구섭취와 추적이 가능할 때 퇴원을 고려한다.

### 6. ER 함정
- 바이러스성 위장염으로 단정하기 전에 최근 항생제·입원, 여행, 혈변과 집단발생을 확인한다.
- 설사와 복통이 적어도 고령·면역저하자는 중증 감염일 수 있다.
