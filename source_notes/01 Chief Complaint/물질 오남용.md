## 환자교육
V/S 환자 상태 - 의존 정도 평가, 간기능, 신기능 검사
격려 / 칭찬
치료 권유 / 치료 설명 / 치료 효과
위험성, 응급 상황 교육, 다음 방문질문

진정제 (로라제팜 - 아티반)
: 졸음, 주의력 감퇴, 비현실감, 이인증 / 호흡마비, 혼수, 의식저하, 저혈압
: 불안, 경련, 섬망, ANS 항진 / flumazenil, 위세척, 활성탄, 수액

각성제 (메트암페타민 - 필로폰, 다이어트약 - 푸링, 엑스터시)
: 능률, 성욕 증가, 불안, 착란, 동곤 산동, 고열 / 교감 항진, 오심, 구토
: 우울, 피로, 불쾌, 불안, 과수면 / 경하면 대증요법, haloperidol, SSRI

코카인
: 능률, 성욕 증가, 불안, 착단 / 비중격 천공, 호흡기계 손상
: 우울, 불쾌, 불안, 과수면 / 암페타민, TCA, bromocriptine

아편계 (메페리딘 - 데메롤, 모르핀)
: 고통 경감, 졸음, 정신운동 지연, 식욕 저하 / 부교감 항진
: 교감 저하, 통증, 오심, 구토, 발열, 소름 / Naloxone, Methadone

대마초 (마리화나)
: 이완, 지각 예민 / 결막 충혈, 식욕 증가, 무욕증후군
: 금단 증상 없음 / BZD, haloperidol

환각제 (LSD)
: 지각 풍부, 현실감 상실 / 무욕증후군
: 금단 증상 없음 / BZD, haloperidol

흡입제 (본드)
: 다행감, 붕 뜸, 공포, 환각 / 오심, 식욕 상실, 납중독, 안구진탕
: 금단 증상 없음 / 흡입 중단

비마약 진통제 (NSAID, aspirin)
: 자살 시도 / 속쓰림, 위궤양, 신기능 저하, 빈맥, 발열, 의식저하, 호흡곤란
: 금단 증상 없음 / 약물 중단, 위세척, 활성탄

스테로이드 (헬스 약)
: 남성 호르몬 과다 증상 / 여드름, 여성형 유방, 발기부전, 탈모
: 우울하고 나른해짐 / 약물 중단

마취제 (프로포폴)
: 진정, 황홀감, 도취감, 회복감 / 기억 상실, 무의식, 호흡곤란, 심박 저하
: 불안, 불면 / 약물 중단, 호흡 보조
