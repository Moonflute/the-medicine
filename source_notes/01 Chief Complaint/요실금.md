# 요실금

## Concept
요실금은 일시적 유발요인을 먼저 배제하고 복압성, 절박성, 범람성, 기능성 양상으로 나누어 접근한다.

## 감별진단
소변 저장 문제 : 복압 요실금, 절박 요실금
소변 배출 문제 : 범람 요실금, 신경성 요실금
기타 : 과민 방광, 약물유발, 알코올 유발, 일시적 요실금

= 복압 요실금 / 소변검사, 요역동학검사 / 케겔 운동, AA, 수술

= 절박 요실금 / 소변검사, 요역동학검사, 방광내압 측정술 / 행동 치료, 약물 치료

요실금 + 요도 협착.당뇨신경병/전립샘 비대증/파킨슨병
= 범람 요실금, 신경성 요실금 / 요역동학검사, 직장경유초음파 / 카테터 

빈뇨 + 추운 날씨에서 악화 + 절박뇨 + 야간뇨
= 과민 방광 / 소변검사, 요역동학검사 / 케겔 운동, 방광 훈련

## 콜 접수
- 기존 요실금과 새 발생 여부, 배뇨량·빈도, 배뇨통·발열, 의식 변화, Foley 제거·이뇨제 투여 시각과 보행/화장실 접근성을 확인한다.

## 위험 판단
- 방광 팽만·소량 반복 실금은 overflow retention 가능. 새 의식저하·발열·저혈압 또는 급격한 Cr 상승이면 단순 패드/약물 처방에 앞서 원인 평가.

## 원인 감별·추가검사
- **Bladder scan post-void residual**, 증상성 감염 단서가 있으면 **소변검사**, 필요 시 **혈당·Cr**를 확인한다. 섬망·이동 제한·변비·약물 원인을 구분한다.

## 처치
### 즉시 조치
- 요저류가 확인되면 배액 여부를 판단하고 피부 손상·낙상을 예방한다.
### 원인 치료
- 배뇨 일정·이동 도움, 이뇨제 투여 시각, 변비와 섬망 유발 원인을 교정한다. Oxybutynin 등 항콜린제는 급성 병동에서 섬망·저류 악화 위험으로 경험적으로 시작하지 않는다.

## 경과관찰
- 실금 횟수·잔뇨량·피부 상태와 배뇨 시도를 기록한다. 요저류·감염 징후가 새로 생기면 재평가한다.
