# 요실금

## Concept
요실금은 일시적 유발요인을 먼저 배제하고 복압성, 절박성, 범람성, 기능성 양상으로 나누어 접근한다.

## 감별진단
소변 저장 문제 : 복압 요실금, 절박 요실금
소변 배출 문제 : 범람 요실금, 신경성 요실금
기타 : 과민 방광, 약물유발, 알코올 유발, 일시적 요실금

요실금 + 재채기/기침/운동 시 발생 + 분만력 + 자궁탈출증
= 복압 요실금 / 소변검사, 요역동학검사 / 케겔 운동, AA, 수술

요실금 + 소변이 마려울 때 참지 못함 + 빈뇨 + 야뇨 + 방광 결석
= 절박 요실금 / 소변검사, 요역동학검사, 방광내압 측정술 / 행동 치료, 약물 치료

요실금 + 요도 협착.당뇨신경병/전립샘 비대증/파킨슨병
= 범람 요실금, 신경성 요실금 / 요역동학검사, 직장경유초음파 / 카테터 

빈뇨 + 추운 날씨에서 악화 + 절박뇨 + 야간뇨
= 과민 방광 / 소변검사, 요역동학검사 / 케겔 운동, 방광 훈련

## 접근
- baseline과 새 발생을 구분하고 delirium, UTI, diuretic, mobility barrier, constipation과 overflow retention을 확인한다.
## 검사
- bladder scan post-void residual, 증상이 있을 때 urinalysis, 단서에 따라 glucose·Cr를 확인한다.
## 치료
- scheduled toileting, 이동 도움, diuretic timing과 constipation을 교정한다. oxybutynin 등 anticholinergic은 delirium·retention을 악화할 수 있어 급성 병동에서 경험적으로 시작하지 않는다.
