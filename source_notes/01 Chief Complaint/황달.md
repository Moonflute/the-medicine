# 황달

## Concept
황달은 비결합형과 결합형 빌리루빈 상승을 구분하고 간세포성·담즙정체성 양상과 급성 간기능부전 징후를 함께 본다.

## 감별진단
간 : 급성 바이러스/독성/알코올성 간염, 간경화/간암, 윌슨병, 길버트 증후군
담 : 급성 담낭염, 담관염, 담관암
췌 : 만성 췌장염, 췌두부암
기타 : 용혈성 질환 / 감염 단핵구증, 가성 황달

## 환자교육
검사 : 혈액 검사
치료 : 안정, 수액요법, 항바이러스제 등
교육 : 생활 습관 개선 (한약 등 섭취 자제, 예방접종)

미열 + 피로 + 관절/근육통 + 여행력/성 접촉 + RUQ 압통 + 간비대
= 바이러스 간염 / LFT, 간염항체검사 / 수액 정주, 영양 공급, 간이식

미열 + 피로 + 관절/근육통 + 한약/건강식품/약물
= 독성 간염 / LFT / 원인 약물 중단, 간이식

피로 + 체중감소 + 복수 + 음주 + RUQ pain + angioma + tremor
= 알코올성 간염-간경화증-간암 / LFT, CT, 혈액검사 				/ 금주, 영양 공급, 복수 조절, 간이식

신경학적 이상 + 어린 나이 + 가족령 + KF ring
= 윌슨병 / 혈중 셀룰로플라스민, 소변 Cu / 약물, 간이식, 섭취제한

스트레스 상황 (운동, 피로, 금식) + 가족성
= 길버트 증후군 / LFT / 안심시키기, 원인 요소 관리

발열 + 오한 + RUQ pain + Murphy’s sign (+)
= 급성 담낭염 / LFT, US, CT / 항생제, 담낭절제술, 경피적담낭배액술

발열 + 오한 + RUQ pain + 민물고기 섭취
= 담관염 / LFT, US, MRI, ERCP / 항생제 내시경, 경피적담관배액술

체중 감소 + Courvoisier’s sign
= 담관암, 췌두부암 / 내시경역행담췌관조영, CT, MRI / 수술, 항암

복통 (숙이면 완화) + 소화불량 + 지방변 + 음주 + 담석
= 만성 췌장염 / CT, US, amylase, lipase / 금주, 진통제, 췌장 효소 공급

호흡곤란 + 어지럼 + 쉽게 멍듬
= 용혈성 질환 / CBC, LFT, 말초혈액도말검사 / 비장절제술, 스테로이드

공막 황달 (-)
= 가성 황달 / LFT / 없음

## 접근
- bilirubin의 입원 기준치와 상승속도, 수술·TPN·수혈·새 약물, 복통·발열·저혈압과 pruritus를 확인한다. cholangitis, drug-induced liver injury, hemolysis, sepsis-associated cholestasis와 hepatic failure를 구분한다.
- 발열·RUQ pain·저혈압·의식변화가 동반되면 acute cholangitis로 항균제와 긴급 biliary drainage를 준비한다.
## 검사

- 다른 원인으로 설명되지 않는 급성 간염에서는 노출력과 역학을 고려해 E형 간염도 감별하며 anti-HEV IgM과 HEV RNA 검사를 검토한다. 특히 면역억제 환자는 항체가 검출되지 않을 수 있어 음성 항체만으로 배제하지 않고 RNA 검사로 현재 감염을 평가한다. 장기이식 등 면역억제 상태에서는 지속 감염 가능성도 고려하여 전문 진료로 연결한다.
- 급성 간염을 의심하는 증상·노출력이 있으면 IgM anti-HAV로 A형 간염을 평가한다. Total anti-HAV 또는 IgG anti-HAV 양성만으로 현재 황달의 원인을 급성 A형 간염으로 판단하지 않는다.
- 급성 B형 간염이 의심되면 HBsAg와 IgM anti-HBc를 확인하고 이전 HBV 검사·감염력과 비교한다. HBsAg는 급성·만성 감염 모두에서 양성일 수 있으며, IgM anti-HBc도 만성 HBV의 심한 악화나 재활성화에서 양성일 수 있어 단독 결과만으로 새 감염을 확정하지 않는다.
- 간세포 손상 양상의 황달에서는 급성·만성 경과와 노출력을 함께 확인해 바이러스간염 검사를 선택한다. HCV 항체 양성은 현재 감염을 확정하지 않으므로 HCV RNA로 확인한다. 최근 6개월 이내 노출 가능성이나 급성 HCV 의심이 있으면 항체 음성이라도 RNA 검사가 필요하다.
- 이전 간검사와 증상 시작 시점을 확인하되, 급성·만성을 나누기 위해 6개월을 기다리지 않는다. 중증도와 진행 양상에 따라 원인 검사와 전문 평가를 바로 진행한다.
- total/direct bilirubin, AST/ALT, ALP/GGT, INR, albumin, CBC, hemolysis panel과 acetaminophen 노출을 확인한다. RUQ ultrasound를 우선하고 폐색 의심 시 MRCP/CT/ERCP를 선택한다.
## 치료
- 의심 간독성 약물과 불필요한 hepatotoxic agent를 중단한다. cholangitis는 배양 후 원내 담도감염 항균제를 신속히 시작하고 ERCP source control을 지연하지 않는다.
- INR 상승, hypoglycemia, encephalopathy가 있는 acute liver failure이면 ICU·간이식센터에 즉시 연락한다. 단순 bilirubin 감소 목적의 약물은 사용하지 않는다.

## ER

### 1. 즉시 평가 및 안정화
- 활력징후, 의식, 출혈, 저혈당과 복통·발열을 확인한다.
- 발열·우상복부통·황달에 저혈압·의식 변화가 동반되면 급성 담관염과 패혈증으로 신속히 치료한다.

### 2. 놓치면 안 되는 질환
- 급성 담관염·담도폐쇄
- 급성 간부전 : 황달과 응고장애·뇌병증
- 독성·약물성 간손상, 특히 acetaminophen
- 용혈과 DIC
- 급성 바이러스간염·패혈증성 담즙정체

### 3. 초기 검사
- AST/ALT, ALP/GGT, bilirubin 분획, PT/INR, 혈당, CBC·신장기능을 시행한다.
- 복통·담도폐쇄 의심은 우상복부 초음파를 우선하고 필요 시 CT·MRCP·ERCP 경로를 적용한다.
- 급성 간손상은 약물농도와 바이러스·자가면역 검사를 임상 단서에 따라 선택한다.

### 4. 초기 처치 및 재평가
- 담관염은 항균치료와 긴급 담도배액을 준비한다.
- 급성 간부전은 저혈당·뇌부종·출혈 위험을 관리하고 간이식 가능 기관과 조기에 협의한다.
- 의식, 혈당, INR, 신장기능과 산증을 반복 평가한다.

### 5. Disposition
- 담관염, 급성 간부전, 진행 응고장애·신손상은 입원한다.
- 안정적인 만성 황달이라도 새 폐쇄·종양 가능성이 있으면 신속 전문 평가를 연결한다.

### 6. ER 함정
- AST/ALT가 감소해도 광범위 간괴사에서 상태가 악화될 수 있어 INR·의식과 함께 본다.
- 황달이 뚜렷하지 않아도 초기 담관염·간부전이 가능하다.
