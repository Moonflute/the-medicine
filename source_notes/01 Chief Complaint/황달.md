# 황달

## Concept
‘탈수, 출혈’  주로 간담췌지만 시간이 부족하고 진단도 애매..

## 감별진단
간 : 급성 바이러스/독성/알코올성 간염, 간경화/간암, 윌슨병, 길버트 증후군
담 : 급성 담낭염, 담관염, 담관암
췌 : 만성 췌장염, 췌두부암
기타 : 용혈성 질환 / 감염 단핵구증, 가성 황달

## 환자교육
검사 : 혈액 검사
치료 : 안정, 수액요법, 항바이러스제 등
교육 : 생활 습관 개선 (한약 등 섭취 자제, 예방접종)

미열 + 피로 + 관절/근육통 + 여행력/성 접촉 + RUQ 압통 + 간비대
= 바이러스 간염 / LFT, 간염항체검사 / 수액 정주, 영양 공급, 간이식

미열 + 피로 + 관절/근육통 + 한약/건강식품/약물
= 독성 간염 / LFT / 원인 약물 중단, 간이식

피로 + 체중감소 + 복수 + 음주 + RUQ pain + angioma + tremor
= 알코올성 간염-간경화증-간암 / LFT, CT, 혈액검사 				/ 금주, 영양 공급, 복수 조절, 간이식

신경학적 이상 + 어린 나이 + 가족령 + KF ring
= 윌슨병 / 혈중 셀룰로플라스민, 소변 Cu / 약물, 간이식, 섭취제한

스트레스 상황 (운동, 피로, 금식) + 가족성
= 길버트 증후군 / LFT / 안심시키기, 원인 요소 관리

발열 + 오한 + RUQ pain + Murphy’s sign (+)
= 급성 담낭염 / LFT, US, CT / 항생제, 담낭절제술, 경피적담낭배액술

발열 + 오한 + RUQ pain + 민물고기 섭취
= 담관염 / LFT, US, MRI, ERCP / 항생제 내시경, 경피적담관배액술

체중 감소 + Courvoisier’s sign
= 담관암, 췌두부암 / 내시경역행담췌관조영, CT, MRI / 수술, 항암

복통 (숙이면 완화) + 소화불량 + 지방변 + 음주 + 담석
= 만성 췌장염 / CT, US, amylase, lipase / 금주, 진통제, 췌장 효소 공급

호흡곤란 + 어지럼 + 쉽게 멍듬
= 용혈성 질환 / CBC, LFT, 말초혈액도말검사 / 비장절제술, 스테로이드

공막 황달 (-)
= 가성 황달 / LFT / 없음

## ER

### 1. 즉시 평가 및 안정화
- 활력징후, 의식, 출혈, 저혈당과 복통·발열을 확인한다.
- 발열·우상복부통·황달에 저혈압·의식 변화가 동반되면 급성 담관염과 패혈증으로 신속히 치료한다.

### 2. 놓치면 안 되는 질환
- 급성 담관염·담도폐쇄
- 급성 간부전 : 황달과 응고장애·뇌병증
- 독성·약물성 간손상, 특히 acetaminophen
- 용혈과 DIC
- 급성 바이러스간염·패혈증성 담즙정체

### 3. 초기 검사
- AST/ALT, ALP/GGT, bilirubin 분획, PT/INR, 혈당, CBC·신장기능을 시행한다.
- 복통·담도폐쇄 의심은 우상복부 초음파를 우선하고 필요 시 CT·MRCP·ERCP 경로를 적용한다.
- 급성 간손상은 약물농도와 바이러스·자가면역 검사를 임상 단서에 따라 선택한다.

### 4. 초기 처치 및 재평가
- 담관염은 항균치료와 긴급 담도배액을 준비한다.
- 급성 간부전은 저혈당·뇌부종·출혈 위험을 관리하고 간이식 가능 기관과 조기에 협의한다.
- 의식, 혈당, INR, 신장기능과 산증을 반복 평가한다.

### 5. Disposition
- 담관염, 급성 간부전, 진행 응고장애·신손상은 입원한다.
- 안정적인 만성 황달이라도 새 폐쇄·종양 가능성이 있으면 신속 전문 평가를 연결한다.

### 6. ER 함정
- AST/ALT가 감소해도 광범위 간괴사에서 상태가 악화될 수 있어 INR·의식과 함께 본다.
- 황달이 뚜렷하지 않아도 초기 담관염·간부전이 가능하다.

근거: Tintinalli's Emergency Medicine Manual, 8e, Ch. 48; 최신 담관염·급성간부전 공식 지침과 함께 적용.
