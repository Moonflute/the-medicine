# 실신

## Concept
'CV+NR’ 경련 아닌지 확인, 전-중-후 중심으로 문진

## 감별진단
신경계 : (ANS) 혈관미주신경실신, 기립성 저혈압, 배뇨 실신 / (CNS) 지주막하출혈, 일과성 허혈 발작
순환계 : 심근경색증, 비대심근병증, 부정맥, 빈혈, 대동맥박리
기타 : 저혈당 쇼크 / 공황장애, 과다환기증후군

## Hx

### O / L / D / Co / Ex (Onset, Location, Duration, Course, Experienced)

### C (Character)
#### CC-specific
- 실신 전 : 눈앞 캄캄, 메스꺼움, 식은땀, 어지럼
- 실신 중 : 경련 배제 (눈 돌아감, 혀 깨물, 팔다리 떨림, 변실, 요실)
- 실신 후 : 심한 두통, 피로, 손발저림

### A (Associated symptoms)
#### CC-specific
- 두통, 구토, 말어눌, 힘빠짐
- Dyspnea
- Palpitation
- P
- 출혈, 탈수력
- 불안, 숨헐떡임

### F (Factor)
#### CC-specific
- 오래 서 있기, 소변 or 대변 중, 기침, 음식, 일어서다 / 누워서 호전

### E (Event)

### 외과력
#### CC-specific

## PEx
두부 외상 시진
V/S 눈 입 목(경동맥 청진)
뇌신경검사
흉부 : 심음 청진, 맥박 측정 (순환기 의심 시)
복부 : 시 – 청 – 타 – 촉 (소화기 의심 시)
수막 자극 징후
사지 (근력/감각/DTR)

## 환자교육
검사 : 24hr 혈압측정
치료 : 약물 치료, pacemaker
교육 : 상황 주의, 금주, 주변인 교육, 전조 증상 시 휴식

전구 증상 + 덥거나 오래 서 있는 스트레스 상황 실신
= 혈관미주신경실신 / 심전도, 기립경사검사 / 상활 회피, BB, 혈관수축제

갑자기 일어서다가 실신 (+ 저혈량 증상)
= 기립 저혈압 / 기립경사검사 (3분) / 천천히 일어나기, 수분 섭취, 약제

배뇨 중이나 직후에 실신
= 배뇨 실신 / … / 일어나기 전 잠시 앉아 있기, 자기 전 소변 보기

흉통 + 호흡곤란 + 심잡음 + 경정맥 확장 + 수포음
= 심근경색증 / EKG, 심근효소검사, angio / 관상동맥재개통술, aspirin, BB

운동 중 실신 + 호흡곤란 + 젊은 나이 + 급사력 + valsalva 심잡음 증가
= 비대심근병증 / EKG, echo / BB, CCB, 운동 금지, 수술

두근거림 후 실신 + 맥박 이상
= 부정맥 / EKG, 24hr holter / BB, CCB

피로 + 어지럼 + 호흡곤란 + 위절제술 병력 + 결막 창백
= 빈혈 / CBC, PBS, ferritin / 빈혈 원인 치료

의식소실 + 찢어지는 흉통 + 어지럼 + 호흡곤란
= 대동맥박리 / CT, X-ray / 응급수술, BB

의식소실 + 극심한 두통 + 구토 + 고혈압
= 지주막하출혈 / CT, CSF, brain angio / 뇌동맥결찰술, 혈압 조절, shunt

의식소실 + 마비 + 저림 + 언어장애 + 24시간 내 회복
= 일과성 허혈 발작 / CT, MRI, echo, EKG / 항혈소판제, 항응고제

실신 + 두근거림 + 떨림 + 식은땀 + 당뇨병 병력
= 저혈당 쇼크 / 혈당, 전해질검사, 요중 케톤 / 사탕, 5% dextrose 용액

실신 전 불안함 느낌
= 공황장애, 과환기증후군 / … / 인지 행동 치료, SSRI
