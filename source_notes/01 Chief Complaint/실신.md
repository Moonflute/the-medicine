# 실신

## Concept
실신은 일시적 의식소실과 자발적 회복이 있었는지 확인하고 전·중·후 경과로 경련과 구분하며 운동 중 발생은 심인성을 우선한다.

## 감별진단
신경계 : (ANS) 혈관미주신경실신, 기립성 저혈압, 배뇨 실신 / (CNS) 지주막하출혈, 일과성 허혈 발작
순환계 : 심근경색증, 비대심근병증, 부정맥, 빈혈, 대동맥박리
기타 : 저혈당 쇼크 / 공황장애, 과다환기증후군

## 환자교육
검사 : 24hr 혈압측정
치료 : 약물 치료, pacemaker
교육 : 상황 주의, 금주, 주변인 교육, 전조 증상 시 휴식

전구 증상 + 덥거나 오래 서 있는 스트레스 상황 실신
= 혈관미주신경실신 / 심전도, 기립경사검사 / 상활 회피, BB, 혈관수축제

갑자기 일어서다가 실신 (+ 저혈량 증상)
= 기립 저혈압 / 기립경사검사 (3분) / 천천히 일어나기, 수분 섭취, 약제

배뇨 중이나 직후에 실신
= 배뇨 실신 / … / 일어나기 전 잠시 앉아 있기, 자기 전 소변 보기

흉통 + 호흡곤란 + 심잡음 + 경정맥 확장 + 수포음
= 심근경색증 / EKG, 심근효소검사, angio / 관상동맥재개통술, aspirin, BB

운동 중 실신 + 호흡곤란 + 젊은 나이 + 급사력 + valsalva 심잡음 증가
= 비대심근병증 / EKG, echo / BB, CCB, 운동 금지, 수술

두근거림 후 실신 + 맥박 이상
= 부정맥 / EKG, 24hr holter / BB, CCB

피로 + 어지럼 + 호흡곤란 + 위절제술 병력 + 결막 창백
= 빈혈 / CBC, PBS, ferritin / 빈혈 원인 치료

의식소실 + 찢어지는 흉통 + 어지럼 + 호흡곤란
= 대동맥박리 / CT, X-ray / 응급수술, BB

의식소실 + 극심한 두통 + 구토 + 고혈압
= 지주막하출혈 / CT, CSF, brain angio / 뇌동맥결찰술, 혈압 조절, shunt

의식소실 + 마비 + 저림 + 언어장애 + 24시간 내 회복
= 일과성 허혈 발작 / CT, MRI, echo, EKG / 항혈소판제, 항응고제

실신 + 두근거림 + 떨림 + 식은땀 + 당뇨병 병력
= 저혈당 쇼크 / 혈당, 전해질검사, 요중 케톤 / 사탕, 5% dextrose 용액

실신 전 불안함 느낌
= 공황장애, 과환기증후군 / … / 인지 행동 치료, SSRI

## 접근
- 실제 의식소실과 회복시간, 자세·배뇨·통증, telemetry event를 확인하고 부정맥, 출혈, PE, ACS, seizure, orthostatic hypotension과 약물 원인을 본다. 낙상 손상과 항응고 여부를 동시에 평가한다.
- 운동 중 실신, 비정상 ECG, 지속 저혈압, 흉통·호흡곤란, 새 심잡음 또는 가족 돌연사는 monitored evaluation 대상이다.
## 검사
- orthostatic BP, 12유도 ECG, bedside glucose, CBC·electrolytes를 기본 단서에 따라 시행하고 telemetry를 검토한다. troponin, echo, CTPA, brain imaging은 임상 가설에 따라 선택한다.
## 치료
- 저혈량이면 balanced crystalloid (하트만액·Plasma Solution A 등) 250–500 mL IV 후 orthostatic 증상·폐진찰을 재평가한다. 원인 약물과 과도한 이뇨·혈압약을 조정한다.
- 부정맥·출혈·PE·ACS는 원인 치료로 전환한다. 정상 CT나 일시적 회복만으로 고위험 실신의 모니터링을 종료하지 않는다.

## ER

### 1. 즉시 평가 및 안정화
- 실제 일시적 의식소실인지 확인하고 ABC, 활력징후, 혈당, 외상 여부를 우선 평가한다.
- 지속 저혈압, 흉통, 호흡곤란, 신경학적 결손, 활동성 출혈 또는 위험 부정맥이 있으면 원인별 소생을 시작한다.
- 모든 환자에서 자세한 사건 전후 병력, 심혈관 진찰과 12유도 심전도를 확보한다.

### 2. 놓치면 안 되는 질환
- 치명적 부정맥·구조적 심질환 : 운동 중 실신, 전구증상 없음, 심계항진, 비정상 ECG, 돌연사 가족력
- [[ST분절 상승 심근경색증 (STEMI) (ST-Elevation Myocardial Infarction)]]·[[대동맥 박리 (Aortic Dissection)]]·[[폐색전증 (Pulmonary Embolism)]] : 흉통, 호흡곤란 또는 쇼크 동반
- 지주막하출혈·뇌졸중 : 돌발 두통, 지속 신경학적 이상
- 출혈·자궁외임신 : 위장관 출혈, 질출혈, 임신 가능성과 저혈량 소견
- 경련 : 장시간 혼돈, 혀 외측 손상, 목격된 강직간대운동

### 3. 초기 검사
- 12유도 심전도는 필수이며, 혈당·혈색소·전해질·troponin·임신반응검사는 임상 단서에 따라 시행한다.
- 기립 활력징후는 안정 환자에서 보조적으로 사용하되 정상 결과로 중증 원인을 배제하지 않는다.
- 심초음파, 지속 심전도 감시, CT는 심질환·출혈·신경학적 질환이 의심될 때 선택한다.
- 신경학적 이상이나 두부외상 단서가 없는 단순 실신에 일률적 뇌 CT를 시행하지 않는다.

### 4. 초기 처치 및 재평가
- 저혈량, 출혈, 부정맥, ACS, 폐색전증 등 확인된 원인을 치료한다.
- 회복 후 보행 가능 여부, 반복 증상, 활력징후와 ECG 변화를 재평가한다.
- 위험도 도구는 임상 판단을 보조할 뿐 고위험 단서를 대체하지 않는다.

### 5. Disposition
- 비정상 ECG, 심장질환, 운동 중 실신, 가족력, 지속 활력징후 이상, 중증 빈혈·출혈은 관찰 또는 입원이 필요하다.
- 명확한 미주신경성·기립성 실신이고 고위험 소견이 없으며 회복이 완전할 때 퇴원을 고려한다.
- 원인 불명이나 반복 실신은 조기 외래 평가 또는 리듬 모니터링 계획을 마련한다.

### 6. ER 함정
- 고령자의 낙상은 기억되지 않은 실신일 수 있다.
- 경련성 움직임이 있었다는 사실만으로 간질로 단정하지 않으며, 부정맥성 실신에서도 짧은 근간대가 나타날 수 있다.
