# 구토

## Concept
‘탈수’, 크게 신경계문제 or 위장관문제

## 감별진단
신경 : 양성돌발체위현기증, 뇌수막염, 뇌/거미막밑출혈
정신 : 신경성 폭식증, 신경성 식욕부진
소화 : 위염, 위궤양, 십이지장궤양, 위암, 장폐색증 (유문부 폐쇄) 식중독, 급성 위장염, 급성 담낭염
기타 : 임신, 요독증, (소아의 날문협착증, 장중첩증 )

소아 + 분출성 구토 + 토하고 먹으려 함
= 날문협착증 / US / 날문근절개술, 복부초음파

= 장중첩증 / 복부초음파 / 공기정복술, 바륨정복술, 응급 수술

구토 + 메스꺼움 + 어지럼증 + Dix-Hallpike (+)
= 양성돌발체위현기증 / Dix / Epley maneuver

구토 + 두통 + 발열 + 경부 강직 + 수막 자극 징후
= 뇌수막염 / 뇌 CT, CSF 천자 / Cefotaxime + Vancomycin

구토 + 두통 + 의식저하 + 외상 + 수막 자극 징후 + 신경학적 이상
= 뇌출혈, 거미막밑출혈 / 뇌 CT, CSF 천자 / 개두술, 혈종제거술

고의적 구토 + 젊은 여성 + 체형에 대한 인식
= 신경성 폭식증, 식욕부진 / … / 인지 행동 치료, SSRI

구토 + 발열 + 복통 + 설사 + 탈수 + 상한음식 + 복부 압통 + 주변인도
= 식중독, 급성 위장염 / CBC, 전해질검사, 대변배양검사 / 수액, 항생제

구토 + 발열 + 복통 + 소화불량 + 식후 악화 + Murphy (+)
= 급성 담낭염 / CT, US, LFT / 담낭절제술, 항생제, 경피적 담낭배액술

구토 + 복통 + 속쓰림 + 신물 + 식후 악화 + 식사와 관련
= 소화기 궤양 / 위내시경, 요소날숨검사 / PPI, 제산제, 위점막보호제

구토 + 체중 감소 + 빈혈 + 흑색변 + 림프절 비대
= 위암 / 위내시경 / 위절제술, EMR

구토 + 식후 복통 + 복부 수술력
= 장폐색증 / AXR / 코위관, 전해질 교정, 수술

## ER

### 1. 즉시 평가 및 안정화
- 탈수·쇼크, 의식저하와 흡인 위험을 확인하고 혈당을 측정한다.
- 심한 복통·팽만, 혈성 또는 담즙성 구토, 두통·신경학적 이상, 임신 가능성, 독성 노출을 즉시 선별한다.
- 필요하면 정맥 수액과 항구토를 시작하고 전해질 이상을 교정한다.

### 2. 놓치면 안 되는 질환
- [[장폐색]]·장염전·천공 : 복부팽만, 배변·가스 중단, 복막자극
- 두개내압 상승·뇌출혈·뇌수막염 : 두통, 의식 변화, 신경학적 이상
- DKA·부신위기 등 대사응급 : 다뇨, 체중감소, 저혈압, 산증 소견
- ACS : 고령자·당뇨병 환자의 오심·구토와 상복부 불편감
- 임신오조·자궁외임신 : 임신 가능성과 복통·질출혈
- [[중독 (Poisoning)]] : 약물·화학물질 노출, 비정상 활력징후·의식

### 3. 초기 검사
- 전해질·신장기능·혈당·ketone·lipase·간기능·소변·임신반응검사를 임상 단서에 따라 선택한다.
- 심혈관 위험 또는 상복부 증상이 있으면 심전도와 troponin을 고려한다.
- 폐색·천공·국소 복막염이 의심되면 적절한 복부 영상검사를 시행한다.
- 두부 영상은 신경학적 단서, 두부외상 또는 두개내압 상승 의심 시 선택한다.

### 4. 초기 처치 및 재평가
- 원인별 치료와 함께 수액, 항구토, 전해질·산염기 이상을 교정한다.
- 반복 진찰로 복통, 소변량, 의식, 경구섭취 가능 여부를 확인한다.
- 지속 구토에서 QT 연장 약물, 전해질 이상과 항구토제 부작용을 함께 고려한다.

### 5. Disposition
- 쇼크, 중증 전해질·산염기 이상, 폐색·천공·신경계·대사응급, 지속적인 경구섭취 불가는 입원이 필요하다.
- 활력징후와 검사가 안정되고 경구섭취가 가능하며 위험 원인이 배제될 때 퇴원을 고려한다.

### 6. ER 함정
- 구토를 단순 위장염으로 보기 전에 연령·임신·약물과 신경학적 단서를 확인한다.
- 담즙성 구토, 혈성 구토, 분출성 구토는 별도 위험 신호다.
