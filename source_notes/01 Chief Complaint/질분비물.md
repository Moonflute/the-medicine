# 질분비물

## Concept
질분비물은 생리적 변화와 질염·자궁경부염을 구분하고 골반통·발열이 동반되면 상부 생식기 감염 가능성을 평가한다.

## 감별진단
세균질증, 편모충질염, 칸디다질염, 위축성질염
골반염 / 자궁경부염

## 환자교육
검사 : 현미경 검사
치료 : 칸디다 → Fluconazole, Miconazole..
교육 : 잦은 질세척 좋지 않음, 증상 지속 시 관찰, 자궁 내 장치 감염가능

회색, 생선 비린내 분비물
= 세균질증 / wet smear, whiff test, 배양 / metronidazole

화농성, 찌르는 냄새, 기포 분비물 + 소양증 + 딸기 모양 질경부
= 편모충 질염 / wet smear, 배양 / metronidazole (파트너도)

치즈 형태의 분비물 + 화끈거림 + 외음부 소양감 + 배뇨통
= 칸디다 질염 / wet smear, 배양 / fluconazole

출혈 + 식은땀 + 얼굴 화끈거림 + 성교통 + 수축된 질경부
= 위축성 질염 / wet smear / topical estrogen cream

골반통 + 움직일 때 통증 + 발열 + 배뇨통 + 복통 + NV+ 하복부 압통
= 골반염 / CBC, 질분비물 배양, 골반초음파 / 안정, 수액, 진통제, 항생제

노란색/초록색 화농성 질분비물 + 질경부 통증/염증
= 자궁경부염 / 질분비물 염색 / ceftriaxone + doxycycline (파트너도)

## 관련질환

## 접근
- color·odor, pruritus·pain, sexual exposure, antibiotic use, pregnancy, fever·pelvic pain과 수술·기구를 확인한다. PID·postoperative infection과 retained foreign body를 선별한다.
## 검사
- pregnancy test, vaginal pH·microscopy/NAAT와 STI 검사를 동의·위험에 따라 시행한다. fever·pelvic pain이면 CBC와 ultrasound를 고려한다.
## 치료
- Candida, bacterial vaginosis, trichomoniasis와 cervicitis를 검사·임상 기준에 맞춰 치료하고 무차별 fluconazole·항생제를 반복하지 않는다. 임신과 약물상호작용을 확인한다.
- PID·농양·수술부위 감염이면 산부인과와 원내 IV 항균·source control 경로로 전환한다.
