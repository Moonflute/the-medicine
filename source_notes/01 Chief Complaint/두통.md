# 두통

## Concept
두통은 갑작스러운 최고 강도, 새 신경학적 이상, 발열·면역저하, 임신·산후처럼 이차성 원인을 시사하는 맥락을 먼저 찾는다.

## 감별진단
원발성 : 편두통, 긴장 두통, 군발 두통, 삼차 신경통
이차성 : 거미막밑츨혈, 뇌내 출혈 / 뇌종양 / 뇌수막염, 측두동맥염
기타 : 약물 과용, 외상 후 두통, 크롬친화세포종

## 환자교육
검사 : 이차성 두통 감별 검사 시행 - 혈액검사, lumbar punture, 영상
치료
교육 : 생활습관 개선, 예방 약물은 좀 걸림

일측성 + 박동성 + 전조 증상 + 메스꺼움 + 구토 + 빛과 소리에 민감
= 편두통 / … / NSAID, Triptan - BB, TCA

양측성 + 조이는 + 뒷목 뻐근 + 저녁 악화 + 진통제가 들음
= 긴장 두통 / … / 목 스트레칭, 운동, NSAIDs, 마사지

안구통 동반 + 눈물/콧물 + 남자 + 주기적으로 나타남
= 군발 두통 / … / 산소 치료 - sumatriptan, verapamil, lithium

편측성 + 찌릿한 통증 + 얼굴 건드리면 통증 유발됨
= 삼차 신경통 / … / 항경련제, 필요 시 수술

극심한 통증 + 오심/구토 + 의식장애 + 국소 신경학적 이상 + 수막자극 
= SAH, ICH / CT, CSF, angio / 혈압 조절, 산소 공급, coiling, clipping

두통 + 체중 감소 + 오심/구토 + 의식 변화 + 국소 신경학적 이상
= 뇌종양 / CT, MRI / 수술적 절제, 방사선 치료, 항암화학요법

심한 두통 + 발열/오한 + 구토 + 수막 자극 징후
= 뇌수막염 / CT, CSF / 수술, RTx, CTx

관자놀이 두통 + 발열 + 근육통 + 턱관절 통증
= 측두동맥염 / ESR, CRP / 고용량 스테로이드

만성 두통 + 만성 약물 복용력 + 편두통 유사 증상
= 약물 과용 두통 / … / 약물 중단

두부 외상력 + 이후 증상 발생
= 외상 후 두통 / CT, MRI / 혈압 조절, 뇌압 조절, 두개골 감압술

두통 + 두근거림 + 식은 땀 + 불안 + 고혈압
= 크롬친화세포종 / 24hr 소변 메타네프린, CT / AB, 부신절제술

## 관련질환
[[군발두통 (Cluster headache)]], [[뇌수막염 (Meningoencephalitis)]], [[뇌종양 (Brain tumor)]], [[삼차신경통 (Trigeminal neuralgia)]], [[크롬친화세포종 (Pheochromocytoma)]], [[편두통 (Migraine)]]

## 접근
- 갑작스러운 최대강도, 새 신경학적 이상·의식변화, 발열·수막자극, 임신·산후, 항응고, 암·면역억제, 최근 LP·epidural과 혈압을 확인한다.
- thunderclap, 새 deficit, seizure, papilledema 또는 hypertensive emergency이면 단순 진통 후 관찰하지 않는다.
## 검사
- 신경학적 진찰과 fundus, glucose를 확인하고 적응증에 따라 noncontrast CT±CTA, MRI/MRV, ESR·CRP와 LP를 선택한다. LP 전 mass effect 위험을 판단한다.
## 치료
- 위험 원인 평가와 함께 Acetaminophen (타이레놀정) 500–1,000 mg PO q6h PRN을 사용한다. 오심 동반 migraine형이면 Metoclopramide (맥페란정/맥페란주) 10 mg IV를 신기능·EPS 위험 확인 후 고려한다.
- SAH, meningitis, cerebral venous thrombosis, preeclampsia 또는 intracranial hypotension은 각각의 전문 경로로 즉시 전환한다.

## ER

### 1. 즉시 평가 및 안정화
- 갑작스러운 발병, 최대 강도 도달 시간, 신경학적 결손, 의식 변화, 발열·경부강직, 임신·산후 여부를 먼저 확인한다.
- 쇼크, 경련, 의식저하 또는 뇌탈출 징후가 있으면 ABC 안정화와 긴급 영상·전문과 협진을 동시에 진행한다.
- 진통 전후 신경학적 진찰과 시야·동공·안저 단서를 기록한다.

### 2. 놓치면 안 되는 질환
- [[지주막하 출혈 (Subarachnoid hemorrhage)]] : thunderclap headache, 운동·성행위 중 발병, 경부강직
- 뇌출혈·[[허혈성 뇌졸중 (Ischemic stroke)]]·정맥동혈전증 : 국소 결손, 경련, 임신·산후 또는 혈전 위험
- [[세균성 뇌수막염 (Bacterial Meningitis)]]·뇌염 : 발열, 경부강직, 발진, 의식 변화
- 측두동맥염 : 고령, 새 두통, 턱파행, 시각 증상
- 급성 폐쇄각녹내장 : 안통, 충혈, 시력저하, 구토
- 자간전증·PRES : 임신 20주 이후 또는 산후의 고혈압·시각증상·경련

### 3. 초기 검사
- 비조영 뇌 CT의 민감도는 발병 시간과 판독 조건에 따라 달라지므로, SAH 의심이 남으면 추가 검사 경로를 적용한다.
- 국소 결손·정맥동혈전·동맥박리가 의심되면 CT/MR angiography 또는 venography를 선택한다.
- 뇌수막염 의심 시 혈액배양과 항균치료를 지연하지 않으면서 요추천자와 선행 영상 필요성을 판단한다.
- 임신반응, 염증수치, 안압 등은 임상 단서에 따라 시행한다.

### 4. 초기 처치 및 재평가
- 원인별 치료와 함께 통증·오심을 조절하고 신경학적 변화와 혈압을 반복 평가한다.
- 일차성 두통으로 판단하더라도 이전과 다른 양상, 재발 속도와 치료 반응을 재검토한다.

### 5. Disposition
- 이차성 두통 의심, 신경학적 이상, 감염·출혈·혈관질환·임신성 고혈압 질환은 입원 또는 긴급 전문 평가가 필요하다.
- 일차성 두통으로 합리적으로 판단되고 증상이 조절되며 신경학적 진찰이 정상일 때 퇴원을 고려한다.

### 6. ER 함정
- 통증이 호전되었다는 사실은 지주막하출혈이나 다른 이차성 두통을 배제하지 않는다.
- 편두통 병력이 있어도 이번 두통이 평소와 다른지 별도로 확인한다.

근거: Tintinalli's Emergency Medicine Manual, 8e, Ch. 140-141; 최신 지주막하출혈·뇌수막염·임신성 고혈압 공식 지침과 함께 적용.
