# 다뇨

## Concept
다뇨는 실제 소변량 증가와 빈뇨를 먼저 구분하고, 실제 다뇨라면 삼투성 이뇨와 수분 이뇨로 나누어 접근한다.

## 감별진단
I/O 조절문제 : 원발 다음증, (중추/신장) 요붕증, 당뇨병
비뇨기 : 만성 신부전, 요로 감염, 폐쇄 후 이뇨
기타 : 이뇨 약물, 커피

## 환자교육
검사 : 24hr urine collection, 수분제한검사, 혈액검사, 소변검사, 뇌 MRI
치료 :
교육 : 탈수 예방할 것, 배뇨일지 작성, 이뇨작용 기호식품 자제

수분 과다 섭취 + 기타 정상
= 원발 다음증 / 전해질검사, 소변검사 / 수분 섭취 제한, 필요 시 입원

다뇨 + 빈뇨 + 아갼뇨 + 시야장애 + 뇌수술력 + 두부외상력
= 중추 요붕증 / 전해질검사, 소변검사, MRI / desmopressin, 수술

다뇨 + 비뇨기 과거력 + 리튬 복용력
= 신장 요붕증 / 전해질검사, 소변검사 / thiazide, amiloride, 인도메타신

다뇨 + 다음 + 다갈 + 체중 감소 + 소변 단내
= 당뇨병 / 혈중 포도당, 당화혈색소, 소변검사 / 혈당강하제, 식습관 조절

다뇨 + 피로 + 부종 + 가려움증 + 고혈압
= 만성 신부전 / BUN/Cr, 전해질검사, 소변검사 / ACEi, ARB, 혈액 투석

다뇨 + 배뇨통 + 질분비물
= 요로 감염 / 소변검사, 소변배양검사, CBC / ciprofloxacin, ampicillin

다뇨 + 도뇨관 삽입력 + 나머지 정상
= 폐쇄 후 이뇨 / 소변검사, 소변배양검사 / 경과 관찰

이뇨제 / 커피 등 카페인 음료 과량 섭취 + 기타 정상
= 이뇨제, 커피로 인한 다뇨증 / 전해질검사, 소변검사 / 약물 중단

## 관련질환
[[당뇨병 (Diabetes Mellitus)]], [[요로 감염 (Urinary Tract Infection)]], [[요붕증 (Diabetes Insipidus)]]

## 콜 접수
- 실제 24시간 소변량(성인 다뇨 대개 >3 L/day)과 1회 배뇨량을 확인해 소량씩 자주 보는 빈뇨와 구분한다. 시간당 추세와 I/O·체중 변화, 수액·이뇨제, 고혈당, 최근 요폐 해소·AKI 회복, 뇌하수체 수술 이력을 확인한다.

## 위험 판단
- 저혈압·심한 갈증·의식 변화, 빠르게 상승하는 Na 또는 대량 지속 다뇨는 탈수/diabetes insipidus 위험. 상급자·신장내과/내분비내과에 즉시 보고한다.

## 원인 감별·추가검사
- **혈당·Na·K·Ca·Cr**, **혈청/소변 삼투압**, 필요 시 **소변 Na**를 확인한다. 고혈당성 삼투성 이뇨와 묽은 소변의 수분 이뇨(DI·과도한 수분 섭취)를 구분한다. 저K·고Ca, lithium 등 신성 DI 유발요인과 post-obstructive diuresis를 확인한다. 불안정 환자에게 수분제한 검사를 임의로 시행하지 않는다.

## 처치
### 즉시 조치
- 활력징후와 Na 추세, 체액상태를 보면서 경구/경장 물 또는 **정맥 수액**으로 진행 손실을 보충한다. 저혈압·저관류면 소생을 먼저 시행한다.
### 원인 치료
- 불필요한 이뇨제·과도한 수액을 조정한다. 중추성 DI가 확인되면 **Desmopressin (미니린정/주사 등)**을 전문과·원내 프로토콜로 투여한다.

## 경과관찰
- 시간당 소변량·I/O와 **Na·K 재검**을 초기 2–4시간 간격으로 추적한다. Desmopressin 후 급격한 소변량 감소·저Na 과교정도 확인한다.
