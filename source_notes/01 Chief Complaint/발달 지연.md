# 발달 지연

## Concept
‘소아’, PEx 없음

## 감별진단
전반적 : 저산소뇌병증, 태아알코올증후군, 다운/터너
언어 : 발음장애, 청력장애, 자폐 스팩트럼 장애, 체질 지연
운동 : 뇌성마비, 척수근위축증

## Hx

### CC-specific assessment
#### CC-specific
- 생년월일 확인
- 성장 확인
- 현재 키/체중/머리둘레 확인 → percentile 확인
- 성장 속도 확인 (4cm/년), 2차 성징 확인
### C (Character)
#### CC-specific
- 발달이 느리다고 생각하는 이유?
- 주산기력
- 임신 나이, 임신 중 음주, 흡연, 커피 / 엽산, 철분
- 출생력
- 재태주수, 분만법, 신생아 대사검사, 유전자검사, 청력검사
- 발달력
- 서기(9개월) 걷기(11개월) 뛰기(2년)
- 남에게 물건 주기(12개월)
- 옹알이(6개월) 마마빠빠 (12개월)
- 눈맞춤, 또래와, 반복행동?
- 소리가 나면 고개를 돌리는지?

### 외과력
#### CC-specific
- 외상력 : 입원/수술, 예방접종
- 과약

### 사회력
#### CC-specific
- 사회력 : 양육 환경, 식습관, 운동, 수면 습관

### 가족력
#### CC-specific
- 가족력 : 부모의 발달이 늦음 여부, 형제/자매?

## PEx

### Special examination
#### CC-specific
- 시행하지 않음

## 환자교육
검사 : 자폐 스펙트럼 장애, 청력검사, 뇌파검사, 뇌 MRI
치료 : 언어 치료, 행동 치료
교육 : 자책하지 말 것

전반적 지연 + 난산 병력 + NICU
= 저산소뇌병증 / brain US, MRI / 보존적 치료

전반적 지연 + 코가 짧고 위로 향함 + 윗입술 얇음 + 음주력
= 태아 알코올 증후군 / 임신 시 검사? / 예방을 해야..

전반적 지연 + 둥글고 납작한 얼굴 + 낮은 코 + 지능 저하 + 비만
= 다운 증후군 / 염색체검사 / 주기적 검진, 예방접종

전반적 지연 + 3년 이후 느려짐 + 작은턱 + 외반주
= 터너 증후군 / 염색체검사 / 성장호르몬, E, P 공급

언어 지연 + 발음 부정확
= 발음장애 / 성대 이상 확인 / 언어 치료

언어 지연 + 큰 소리 반응 저하
= 청력장애 / 청력검사 / 중이염 관련 수술, 언어 교육

언어 지연 + 사회성 저하 + 특이 행동 반복
= 자폐 스팩트럼 장애 / 청력검사, 뇌파검사 / 부모 교육, 행동 치료

언어 지연 + 부모 사춘기 느렸음
= 체질 지연 / 손목 X-ray, IGF-1 / 안심

운동 지연 + 보행 이상 + 경직성 양측 운동 마비
= 뇌성마비 / 뇌초음파, 자기공명영상 / 재활 운동, 후방신경근절개술

운동 지연 + 심한 대칭적 근력 저하 + 개구리 다리 장애
= 척수근위축증 / 혈액 유전자결손 확인 / 보존적 요법
