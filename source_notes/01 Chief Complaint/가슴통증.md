# 가슴통증

## Concept
흉통은 ACS뿐 아니라 대동맥박리, 폐색전증, 기흉처럼 초기 양상이 겹치는 시간 민감 질환을 먼저 구분한다.

## 감별진단
소화기 : GERD, 궤양
순환기 : 안정/불안정/변형 협심증, 급성 심근경색증 / 심장막염, 대동맥 박리
호흡기 : 폐렴, 흉막염, 폐색전증, 기흉
기타 : 대상포진 / 갈비연골염 / 불안, 우울

## 환자교육
쥐어짜는 통증 (30분 이하) + 운동 시 악화 + 기저질환/흡연
= 안정 협심증 / EKG, 운동부하, 심근효소검사, SPECT / Aspirin, NTG, BB

쥐어짜는 통증 + 운동 시 악화 + 쉬는 중에도 발생 + 기저질환/흡연
= 불안정 협심증 / EKG, 운동부하, 심근효소검사, SPECT 				/ Aspirin, NTG, BB, 관상동맥재개통술

쥐어짜는 통증 (30분 이상) + 팔/어깨 방사 + 기저질환/흡연
= 급성 심근경색증 / EKG, 운동부하, 심근효소검사, SPECT 			/ Aspirin, NTG, BB, 관상동맥재개통술

갑작스러운 흉통 + 과음 + 젊은 나이
= 변형협심증 / EKG, 운동부하, 심근효소검사, SPECT / CCB, NTG

찌르는 통증 + 숙이면 완화 + 숨쉬면 악화 + 심음에서 마찰음
= 심장막염 / Echo, EKG, CXR / NSAID, aspirin, 심장막 천자

찢어지는 통증 + 등 방사 + 심한 호흡곤란 + 말판증후군 + 대동맥 잡음
= 대동맥 박리 / CXR, CT / 응급수술

찌르는 통증 + 호흡기 감염 증상 + 호흡음 crackle + 타진 탁음
= 폐렴 / CXR, 객담배양검사, 혈액 배양, 혈구검사 / 경험적 항생제, 수액

들숨 시 통증 + 감염 증상 + 성음진탕 감소 + 호흡음 감소
= 흉막염 / CXR, CBC, 가슴막 천자, 혈액배양 / NSAID, acetaminophen

급성 호흡곤란 + 흉통 + 객혈 + 누워있는 이력 + Homan (+) + 목정맥 확장 + 부종
= 폐색전증 / CT, ECG, echo / heparin, 혈전용해제, IVC 필터

찌르는 통증 + 호흡 시 악화 + 젊은 남성 + 과공명/성음진탕/호흡 감소
= 기흉 / CXR / 산소 마스크, 가슴막 천자, 흉관 삽입, 흉막유착술

타는 통증 (명치) + 식후/누우면 악화
= 위식도역류병 / 위내시경, 24hr 식도 pH 검사 / PPI, 제산제, 생활 습관 

쓰린 통증 (명치) + 공복, 식후 악화 + 상복부 압통
= 소화기 궤양 / 위내시경, 요소날숨검사, 신속요소분해효소 / PPI, 제균

피부 발진 (띠 모양) + 고령 + 면역억제
= 대상포진 / 불필요 / 항바이러스제, 통증 조절

(+) 갈비연골염, 정신적

## 접근

- 입원 중 새 흉통은 현재 입원질환과 별개로 ACS, 대동맥박리, PE, 기흉, 심장압전, 식도파열을 먼저 선별한다. 통증 시작시각·지속시간과 함께 최근 수술·부동·항응고 중단, 중심정맥관 삽입, 수혈, 내시경·구토, 투석 시점을 확인한다.
- 활력징후, 양팔 혈압, 산소포화도, 심장·폐 청진, 맥박 비대칭, 새 심잡음, DVT 징후와 흉벽 압통을 확인한다. 기존 ECG와 입원 당시 troponin, hemoglobin, creatinine을 현재 값과 비교한다.
- 저혈압, 지속 통증, ST 변화, 치명적 부정맥, 새 저산소증·신경학적 이상이 있으면 병실 검사를 기다리지 말고 모니터링 가능한 구역으로 이동시키고 신속대응팀과 해당 시술팀을 활성화한다.

## 검사

- 12유도 ECG를 인지 후 10분 이내 시행하고 이전 ECG와 비교한다. 초기 ECG가 비진단적이어도 통증이 지속·재발하면 15–30분 간격으로 반복하고 지속 모니터링한다.
- High-sensitivity troponin은 검사실의 0/1시간 또는 0/2시간 protocol로 추적한다. CK-MB를 일률적으로 추가하지 않으며, 빈혈·AKI·sepsis에서 troponin 상승은 임상·ECG 변화와 함께 해석한다.
- CBC, 전해질·Cr, glucose, coagulation은 출혈·항혈전치료·조영검사 가능성을 고려해 선택한다. 흉부 X선은 기흉·폐렴·종격 이상 평가에 사용하지만 ACS·PE·박리를 배제하지 못한다.
- PE와 대동맥박리는 임상 사전확률을 먼저 판단한 뒤 D-dimer 또는 CT angiography를 선택한다. 불안정 환자는 bedside echocardiography로 심실기능, 심낭액, 우심실 부담과 용적상태를 확인한다.

## 치료

### 허혈성 흉통이 의심될 때
- Aspirin (아스피린프로텍트정 100 mg 등) 총 300 mg PO loading을 가능한 빨리 투여한다. 이미 복용했는지 확인하고 aspirin 과민반응, 활동성 출혈 또는 대동맥박리 의심 시 보류한다.
- Nitroglycerin (니트로링구알스프레이 0.4 mg/dose 등) 0.4 mg SL q5min, 최대 3회까지 투여하면서 매회 혈압과 통증을 재평가한다. 저혈압, 우심실경색, 중증 대동맥판막협착 또는 최근 PDE-5 inhibitor 복용 시 투여하지 않는다.
- 산소는 일률적으로 투여하지 않는다. 저산소증이면 SpO2 94–98%를 목표로 하되 hypercapnic respiratory failure 위험에서는 88–92%를 목표로 한다.
- 추가 항혈소판제·항응고제는 현재 항혈전제와 마지막 투여시각, 출혈·수술 계획, 박리 가능성을 확인한 뒤 심장내과·원내 ACS protocol에 따라 시작한다.

### 재평가와 전환
- 진통 반응만으로 ACS를 배제하지 않는다. 통증, 활력징후와 ECG를 5–15분 단위로 재평가하고 STEMI·불안정 ACS이면 즉시 cath lab pathway를 가동한다.
- PE, 박리, 기흉, 심장압전 또는 식도파열이 의심되면 aspirin·항응고제를 자동 투여하지 말고 해당 원인의 영상·시술·수술 경로로 전환한다.

## ER

### 1. 즉시 평가 및 안정화
- ABC와 활력징후를 확인하고 심전도·산소포화도·심장 모니터링을 시작한다.
- 저혈압, 의식 변화, 지속되는 허혈성 통증, 중증 호흡곤란, 치명적 부정맥이 있으면 소생과 원인 치료를 동시에 진행한다.
- 급성관상동맥증후군이 의심되면 첫 의료접촉 후 지체 없이 12유도 심전도를 확보하되, 정상 초기 심전도만으로 배제하지 않는다.

### 2. 놓치면 안 되는 질환
- [[ST분절 상승 심근경색증 (STEMI) (ST-Elevation Myocardial Infarction)]]·[[비ST분절 상승 심근경색증 (NSTEMI) (Non-ST-Elevation Myocardial Infarction)]] : 압박감, 운동 연관, 식은땀, 방사통 또는 비전형적 허혈 증상
- [[대동맥 박리 (Aortic Dissection)]] : 갑작스러운 최대 강도의 통증, 등 방사, 맥박·혈압 차이, 신경학적 이상
- [[폐색전증 (Pulmonary Embolism)]] : 급성 호흡곤란, 흉막통, 실신, 저산소증, 혈전 위험인자
- [[긴장성 기흉 (Tension Pneumothorax)]] : 급격한 호흡 악화, 편측 호흡음 감소, 저혈압
- 심장압전·식도파열 : 쇼크, 경정맥 팽창, 심음 감소 또는 구토 후 심한 흉통과 피하기종

### 3. 초기 검사
- 12유도 심전도와 serial ECG, 고감도 troponin을 임상 위험도와 시간 경과에 맞춰 해석한다.
- 흉부 X선은 폐질환·종격 이상을 평가하지만 ACS·대동맥박리·폐색전증을 단독으로 배제하지 못한다.
- 대동맥박리·폐색전증은 사전확률을 먼저 평가한 뒤 D-dimer 또는 CT를 선택한다.
- 불안정 환자는 bedside echocardiography로 심실기능, 심낭액, 우심실 부담, 대동맥근부와 용적상태를 신속히 확인한다.

### 4. 초기 처치 및 재평가
- 원인별 시간 민감 치료를 시작하고, 저산소증·쇼크·치명적 부정맥을 우선 교정한다.
- ACS 치료 전 대동맥박리, 활동성 출혈, 최근 항응고제 사용 등 항혈전치료 위험을 확인한다.
- 통증 변화, 활력징후, 심전도와 troponin 추세를 반복 평가한다.

### 5. Disposition
- STEMI, 불안정한 ACS, 대동맥박리, 고위험 폐색전증, 긴장성 기흉 의심은 즉시 해당 전문과·시술팀을 활성화하고 입원한다.
- 초기 검사가 정상이어도 중간 이상 위험도이거나 증상이 지속·재발하면 관찰과 serial testing이 필요하다.
- 퇴원은 저위험 임상경로를 충족하고 위험 질환이 합리적으로 배제되며 명확한 재내원 기준과 추적계획이 있을 때만 고려한다.

### 6. ER 함정
- 고령자, 여성, 당뇨병 환자는 전형적 흉통 없이 호흡곤란·오심·피로·실신으로 ACS가 나타날 수 있다.
- 통증이 호전되었거나 압통이 있다는 이유만으로 심혈관 응급질환을 배제하지 않는다.
