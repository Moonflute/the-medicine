# 콧물/코막힘

## Concept
‘ENT’ 악화인자를 잘 문진

## 감별진단
감염 : 상기도 감염, 부비동염
비감염 : 혈관 운동/알레르기/약물유발 비염 / 부비동 종양, 뇌척수액, 이물

## Hx
O
Location
	일측성, 양측성
D Co Ex
Character
	양상 (수양성/점액성), 양, 색, 냄새, 피
Associated Sx 
	General  : Weight loss, Fatigue, Fever, Chill, Edema
	FCCSR
	(호흡기계) 호흡곤란, 쌕쌕거림
	(알레르기) 재채기, 눈코 소양증
	(이비인후) 콧물/코막힘/후비루/인후통/냄새
	안면부 감각 이상, 신경학적 이상 소견
Factor 
	악화 (계절, 장소, 동물 / 찬바람, 뜨거운 음식)
E 
외과약사가여 : ACEi, NSAIDs, 피임약, 국소혈관수축제

## PEx
V/S 눈 입 코 부비동(압통) 목(림프절)
흉부 : 시 – 촉 – 타 – 청
사지 : 곤봉지, 청색증

## 환자교육
검사 : Water’s view X-ray, Facial CT, 비내시경, skin prick
치료 : 병바병
교육 : 금연, 예방접종 교육, 비충혈제거제 오래 사용하지 말 것, 환경 관리

맑은 콧물 + 재채기 + 가려움 + 코막힘 + 비점막 부음
= 알레르기 비염 / 코내시경, prick test, IgE 
	/ 회피요법, 항히스타민제, 면역요법

발열 + 기침 + 가래 + 인후통 + 코막힘 + 목 부음
= 상기도 감염 / 후두경, CBC, CXR / 휴식과 수분 섭취, NSAID, 항생제

코막힘 + 호흡곤란 + 후각 저하 + 두통 + 부비동 압통
= 부비동염 / 코내시경, water’s view, CT / 코세척, 충혈제거제, 항생제

맑은 콧물 + 뜨거운 음식 먹을 때 악화
= 혈관 운동 비염 / Water’s view, skin prick test 
	/ 회피요법, 항히스타민, 비강 스테로이드

편측 콧물 + 피 섞임 + RTx 이력 + 코담배 + 신경 이상 등
= 부비동 종양 / 코내시경, CT, MRI / 수술, 방사선조사, 항암 치료

두부외상력 + 신경학적 이상 소견
= 뇌척수액 콧물 / 두경부 CT, MRI / 수술, 방사선조사, 항암 치료

ACEi, NSAIDs, 국소혈관수축제 복용 중 + 특이 소견 없음
= 약물유발 비염 / 불필요 / 약물 중단 및 교체

코에 이물질 들어간 적 있음
= 코이물 / 두경부 CT, MRI / 코내시경, 수술
