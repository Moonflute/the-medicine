# 핍뇨

## Concept
pre – renal – post 순으로 체크, 체액 감소일수도, 막힌거일수도

## 감별진단
pre : 혈량저하증/심부전/약물에 의한 급성 신손상
renal : 사슬알균 감염 후 토리콩팥염, 요로 감염 / 조영제, 횡문근융해증, 이식 거부 반응 / 악성 고혈압, 용혈요독증후군
post : 양성 전립샘 비대, 전립샘암

핍뇨 + 혈액소실 증상 + 탈수 소견
= 혈량저하에 의한 급성 신손상 / 소변검사, 전해질검사, CBC / 수액 공급

핍뇨 + 피로 + 호흡곤란 + 부종 + 수포음 청진
= 심부전에 의한 급성 신손상 / echo, EKG, CXR / ACEi, ARB, BB

핍뇨 + 약물 복용 중 (ACEi, ARB, NSAID) + 나머지 정상
= 약물 유발 급성 신손상 / 소변검사, BUN/Cr, 신장초음파 / 약물 중단

핍뇨 + 혈뇨 + 최근 감염력 + 근육통 + 옆구리 통증 + CVAT(+) + 부종
= PSGN / 소변검사, BUN/Cr, 신장초음파 / 수액, 이뇨제

핍뇨 + 배뇨통 + 질분비물
= 요로 감염 / 소변검사, 소변배양검사, CBC / Ciprofloxacin, Ampicillin

핍뇨 + 최근 조영제, aminoglycoside, cisplatin 복용력 + 하지 오목 부종
= 약제 유발 급성 신독성 / 소변검사, BUN/Cr / 약물 중단, 수액 공급

핍뇨 + 적색뇨 + 과도한 운동 + 근육통 + 감전 등
= 횡문근융해증 / 소변검사, BUN/Cr / 수액 공급, 이뇨제

핍뇨 + 신장 이식 병력 + 하지 오목 부종
= 이식 거부 반응 / 소변검사, BUN/Cr, 신장초음파 / 면역억제제 강화

핍뇨 + 심한 고혈압 + 망막 출혈 + 유두 부종
= 악성 고혈압 / 소변검사, echo, 신장초음파 / nitrate, BB

핍뇨 + 소아 + 대장염 증상 후 발병 + 탈수
= 용혈요독증후군 / 소변검사, BUN/Cr, PBS / 혈액 투석, 수혈

핍뇨 + 전립샘 비대증 + 요도 협착 + 아랫배 통증
= 양성 전립샘 비대, 전립샘암/염 / US, PSA / AB, androgen 억제제

## ER

### 1. 즉시 평가 및 안정화
- 실제 소변량과 측정시간을 확인하고 쇼크·탈수·폐부종, 방광팽만과 catheter 문제를 즉시 평가한다.
- 고칼륨혈증, 중증 산증, 폐부종, 요독성 합병증이 있으면 신대체치료 가능성을 조기에 판단한다.

### 2. 놓치면 안 되는 질환
- 쇼크·패혈증·출혈에 의한 신전성 AKI
- 급성 세뇨관손상·사구체신염·rhabdomyolysis
- 양측 요로폐색·단일신 폐색과 catheter obstruction
- 심부전·복부구획증후군
- 고칼륨혈증과 급성 투석 적응증

### 3. 초기 검사
- 전해질·신장기능, 혈액가스, CBC, 소변검사와 침사를 시행한다.
- bladder scan과 신장·요로 초음파로 저류·수신증을 평가한다.
- 심전도는 고칼륨혈증 의심 시 즉시 시행하되 정상 심전도만으로 위험을 배제하지 않는다.

### 4. 초기 처치 및 재평가
- 저관류는 원인에 맞게 교정하되 심부전·폐부종에서 무조건 수액을 투여하지 않는다.
- 폐색은 catheter 교정 또는 비뇨기 배액을 시행한다.
- 신독성 약물을 중단·조정하고 소변량, 체중, 전해질과 산염기 상태를 반복 평가한다.

### 5. Disposition
- 진행 AKI, 전해질·산염기 이상, 폐부종, 감염성 폐색 또는 원인 불명 핍뇨는 입원한다.
- 일시적 원인이 교정되고 신기능·소변량이 안정된 경우에만 단기 추적을 전제로 퇴원을 고려한다.

### 6. ER 함정
- creatinine은 급성 손상 초기에 늦게 상승할 수 있다.
- 이뇨제 반응이나 fractional excretion 단일 수치만으로 AKI 원인을 확정하지 않는다.
