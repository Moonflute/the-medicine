# 핍뇨

## Concept
핍뇨는 체액상태와 요로폐색 여부를 먼저 확인한 뒤 신전성, 신성, 신후성 원인으로 나누어 접근한다.

## 감별진단
pre : 혈량저하증/심부전/약물에 의한 급성 신손상
renal : 사슬알균 감염 후 토리콩팥염, 요로 감염 / 조영제, 횡문근융해증, 이식 거부 반응 / 악성 고혈압, 용혈요독증후군
post : 양성 전립샘 비대, 전립샘암

## 환자교육
검사 : 혈액검사, 소변검사, 영상검사
치료 : 수액요법, 약물중단, 응급혈액 투석
교육 : 수액 치료 필요 강조, 투석 필요할 수 있음 설명

핍뇨 + 혈액소실 증상 + 탈수 소견
= 혈량저하에 의한 급성 신손상 / 소변검사, 전해질검사, CBC / 수액 공급

핍뇨 + 피로 + 호흡곤란 + 부종 + 수포음 청진
= 심부전에 의한 급성 신손상 / echo, EKG, CXR / ACEi, ARB, BB

핍뇨 + 약물 복용 중 (ACEi, ARB, NSAID) + 나머지 정상
= 약물 유발 급성 신손상 / 소변검사, BUN/Cr, 신장초음파 / 약물 중단

핍뇨 + 혈뇨 + 최근 감염력 + 근육통 + 옆구리 통증 + CVAT(+) + 부종
= PSGN / 소변검사, BUN/Cr, 신장초음파 / 수액, 이뇨제

핍뇨 + 배뇨통 + 질분비물
= 요로 감염 / 소변검사, 소변배양검사, CBC / Ciprofloxacin, Ampicillin

핍뇨 + 최근 조영제, aminoglycoside, cisplatin 복용력 + 하지 오목 부종
= 약제 유발 급성 신독성 / 소변검사, BUN/Cr / 약물 중단, 수액 공급

핍뇨 + 적색뇨 + 과도한 운동 + 근육통 + 감전 등
= 횡문근융해증 / 소변검사, BUN/Cr / 수액 공급, 이뇨제

핍뇨 + 신장 이식 병력 + 하지 오목 부종
= 이식 거부 반응 / 소변검사, BUN/Cr, 신장초음파 / 면역억제제 강화

핍뇨 + 심한 고혈압 + 망막 출혈 + 유두 부종
= 악성 고혈압 / 소변검사, echo, 신장초음파 / nitrate, BB

핍뇨 + 소아 + 대장염 증상 후 발병 + 탈수
= 용혈요독증후군 / 소변검사, BUN/Cr, PBS / 혈액 투석, 수혈

핍뇨 + 전립샘 비대증 + 요도 협착 + 아랫배 통증
= 양성 전립샘 비대, 전립샘암/염 / US, PSA / AB, androgen 억제제

## 접근

- 실제 시간당 소변량과 누적 balance를 확인하고 체중·Cr의 입원 기준치와 비교한다. Foley가 있으면 tubing kinking, bag 위치, sediment·blood clot과 catheter obstruction을 먼저 교정하고, 없거나 불확실하면 bladder scan으로 요저류를 확인한다.
- 출혈·설사·금식·sepsis에 의한 저관류, 수액·수혈 후 congestion·심부전, 조영제·NSAID·ACE inhibitor/ARB·diuretic·aminoglycoside·vancomycin 등 최근 노출, 수술 후 rhabdomyolysis와 요로폐색을 확인한다.
- 고칼륨혈증, 중증 산증, 폐부종·저산소증, 요독성 심낭염·뇌병증 또는 빠르게 진행하는 AKI가 있으면 단순 수액시험을 반복하지 말고 신장내과·중환자 평가를 즉시 요청한다.

## 검사

- BMP, Mg·phosphate, CBC, urinalysis와 sediment를 시행하고 CK, lactate, hemolysis·GN 검사는 임상 단서에 따라 추가한다. creatinine은 급성 손상 초기에 늦게 상승할 수 있으므로 소변량 추세를 함께 본다.
- ECG는 K 상승 또는 빠른 AKI에서 즉시 시행한다. bladder scan으로 하부폐색을 확인하고, 원인이 불명확하거나 상부폐색 위험이 있으면 신장·요로초음파를 24시간 이내 시행한다.
- 활력징후, 폐음·부종·JVP, intake/output와 체중으로 volume status를 반복 평가한다. 처치 후 소변량은 1시간 이내, K·산염기·Cr은 중증도에 따라 2–6시간 이내 재검한다.

## 치료

### 원인 교정
- 저혈량이 임상적으로 명확하고 폐울혈이 없으면 balanced crystalloid (하트만액·Plasma Solution A 등) 250–500 mL IV를 15–30분에 투여한 뒤 혈압·맥박·폐진찰과 소변량을 즉시 재평가한다. 반응 없이 congestion이 생기면 추가 bolus를 중단한다.
- 신독성 약물을 중단하고 모든 약을 현재 eGFR과 AKI에 맞춰 감량한다. Foley obstruction은 irrigation·교체로 해결하고, 감염성 폐색·양측 폐색·단일신 폐색은 즉시 비뇨의학과에 의뢰해 진단 후 12시간 이내 배액을 목표로 한다.
- Loop diuretic은 AKI 자체를 치료하거나 소변량 숫자를 늘리기 위해 사용하지 않는다. 폐부종·체액과다일 때만 Furosemide (라식스주 20 mg/2 mL) 20–40 mg IV를 투여하고 1–2시간 내 소변량·호흡·혈압·Cr·K를 재평가한다.

### 고칼륨혈증 동반 시
- ECG 변화 또는 K가 중증으로 상승하면 Calcium gluconate 10% (칼슘글루코네이트주 10%, 10 mL) 10 mL IV over 5–10min으로 심근을 안정화하고 5–10분 후 ECG 변화가 지속되면 반복을 고려한다.
- Regular insulin (휴물린알주 등) 10 units IV + Glucose 50% (대한포도당주사액 50% 등) 50 mL, 25 g IV를 투여하고, Salbutamol (벤토린네뷸) 10–20 mg nebulization을 보조로 사용한다. 투여 전과 이후 최소 4–6시간 동안 혈당을 반복 측정한다.
- 약물치료는 K를 제거하지 못한다. refractory hyperkalemia, 중증 산증, 폐부종 또는 요독성 합병증이면 신대체치료를 지연하지 않는다.

## ER

### 1. 즉시 평가 및 안정화
- 실제 소변량과 측정시간을 확인하고 쇼크·탈수·폐부종, 방광팽만과 catheter 문제를 즉시 평가한다.
- 고칼륨혈증, 중증 산증, 폐부종, 요독성 합병증이 있으면 신대체치료 가능성을 조기에 판단한다.

### 2. 놓치면 안 되는 질환
- 쇼크·패혈증·출혈에 의한 신전성 AKI
- 급성 세뇨관손상·사구체신염·rhabdomyolysis
- 양측 요로폐색·단일신 폐색과 catheter obstruction
- 심부전·복부구획증후군
- 고칼륨혈증과 급성 투석 적응증

### 3. 초기 검사
- 전해질·신장기능, 혈액가스, CBC, 소변검사와 침사를 시행한다.
- bladder scan과 신장·요로 초음파로 저류·수신증을 평가한다.
- 심전도는 고칼륨혈증 의심 시 즉시 시행하되 정상 심전도만으로 위험을 배제하지 않는다.

### 4. 초기 처치 및 재평가
- 저관류는 원인에 맞게 교정하되 심부전·폐부종에서 무조건 수액을 투여하지 않는다.
- 폐색은 catheter 교정 또는 비뇨기 배액을 시행한다.
- 신독성 약물을 중단·조정하고 소변량, 체중, 전해질과 산염기 상태를 반복 평가한다.

### 5. Disposition
- 진행 AKI, 전해질·산염기 이상, 폐부종, 감염성 폐색 또는 원인 불명 핍뇨는 입원한다.
- 일시적 원인이 교정되고 신기능·소변량이 안정된 경우에만 단기 추적을 전제로 퇴원을 고려한다.

### 6. ER 함정
- creatinine은 급성 손상 초기에 늦게 상승할 수 있다.
- 이뇨제 반응이나 fractional excretion 단일 수치만으로 AKI 원인을 확정하지 않는다.
