# 피로

## Concept
피로는 졸림·운동불내성과 구분하고 수면·기분·생활요인과 빈혈·내분비·감염·장기질환 가능성을 기간과 기능 저하에 맞춰 평가한다.

## 감별진단
일과성 피로
정신적 : 주요 우울증, 만성 피로증후군
내분비 : 갑상샘 저하증, 애디슨병, 당뇨, 폐경
염증성 : 만성 간염, 폐결핵, 자가면역질환
만성 질환 : 심부전, 빈혈, 만성 폐질환, 신부전, 암

## 환자교육
검사 : CBC
치료 : 인지행동 치료, 수면 환경 개선
교육 : 운동 권장, 기질적 원인 의심 시 검사

무리해서 피로함 + 휴식으로 완화 + 나머지 정상
= 일과성 피로 / … / 휴식

피로 + MDD 기준 만족 + 기타 정상
= 주요 우울증 / Beck 우울척도검사 / SSRI, 중증이면 입원치료

피로 + 만성 피로증후군 기준 만족 + 기타 정상
= 만성 피로증후군 / 나머지 배제 / 생활 습관 교정

피로 + 체중 증가 + 변비 + 추위불내성 + 갑상샘 종대
= 갑상샘저하증 / TFT / Levothyroxine

피로 + 체중 감소 + 설사 + 더위불내성 + 갑상샘 종대
= 갑상샘항진증 / TFT / propylthiouracil, methimazole

피로 + 다음 + 다뇨 + 다갈
= 당뇨 / 혈당검사 / 혈당조절

피로 + 얼굴 화끈거림, 홍조 + 폐경력
= 폐경에 의한 피로 / 호르몬 검사 / 호르몬제

피로 + 황달 + 복수 + 간비대
= 만성 간염 / LFT, 간염 바이러스 검사 / rivavirin, entecarvir

피로 + 발열 + 체중 감소 + 객혈 + 야간 발한
= 폐결핵 / AFB, 투베르쿨린 검사 / 항결핵제

피로 + 심부전 + 호흡곤란 + 오목 부종 + 경정맥 확장
= 울혈 심부전 / echo, EKG / nitrate, 이뇨제

피로 + 체중 감소 + 암 가족력 + 종괴 촉진
= 암 / 혈액검사, CT / RTx, CTx, 수술

## 관련질환
[[폐결핵 (Pulmonary Tuberculosis)]], [[폐경 (Menopause)]]

## 접근
- anemia, infection, hypoxia, sleep disruption, deconditioning, depression, adrenal·thyroid 문제와 sedating medication을 검토한다.
## 검사
- CBC, CMP, glucose, TSH, CRP와 SpO2를 임상 단서에 따라 선택하고 무차별 vitamin·tumor marker 검사를 피한다.
## 치료
- 원인 교정, 수면 묶음, 영양과 조기재활을 적용한다. stimulant나 vitamin을 원인 없이 경험적으로 시작하지 않는다.
