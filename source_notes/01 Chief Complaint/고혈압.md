# 고혈압

## Concept
'FM’, 고혈압에 의한 영향평가도 해야함

## 감별진단
일차성 고혈압 : 본태 고혈압
일시적 고혈압 : 백의 고혈압
이차성 고혈압
비뇨기 : 만성 신부전, 신동맥 협착증
내분비 : 갑상샘 항진증 / 일차 알도스테론증, 쿠싱증후군, 크롬친화세포종
기타 : 폐경, 약물 원인

## 환자교육
검사 : 자가혈압 측정, 혈액검사 (신장, 내분비)
치료 : lifestyle modification
교육 : 생활 습관 개선, 치료의 중요성, 자가 혈압 측정 지시, 목표 혈압 제시

고혈압 + 비만 + 운동 부족 + 나머지 정상
= 본태 고혈압 / … / 생활 습관 교정

고혈압 + 집에서는 정상
= 백의 고혈압 / … / 집에서 혈압 측정

고혈압 + 거품뇨 + 소변 감소 + 하지 부종
= 만성 신부전 / 신장초음파, BUN/Cr, 소변검사 / ACEi, ARB, 신대체요법

고혈압 + 소변 감소 + 신동맥 잡음 + 신동맥 bruit
= 신동맥 협착증 / US, renal scan / ACEi, ARB, 풍선혈관성형술

고혈압 + 두근거림 + 체중 감소 + 발한 + 더위불내성
= 갑상샘항진증 / TFT / 메티마졸, 방사성 요오드

고혈압 + 근력 약화 + 피로 + 경련 + 젊은 나이
= 일차 알도스테론증 / plasma renin activity, CT / 부신절제술, 
spironolactone

고혈압 + 자색선조 + 비만 + 다모증 + 멍 + 스테로이드
= 쿠싱증후군 / cortisol, dexa 억제검사 / 원인 치료

고혈압 + 두통 + 빈맥 + 기립성 저혈압
= 크롬친화세포종 / 24hr 메타네프린검사, CT / AB, BB, 부신절제술

고혈압 + 얼굴 화끈거림 + 수면장애 + 기타 정상
= 폐경에 의한 고혈압 / FSH, estradiol / 안정, 호르몬 대체요법

고혈압 + 약물 복용(steroid, NSAIDs, 한약) + 기타 정상
= 약물에 의한 고혈압 / … / 약물 중단
