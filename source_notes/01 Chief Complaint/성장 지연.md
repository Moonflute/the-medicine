# 성장 지연

## Concept
‘소아’, PEx 없음

## 감별진단
1차성 : 가족성 저신장, 골격 형성 장애, 염색체 이상, 선천대사 이상, IGRD,
2차성 : 영양 결핍, 만성 전신질환, 정신사회성 저신장 / 성장호르몬 결핍, (거짓)갑상샘저하, 체질성 성장지연

## Hx

### CC-specific assessment
#### CC-specific
- 생년월일 확인
- 성장 확인
- 현재 키/체중/머리둘레 확인 → percentile 확인
- 성장 속도 확인 (4cm/년), 2차 성징 확인
- 주산기력
- 임신 중 음주, 흡연, 커피 / 엽산, 철분
- 출생력
- 재태주수, 분만법, 신생아 대사검사, 유전자검사, 청력검사
- 발달력
- 서기(9개월) 걷기(11개월) 뛰기(2년)
- 남에게 물건 주기(12개월)
- 옹알이(6개월) 마마빠빠 (12개월)
- 눈맞춤, 또래와, 반복행동?
- 소리가 나면 고개를 돌리는지?

### 외과력
#### CC-specific
- 외상력 : 입원/수술, 예방접종
- 과약

### 사회력
#### CC-specific
- 사회력 : 양육 환경, 식습관, 운동, 수면 습관

### 가족력
#### CC-specific

## 환자교육
검사 : 손목 X-ray, 호르몬 농도 측정
치료 : 호르몬 이상 시 투여
교육 : 주기적인 검사 필요 교육

이유 없는 골절 등 골격 이상 없음
= 골격 형성 장애 / 전신 X-ray / 수술, 운동, 물리치료

성장 속도 감소 + 익상경, 작은턱, 외반주, 기형 + 골연령 정상
= 염색체 이상 (터너증후군) / 염색체검사 / 성장호르몬

신생아 대사검사 이상 병력
= 선천대사 이상 / 혈중 암모니아 검사, 기타 검사 / 대사체 보충, 섭취 제한

난산력 + NICU 입원력 + 임신 시 문제
= 자궁 내 성장 지연 / brain US, MRI / 상태에 맞춰 치료

부모님 저신장 + 성장 곡선 이탈 없음
= 가족성 저신장 / 손목 x-ray, IGF-1 / 경과 관찰

영양 섭취 부족
= 영양 결핍 / 혈중 영양소 측정 / 영양 공급

성장 속도 느림 + 왜소증
= 성장 호르몬 결핍증 / IGF-1, 저혈당검사 / 성장 호르몬 검사

황달 + 변비 + 수유 지연 + 얼룩덜룩
= 갑상샘저하증 / 감상샘기능검사 / Levo

부모님 성장 느림 + 성장 속도 정상
= 체질성 성장 지연 / 손목 X-ray, IGF-1 / 안심시키기

+ 만성 전신성 질환, 정신사회성 질환..
