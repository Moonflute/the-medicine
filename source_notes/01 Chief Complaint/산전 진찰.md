# 산전 진찰

## Concept
‘산과‘ 시간이 매우 부족하니 주의, 그냥 PE도 해야

## 감별진단
임신관련 : 입덧, 고령 임신, 유산
내과적 : 임신 고혈압, 전자간증, 임신 당뇨병
산과적 : 태반조기박리, 전치태반, 조기 양막 파수, 조기 산통

## Hx

### PPI

### O (Onset)
#### CC-specific
- 임신반응검사, 마지막 월경일, 출산 예정일, 증상 있으면 onset

### L / D / Co / Ex (Location, Duration, Course, Experienced)

### C (Character)
#### CC-specific
- 산모 평가 : 키, 체중, 혈액형, 예방접종 (풍진, B형 간염), 계획된?
- 월경력 : 월경 주기, 양, 규칙성, 통증, 피임 여부, 방법, 초경 시기
- 산과력 : 결혼 여부, 만조유생, 출산 방법,
- 주산기력 : 이전 임신 시 질환, 출산, 아이 이상은 없었는지 확인

### A (Associated symptoms)
#### CC-specific
- (임신상태평가) 메스꺼움, 구토 / 질분비물, 출혈, 통증
- (전자간) 두통, 시야장애, 어지럼증, 호흡곤란, 거품뇨
- (당뇨병) 다음, 다갈, 다뇨, 부종
- (갑상샘) 두근거림, 더위불내성, 체중 감소

### 외과력

## 환자교육
검사 : 혈액검사, 소변검사, 질초음파, 도말검사
치료 : 이상 시
교육 : 검사일, 주의사항, 내원 필요한 응급상황 설명
	4주 (~28주) 2주 (29주~36주) 1주 (37주~)

임신 + 구역 + 구토
= 입덧 / 전해질검사 / 식습관 교정, 탈수 심하면 수액 치료

임신 + 산모 35세 이상
= 고령 임신 / 융모악 융모 표본채취, 양수천자 / 산전 관리 잘

임신 + 질출혈 (전반기에 자궁 개대가 없는 상태에서)
= 유산 / 질초음파, 혈중 hCG 검사, serum FSH / 절대 안정, D&C

임신 + 부종 + 두통 + RUQ pain + 시력 변화
= 임신 고혈압, 전자간증 / 소변검사, LFT, CBC / hydralazine, 유도분만

임신 + 부종 + 기타 특이소견 적음
= 양수과다증 / 소변검사, LFT, CBC / 안정 및 경과관찰, 원인치료

임신 + 소변에서 당 확인
= 임신 당뇨병 / 경구당부하검사, HbA1C 검사 / 식이요법, 인슐린

임신 + 과도한 질출혈 + 복통
= 태반조기박리, 전치태반 / 질초음파, 복부초음파, CBC / 수혈, 제왕절개

통증 = 태반조기박리, 무통 =전치태반

임신 + 질분비물 + 조기 산통
= 조기 양막 파수, 조기 산통 / 자궁경부검사, 니트라진검사 / 안정, 출산
