# 혈뇨

## Concept
'출혈’, 가성 배제하고 감염도 확인

## 감별진단
가성 혈뇨
	채소 섭취, 리팜핀, 횡문근융해증
상부 요로
	IgA 신병증, 사슬알균 감염후 토리콩팥염, 급성 신우신염 / 신장암
하부 요로
	요로 결석, 요도 손상 / 요로 감염, 전립샘염 / 방광암, 전립샘암

## Hx
O L D Co Ex
Character
	양상 (양, 색, 초반-후반, 냄새, 거품, 덩어리, 피딱지), 통증	
Associated Sx 
General  : Weight loss, Fatigue, Fever, Chill, Edema
출혈 경향 : 코피, 출혈 후 잘 안 멎음, 멍이 잘 듦, 생리량 증가
탈수 증상 : 두근거림, 어지럼, 호흡곤란, 갈증
FUND HIS
최근 감기 증상	
Factor
	심한 운동, 사우나, 근육통, 붉은 채소 섭취력
E
외과약사가여 : 결핵약, 항응고제

## PEx
V/S 눈 입(출혈 경향) 목(림프절)
피부(긴장도, 부종) CVAT
복부 : 시 – 청 – 타 – 촉 + DRE (남자면 필수)
외성기 진찰 (증상 있는 경우)

## 환자교육
검사 : 소변검사, 혈액검사, 영상검사 (필요 시 biopsy)
치료 : 경미하면 경과 관찰
교육 : 추적검사 필요성 설명, 안정 필요, 충분한 수분 섭취

붉은뇨 + 결핵약 복용력 + 기타 정상
= 리팜핀에 의한 가성 혈뇨 / 소변검사 / 안심시키기

붉은뇨 + 과도한 운동 or 사우나 / 기타 정상
= 횡문근융해증 / 혈중 CK, EKG / 수액 공급, 이뇨제

혈뇨 + 2~3일 전 상기도 감염 + 기타 정상
= IgA 신병증 / 소변검사, 신장 조직검사 / 혈압 조절, 수분 염분 제한

혈뇨 + 1~2주 전 상기도 감염 + 부종 + 체중 증가
= 사슬알균 감염 후 토리콩팥염 / 소변검사, 신장 조직검사 			/ 염분 제한, 항생제

혈뇨 + 발열 + 오한 + 배뇨통 + CVAT(+)
= 급성 신우신염 / 소변검사, 신장초음파, CBC / 항생제

혈뇨 + 체중 감소 + 종괴 총진
= 신장암 / CT, US / 신장절제술

혈뇨 + 날카로운 옆구리 통증 + 재발 + CVAT(+)
= 요로 결석 / KUB, CT, 소변검사 / 대기, 쇄석술, 수술

혈뇨 + 발열 + 배뇨통 + 질문비물 + 가려움증 + 골반 내진
= 요로 감염 / 소변검사, 배양검사 / 항생제

혈뇨 + 체중 감소 + 잔뇨감 + 소변줄기 가늘어짐 + DRE 전립샘 비대
= 전립샘염,암 / 소변검사, US / 정맥항생제, AB, cystostomy

소변 초반에 혈뇨 + 외상력 + 외성기 진찰 상 회상
= 요도 손상 / 골반 CT / 수술
