# 허리 통증

## Concept
‘PEx’, 신경 이상인지 근육 이상인지 감별

## 감별진단
근육
	요추염좌, 요추압박골절
신경
	추간판탈출증, 척추관협착증, 척추 종양, 마미증후군
기타
	강직척추염, 골 관절염

## Hx
O L D Co Ex
Character
	양상 (찌르듯이, 찌릿, 둔하고 뻐근), NRS
	동반 (압통, 발적, 종창, 열감, 움직일 때 소리, 움직임 제한)
Associated Sx 
	General  : General weakness, Weight loss, Fatigue
사지 근력 약화, 감각 이상
파행
요실금, 변실금, 항문 주위 감각 이상 (마미증후군)
조조강직, 포도막염 과거력 (강직척추염)
Factor
	자세, 운동 영향
E 
외과약사가여 

## PEx
V/S
통증 부위 시진, 촉진, ROM, 걸음 시진
하지 : 감각, 근력, DTR, tip-toe gait
SLRT test, Patrick test, Schober test
말초동맥 맥박 촉진

## 환자교육
검사 : X-ray, CT, MRI
치료 : 안정
교육 : 허리 스트레칭, 신경 증상 발생 시 응급 조치 필요함을 교육

허리 통증 + 운동 or 무거운 짐 듬 + 운동시 악화 + 압통점
= 요추염좌 / X-ray / 침상 안정, 물리 치료, 요추 보조기

허리 통증 + 넘어짐 +골다골증 + 요추부 운동 제한 + 신경학적 이상
= 요추압박골절 / X-ray, CT, MRI / 요추보조기, 골다공증 치료, 수술

허리 통증 + 저림 + SLRT (+) + 근력/감각 이상 + DTR 감소
= 요추간판탈출증 / X-ray, CT, MRI / 요추보조기, 수술

허리 통증 + 파행 + 허리 젖히면 악화 + 쉬면 완화 + 근력/감각 정상
= 척추관협착증 / X-ray, CT, MRI / 요추보조기, 수술

통증 + 체중 감소 + 암 병력 + 감각/근력 이상
= 척추 종양 / X-ray, CT, MRI / 요추보조기, 수술

통증 + 변실금 + 요실금 + 근력, DTR 저하 + 회음부/항문 감각 마비
= 마미증후군 / X-ray, CT, MRI / 응급수술로 감암

아침에 허리 뻣뻣 + 운동 시 완화 + 휴식 시 악화 + Schober/Patrick (+)
= 강직척추염 / X-ray, HLA B27, ESR, CRP / NSAID, 재활, 운동

30분 미만 조조강직 + 고령 + ROM 감소
= 골관절염 / X-ray / NSAIDs, 재활, 운동, 생활 습관 개선
