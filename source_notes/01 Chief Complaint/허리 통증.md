# 허리 통증

## Concept
‘PEx’, 신경 이상인지 근육 이상인지 감별

## 감별진단
근육 : 요추염좌, 요추압박골절
신경 : 추간판탈출증, 척추관협착증, 척추 종양, 마미증후군
기타 : 강직척추염, 골 관절염

## Hx

### O / L / D / Co / Ex (Onset, Location, Duration, Course, Experienced)

### C (Character)
#### CC-specific
- 양상 (찌르듯이, 찌릿, 둔하고 뻐근), NRS
- 동반 (압통, 발적, 종창, 열감, 움직일 때 소리, 움직임 제한)

### A (Associated symptoms)
#### CC-specific
- General : General weakness, Weight loss, Fatigue
- 사지 근력 약화, 감각 이상
- 파행
- 요실금, 변실금, 항문 주위 감각 이상 (마미증후군)
- 조조강직, 포도막염 과거력 (강직척추염)

### F (Factor)
#### CC-specific
- 자세, 운동 영향

### E (Event)

## PEx

### V/S
#### CC-specific

### 사지
#### CC-specific
- 말초동맥 맥박 촉진

### 신경학적 검사
#### CC-specific
- 하지 : 감각, 근력, DTR, tip-toe gait

### 특수 진찰
#### CC-specific
- 통증 부위 시진, 촉진, ROM, 걸음 시진

## 환자교육
검사 : X-ray, CT, MRI
치료 : 안정
교육 : 허리 스트레칭, 신경 증상 발생 시 응급 조치 필요함을 교육

허리 통증 + 운동 or 무거운 짐 듬 + 운동시 악화 + 압통점
= 요추염좌 / X-ray / 침상 안정, 물리 치료, 요추 보조기

허리 통증 + 넘어짐 +골다골증 + 요추부 운동 제한 + 신경학적 이상
= 요추압박골절 / X-ray, CT, MRI / 요추보조기, 골다공증 치료, 수술

허리 통증 + 저림 + SLRT (+) + 근력/감각 이상 + DTR 감소
= 요추간판탈출증 / X-ray, CT, MRI / 요추보조기, 수술

허리 통증 + 파행 + 허리 젖히면 악화 + 쉬면 완화 + 근력/감각 정상
= 척추관협착증 / X-ray, CT, MRI / 요추보조기, 수술

통증 + 체중 감소 + 암 병력 + 감각/근력 이상
= 척추 종양 / X-ray, CT, MRI / 요추보조기, 수술

통증 + 변실금 + 요실금 + 근력, DTR 저하 + 회음부/항문 감각 마비
= 마미증후군 / X-ray, CT, MRI / 응급수술로 감암

아침에 허리 뻣뻣 + 운동 시 완화 + 휴식 시 악화 + Schober/Patrick (+)
= 강직척추염 / X-ray, HLA B27, ESR, CRP / NSAID, 재활, 운동

30분 미만 조조강직 + 고령 + ROM 감소
= 골관절염 / X-ray / NSAIDs, 재활, 운동, 생활 습관 개선

## ER

### 1. 즉시 평가 및 안정화
- 활력징후와 복부·혈관·신경학적 상태를 평가하고 외상, 암·감염 위험, 배뇨·배변 변화와 saddle anesthesia를 확인한다.
- 쇼크, 진행성 양측 약화, cauda equina 증상 또는 복부 대동맥질환 의심은 긴급 경로로 평가한다.

### 2. 놓치면 안 되는 질환
- cauda equina syndrome·척수압박
- 척수경막외농양·vertebral osteomyelitis
- [[복부 대동맥류 (Abdominal Aortic Aneurysm)]]·[[대동맥 박리 (Aortic Dissection)]]
- 신우신염·감염성 요로폐색
- 골절, 암 전이와 후복막출혈

### 3. 초기 검사
- 위험 소견 없는 비특이 요통은 일률적 영상검사가 필요하지 않다.
- 신경학적 결손·cauda equina·감염·암 의심은 응급 MRI를 시행한다.
- 외상·골절은 CT, 혈관·복부·비뇨기 원인은 해당 초음파·CT와 검사를 선택한다.

### 4. 초기 처치 및 재평가
- 진통과 조기 활동을 제공하되 응급 원인은 감압·항균치료·혈관중재 등 원인 치료를 지연하지 않는다.
- 근력, 감각, 회음부 감각, 보행과 방광기능을 재평가한다.

### 5. Disposition
- 진행 신경결손, cauda equina, 감염·골절·혈관성 원인, 조절되지 않는 통증은 입원한다.
- 위험 소견 없는 요통은 활동·진통·추적과 즉시 재내원 신호를 교육하고 퇴원한다.

### 6. ER 함정
- 요실금만 묻지 말고 요저류·배뇨감각 저하와 saddle anesthesia를 확인한다.
- 주사약물 사용, 면역저하 환자의 척수감염은 발열·백혈구증가가 없을 수 있다.
