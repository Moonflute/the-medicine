# 예방접종

## Concept
‘상담’, 예방접종표 있는지 확인, 예방접종을 공부

## 감별진단
나이별 필수접종 확인

## Hx
환자정보확인, 수첩 확인
현재 상태 확인 : 아픈 곳, 감염 증상
성장/발달/출산력 확인
	출산력 : GA, 분만법, 출생 당시 문제 여부
	성장력 : 키 몸무게
	발달력 : 발달은 느리지 않는가
금기 확인
	1개월 내 홍역, 유행성 이하선염, 풍진, 수두, 기타 전염병
	면역 결핍, 백혈병, 암 치료력
	최근 경련, 신경계 질환, 선천성 기형, 심질환
	스테로이드 치료력, 수혈력, 면역억제제 치료력, 주사력
	항생제, 달걀 알레르기, 이전 이상반응력
건강검진
외과가약사여

## PEx
신체진찰 없음

## 환자교육
접종확인 및 설명 (오늘백신 확인, 이후백신 확인)

부작용 
	발적, 통증, 발열, 경련 발생 가능

이상반응
	접종 후 30분동안은 관찰 필요

주의	3시간 이상 관찰하고 무리한 운동 하지 말고 안정할 것
	감염되지 않게 목욕하지 말 것, 긁거나 만지지 말 것

권고	호흡곤란, 구토, 고열 발생 시 병원 내원

질문

홍역 / 볼거리 / 풍진 (MMR) or 수두 : 동시 아니면 1달 간격

지연 특이상황
pRBC 수혈 	: 5개월
전혈수혈 	: 6개월
TTP 		: 8개월
가와사키 	: 10개월
면역결핍 치료 	: 11개월
CMV Ig 	: 11개월
