# 예방접종

## Concept
예방접종은 연령·위험요인·과거 접종기록을 기준으로 필요한 백신을 정하고, 누락 접종은 처음부터 다시 시작하지 않고 보완한다.

## 감별진단
나이별 필수접종 확인

## Hx

### CC-specific assessment
#### CC-specific
- 환자정보확인, 수첩 확인
- 현재 상태 확인 : 아픈 곳, 감염 증상
- 성장/발달/출산력 확인
- 출산력 : GA, 분만법, 출생 당시 문제 여부
- 성장력 : 키 몸무게
- 발달력 : 발달은 느리지 않는가
- 금기 확인
- 1개월 내 홍역, 유행성 이하선염, 풍진, 수두, 기타 전염병
- 면역 결핍, 백혈병, 암 치료력
- 최근 경련, 신경계 질환, 선천성 기형, 심질환
- 스테로이드 치료력, 수혈력, 면역억제제 치료력, 주사력
- 항생제, 달걀 알레르기, 이전 이상반응력
- 건강검진
- 외과가약사여

## PEx

### 특수 진찰
#### CC-specific
- 신체진찰 없음

## 환자교육
접종확인 및 설명 (오늘백신 확인, 이후백신 확인)

부작용 
	발적, 통증, 발열, 경련 발생 가능

이상반응
	접종 후 30분동안은 관찰 필요

주의	3시간 이상 관찰하고 무리한 운동 하지 말고 안정할 것
	감염되지 않게 목욕하지 말 것, 긁거나 만지지 말 것

권고	호흡곤란, 구토, 고열 발생 시 병원 내원

질문

홍역 / 볼거리 / 풍진 (MMR) or 수두 : 동시 아니면 1달 간격

지연 특이상황
pRBC 수혈 	: 5개월
전혈수혈 	: 6개월
TTP 		: 8개월
가와사키 	: 10개월
면역결핍 치료 	: 11개월
CMV Ig 	: 11개월

## 접근
- 입원은 누락 백신을 확인할 기회이지만 현재 중등도·중증 급성질환, 임신, 면역억제, 비장절제·이식과 과거 중증 알레르기를 먼저 확인한다.
## 검사
- 환자 기록·예방접종도우미 등 신뢰 가능한 이력을 확인한다. 항체검사는 지침상 필요한 경우에만 시행한다.
## 치료
- 불활성 백신은 대부분 입원 중 투여 가능하고 경미한 감염만으로 연기하지 않는다. live vaccine은 임신·중증 면역저하에서 금기다.
- influenza, pneumococcal, COVID-19, HBV와 비장절제 관련 백신을 연령·위험군 지침에 맞춰 퇴원 전 투여하거나 날짜가 명확한 예약으로 남긴다.
