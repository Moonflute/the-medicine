# 음주 상담

## Concept
‘상담’ 변형 문진을 잘 숙지, 지시문에 PE 시행 여부 확인

## 감별진단
 : 크게 중요하지는 않음
과음, 폭음, 알코올 사용장애, 알코올 금단

## Hx
음주 행태 : 언제부터, 양, 최대, 방식
음주 이유 : 음주 이유, 누구와 함께 
금주 의도 : 1개월 내 금주 계획 여부 
금주 시도 : 금주 시도 여부, 금주 기간, 실패 이유, 금단 증상
의존성 (CAGE) 
	Cut down : 술을 줄여야겠다고 느낀 적?
	Annoyed : 술로 인해 다른 사람들로부터 비난 받은 적?
	Guilty : 술 마시는 것에 대해 죄책감?
	Eye opener : 아침에 해장술을 마신 적?
내성 : 같은 정도로 취하기 위한 양, 술 마시는 시간이 증가?
남용 : 법적 / 의무 / 활동 / 관계 / 신체
Associated Sx 
	General  : Weight loss, Fatigue, Fever, Chill
	소화기 : AVNCD-B SS
	정신적 : 기분장애, 불안장애, 기억장애
Event
외상력 : 입원/수술
과거력 : HTN/DM/Hepatitis/Pul.Tb (+cancer, etc.)
약물력
사회력 : smoking, 직업/식습관/운동/스트레스
가족력 :가족 중 술담배 문제를 가진 사람
여성력

Risk : 음주 시 어떤 점이 위험할 수 있는지 아는가?
Reward : 금주 시 어떤 좋은 점이 있는지 아는가?

## PEx
 : 생략될 수 있음 
V/S 눈 (결막, 공막), 입, 흉부 (청진)
손(angioma, flapping tremor), 복부 (시 촉 전도만)

## 환자교육
환자 상태
	의존도 설명, 검사 설명 (혈액검사, 간기능검사, 복부 초음파)
격려 / 칭찬
조력자 / 방해자
시작일 / 전략
2주 내 시작일 지정
주변에 금주 사실 알리기
술자리 피하기
단주 동맹, 알코올 자조단체 참여 가능
음주 일기 작성
금단증상 / 약물처방
2~3일에 가장 심함
손떨림, 불면증, 메스꺼움, 구토, 환청, 환시, 불안, 식은땀, 두근거림
증상을 완화시키는 신경안정제(Benzodiazepine) 처방 가능
