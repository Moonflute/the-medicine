# 멍

## Concept
멍과 출혈은 점막·피부 중심인지 관절·근육의 깊은 출혈인지에 따라 혈소판·혈관 문제와 응고인자 문제를 구분한다.

## 감별진단
외상
혈관 이상 : 쿠싱 증후군, H-S Purpra
혈액 이상 : 응고 장애 : 간질환, vit K 결핍, 항응고제 복용, 혈우병 / 혈소판 이상 : ITP, DIC, vWD, HUS, TTP

## 환자교육
검사 : 혈액응고검사, 말초혈액도말검사, LFT
치료 : 약물 중단 / 수치에 따라 steroid, Ig
교육 : 외상 유발 상황 피하기, 출혈 심할 때 바로 내원, 수술/발치 주의

자색선조 + 둥근 얼굴 + 목 뒤 덩이 + 한약 + 복부 자색선조
= 쿠싱증후군 / 24hr 소변 코티솔 / 스테로이드 중단, 뇌하수체절제술

종아리 자색반 + 복통 + 구토 + 관절통 + 소아
= 헤노흐 쇤라인 자반병 / CBC, 소변검사, 피부 생검 / steroid

황달 + 복수 + 음주력 + 만성 간염
= 간질환, 간경화증 / LFT, US / 항바이러스제, 인터페론

출혈 경향 + 피부 자반 + 기타 증상 없음 (+ 항응고제)
= vit K 결핍, 항응고제 / PT, aPTT / vit K, protamine sulfate

어릴적부터 잦은 코피 + 관절 통증 + 부종 + 남아
= 혈우병 / PT, aPTT, 응고인자검사 / 결핍된 응고인자 투여

피부 점상 출혈반 + 구강, 잇몸 출혈 + 상기도 감염력 + 기타 배제
= 특발혈소판감소자반병 / CBC, PBS, PT, 골수검사 				/ 경과관찰, 수혈, Steroid, Ig, 비장절제술

감염, 염증력 + 호흡곤란 + 두근거림 + 빈맥, 빈호흡 + 저혈압
= 파종혈관내응고 / CBC, PT, fibrinogen 					/ Vit K, FFP, 항응고제, 항혈소판제

어지럼 + 체중 감소 + 피로 + 식욕 부진 + 발열 + 빈혈 + 림프절 종대
= 골수기능저하 / CBC, PBS, 염색체 / 항암치료, 방사선치료, 골수 이식

점상 출혈 + 잇몸 출혈 + 코피 + 과다월경
= 본빌레브란드병 / CBC, PT, vWF / desmopressin, vWF

핍뇨 + 설사
= 용혈요독증후군 / 소변검사, BUN,Cr, PBS / 보존적, 혈액 투석, 수혈

점상 출혈 + 정신신경계 증상 + 발열 + 신장이상
= 혈전혈소판감소자반병 / CBC, PBS, PT, 골수검사 / 혈장교환,, 보존적

## 접근
- 주사·혈압커프·낙상, anticoagulant·antiplatelet, thrombocytopenia와 DIC를 확인하고 위치·크기·진행과 다른 출혈을 기록한다.
## 검사
- CBC·platelet, PT/INR·aPTT, fibrinogen, renal·liver function을 시행한다. Hb 감소·옆구리 통증은 retroperitoneal bleeding 영상을 고려한다.
## 치료
- 작고 안정적인 주사부위 멍은 압박·관찰한다. 진행성 혈종, Hb 감소 또는 critical-site bleeding은 항혈전제를 보류하고 원내 reversal·수혈·시술 protocol을 적용한다.

## ER

### 1. 즉시 평가 및 안정화
- 활력징후, 점막·위장관·두개내 출혈 증상과 멍의 범위·발생속도를 확인한다.
- 저혈압, 의식 변화, 심한 두통, 진행 출혈이 있으면 중증 출혈·응고장애 경로로 평가한다.

### 2. 놓치면 안 되는 질환
- 혈소판감소증·TTP·DIC
- 혈우병·후천응고인자억제
- 항응고제·항혈소판제 관련 출혈
- 간부전·혈액암
- 신체학대·가정폭력

### 3. 초기 검사
- CBC와 말초도말, PT/INR, aPTT, fibrinogen, 신장·간기능을 임상상에 맞춰 시행한다.
- 용혈·TTP 의심은 LDH, bilirubin, haptoglobin과 신경·신장 소견을 함께 본다.
- 외상 또는 국소 증상에 따라 출혈 영상검사를 선택한다.

### 4. 초기 처치 및 재평가
- 중증 출혈은 원인별 혈액제제·응고인자·약물 역전과 출혈 조절을 시행한다.
- TTP·DIC·급성백혈병 의심은 혈액내과와 즉시 협의한다.
- 새 출혈, 혈소판·응고와 장기기능 추세를 재평가한다.

### 5. Disposition
- 중증 출혈, 심한 혈소판감소, 용혈·DIC·TTP, 안전하지 않은 환경은 입원한다.
- 경미한 멍이라도 원인 불명·반복이면 신속한 추적검사를 연결한다.

### 6. ER 함정
- 정상 PT/aPTT가 혈소판질환·von Willebrand disease를 배제하지 않는다.
- 멍의 위치·발달단계만으로 학대 여부를 단정하지 않고 전체 맥락을 평가한다.
