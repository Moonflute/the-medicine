# 변비

## Concept
'배변’ 배변습관 확인, 소화기 관련 추가 문진

## 감별진단
기능성 변비 (90%)
기질성 변비 : 소화기 : 결장/직장암, 직장류, 과민성 대장증후군 / 기타 : 갑상샘저하증, 약물 유발, 신경 이상

## 환자교육
검사 : AXR, 대장내시경, 갑상샘기능검사
치료 : 병바병
교육 : 안심시키기 (기질적 원인이 없는 경우가 90%)
	변비약 장기간 복용 시 악화 가능성 설명 필요, 생활습관개선

만성 변비 + 평소 건강 + 저섬유성 식사 + 저수분 식사 + 젋은 여자
= 기능성 변비 / AXR, 대장통과시간, 항문압 / 생활 습관 교정

변비 + 설사 + 혈변 + 대변 가늘어짐 + 체중 감소 + 피로 + DRE 종괴
= 결장암, 직장암 / 대장내시경, US, CT, MRI / 수술, RTx, CTx

변비 + 설사 + 복부 팽만 + 소화불량 + 배변 후 호전 + 점액질 변
= 과민 대장증후군 / 대변검사, 대장내시경, CBC / 생활 습관 교정, 완하제

변비 + 잔변감 + 밀려나오는 느낌 + 골반 내진 상 질쪽으로 덩이 내려옴
= 직장류 / 배변조영술, 대장내시경 / 케겔 운동, 페서리 수술

변비 + 피로 + 체중 증가 + 추위불내성 + 하지 부종 + 갑상샘 종대
= 갑상샘저하증 / TFT / 갑상샘호르몬

변비 + 아편제제/철/항콜린제/항고혈압제 + 기타 정상
= 약물 유발 변비 / 없음 / 약물 중단

변비 + 치매 + 파킨슨병 + NEx 이상
= 신경 이상 변비 / 신경계 검사 / 변비약

## ER

### 1. 즉시 평가 및 안정화
- 활력징후, 탈수, 복부팽만·복막자극, 구토와 가스·대변 중단을 확인한다.
- 심한 통증, 발열·독성 외관, 혈변, 고령·수술력은 단순 변비보다 폐색·허혈을 우선 평가한다.

### 2. 놓치면 안 되는 질환
- [[장폐색]]·장염전·천공
- 분변매복과 stercoral colitis
- 대장암·협착
- 척수압박·cauda equina syndrome
- opioid, anticholinergic 약물과 고칼슘혈증·갑상샘저하

### 3. 초기 검사
- 단순 변비는 임상진단이 중심이다.
- 폐색·천공·염증 또는 이차 원인이 의심되면 CBC, 전해질·칼슘·신장기능과 복부 CT를 선택한다.
- 직장수지검사는 매복·출혈·종괴를 확인할 임상 적응증이 있을 때 시행한다.

### 4. 초기 처치 및 재평가
- 분변매복은 관장·수기제거를 상황에 맞춰 시행하고, 폐색·천공이 배제된 뒤 완하제를 사용한다.
- 폐색·염전·천공은 금식, 감압·수액과 외과 협진을 진행한다.
- 통증, 팽만, 구토와 배변·가스 통과를 재평가한다.

### 5. Disposition
- 폐색·천공·stercoral colitis, 심한 전해질 이상 또는 치료 실패는 입원한다.
- 위험 원인이 배제되고 증상 조절과 추적이 가능할 때 퇴원한다.

### 6. ER 함정
- overflow diarrhea가 분변매복을 가릴 수 있다.
- 단순 X선의 대변량만으로 증상 원인을 확정하지 않는다.
