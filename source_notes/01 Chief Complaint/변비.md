# 변비

## Concept
'배변’ 배변습관 확인, 소화기 관련 추가 문진

## 감별진단
기능성 변비 (90%)
기질성 변비 : 소화기 : 결장/직장암, 직장류, 과민성 대장증후군 / 기타 : 갑상샘저하증, 약물 유발, 신경 이상

## Hx

### O / L / D / Co / Ex (Onset, Location, Duration, Course, Experienced)

### C (Character)
#### CC-specific
- 변 굵기, 색, 힘, 딱딱, 잔변감, 막힌 느낌, 손으로 긁어냄,,
- 배변 습관 (앉아있는 시간, 장소, 참는시간, 신문, 핸드폰)

### A (Associated symptoms)
#### CC-specific
- General : Weight loss, Fatigue, Fever, Chill
- AVNCD (Anorexia, Vomiting, Nausea, Constipation, Diarrhea)-B P + 팽만감, 복부 종괴, 항문 덩이/통증, 폐쇄
- 추위불내성, 피부 푸석푸석
- 우울, 불안, 기분저하 / 수면장애

### F (Factor)
#### CC-specific
- 배변 후 호전 여부

### E (Event)

### Background history (외과력)
- 맵거나 기름진 음식, 식이섬유, 채소류, 물

## PEx
V/S 눈 입 목(갑상샘, 림프절)
피부 (긴장도, 부종)
복부 : 시 – 청 – 타 – 촉
DRE
골반내진

## 환자교육
검사 : AXR, 대장내시경, 갑상샘기능검사
치료 : 병바병
교육 : 안심시키기 (기질적 원인이 없는 경우가 90%)
	변비약 장기간 복용 시 악화 가능성 설명 필요, 생활습관개선

만성 변비 + 평소 건강 + 저섬유성 식사 + 저수분 식사 + 젋은 여자
= 기능성 변비 / AXR, 대장통과시간, 항문압 / 생활 습관 교정

변비 + 설사 + 혈변 + 대변 가늘어짐 + 체중 감소 + 피로 + DRE 종괴
= 결장암, 직장암 / 대장내시경, US, CT, MRI / 수술, RTx, CTx

변비 + 설사 + 복부 팽만 + 소화불량 + 배변 후 호전 + 점액질 변
= 과민 대장증후군 / 대변검사, 대장내시경, CBC / 생활 습관 교정, 완하제

변비 + 잔변감 + 밀려나오는 느낌 + 골반 내진 상 질쪽으로 덩이 내려옴
= 직장류 / 배변조영술, 대장내시경 / 케겔 운동, 페서리 수술

변비 + 피로 + 체중 증가 + 추위불내성 + 하지 부종 + 갑상샘 종대
= 갑상샘저하증 / TFT / 갑상샘호르몬

변비 + 아편제제/철/항콜린제/항고혈압제 + 기타 정상
= 약물 유발 변비 / 없음 / 약물 중단

변비 + 치매 + 파킨슨병 + NEx 이상
= 신경 이상 변비 / 신경계 검사 / 변비약
