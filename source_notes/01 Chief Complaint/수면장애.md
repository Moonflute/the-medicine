# 수면장애

## Concept
수면장애는 수면 기회가 충분한지 확인한 뒤 불면, 수면호흡장애, 일주기장애, 과다수면과 물질·약물 영향을 구분한다.

## 감별진단
원발성 : 불면장애, 하루 주기율동 수면장애, 기면병 / 폐쇄수면무호흡, 하지 불안증후군, 주기성 사지 운동장애, 렘수면 행동장애
속발성 : 주요 우울장애, 물질/약물성/폐경/신체 질환 수면장애

## 환자교육
검사 : 수면다원검사, 혈액검사
치료 : 수면제 처방, 수면일지 작성, 인지행동 치료
교육 : 수면 위생, 수면제 사용 (부작용 주의)

(수면장애 + 주간증상) x 1주 3회 이상, 3개월 이상 지속
= 불면장애 / 수면다원검사 / 수면 위생 개선, 인지행동 치료, BZD

낮밤이 바뀌는 생활
= 하루 주기 율동 수면장애 / 수면다원검사 / 수면각성주기조절, 광치료, 멜라토닌

코골이 + 개운하지 않음 + 주간 졸림 + 비만 + 좁은 기도
= 폐쇄수면무호흡 / 수면다원검사 / CPAP, 옆으로 자기, 다이어트, 수술

자기 전에 다리가 불편 + 고령 + 다양한 기저질환
= 하지 불안증후군 / 수면다원검사, 철분검사 / 철분 보충, 도파민제

입면장애 + 자다가 깸 + 주간 졸림 + 수면 중 사지운동
= 주기성 사지 운동장애 / 수면다원장애 / 철분 보충, 도파민제

자다가 과격한 행동을 함
= 렘 수면 행동장애 / 수면다원검사 / 안전한 수면 환경 조성, 멜라토닌

수면 발작 + 탈력 발작 + 자거나 깰 때 환각이나 마비
= 기면병 / 야간수면다원검사, CSF hypocretin / Modafinil, SSRI

우울 + 의욕 저하 + 식용 저하 + 죄책감 + 피로 (우울증 증상)
= 주요 우울장애 / Beck 우울척도검사 / SSRI

물질/약물 오남용
= 물질/약물로 유도된 수면장애 / / 약물 중단, 대체 약물 투여

얼굴 화끈거림 + 예민 + 무기력 (폐경 증상)
= 폐경으로 유도된 수면장애 / 혈중 FSH, estradiol / 호르몬 대체요법

앓고 있는 질환으로 불편함
= 신체 질환으로 인한 수면장애 / 원인에 따라 / 기저 질환 치료

## 접근
- 통증·dyspnea, nocturia, delirium, withdrawal, steroid·caffeine과 병동 처치시간을 확인한다. 새 낮밤 역전은 delirium을 먼저 평가한다.
## 검사
- 투약·수면 schedule review가 우선이며 OSA·hypoventilation 위험과 야간 SpO2를 단서에 따라 확인한다.
## 치료
- 야간 처치를 묶고 빛·소음·낮잠을 조정한다. 필요 시 Melatonin prolonged-release (서카딘정 2 mg) 2 mg PO 취침 1–2시간 전을 고려하며 sedative-hypnotic 신규 처방은 낙상·섬망 위험을 확인한다.
