# 두근거림

## Concept
두근거림은 실제 맥박 변화와 일치하는지 확인하고 갑작스러운 시작·종료, 운동 연관성, 실신 동반 여부로 부정맥 가능성을 가른다.

## 감별진단
순환기 : 생리적 빈맥, 심방 세동/조동, 돌발심실상빈맥, 조기심실수축 / 판막 질환, 심부전
내분비 : 갑상샘항진증, 크롬친화세포종, 저혈당, 폐경 전후
정신적 : 불안장애, 공황장애, 신체화장애
기타 : 저혈량, 저혈당 / 약물

## 환자교육
검사 : EKG, 혈액검사, 소변 메타네프린
치료 : 병바병
교육 : 스트레스 주의, 생활습관 교정

두근거림 + 호흡곤란 + 흉통 + 불규칙한 맥박
= 심방세동,조동 / EKG, Holter, echo / BB, CCB, warfarin

갑작스러운 규칙적인 두근거림 + 갑자기 종료 + 이후 요의
= 돌발심실상빈맥 / EKG, Holter / 미주신경자극법, 발살바법, adenosine 

불규칙한 두근거림 + 쿵 내려앉는 느낌 + 어지럼
= 조기심실수축 / ECG, Holter / BB, CCB, radiofrequency ablation

두근거림 + 어지럼 + 실십 + 호흡곤란 + 흉통 + 심잡음 청진
= 판막 질환 / ECG, echo / 이뇨제, 원인별 치료

두근거림 + 호흡곤란 + 피로 + 하지 부종 + 호흡 수포음
= 심부전 / ECG, echo / ACEi, ARB, BB, diuretics, Digoxin

두근거림 + 호흡곤란 + 피로 + 어지럼 + 결막 창백
= 빈혈 / CBC, ferrtin / 철분 보충, 코발라민, 엽산 보충

두근거림 + 구토 + 설사 + 탈수 소견 + 피부 긴장도 저하
= 저혈량증 / 전해질검사 / 수액 정주

두근거림 + 두통 + 식은땀 + 기립성 저혈압
= 크롬친화세포종 / 24hr urine 메타네프린, CT / AB, BB, 부신절제술

두근거림 + 더위불내성 + 체중 감소 + 피로 + 설사 + Goiter
= 갑상샘항진증 / TFT, ECG / 항갑상샘제, BB, 방사성 요오드 치료

두근거림 + 어지럼 + 실신 + 인슐린 복용력 + 당뇨병력 + 굶음
= 저혈당 / 혈당검사 / 경구 당 공급, 포도당 용액, 교육

두근거림 + 얼굴 화끈거림 + 식은땀 + 정서적 불안정
= 폐경기 증후군 / FST, estradiol / HRT, 생활 습관 교정

두근거림 + 죽을 것 같은 공포감 + 예기불안
= 불안장애, 공황장애 / 기질적 질환 감별 / SSRI, 인지 행동 치료

## 접근
- 증상 중 pulse와 telemetry strip을 확보하고 저혈압, 흉통, 폐부종, 실신을 확인한다. 새 약물, K·Mg 이상, anemia·sepsis·hypoxia, withdrawal과 중심정맥관 위치를 검토한다.
- 불안정 빈맥이면 즉시 synchronized cardioversion과 신속대응팀을 준비한다.
## 검사
- 12유도 ECG, K·Mg·Ca, CBC, glucose, renal function과 troponin·TSH를 단서에 따라 시행한다. 기존 ECG와 QTc, telemetry onset을 비교한다.
## 치료
- 규칙적 narrow-complex SVT가 안정적이면 vagal maneuver 후 Adenosine (아데노코주 6 mg/2 mL 등) 6 mg rapid IV push, 실패 시 12 mg을 투여한다. 불규칙·wide-complex rhythm에는 사용하지 않는다.
- 안정된 AF with RVR는 원인 교정과 함께 Metoprolol (베타록주 1 mg/mL) 2.5–5 mg IV q5min, 최대 15 mg을 고려하되 저혈압·급성 심부전·기관지경련에서 피한다. rhythm과 혈압을 5–15분마다 재평가한다.

## ER

### 1. 즉시 평가 및 안정화
- 현재 빈맥·서맥과 혈역학적 불안정을 동시에 확인하고 심전도 모니터와 12유도 심전도를 확보한다.
- 저혈압, 의식 변화, 허혈성 흉통, 급성 심부전·쇼크가 동반된 부정맥은 즉시 불안정 부정맥 경로로 치료한다.

### 2. 놓치면 안 되는 질환
- 심실빈맥·고도 방실차단·pre-excited atrial fibrillation
- ACS·심근염·폐색전증
- 갑상샘위기, 패혈증, 출혈, 저산소증
- 전해질 이상과 digoxin·교감신경흥분제 등 약물·중독

### 3. 초기 검사
- 증상 중 12유도 심전도와 이전 심전도를 비교한다.
- 전해질, 혈색소, 갑상샘·troponin·임신검사는 임상 단서에 따라 선택한다.
- 간헐 증상이 사라졌으면 모니터링과 외래 rhythm recording 필요성을 판단한다.

### 4. 초기 처치 및 재평가
- 불안정 부정맥은 동기화 심율동전환 또는 pacing을 포함한 즉시 치료를 시행한다.
- 안정 환자는 QRS 폭, 규칙성과 기전을 확인한 뒤 원인별 치료를 시행한다.
- 약물·전해질·허혈·저산소증 등 유발 원인을 교정한다.

### 5. Disposition
- 불안정, 심실성 부정맥, 고도 전도장애, 구조적 심질환·허혈 동반은 입원한다.
- 양성 조기수축 또는 종료된 저위험 빈맥은 추적·재내원 계획이 있을 때 퇴원을 고려한다.

### 6. ER 함정
- 증상이 사라진 뒤 정상 심전도만으로 위험 부정맥을 배제하지 않는다.
- 젊은 환자에서도 실신·운동 연관·돌연사 가족력은 고위험 단서다.
