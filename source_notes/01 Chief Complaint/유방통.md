# 유방통

## Concept
유방통은 주기성·양측성 통증과 국소적 비주기성 통증을 구분하고 종괴, 피부·유두 변화가 동반되면 별도로 평가한다.

## 감별진단
염증성 : 유선염, 유방 농양
생리적 : 주기유방병증, 유방울혈
외부적 : 유방 외상 / 피임약, 호르몬 대체요법, 카페인에 의한 유방통

단단한 덩이 : 섬유낭병, 섬유선종, 유방암
물렁한 덩이 : 유방낭종, 관내유두종, 젖낭종

## 환자교육
검사 : 유방초음파, 유방촬영술, 조직검사
치료 : 병바병
교육 : 자가검진, 정기검진 강조 (30세 자가 40세 촬영), 생활 습관 교정

단단 덩이 + 월경 전 유방통
= 섬유낭병 / 유방촬영술, 유방초음파 / 경과 관찰, 절제 생검

물렁 덩이 + 월경 주기 유방통
= 유방낭종 / 유방촬영술, 유방초음파 / 경과 관찰, 절제 생검

단단 덩이 + 주기 무관 + 무통성 + 미끄러짐
= 섬유선종 / 유방촬영술, 유방초음파, 세침 흡인, 절제 생검 / 절제 생검

단단 덩이 + 주기 무관 + 종양 소견
= 유방암 / 유방촬영술, 유방초음파, CNB / 수술, RTx, CTx

작은 덩이 + 혈성 분비물
= 관내유두종 / 유방촬영술, 유방초음파, 세침 흡인 / 전절제

물렁 덩이 + 최근 수유력
= 젖낭종 / 유방촬영술, 유방초음파, 세침 흡인 / 세침 흡인

다발 덩이 + 월경 시작 통증 + 기타 배제됨
= 주기유방병증 / 유방촬영술, 유방초음파 / 안심

유방통 + 호르몬제 투약 + PEx 정상
= 호르몬에 의한 유방통 / 유방촬영술, 유방초음파 / 안심

유방통 + 열감 + 양측 발적 + 최근 출산
= 유방울혈 / 필요 없음 / 마사지, 찜질

유방통 + 발열 + 한측 발적 + 압통 + 수유중
= 유선염 / 유방촬영술, 유방초음파 / 수유 자주, 찜질

유방통 + 열감 + 발열 + 오한 + 압통 + fluctation
= 유방 농양 / 유방촬영술, 유방초음파 / 절개 배농, 항생제

유방통 + 카페인 과다 섭취 + 기타 정상
= 카페인성 유방통 / 유방촬영술, 유방초음파 / 카페인 끊기

## 접근
- unilateral focal pain, fever·erythema, lactation, trauma·line position과 흉벽·심장성 통증을 구분한다. mass·skin change·bloody nipple discharge는 영상평가한다.
## 검사
- focal persistent pain이나 진찰 이상이면 age-appropriate ultrasound/mammography를 선택한다. diffuse cyclic pain만으로 광범위 검사를 하지 않는다.
## 치료
- 감염·농양을 배제한 통증은 Acetaminophen (타이레놀정) 500–1,000 mg q6h PRN과 지지 브라를 사용한다. mastitis/abscess는 수유상태·배양·원내 항균지침과 drainage 여부를 반영한다.
