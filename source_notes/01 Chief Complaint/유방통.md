# 유방통

## Concept
‘부인과’ 두 CC의 질환이 매우 겹치므로 함께 고려한다

## 감별진단
염증성 : 유선염, 유방 농양
생리적 : 주기유방병증, 유방울혈
외부적 : 유방 외상 / 피임약, 호르몬 대체요법, 카페인에 의한 유방통

단단한 덩이 : 섬유낭병, 섬유선종, 유방암
물렁한 덩이 : 유방낭종, 관내유두종, 젖낭종

## Hx
PPI 멘트
O L D Co Ex
Character
	(통증 <-> 덩이) NRS / 개수, 크기, 단단, 경계, 통증
월경력 : 월경 중 여부, 주기, LMP, 임신 가능성, 초경, 폐경
산과력 : 결혼 여부, 아이 수, 첫 아이 임신 시기
관련 : 수유, 출산 나이, 모유수유
Associated Sx
General  : Weight loss, Fatigue, Fever, Chill, Edema
유방 : 피부 발적, 부종, 열감, 피부 함몰
유두 : 유두 함몰, 유두 분비물
림프절 : 겨드랑이 멍울, 압통
정신 : 우울, 불안, 수면장애
Female & Factor
Event : 건강검진 이력 (산부인과 검진)
외과약사가여

## PEx
V/S
하이브리드 : 유방진찰

## 환자교육
검사 : 유방초음파, 유방촬영술, 조직검사
치료 : 병바병
교육 : 자가검진, 정기검진 강조 (30세 자가 40세 촬영), 생활 습관 교정

단단 덩이 + 월경 전 유방통
= 섬유낭병 / 유방촬영술, 유방초음파 / 경과 관찰, 절제 생검

물렁 덩이 + 월경 주기 유방통
= 유방낭종 / 유방촬영술, 유방초음파 / 경과 관찰, 절제 생검

단단 덩이 + 주기 무관 + 무통성 + 미끄러짐
= 섬유선종 / 유방촬영술, 유방초음파, 세침 흡인, 절제 생검 / 절제 생검

단단 덩이 + 주기 무관 + 종양 소견
= 유방암 / 유방촬영술, 유방초음파, CNB / 수술, RTx, CTx

작은 덩이 + 혈성 분비물
= 관내유두종 / 유방촬영술, 유방초음파, 세침 흡인 / 전절제

물렁 덩이 + 최근 수유력
= 젖낭종 / 유방촬영술, 유방초음파, 세침 흡인 / 세침 흡인

다발 덩이 + 월경 시작 통증 + 기타 배제됨
= 주기유방병증 / 유방촬영술, 유방초음파 / 안심

유방통 + 호르몬제 투약 + PEx 정상
= 호르몬에 의한 유방통 / 유방촬영술, 유방초음파 / 안심

유방통 + 열감 + 양측 발적 + 최근 출산
= 유방울혈 / 필요 없음 / 마사지, 찜질

유방통 + 발열 + 한측 발적 + 압통 + 수유중
= 유선염 / 유방촬영술, 유방초음파 / 수유 자주, 찜질

유방통 + 열감 + 발열 + 오한 + 압통 + fluctation
= 유방 농양 / 유방촬영술, 유방초음파 / 절개 배농, 항생제

유방통 + 카페인 과다 섭취 + 기타 정상
= 카페인성 유방통 / 유방촬영술, 유방초음파 / 카페인 끊기
