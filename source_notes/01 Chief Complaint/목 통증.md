# 목 통증

## Concept
목 통증은 기계적 통증과 신경근병증·척수병증을 구분하고 외상, 감염, 혈관성 원인을 시사하는 징후를 따로 찾는다.

## 감별진단
근육 : 경추염좌, 채찍질손상, 근막통증증후군
신경 : 경추간판탈출증, 척추관협착증, 척추 종양, 수막염, 삼차신경통
기타 : 류마티스 관절염, 전방 구조물

## Hx

### O / L / D / Co / Ex (Onset, Location, Duration, Course, Experienced)

### C (Character)
#### CC-specific
- 양상 (찌르듯이, 찌릿, 둔하고 뻐근), NRS
- 동반 (압통, 발적, 종창, 열감, 움직일 때 소리, 움직임 제한)
- 찌릿하고 털이 서는 느낌이 있는가?
- 목소리 이상이 있는가?

### A (Associated symptoms)
#### CC-specific
- General : General weakness, Weight loss, Fatigue
- 사지 근력 약화, 감각 이상
- 두통, 감기 증상, 목 뻣뻣
- 얼굴에 전기
- 통증이 있을 때 땀이 나고 털이 곤두서는 증상

### F (Factor)
#### CC-specific
- 자세, 운동 영향

### E (Event)

## PEx

### V/S
#### CC-specific
- V/S

### 신경학적 검사
#### CC-specific
- 상지 : 감각, 근력, DTR
- Spurling test, Lhermitte sign
- 수막 자극 징후

### 특수 진찰
#### CC-specific
- 통증 부위 시진, 촉진, ROM (앞뒤 좌우 돌리기)

## 환자교육
검사 : X-ray, CT, MRI
치료 : 병바병
교육 : 목 스트레칭, 신경 증상 악화가 아니면 수술은 천천히 고려

뒷목 통증 + 움직이면 악화 + 쉬면 완화 + 방사통 x
= 경추 염좌 / X-ray, CT, MRI / 경추 보조기, 침상 안정, 스트레칭

교통 사고 등 외상 후 목 통증 + 두통 + 어깨 통증 + 구역 + 두토
= 채찍질 손상 / X-ray, CT, MRI / 경추 보조기, 침상 안정, 스트레칭

목 통증 + 활동성 유발점으로 ANS 증상 + 단단한 띠 형태
= 근막통증 증후군 / 임상 증상으로 / 마사지, 진통제, 온열 치료

목/팔/손가락 방사통 + 목 젖히면 악화 + Spurling (+)
= 경추간판탈출증 / X-ray, CT, MRI / 경추 보조기, 침상 안정, 스트레칭

목/어깨/양팔 통증 + 서서히 악화 + 50세 이상
= 척추관협착증 / X-ray, CT, MRI / 경추 보조기, 침상 안정, 스트레칭

체중 감소 + 배뇨장애 + 신경학적 이상 증상
= 척추 종양 / X-ray, CT, MRI / 수술, 항암화학요법, RTx

발열 + 감기 증상 + 수막 자극 징후 양성
= 수막염 / CSF 검사, MRI, CT / 항생제, dexamethasone

찌르는 듯한 얼굴 통증
= 삼차신경통 / MRI / carbamazepine, 수술

체중 감소 + 목소리 변화 + 연하곤란 + 발음 곤란
= 전방 구조물 / Neck CT / 수술

아침에 뻣뻣함 + 손관절 등도 통증
= 류마티스 관절염 / X-ray, RA, CCP / NSAIDs, glucocorticoid

## 관련질환

## 접근
- 자세통 외에 meningitis, cervical epidural abscess/hematoma, central line 합병증과 deep neck infection을 확인한다. 발열·신경결손·연하/호흡장애는 긴급 평가한다.
## 검사
- 신경학적 진찰, CBC·CRP·cultures를 단서에 따라 시행하고 cord infection·hematoma 의심 시 urgent MRI, trauma이면 CT를 선택한다.
## 치료
- 위험 원인이 배제된 근육성 통증은 Acetaminophen (타이레놀정) 500–1,000 mg q6h PRN, 온찜질과 조기운동을 사용한다. 진정성 근이완제는 낙상·섬망 위험을 고려한다.

## ER

### 1. 즉시 평가 및 안정화
- 외상에서는 경추를 보호하며 ABC와 신경학적 결손을 먼저 평가한다.
- 발열·독성 외관, 진행성 사지약화, 호흡·연하곤란, 갑작스러운 두통·신경학적 증상은 응급 원인을 시사한다.

### 2. 놓치면 안 되는 질환
- 경추 골절·불안정과 척수손상
- 척수경막외농양·discitis·osteomyelitis
- 동맥박리·지주막하출혈·뇌수막염
- 심경부감염·후두개염
- ACS·대동맥박리의 연관통

### 3. 초기 검사
- 외상 영상은 validated cervical spine rule과 위험인자에 따라 CT를 선택한다.
- 신경학적 결손·감염·압박 의심은 응급 MRI가 필요하다.
- 동맥박리·혈관질환은 CT/MR angiography를 시행한다.

### 4. 초기 처치 및 재평가
- 불안정 손상은 고정과 신경외과 협진, 감염은 배양·항균치료와 수술 평가를 시행한다.
- 기도 위험의 심경부감염은 영상보다 통제된 기도 확보가 우선이다.
- 통증 조절 후 신경학적 진찰을 반복한다.

### 5. Disposition
- 외상성 불안정, 신경학적 결손, 척수감염·압박, 혈관질환·기도 위험은 입원한다.
- 단순 근골격 통증은 위험 소견이 없고 기능·추적이 확보될 때 퇴원한다.

### 6. ER 함정
- 발열이 없다고 척수경막외농양을 배제하지 않는다.
- 외상 후 정상 단순 X선만으로 고위험 경추손상을 배제하지 않는다.
