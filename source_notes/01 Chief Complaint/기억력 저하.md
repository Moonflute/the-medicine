# 기억력 저하

## Concept
‘정신’, MMSE+PE 까지 빠르게, ‘보호자에게 확인하겠다’ ‘ 학력‘

## 감별진단
치매
	알츠하이머, 혈관성, 전두측두엽, 레비소체 / 약물, 외상, MCI
정신
	가성 치매, 섬망, 코르사코프 증후군
기타
	정상압 수두증 / 갑상샘저하증

## Hx
Onset : 급성 여부
L D Co Ex
Character
	기억이 떨어졌다는 게 어떤 의미인가
	양상 : 최근/과거 기억 중 기억나지 않는 것
	길찾기 / 가스불 / 계산 / 단어 떠올리기 (길가계단)
	정도 : 일상 생활 지장 여부 (옷입기, 식사, 보행, 화장실, 집안일)
Associated Sx 
	(전두) 성격 변화
(레비) 환시, 양손 떨림, 경직, 행동 느려짐, 보폭 감소
(혈관) 갑작스럽게 나타남, 두통, 팔다리 힘 빠짐
(우울증) 우울, 의욕 감소, 체중 변화
(정상압) 요실금, 보행이상
추위불내성
FE 
외과약사가여 : 최종 학력 (조심스럽게 질문)

## PEx
V/S 간이 MMSE
뇌신경검사, 목(갑상샘), 손 (tremor)
사지 검사, 보행 검사

## 환자교육
검사 : 혈액 검사, 뇌 MRI, 뇌 PET (amyloid)
치료 : 알츠하이머 진단 시 donepezil
교육 : 취미 활동, 규칙적인 운동, 생활 습관 개선, 지원 센터

서서히 진행됨 + 최근 기억 저하 + 약속 잊음 + 시각 지남력 저하
= 알츠하이머 치매 / MRI, PET, 신경심리검사 / 인지기능개선제, 인지재활

갑자기 발병 + 계단식 악화 + 신경학적 증상 + HTN/stroke 병력
= 혈관 치매 / CT, MRI / 위험 인자 조절, 항혈소판제, 인지기능개선제

성격 변화 + 충동 행동 + 부적적한 사회적 행동 + 실어증
= 전두측두엽 치매 / MRI, PET / SSRI, 언어 치료

기복이 있는 인지 기능 + 환시 + 파킨슨 증후군 증상
= 레비소체 치매 / MRI, PET / 인지기능개선제, 약물

최근에 약 복용/외상 + 기타 정상
= 약물 유발성/외상 치매 / … / …

일상 생활에 지장은 없는 정도의 인지장애
= 경도인지장애 / 정신상태검사, 신경심리검사 / 운동, 약물은 안씀

우울 + 의욕 저하 + 검사 귀찮아함
= 가성 치매 / Beck 우울척도검사, 정신상태검사 / SSRI, TCA

최근 입원력 + 기복 있는 주의력/지남력 저하 + 인지 기능 저하 동반
= 섬망 / … / 교정 가능한 원인 치료, haloperidol, 적절한 환경 조성

만성 알코올 중독 + 새로 발생하는 일을 기억하지 못함 + 작화증
= 코르사코프 증후군 / … / Vit B, 영양 공급

보행장애 + 요실금 + 인지장애
= 정상압 수두증 / CT, MRI / 뇌실복막강 shunt

추위불내성 + 체중 증가 + 의욕 저하 + 변비
= 갑상샘저하증 / TFT / levothyroxine
