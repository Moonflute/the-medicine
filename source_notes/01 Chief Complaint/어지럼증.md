# 어지럼증

## Concept
PEx 시간 많이 걸림, 진단은 증상 지속시간을 우선으로

## 감별진단
말초성
	양성돌발체위현기증 (BPPV), 메니에르병, 전정신경염, 
중추성 
	소뇌 경색, 뇌졸중, 뇌종양, 파킨슨병, 전정편두통
기질성
	기립 저혈압, 저혈당, 빈혈, 당뇨병신경병증
정신
	불안장애, 과호흡증후군

## Hx
O L D Co Ex
Character
	양상, 정도 (실신, 구토 동반 확인), 지속 시간
Associated Sx 
	난청, 이명, 이충만감, 청력 저하
	FCCSR, NV
	팔다리 감각 이상, 근력 저하, 시력 이상, 발음 이상, 보행장애
	손떨림, 몸뻣뻣, 행동 느려짐
	두통
	탈수 증상
	우울/불안/답답/죽을 것 같은 느낌 낌
Factor
	자세에 따른 변화, 일어설 때 증상, 식사 변화 
E 
외과약사가여 : 최근 약물 변화

## PEx
V/S 눈 (안진) 목 (Head impulse)
뇌신경검사 (동공 반사, 안구 운동, 얼굴 감각, 얼굴 운동)
청력검사 (Rinne, Weber) - 메니에르 의심 시
소뇌기능검사
Dix-Hallpike (BPPV 의심 시)
여유 있으면 팔다리 감각검사

## 환자교육
검사 : 이경검사, 청력검사, 전정기능검사, 머리 영상검사
치료 : 병바병
교육
	어지럼을 유발할 수 있는 생활습관 개선
	쓰러질 것 같으면 안정된 곳으로 이동하여 머리를 다치지 않게 

30초 가량 어지럼증 + 오심,구토 + 움직일 시 악화 + Dix (+)
= 양성돌발체위현기증 / Dix (+) / Epley 수기

수 분,시간 어지럼증 + 난청 + 이명 + 이충만감
= 메니에르병 / 청력검사, 전정기능검사, MRI, CT / 약물치료, 감압술

수 시간,일 어지럼증 + 구역 + 구토 + 상기도 감염 + 안진
= 전정신경염 / 전정기능검사, 청력검사 / BZD, 항구토제, 재활운동

가만히 있어도 어지럼증 + 자세 불균형 + 신경학적 이상 + 안진
= 소뇌 경색 / brain CT, MRI / 혈전용해제, 항혈소판제, 항응고제

손떨림 + 균형장애 + 보행장애 + 행동 느려짐
= 파킨슨병 / 뇌 MRI, PET / levodopa

수 시간 어지럼증 + 편두통
= 전정편두통 / 불필요 / 급성기 NSAIDs, Triptan

일어날 때 나타남 + 출혈 + 탈수
= 기립 저혈압 / 3 position / 천천히 움직일 것, 약제 중단

아찔한 어지럼증 + DM, anemia
= 저혈당, 빈혈 / 혈당검사, 혈액검사 / 당류 공급, 철분 보충

조절되지 않는 당뇨 병력
= 당뇨병 신경병증 / 혈당검사, 당화혈색소, 자율신경검사 / 혈당 조절

어지럼증 + 불안 + 답답
= 불안장애, 과호흡증후군 / 불필요 / SSRI, BZD, 인지행동치료
