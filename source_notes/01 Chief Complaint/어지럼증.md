# 어지럼증

## Concept
PEx 시간 많이 걸림, 진단은 증상 지속시간을 우선으로

## 감별진단
말초성 : 양성돌발체위현기증 (BPPV), 메니에르병, 전정신경염,
중추성 : 소뇌 경색, 뇌졸중, 뇌종양, 파킨슨병, 전정편두통
기질성 : 기립 저혈압, 저혈당, 빈혈, 당뇨병신경병증
정신 : 불안장애, 과호흡증후군

교육
	어지럼을 유발할 수 있는 생활습관 개선
	쓰러질 것 같으면 안정된 곳으로 이동하여 머리를 다치지 않게 

30초 가량 어지럼증 + 오심,구토 + 움직일 시 악화 + Dix (+)
= 양성돌발체위현기증 / Dix (+) / Epley 수기

수 분,시간 어지럼증 + 난청 + 이명 + 이충만감
= 메니에르병 / 청력검사, 전정기능검사, MRI, CT / 약물치료, 감압술

수 시간,일 어지럼증 + 구역 + 구토 + 상기도 감염 + 안진
= 전정신경염 / 전정기능검사, 청력검사 / BZD, 항구토제, 재활운동

가만히 있어도 어지럼증 + 자세 불균형 + 신경학적 이상 + 안진
= 소뇌 경색 / brain CT, MRI / 혈전용해제, 항혈소판제, 항응고제

손떨림 + 균형장애 + 보행장애 + 행동 느려짐
= 파킨슨병 / 뇌 MRI, PET / levodopa

수 시간 어지럼증 + 편두통
= 전정편두통 / 불필요 / 급성기 NSAIDs, Triptan

일어날 때 나타남 + 출혈 + 탈수
= 기립 저혈압 / 3 position / 천천히 움직일 것, 약제 중단

아찔한 어지럼증 + DM, anemia
= 저혈당, 빈혈 / 혈당검사, 혈액검사 / 당류 공급, 철분 보충

조절되지 않는 당뇨 병력
= 당뇨병 신경병증 / 혈당검사, 당화혈색소, 자율신경검사 / 혈당 조절

어지럼증 + 불안 + 답답
= 불안장애, 과호흡증후군 / 불필요 / SSRI, BZD, 인지행동치료

## ER

### 1. 즉시 평가 및 안정화
- 증상을 회전감이라는 표현보다 발병 양상, 지속시간, 유발요인과 동반 신경학적 증상으로 분류한다.
- 보행 불가, 새 신경학적 결손, 심한 두통·경부통, 흉통·실신, 지속 구토가 있으면 중추·심혈관 원인을 우선 평가한다.
- 혈당, 활력징후, 안구운동과 보행을 포함한 신경학적 진찰을 시행한다.

### 2. 놓치면 안 되는 질환
- 후순환 [[허혈성 뇌졸중 (Ischemic stroke)]]·소뇌출혈 : 지속성 급성 전정증후군, 보행실조, 신경학적 소견
- 동맥박리 : 새 경부통·두통, 외상, Horner syndrome
- 부정맥·ACS·출혈 : 실신 전구, 흉통, 심계항진, 저혈압
- 일산화탄소·약물 중독 : 노출력, 동시 다발 환자, 의식 변화
- 중증 빈혈·감염·대사 이상

### 3. 초기 검사
- 심전도, 혈당과 선택적 혈액검사는 임상 단서에 따라 시행한다.
- HINTS는 지속성 급성 전정증후군에서 숙련된 검사자가 시행할 때만 활용한다.
- 후순환 뇌졸중 의심에서 단순 CT 정상만으로 배제하지 않고 MRI·혈관영상 필요성을 판단한다.
- 유발성 짧은 현훈은 적절한 체위검사로 말초 원인을 확인한다.

### 4. 초기 처치 및 재평가
- 원인 치료와 함께 심한 오심·구토를 조절하되 과도한 진정으로 신경학적 평가를 방해하지 않는다.
- 보행, 안구운동, 신경학적 소견과 증상 변화가 초기 판단과 일치하는지 재평가한다.

### 5. Disposition
- 중추 원인 의심, 새 신경학적 소견, 보행 불가, 지속 구토·탈수 또는 심혈관 원인은 입원·관찰한다.
- 명확한 말초성 진단, 안전한 보행과 경구섭취, 추적계획이 있을 때 퇴원을 고려한다.

### 6. ER 함정
- 고립성 어지럼증도 후순환 뇌졸중일 수 있다.
- 증상 표현만으로 말초성·중추성을 구분하지 않으며, CT 정상에 과도하게 의존하지 않는다.
