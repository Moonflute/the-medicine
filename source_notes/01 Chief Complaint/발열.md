# 발열

## Concept
발열은 체온의 높이보다 환자의 전신 상태, 면역·연령 위험, 감염 초점과 장기기능 이상 여부가 우선순위를 결정한다.

## 감별진단
감염 : 소화기/순환기/호흡기/비뇨기/신경계/연조직염..
기타 : 약물 유발열, 림프종, 백혈병

## 환자교육
검사 : 혈액 검사, 혈액 배양, 항원검사, 항체검사, 영상검사
치료 : 항생제, 수액, 진통제, 농양 확인 시 제거
교육 : 발열 시 체온 체크, 어지럽거나 의식변화, 두근거림 시 내원, 위생 

소화기 증상 + 피부 발진 + 복부 압통
= 장티푸스 / 혈액, 대변, 소변 배양검시 / 항생제 (Cefa)

소화기 증상 + 피부 수포 + 해산물 섭취력
= 비브리오 위장염 / 혈액, 대변 배양, PCR / Cefa Doxy, 배농

호흡기 증상 + 특정 지역 (조치원)
= 인플루엔자 / 객담검사, PCR / 수분 보충

비뇨기 증상 + 옆구리 통증 + CVAT (+)
= 급성 신우신염 / 소변검사, 소변배양검사 / 항생제

신경계 증상 + 구토 + 수막자극징후 (+)
= 뇌수막염 / 뇌척수액검사, brain CT / 항생제

피부 병변 + 압통 + 발적
= 연조직염 / CBC, 혈액 배양, 조직생검 / 항생제, 소염제, steroid

피부 가피 + 발한 + 소화기 질환
= 쯔쯔가무시 / CBC, CXR, LFT / Tetra, doxycline

삼일열,사일열 + 여행력 (연천군, 북부) + 황달 + 간비대
= 말라리아 / 말초혈액도말 / 항말라리아제

약물 섭취력 + 기타 배제됨
= 약물 유발열 / CBC, LFT / 약물 중단

체중 감소 + 야간 발한 + 림프절 종대
= 림프종, 백혈병 / CBC, CT, 골수검사, PET / 항암제

## 접근

- 입원 당시 체온과 현재 체온을 비교하고 측정 부위·방법, 해열제 투여 시각, 발열 시작 시점을 확인한다. 수술·시술일, 수혈·주입 시작, 새 약물 투여, 중심정맥관·Foley catheter·배액관 삽입 시점과의 시간 관계를 먼저 맞춘다.
- 폐, 요로, 수술부위·피부연조직, 혈관 catheter, 복강·담도와 C. difficile 감염을 진찰한다. 호중구감소, 장기이식·면역억제, 비장절제, 임신 여부는 초기 대응 강도를 높인다.
- 감염 외에도 수혈반응, 약물열, VTE, 수술 후 염증반응, pancreatitis, gout·pseudogout를 병렬로 본다. 수술 직후의 발열이라는 이유만으로 감염을 배제하거나 배양검사를 일률적으로 시행하지 않는다.
- 저혈압, 새 산소 요구량, 의식 변화, mottling, 소변량 감소 또는 lactate 상승이 있으면 병동 관찰을 지속하지 말고 sepsis pathway와 신속대응팀·중환자 평가로 전환한다.

## 검사

- CBC with differential, 전해질·BUN/Cr, LFT와 lactate는 중증도와 장기기능장애가 의심될 때 시행한다. 호중구감소 가능성이 있으면 ANC를 즉시 확인한다.
- 균혈증·sepsis가 의심되면 서로 다른 부위에서 혈액배양 2세트를 항균제 전에 채취하되 치료를 지연하지 않는다. 중심정맥관 감염이 의심되면 말초혈액과 catheter lumen 검체를 동시에 채취한다.
- 소변검사·배양은 요로 증상, pyuria 또는 원인 불명 sepsis에서 시행한다. Foley 유지 환자에서 CAUTI가 의심되면 catheter를 교체한 뒤 새 catheter에서 검체를 얻는다.
- 흉부 X선은 새 호흡기 증상·저산소증이 있을 때, C. difficile 검사는 설명되지 않는 새 설사에서, 복부·수술부위 영상은 국소 증상이나 source control 필요성이 있을 때 선택한다.
- 안정 환자는 체온·혈압·호흡·의식·소변량을 2–4시간 이내 재평가한다. 배양 결과와 임상 반응은 24–48시간 안에 검토하여 항균제를 축소·변경·중단한다.

## 치료

### 증상 조절
- Acetaminophen (타이레놀정 500 mg 등) 500–1,000 mg PO q6h PRN. 모든 acetaminophen 함유 제제를 합산해 일반 성인은 4 g/day를 넘지 않고, 고령·저체중·영양불량·만성 음주·간질환에서는 3 g/day 이하 또는 추가 감량을 적용한다.
- 해열 자체보다 불편감 완화가 목적이다. 해열 후 체온이 내려갔다는 이유로 중증 감염을 배제하지 않으며, NSAID는 AKI·출혈·심부전 위험이 있으면 피한다.

### 원인 치료와 재평가
- 고위험 sepsis이면 배양 채취로 지연하지 말고 인지 후 1시간 이내 원내 병원획득감염 지침과 최근 배양·colonization을 반영한 IV 항균제를 시작한다. 감염원 확인 후 가능한 한 좁은 항균제로 조정하고 source control을 병행한다.
- 수혈 중 발열이면 즉시 수혈을 중단하고 정맥로는 생리식염수로 유지한 뒤 혈액은행·수혈반응 절차를 따른다. 새 약물과 시간 관계가 뚜렷하고 위험 감염을 배제했다면 의심 약물을 중단한다.
- 해열제 투여 후 1–2시간 내 체온과 증상, sepsis 처치 후에는 혈압·관류·산소 요구량·소변량을 더 짧은 간격으로 재평가한다. 악화하거나 감염원이 조절되지 않으면 신속대응팀, 감염내과 및 수술·시술팀을 호출한다.

## ER

### 1. 즉시 평가 및 안정화
- 활력징후, 의식, 호흡, 말초관류와 소변량을 평가하고 감염원과 장기기능장애를 동시에 찾는다.
- 저혈압, 의식 변화, 호흡부전, mottling, oliguria 또는 lactate 상승은 [[패혈증 (Sepsis)]]·쇼크 가능성을 높인다.
- 면역저하, 무비증, 고령, 임신, 영아는 발열 정도가 낮아도 고위험군으로 평가한다.

### 2. 놓치면 안 되는 질환
- [[패혈증 (Sepsis)]]·패혈성 쇼크
- [[세균성 뇌수막염 (Bacterial Meningitis)]]·뇌염
- 괴사성 연조직감염·독성쇼크 : 통증 과다, 빠른 진행, 피부 변색, 전신독성
- 심내막염 : 심잡음, 색전 소견, 인공판막·주사약물 사용
- 호중구감소성 발열 : 항암치료·혈액질환
- 중증 열질환·약물성 고체온 : 환경·약물 노출과 중추신경 이상

### 3. 초기 검사
- 검사와 배양은 의심 감염원·중증도에 맞추고, 혈액배양은 가능하면 항균제 전에 채취하되 치료를 지연하지 않는다.
- CBC, 대사패널, lactate, 소변·흉부 영상 등은 장기기능과 감염원을 평가하도록 선택한다.
- 뇌수막염·심내막염·호중구감소증은 질환별 진단 경로를 적용한다.
- 바이러스 양성 결과가 동시 세균감염을 완전히 배제하지는 않는다.

### 4. 초기 처치 및 재평가
- 저산소증·저관류를 교정하고 중증 감염 가능성이 높으면 신속한 경험적 항균치료와 source control을 진행한다.
- 수액은 고정량 반복보다 관류와 동적 반응, 심폐 상태를 재평가하며 조절한다.
- 체온, 의식, 혈압, 호흡, 소변량과 lactate 추세를 재평가한다.

### 5. Disposition
- 장기기능장애, 쇼크, 중증 감염원, 면역저하 또는 안전한 추적이 어려우면 입원한다.
- 안정적이고 중증 감염이 합리적으로 배제되며 경구섭취·추적이 가능한 경우에만 퇴원을 고려한다.

### 6. ER 함정
- 정상 체온이나 해열 후 호전만으로 패혈증을 배제하지 않는다.
- qSOFA·SIRS 등 단일 점수는 임상 판단이나 장기기능 평가를 대체하지 않는다.
