# 발열

## Concept
발열은 체온의 높이보다 환자의 전신 상태, 면역·연령 위험, 감염 초점과 장기기능 이상 여부가 우선순위를 결정한다.

## 감별진단
감염 : 소화기/순환기/호흡기/비뇨기/신경계/연조직염..
기타 : 약물 유발열, 림프종, 백혈병

## 환자교육
검사 : 혈액 검사, 혈액 배양, 항원검사, 항체검사, 영상검사
치료 : 항생제, 수액, 진통제, 농양 확인 시 제거
교육 : 발열 시 체온 체크, 어지럽거나 의식변화, 두근거림 시 내원, 위생 

소화기 증상 + 피부 발진 + 복부 압통
= 장티푸스 / 혈액, 대변, 소변 배양검시 / 항생제 (Cefa)

소화기 증상 + 피부 수포 + 해산물 섭취력
= 비브리오 위장염 / 혈액, 대변 배양, PCR / Cefa Doxy, 배농

호흡기 증상 + 특정 지역 (조치원)
= 인플루엔자 / 객담검사, PCR / 수분 보충

비뇨기 증상 + 옆구리 통증 + CVAT (+)
= 급성 신우신염 / 소변검사, 소변배양검사 / 항생제

신경계 증상 + 구토 + 수막자극징후 (+)
= 뇌수막염 / 뇌척수액검사, brain CT / 항생제

피부 병변 + 압통 + 발적
= 연조직염 / CBC, 혈액 배양, 조직생검 / 항생제, 소염제, steroid

피부 가피 + 발한 + 소화기 질환
= 쯔쯔가무시 / CBC, CXR, LFT / Tetra, doxycline

삼일열,사일열 + 여행력 (연천군, 북부) + 황달 + 간비대
= 말라리아 / 말초혈액도말 / 항말라리아제

약물 섭취력 + 기타 배제됨
= 약물 유발열 / CBC, LFT / 약물 중단

체중 감소 + 야간 발한 + 림프절 종대
= 림프종, 백혈병 / CBC, CT, 골수검사, PET / 항암제

## 콜 접수

- 현재 체온(측정 부위·방법)과 입원 후 추세, 발열 시작 시각, 해열제·항균제 투여 시각을 확인한다. 간호사에게 BP, HR, RR, SpO2, 새 산소 요구량, 의식 변화와 최근 소변량을 함께 묻는다.
- 새 기침·호흡곤란, 배뇨 증상, 복통·설사, 두통·목 경직, 수술부위 통증·발적 등 감염원 단서를 확인한다. 입원 이유, 수술·시술일, 중심정맥관·Foley·배액관, 수혈·주입 및 새 약물 시작 시점과 발열의 시간 관계를 맞춘다.
- 항암치료·호중구감소, 이식·면역억제, 비장절제 여부와 최근 배양·내성균 보균, 약물 알레르기를 확인한다.

## 위험 판단

- sepsis/쇼크 경고: MAP <65 mmHg 또는 새로 발생한 SBP <90 mmHg, 의식 변화, 새 저산소증, mottling, 핍뇨, 빠른 호흡·혈압 악화. 발열 정도와 무관하게 즉시 병실 평가 및 신속대응팀·상급자·중환자팀 호출.
- 고위험 감염 단서: 발열과 새 두통·목 경직·경련·의식 변화(수막염/뇌염), 심한 국소 통증과 급속히 진행하는 피부 변화(괴사성 연조직감염), 호중구감소 가능성. 해열제 반응은 위험도 하향 근거가 아니다.
- ANC <500/µL 또는 <1,000/µL이며 감소 중인 환자의 발열은 감염원이 보이지 않아도 즉시 호중구감소 발열 경로로 대응한다. 항정신병약 투여 후 발열·근강직·의식 변화·자율신경 불안정은 악성증후군을 의심한다.
- 안정 환자: 활력징후 안정, 국소 증상·면역저하 없음. 수술 직후라는 이유만으로 모든 배양·영상·경험적 항균제를 일괄 시행하지 않는다.

## 원인 감별·추가검사

- **CBC with differential**(항암치료 환자는 ANC 우선), **전해질·BUN/Cr·LFT**는 중증도와 원인에 맞춰 확인한다. 저관류·sepsis 의심 시 **lactate**를 측정한다.
- 균혈증·sepsis가 의심되면 서로 다른 부위에서 **혈액배양 2세트**를 가급적 항균제 전에 채취하되 투여를 지연하지 않는다. 중심정맥관 감염 의심 시 말초와 catheter lumen에서 짝지어 채취한다.
- 배뇨 증상이나 원인 불명 sepsis에서 요로 감염이 의심되면 **소변검사·배양**을 시행한다. Foley 관련 감염 의심 시 가능하면 교체한 catheter에서 검체를 얻고, 증상 없는 균뇨만으로 원인으로 단정하지 않는다. 새 호흡기 증상·저산소증이면 **흉부 X선**, 설명되지 않는 새 설사면 **C. difficile 검사**, 복부·수술부위 국소 징후면 해당 영상과 배액 필요성을 평가한다.
- 감염 외에 수혈반응, 약물열, VTE, 췌장염, crystal arthritis를 시간 관계·국소 소견으로 감별한다. 관절 삼출이 새로 생기면 septic arthritis 배제를 위해 천자를 고려한다.
- 이미 항균제 투여 중이면 약제·용량·신기능·최근 배양/내성, 새 병원체·진균 가능성, 배액되지 않은 농양/폐색, catheter/인공물 감염, 비감염성 발열을 다시 대조한다. 약물열은 감염을 충분히 평가한 뒤 판단한다.

## 처치

### 즉시 조치
- 쇼크·저관류이면 IV access, 배양·lactate 채취와 항균제 준비를 동시에 진행한다. **Balanced crystalloid** 250–500 mL IV bolus 후 관류·혈압·호흡을 재평가하며, sepsis-induced hypoperfusion/쇼크에서는 첫 3시간 30 mL/kg를 초기 목표로 고려하되 심부전·신부전·폐울혈에 맞춰 매 bolus를 조절한다. 지속 저혈압은 승압제 가능한 감시 환경으로 전환한다.
- 수혈 중 발열이면 수혈을 즉시 중단하고 생리식염수로 정맥로를 유지한 채 혈액은행·수혈반응 절차를 시작한다.

### 증상 조절
- 불편감이 있으면 **Acetaminophen (타이레놀정 500 mg 등)** 500–1,000 mg PO q6h PRN. 모든 복합제 포함 총량은 일반 성인 4 g/day 이하, 고령·저체중·영양불량·만성 음주·간질환에서는 3 g/day 이하 또는 추가 감량한다. 해열은 예후 개선 목적이 아니라 증상 완화 목적이다.
- AKI·출혈·심부전 위험이 있으면 NSAID를 피한다.

### 원인 치료
- 패혈성 쇼크 또는 probable/definite sepsis이면 가능하면 인지 후 1시간 이내 IV 항균제를 시작한다. 쇼크 없는 possible sepsis는 감염 가능성을 신속히 재평가하고 의심이 지속되면 3시간 이내 투여한다. 원내 항균지침, 감염원, 최근 배양·내성균·알레르기·신기능에 따라 선택한다.
- 병원획득 감염/녹농균 위험에서 경험적 선택의 한 예는 **Piperacillin/tazobactam (타조신주 4.5 g)** 4.5 g IV q6h(정상 신기능 기준)이다. MRSA 위험, 호중구감소, 수막염 의심은 별도 경로로 균종 범위를 조정하며, 이 예시를 모든 발열에 적용하지 않는다.
- 수막염 의심은 혈액배양과 즉시 항균제/스테로이드 적응증을 평가하고, 두부 CT가 필요해 요추천자가 지연되어도 항균제를 기다리지 않는다. 호중구감소 발열은 즉시 항녹농균 IV 항균제 경로로 전환한다.
- 농양·담도/요로 폐색·감염 catheter 등은 항균제와 함께 배액·제거 등 source control을 추진한다. 위험 감염을 배제하고 약물열이 유력하면 의심 약물을 중단한다.

## 경과관찰

- 쇼크·저관류는 처치마다 혈압·호흡·의식·산소 요구량·관류·소변량을 재평가하고 필요 시 lactate 추세를 확인한다. 악화·지속 저혈압·source control 지연이면 즉시 신속대응팀/중환자팀에 재의뢰한다.
- 안정 환자는 2–4시간 내 체온·활력징후·새 국소 증상을 재평가한다. 해열제 투여 후 1–2시간 내 증상 호전도 확인하되 체온 하강을 감염 배제 근거로 쓰지 않는다.
- 배양 결과와 임상 반응을 24–48시간 내 재검토하여 항균제를 좁히거나 변경·중단한다. 감염원 확인이 안 되거나 발열이 지속되면 숨은 농양, catheter, 약물·혈전 등 진단을 다시 연다.

## ER

### 1. 즉시 평가 및 안정화
- 활력징후, 의식, 호흡, 말초관류와 소변량을 평가하고 감염원과 장기기능장애를 동시에 찾는다.
- 저혈압, 의식 변화, 호흡부전, mottling, oliguria 또는 lactate 상승은 [[패혈증 (Sepsis)]]·쇼크 가능성을 높인다.
- 면역저하, 무비증, 고령, 임신, 영아는 발열 정도가 낮아도 고위험군으로 평가한다.

### 2. 놓치면 안 되는 질환
- [[패혈증 (Sepsis)]]·패혈성 쇼크
- [[세균성 뇌수막염 (Bacterial Meningitis)]]·뇌염
- 괴사성 연조직감염·독성쇼크 : 통증 과다, 빠른 진행, 피부 변색, 전신독성
- 심내막염 : 심잡음, 색전 소견, 인공판막·주사약물 사용
- 호중구감소성 발열 : 항암치료·혈액질환
- 중증 열질환·약물성 고체온 : 환경·약물 노출과 중추신경 이상

### 3. 초기 검사
- 검사와 배양은 의심 감염원·중증도에 맞추고, 혈액배양은 가능하면 항균제 전에 채취하되 치료를 지연하지 않는다.
- CBC, 대사패널, lactate, 소변·흉부 영상 등은 장기기능과 감염원을 평가하도록 선택한다.
- 뇌수막염·심내막염·호중구감소증은 질환별 진단 경로를 적용한다.
- 바이러스 양성 결과가 동시 세균감염을 완전히 배제하지는 않는다.

### 4. 초기 처치 및 재평가
- 저산소증·저관류를 교정하고 중증 감염 가능성이 높으면 신속한 경험적 항균치료와 source control을 진행한다.
- 수액은 고정량 반복보다 관류와 동적 반응, 심폐 상태를 재평가하며 조절한다.
- 체온, 의식, 혈압, 호흡, 소변량과 lactate 추세를 재평가한다.

### 5. Disposition
- 장기기능장애, 쇼크, 중증 감염원, 면역저하 또는 안전한 추적이 어려우면 입원한다.
- 안정적이고 중증 감염이 합리적으로 배제되며 경구섭취·추적이 가능한 경우에만 퇴원을 고려한다.

### 6. ER 함정
- 정상 체온이나 해열 후 호전만으로 패혈증을 배제하지 않는다.
- qSOFA·SIRS 등 단일 점수는 임상 판단이나 장기기능 평가를 대체하지 않는다.
