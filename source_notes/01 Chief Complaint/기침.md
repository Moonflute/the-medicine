# 기침

## Concept
기침은 지속기간과 유발 상황을 기준으로 감염, 기도질환, 상기도기침증후군, 역류, 약물 원인을 구분한다.

## 감별진단
급성 : 상기도 감염, 하기도 감염(폐렴), 외부 연기/증기
아급성 : 감염 후 기침
만성 : 후비루증후군, 천식, 만성폐쇄폐질환, 폐결핵, 폐암 / GERD, 울혈 심부전, 약물성

## Hx

- 만성 기침에서는 흡연, ACE inhibitor, 후비루·비염, 야간 악화·천명, 속쓰림·신물과 자세 연관, 감염 뒤 지속 여부를 함께 확인하고 두세 원인이 병존할 수 있음을 전제한다.

## 환자교육
검사 : CXR, 부비동 x-ray, PFT, 객담검사
치료 : 대증 치료 (진해거담제, 항히스타민제)
교육 : 금연, 예방접종, 환경 관리

급성 기침 + 가래 + 코막힘 + 인후통 + 목 부음
= 상기도 감염 / 후두경, CBC, CXR / 휴식과 수분 섭취, NSAID, 항생제

급성 기침 + 발열 + 콧물 + 가래 + 호흡곤란 + 객혈 + 수포음 청진
= 폐렴 / CBC, CXR, 가래 배양 / ciprofloxacin, ceftriaxone..

아급성 기침 + 최근 감기력
= 감염 후 기침 / CBC, CXR, 가래 배양 / 휴식과 수분 섭취, ipratropium

만성 기침 + 후비루 증상 + 인후통 + 시진상 후비루 확인
= 후비루 증후군 / 부비동 방사선 촬영 / 원인 질환 치료

만성 기침 + 쌕쌕거림 + 봄/야간 악화 + 알레르기력
= 천식 / PFT, skin prick test / ICS + formoterol

만성 기침 + 쌕쌕거림 + 가래 + 흡연력 + 고령
= 만성폐쇄성폐질환 / PFT, CXR, ABGA / SABA, LAMA

만성 기침 + 발열 + 피로 + 체중 감소 + 야간 발한 + 객혈
= 폐결핵 / tuberculin 검사, AFB / 항결핵제

만성 기침 + 체중 감소 + 흡연 + 객혈 + 고령
= 폐암 / CXR, CT, PFT / 수술, RTx, 항암제

만성 기침 + 속쓰림 + 신물 역류 + 누우면 악화
= 위식도역류병 / 위내시경, 24hr 식도 pH 검사 / PPI, 제산제, 수술

만성 기침 + 피로 + 부종 + 기저 심질환 + 경정맥 확장
= 울혈 심부전 / echo, EKG / ACEi, BB

만성 기침 + 고혈압 약 복용 (-pril) + 기타 정상
= ACEi에 의한 기침 / … / 약물 변경

## 접근
- 저산소증, 호흡곤란, 객혈, 흉통, stridor, 고열·전신쇠약, 체중감소·야간발한, 면역저하, 이물 흡인 가능성 또는 암·결핵 위험이 있으면 단순 진해치료보다 긴급 원인평가를 우선한다.
- 급성 기침은 상기도 감염이 흔하지만 폐렴, 천식/COPD 악화, 심부전, 폐색전증, 흡인과 약물 반응을 병력·진찰에 따라 구분한다. 입원 후 새 기침은 aspiration, 폐렴, 폐부종, 무기폐, 산소장치 자극과 수술·수액·tube feeding 시점도 함께 확인한다.
- 8주 이상 지속되는 성인 만성 기침은 흡연·직업/환경 자극, ACE 억제제 등 약물, 암·감염·이물 가능성을 먼저 검토한 뒤 상기도기침증후군, 천식/기침형 천식, 비천식성 호산구성 기관지염, 역류 관련 기침 및 COPD·기관지확장증을 임상 단서에 따라 평가한다.
- 한 가지 원인만 전제하지 말고 동반 원인을 병렬로 다루며, 목표 치료 뒤 기침 빈도·수면·삶의 질과 부작용을 재평가한다.
## 검사
- 불안정하거나 위험 신호가 있으면 SpO2, 흉부진찰과 흉부 X선부터 시행하고, 감염·심부전·폐색전증·흡인 등 임상 가설에 맞춰 CBC, 배양, 심전도, 혈액가스, 심초음파 또는 영상검사를 선택한다.
- 만성 기침의 초기 평가는 최근 흉부 X선과 spirometry를 포함한다. 천식·호산구성 염증이 의심되면 기관지확장제 반응, FeNO, 혈액/유도객담 호산구 또는 기관지유발검사를 가용성과 임상상에 맞춰 사용한다.
- 진찰과 흉부 X선이 정상인 모든 만성 기침 환자에게 흉부 CT를 일률적으로 시행하지 않는다. 원인 불명·치료 불응, 비정상 진찰/영상 또는 기관지확장증·간질성폐질환·중심기도 병변이 의심될 때 CT·기관지내시경 또는 전문의 평가를 추가한다.
## 치료
- 흡인 위험이 있으면 head elevation과 aspiration precaution을 적용한다.
- 위험 원인이 배제된 마른기침은 Dextromethorphan (러미라정 15 mg 등) 15–30 mg PO q6–8h PRN을 고려하되 serotonergic drug 병용을 확인한다.
- 흡연·자극 노출과 ACE 억제제 같은 원인 약물을 중단·대체할 수 있는지 먼저 검토하고, 분비물이 많은 기침에는 배출·수분·기도 청결과 원인 치료를 우선한다. 진해제는 위험 원인이 배제된 제한된 상황에서만 병용약·호흡억제 위험을 확인해 단기간 사용한다.
- 상기도 증상, 천식/기침형 천식·호산구성 기관지염, 임상적으로 의미 있는 역류, COPD·기관지확장증은 각각의 진료지침에 따라 표적 치료를 하고 반응을 재평가한다. 속쓰림·역류 증거가 없는 만성 마른기침에 위산억제제를 일률적으로 시작하지 않는다.
- 원인 치료 후에도 지속되는 난치성 기침은 호흡기·이비인후 전문 평가로 기관지내시경/후두 평가 필요성을 판단하고, 기침 조절 물리·언어치료 또는 신경조절 치료를 개별화한다.
- 원인별로 UACS는 비강·인두 진찰, 기침형천식은 메타콜린 유발시험, 호산구성 기관지염은 유도객담 호산구 또는 FeNO, GERD는 24시간 식도 pH 검사를 선택한다. 흉부 X선 이상, 객혈, 체중감소·발열, 면역저하, 흡연력 또는 비정상 진찰은 위험신호다.
