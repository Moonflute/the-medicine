# 이론 문제

## 문제

잠복 결핵 감염의 평가·치료에서 반드시 구분해야 할 것은?

## 선택지

A. 활동성 결핵이 없는지 임상·영상과 필요한 검체 검사로 평가하는 것
B. IGRA 양성이면 모든 환자에게 활동성 4제 요법을 자동 시작하는 것
C. 증상이 없으면 어떤 추가 평가도 하지 않는 것
D. TST 음성이면 최근 노출 위험을 항상 무시하는 것

## 해설

잠복 감염은 활동성 질환이 확인되지 않는 감염 상태다. 활동성 질환을 놓친 채 잠복 감염 요법만 사용하지 않도록 평가한다.
