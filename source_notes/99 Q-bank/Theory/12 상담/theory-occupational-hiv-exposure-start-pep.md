# 이론 문제

## 문제

주사침 사고로 HIV 노출 후 예방요법(PEP)이 필요하다. 노출원 검사 결과가 아직 없을 때 시작 시점은?

## 선택지

A. 노출원 HIV 검사 확인 후
B. 노출자의 기저 HIV 검사 결과 확인 후
C. 추적 HIV 검사에서 양전될 때
D. 검사를 진행하면서 즉시

## 해설

직업적 HIV 노출에서 PEP 적응증이면 가능한 한 빨리 시작한다. 노출원에 대한 검사를 병행하되 결과 때문에 첫 투약을 늦추지 않는다.
