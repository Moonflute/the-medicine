# 이론 문제

## 문제

Froment 징후에서 종이를 집을 때 엄지 IP 관절이 굽혀지는 이유는?

## 선택지

A. 약해진 엄지모음근을 긴엄지굽힘근의 작용으로 보상하기 때문
B. 약해진 긴엄지굽힘근을 엄지모음근으로 보상하기 때문
C. 노신경 마비 때문에 엄지 IP 관절을 능동적으로 펼 수 있기 때문
D. 엄지 벌림근의 과활동으로 MCP 관절만 펴지기 때문

## 해설

척골신경이 지배하는 엄지모음근이 약하면 열쇠 집기 동작에서 정중신경 계통의 긴엄지굽힘근을 사용해 보상한다. 이때 엄지 IP 관절이 굽혀지는 것이 Froment 징후이다.
