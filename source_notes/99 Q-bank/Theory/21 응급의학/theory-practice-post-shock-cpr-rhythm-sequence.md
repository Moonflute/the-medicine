# 이론 문제

## 문제

성인 심정지에서 제세동 직후부터 다음 계획된 리듬 확인까지의 기본 순서는?

## 선택지

A. 맥박부터 확인 → CPR 2분
B. 연속 제세동 2회 → 리듬 확인
C. 즉시 CPR 약 2분 → 리듬 확인
D. 호흡 확인 → 맥박 확인 → CPR

## 해설

제세동 후에는 즉시 CPR을 재개하고 약 2분 뒤 리듬을 재평가한다. 매 충격 직후 맥박 확인으로 압박을 지연하지 않는다.

## 오답 포인트

ROSC를 뒷받침하는 징후가 있으면 순환 상태를 확인하되 불필요한 압박 중단을 줄인다.
