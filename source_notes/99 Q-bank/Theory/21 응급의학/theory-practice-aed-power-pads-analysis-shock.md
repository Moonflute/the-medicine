# 이론 문제

## 문제

AED를 적용하는 기본 순서는?

## 선택지

A. 패드 → 전원 → 충격 → 분석
B. 전원 → 분석 → 패드 → 충격
C. 전원 → 패드 → 분석 → 필요 시 충격
D. 패드 → 충격 → 전원 → 분석

## 해설

전원을 켜고 음성 지시에 따라 건조한 맨가슴에 패드를 충분히 밀착시킨 뒤 분석한다. 충격이 권고되면 안전을 확인해 시행하고 즉시 CPR을 재개한다.

## 오답 포인트

분석·충격 때는 환자 접촉을 피한다. 자동제세동기에 수동 제세동기의 에너지·패들 조작 순서를 그대로 적용하지 않는다.
