# Theory Q-bank

이 폴더에는 이론 문제 Markdown만 둡니다.

- 분과 하위 폴더는 원본 질병·CC·약물 문서의 주 분과를 따릅니다.
- 각 문서는 `question_mode`, `target_type`, `target_slug`를 포함해 관련 문서의 이론문제를 필터링할 수 있습니다. 질병·CC·약물 외 공통 소생술·기도관리 개념은 기존 술기 문서를 정본으로 사용할 수 있습니다.
- `target_type: skill`은 술기 문서의 `id`를 `target_slug`로 사용하고 표시 이름을 `target_title`에 기록합니다. 해당 문서의 관련 이론문제 범위와 해설 원문 링크에 함께 사용합니다.
- 검사(`lab`)·술기(`skill`) 기반 문제도 선택 화면에서는 `질병 이론`의 해당 분과(`specialty`)에 함께 표시합니다. 원문 연결을 위한 `target_type`·`target_slug`는 바꾸지 않으며, 문항 주제에 맞는 분과 폴더와 `specialty`를 지정합니다.
- 생성 체크포인트, API 원시 응답, 병합 전 백업은 `workspace_ops/qbank/theory/`에 보관하며 이 폴더에는 넣지 않습니다.

## 보기 품질 기준

- 정답에만 질환명·동의어·정답을 암시하는 괄호 설명을 넣지 않습니다.
- 네 보기는 같은 범주와 비슷한 구체성으로 비교합니다. 질환명 세 개 사이에 정답만 정의 전체를 넣지 않습니다.
- 길이를 맞추려고 불필요한 말로 채우거나 의학적으로 필요한 조건·역치를 삭제하지 않습니다. 부연은 해설로 옮깁니다.
- 오답은 실제 감별 대상·유사 약물·인접 검사·기전의 혼동을 반영합니다. 무관한 장기나 황당한 처치로 채우지 않습니다.
- '항상·절대·모든 환자' 같은 단어만 보고 오답을 지울 수 있게 만들지 않습니다.
- 보기 수정 후 단일 최선 정답, 문제의 조건, 해설의 일치 여부를 확인합니다. 보기 순서가 섞이므로 해설은 글자 대신 내용으로 설명합니다.
- 의학적 의미가 바뀌면 원본 이론과 공식 지침·허가사항을 대조합니다. ID와 정답의 의미는 가능한 한 유지합니다.
- `node apps/medicine-web/scripts/audit-theory-options.mjs`는 누락·중복·길이 등의 점검 보조 도구이며, 플래그 자체가 오류 판정이나 의학적 검수를 뜻하지는 않습니다.
- 보기를 개편하면 이전 보기별 `오답 포인트`의 검수도 무효화됩니다. `wrong_notes_review_status: superseded`는 원문을 보존하되 화면에는 현재 검토한 `해설`만 내보내는 상태입니다. 새 보기와 다시 맞춘 경우에만 `reviewed`로 되돌립니다.
- 커밋 전 `node apps/medicine-web/scripts/retire-theory-option-notes.mjs`로 개편된 보기의 옛 설명을 확인하고, `--apply`로 상태만 기계적으로 갱신할 수 있습니다. 문항·보기·정답·해설을 자동 생성하거나 수정하지 않습니다.
