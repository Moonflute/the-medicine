# 이론 문제

## 문제

새로 삽입한 비위관을 영양·약물 투여에 쓰기 전 위치 확인 원칙은?

## 선택지

A. 공기 주입 시 상복부 소리로 판단한다.
B. 물을 넣은 뒤 기침이 없는지 본다.
C. 외부로 나온 관 길이만 확인한다.
D. 흡인액 pH 또는 X선으로 확인한다.

## 해설

비위관은 사용 전에 위액 흡인물의 안전 범위 pH(통상 1–5.5) 또는 적절히 판독한 X선으로 위치를 확인한다. 흡인 불가·pH 부적합 등에서는 X선이 필요하며 관 경로와 끝 위치를 함께 본다. 확인 전 물·영양액·약물을 주입하지 않는다.

## 오답 포인트

‘공기 주입 시 상복부 소리로 판단한다’: Whoosh test는 기도 내 관에서도 소리가 전달될 수 있어 안전한 확인법이 아니다. ‘물을 넣은 뒤 기침이 없는지 본다’: 기침이 없어도 기도 삽입을 배제하지 못하며 물 주입 자체가 위험하다. ‘외부로 나온 관 길이만 확인한다’: 길이 변화는 재평가 단서지만 최초 위치 확인을 대체하지 않는다.
