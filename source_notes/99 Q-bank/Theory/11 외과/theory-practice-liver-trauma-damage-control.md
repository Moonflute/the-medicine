# 이론 문제

## 문제

간 외상에서 시행하는 손상통제수술의 기본 단계 순서는?

## 선택지

A. 완전한 재건 → 소생으로 생리 상태 회복 → 임시 폐쇄
B. 소생으로 생리 상태 회복 → 초기 출혈 통제 → 최종 재건
C. 초기 출혈 통제 → 소생으로 생리 상태 회복 → 최종 재건
D. 초기 출혈 통제 → 최종 재건 → 소생으로 생리 상태 회복

## 해설

손상통제수술은 패킹 등으로 출혈·오염을 신속히 억제하고 임시 복부 폐쇄 후 중환자 치료로 저체온·산증·응고장애를 교정하는 단계적 접근이다. 상태가 회복되면 재평가·확정 수술을 계획한다.

## 오답 포인트

불안정한 상태에서 긴 재건 수술을 강행하면 악순환을 악화할 수 있다. 패킹 후 단순 방치가 아니라 소생·감시·재수술 계획이 필요하다. 출혈 소생 중에는 체온을 보호하고 승인된 가온 장비로 혈액·수액의 저체온 부담을 줄인다.
