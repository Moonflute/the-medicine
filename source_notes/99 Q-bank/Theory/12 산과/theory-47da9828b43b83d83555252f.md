# 이론 문제

## 문제

양막파수를 직접 뒷받침하는 질경 관찰 소견은?

## 선택지

A. 자궁경부에서 맑은 액체 유출 또는 질 내 pooling 확인
B. 초음파에서 태아 위치만 확인
C. 혈액 백혈구 증가만 확인
D. 자궁수축의 횟수만 측정

## 해설

질경으로 자궁경부를 통한 양수 유출·질 내 고임을 확인하면 파수를 뒷받침한다. 한 번 관찰되지 않았다는 사실만으로 파수를 완전히 배제하지 않으며 불확실하면 병력과 추가 검사를 종합한다.

## 오답 포인트

- **태아 위치·백혈구·수축만:** 양수의 직접 유출을 확인하지 못한다.
