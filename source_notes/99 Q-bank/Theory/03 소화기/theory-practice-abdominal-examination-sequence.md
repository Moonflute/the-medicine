# 이론 문제

## 문제

혈역학적으로 안정된 환자에서 표준 복부진찰을 한다. 일반적으로 권하는 순서는?

## 선택지

A. 시진 → 타진 → 촉진 → 청진
B. 시진 → 청진 → 타진 → 촉진
C. 시진 → 촉진 → 청진 → 타진
D. 시진 → 타진 → 청진 → 촉진

## 해설

복부를 먼저 관찰하고, 타진이나 촉진이 장음에 영향을 줄 수 있으므로 청진을 먼저 한 뒤 타진·촉진한다. 통증이 있는 부위는 촉진의 마지막에 평가한다.

## 오답 포인트

복부진찰은 청진을 타진과 촉진보다 먼저 하는 점이 특징이다. 응급상황에서 순서를 지키느라 소생이나 필요한 평가를 미루지는 않는다.
