# 내시경검사

> 내시경검사 : 카메라가 달린 유연한 또는 강직성 기구를 체내 관강에 넣어 점막을 직접 관찰하고 biopsy/시술까지 수행하는 검사
> 정상범위: 정상범위보다는 점막의 색, 혈관상, 궤양, 종괴, 협착, 출혈, 분비물 유무로 해석

## 1. 개요
- 내시경검사는 lumen을 가진 장기를 직접 보는 검사다.
- 영상검사가 간접적으로 구조를 보여준다면, 내시경은 **점막 표면을 직접 보고 필요하면 조직을 떼거나 치료까지 하는 검사**라는 점이 핵심이다.

## 2. 검사 원리
- 내시경 끝에는 light source와 camera가 달려 있어 내부 영상을 실시간으로 화면에 전달한다.
- 기구 내부 working channel을 통해 biopsy forceps, snare, injection needle, suction/irrigation 장치를 넣을 수 있다.
- 공기 또는 `CO2`를 주입해 관강을 펼치고, 물이나 흡인을 이용해 시야를 확보한다.
- 따라서 내시경의 본질은 **직접 시각화 + 조직 채취 + 시술 가능성**에 있다.

## 3. 공통적으로 보는 것
- 점막 색 변화
- erosion / ulcer
- 종괴 / polyp
- 협착 / 폐색
- 활동성 출혈
- 농성 분비물 또는 이물
- 혈관상 이상

## 4. 공통적으로 할 수 있는 것
- biopsy
- polypectomy
- bleeding control
- dilation
- stent placement 일부
- foreign body removal

## 5. 공통 준비
- 금식
- 항응고제/항혈소판제 확인
- sedation 여부 확인
- aspiration risk 평가
- 동의서 및 합병증 설명

## 6. 공통 위험
- 출혈
- 천공(perforation)
- sedation-related respiratory/circulatory event
- 감염
