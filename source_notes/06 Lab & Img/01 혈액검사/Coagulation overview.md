# Coagulation overview

> Coagulation overview : 응고 경로와 fibrin 형성/분해를 평가하는 혈액검사 묶음
> 정상범위: 항목별로 다르며 `PT/INR`, `aPTT`, `fibrinogen`, `D-dimer`를 함께 해석

## 1. 개요
- coagulation 검사들은 출혈성 질환, 혈전성 질환, liver dysfunction, DIC, anticoagulant effect를 평가할 때 핵심적이다.
- 하나의 검사만으로 coagulation 전체를 설명하지 못하므로 여러 항목을 묶어서 봐야 한다.

## 2. 하위 문서
- [[Prothrombin Time and INR (PT-INR)]]
- [[Activated Partial Thromboplastin Time (aPTT)]]
- [[Fibrinogen]]
- [[D-dimer]]

## 3. 대표 정상범위 표
| 항목 | 하한값 | 상한값 |
|---|---:|---:|
| `PT` | `11 sec` | `13.5 sec` |
| `INR` | `0.8` | `1.1` |
| `aPTT` | `25 sec` | `35 sec` |
| `Fibrinogen` | `200 mg/dL` | `400 mg/dL` |
| `D-dimer` | `0` | `0.50 ug/mL FEU` |

## 4. 해석의 큰 틀
- `PT/INR`는 extrinsic/common pathway를 본다.
- `aPTT`는 intrinsic/common pathway를 본다.
- `Fibrinogen`은 clot substrate와 acute-phase response를 함께 반영한다.
- `D-dimer`는 이미 형성된 cross-linked fibrin이 분해된 흔적을 본다.
