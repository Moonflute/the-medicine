# Liver Function Tests (LFT)

> Liver Function Tests (LFT) : liver-related protein, enzyme, bilirubin을 묶어 보는 패널 검사
> 정상범위: 항목별로 다르며 `AST`, `ALT`, `ALP`, `Albumin`, `bilirubin` 패턴으로 해석

## 1. 개요
- LFT는 liver에서 만들어지거나 liver injury에서 변하는 여러 물질을 묶어서 본다.

## 2. 검사 원리
- albumin, total protein, AST, ALT, ALP, bilirubin 등을 함께 측정한다.
- MedlinePlus는 일부 항목은 liver가 얼마나 잘 작동하는지, 일부는 손상 여부를 보여준다고 설명한다.
- 따라서 단일 수치보다 panel pattern이 중요하다.

## 3. 해석의 큰 틀
- `AST/ALT 우세 상승`: hepatocellular injury pattern
- `ALP/bilirubin 우세 상승`: cholestatic pattern
- `Albumin 저하` 또는 `PT 연장`: synthetic dysfunction 단서
