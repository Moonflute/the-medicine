# 당 질환

## 공통 임상 접근
- 고혈당과 저혈당을 현재의 급성 위험, 장기 합병증, 치료·식사·운동의 시간 관계로 나누어 평가한다.
- 당뇨병 유형과 현재 치료를 확인하고, 신장·눈·신경·심혈관 합병증을 정기적으로 함께 검토한다.
- 혈당 기록 또는 연속혈당 자료는 증상 발생 시점과 연결해 해석한다.

## 먼저 배제할 상황
- 의식 변화, 탈수·저혈압, 구토·복통, 빠른 호흡 또는 현저한 고혈당은 DKA·HHS를 우선 평가한다.
- 발한·떨림·혼돈·경련은 즉시 저혈당을 확인하고 교정한다.

## 하위 질환 감별 포인트
| 질환군 | 구분에 특히 유용한 단서 | 다음 확인 |
|---|---|---|
| DKA·HHS | 탈수·의식 변화·산염기 이상과 케톤 여부 | 전해질·산염기·유발 요인 |
| 저혈당 | 증상과 낮은 혈당의 동시성 | 약물·식사·운동 시간 관계 |
| 망막·신경·콩팥 합병증 | 표적 장기 증상 또는 선별검사 이상 | 장기별 평가와 위험인자 |
| 새벽·소모기 현상 | 야간~아침 혈당 패턴 | 혈당 기록과 야간 저혈당 여부 |
| 당뇨병 자체 | 지속적 고혈당과 유형·치료 맥락 | 진단 기준, 동반질환과 합병증 |
