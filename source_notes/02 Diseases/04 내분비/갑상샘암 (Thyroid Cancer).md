## 1. 개요
**갑상샘암 조직학적 분류**

  - 여포세포 기원: 분화암(유두암, 여포암, 온세포암), 미분화암(역형성암)
  - 방여포세포(C cell) 기원: 속질암
  - 기타: 림프종, 전이암

**암종별 특징**

| 암종 | 핵심 특징 |
| --- | --- |
| 유두암(PTC) | 가장 흔함(80–90%), 예후 양호, BRAF V600E 흔함 |
| 여포암(FTC) | 혈행성 전이, 대체로 예후 양호하나 PTC보다 공격적일 수 있음 |
| 속질암(MTC) | Calcitonin 분비, RET·MEN2/가족력 연관 |
| 역형성암(ATC) | 매우 드물고 공격적, 불량한 예후 |

- **악성 위험인자**: 20세 미만 또는 65세 초과 연령, 갑상샘암 가족력, 두경부 방사선 조사 병력

**동반 기능 이상·갑상샘염 감별**

- **갑상샘중독증**: 호르몬 과다 상태
  - 합성 증가(Graves·독성 결절 등): 보통 TSH↓·fT4/T3↑·RAIU↑
  - 파괴성 갑상샘염·외인성 호르몬: TSH↓·fT4/T3↑·RAIU↓
  - fT4/T3 높은데 TSH 비억제: TSH 분비종양·호르몬 저항성 등 평가
  - hCG 분비종양: hCG의 TSH 수용체 자극, TSH는 억제될 수 있음
- **파괴성 갑상샘염**: 저장 호르몬 유출로 일과성 중독증·낮은 RAIU
- **갑상샘염 유형**
  - 아급성: 바이러스 감염 후, 30–50세 여성 호발
  - 무통성/산후: 자가면역성, 산후 3–6개월 호발
  - 급성: 세균·진균 감염, 면역저하자에서 발생
  - 리델: 중년 여성, 크고 단단한 비대칭 섬유화

## 2. 임상 양상
| 질환 | 임상 양상 |
| --- | --- |
| **갑상샘암** | 대부분 무증상 결절, 진행 시 목 덩이, 압박 증상(기침, 호흡곤란, 삼킴곤란, 쉰 목소리) |
| **갑상샘중독증** | 체중감소, 더위 불내성, 피로, 두근거림, 손떨림, 빈맥(AF 등), 골감소증 |
| **아급성 갑상샘염** | 갑상샘중독증 증상, 심한 목 통증(방사통), 미열, 근육통 |
| **무통성 갑상샘염** | 갑상샘중독증 증상, 통증 없는 대칭적 갑상샘 비후 |
| **급성 갑상샘염** | 갑상샘 통증, 붓기, 발적, 고열, 삼킴곤란 |
| **리델 갑상샘염** | 크고 딱딱하며 비대칭적이고 불규칙한 비후에 의한 압박 증상 |
| **갑상샘중독주기적마비(TPP)** | 갑상샘중독증과 저칼륨혈증 동반 마비, 동아시아 젊은 남성 호발 |
| **갑상샘중독발작(Thyroid storm)** | 고체온, 급성 심부전, 빈맥성 부정맥, 섬망, 의식저하 |

## 3. 검사
**암 진단과 병기 검사**

- **갑상샘암 진단**: 초음파(US), 세침흡인세포검사(FNA), 필요 시 분자유전학적 검사(BRAF 등)
- **갑상샘암 병기 설정**: 경부 초음파, 경부 CT/MRI, 원격 전이 의심 시 PET-CT

**기능 이상과 갑상샘염의 감별**

- **갑상샘중독증 검사**: TSH, fT4, 갑상샘 스캔(RAIU)
- RAIU 증가: 그레이브스병, 독성 갑상샘 결절
- RAIU 감소: 갑상샘염, 요오드 섭취 과다
- **갑상샘염 검사 소견**: 아급성(ESR↑), 무통성(Anti-TPO Ab+), 급성(WBC/CRP↑, FNA상 호중구 침윤), 리델(절제생검)
- **TPP 검사**: 혈중 K+, TFT

**열소작술 전 위치 평가**

- **열소작술(Thermal Ablation) 고려 시**: 초음파를 통한 결절의 위치 및 주변 중요 구조물(반회후두신경, 대혈관, 식도)과의 근접성 평가 필수

## 4. 진단
- **갑상샘암**: 초음파 소견 및 FNA 시행, 속질암은 RET 돌연변이 확인 및 갈색세포종 배제 필요
- **갑상샘중독증 감별**: 그레이브스병(RAIU 증가)과 갑상샘염(RAIU 감소) 감별 중요
- **불현성 갑상샘중독증**: TSH 감소, fT4와 T3 정상

**분화갑상샘암 TNM과 나이별 병기(AJCC 8판)**:

- **T1 / T2 / T3a**: 갑상샘 내 종양 ≤2 cm / >2–≤4 cm / >4 cm. T1a는 ≤1 cm이다.
- **T3b / T4a / T4b**: 육안적 띠근육 침범 / 피하조직·후두·기관·식도·되돌이후두신경 침범 / 척추전근막 침범 또는 경동맥·종격동 혈관 포위. 현미경적 갑상샘외 침범만으로 T3가 되지는 않는다.
- **N1a / N1b**: 중앙구획 VI·VII / 측경부 I–V 또는 인두후 림프절. M1은 원격 전이다.

| 진단 당시 나이 | 병기 | 기준 |
| --- | --- | --- |
| <55세 | I / II | 모든 T·N에서 M0 / M1 |
| ≥55세 | I | T1–2 N0/NX M0 |
| ≥55세 | II | T1–2 N1 M0 또는 T3 모든 N M0 |
| ≥55세 | III / IVA / IVB | T4a M0 / T4b M0 / 모든 T·N M1 |

이 표는 **유두암·여포암 등 분화암**에 적용한다. TNM은 사망 위험 예측에 사용하고, 수술 후 재발 위험도·치료반응 분류는 별도로 평가하여 방사성요오드와 TSH 억제 강도를 정한다. 젊은 환자의 I기라도 림프절 전이·국소 침범이 없다는 뜻은 아니다.

## 5. 치료
**분화암: 관찰·국소 치료**

- **적극적 감시**: 저위험 **cT1aN0M0 유두암**
  - 침범·전이, 기관/반회후두신경과의 위치, 정기 추적 가능성·선호 확인
  - 의미 있는 성장·새 림프절 전이/침범·추적 불가·선호 변화: 수술 재평가
- **수술 선택 시 범위**
  - 일측·갑상샘 국한·임상적 림프절/원격전이 없음·**≤2 cm**: 엽절제 기본
  - 저위험 **>2–4 cm**: 엽절제 우선 고려, 반대 엽 병변·RAI 필요·선호에 따라 전절제
  - **>4 cm**, 육안적 갑상샘외 침범 또는 임상적 전이: 전절제 중심 평가
- **림프절 절제**: 확인된 전이는 치료적 구역 절제, 작은 비침습성 cN0 PTC에 예방적 중앙절제 일률 시행하지 않음
- **소작술**: 선택된 저위험 원발암 또는 수술 위험 큰 국소 재발에서 전문팀 검토

**분화암: 수술 후·진행성 치료**

- **RAI**
  - 저위험: 일상 잔여조직 제거 권하지 않음
  - 중간 위험: 침범·림프절 부담·수술 후 Tg/영상으로 선택
  - 고위험·요오드 섭취성 잔존/전이: 검토
  - 임신·수유: 투여하지 않음. 모든 환자에 같은 용량 적용하지 않음
- **Levothyroxine·TSH**
  - 우수/불확정 반응: 대체로 정상 참고범위
  - 생화학적/구조적 불완전 반응: 정상 미만 억제 고려
  - 이득과 심방세동·골다공증 위험 비교. 저·중간 위험·재발 증거 없으면 강한 억제 장기 일률 유지하지 않음
- **전신치료**: 영상 진행·증상·장기 위협·국소치료 가능성으로 시작 결정, RAI 불응만으로 즉시 TKI 시작하지 않음
  - RET/NTRK 등 표적 평가 → 선택적 억제제 또는 lenvatinib/sorafenib 등
  - 이전 VEGFR 표적치료 후 진행: cabozantinib 등 후속 치료 검토

**속질암(MTC)**

- **수술 전**: 생식세포 RET 검사·유전상담, MEN2 갈색세포종/부갑상샘 평가
  - 갈색세포종 동반 시 먼저 치료
- **수술**: 전절제·중앙경부 평가/절제, 확인된 측경부 전이는 치료적 구역 절제
- **진행성·절제 불가/전이·전신치료 필요·RET 양성**: selpercatinib 우선 검토
- **RAI·TSH 억제는 MTC 치료가 아님**

**역형성암(ATC)**

- **초기**: 기도·절제 가능성, BRAF V600E·치료 가능한 융합 신속 확인
- **절제 불가/전이·BRAF V600E 양성**: dabrafenib + trametinib
- **표적 없음**: 수행상태·목표에 따른 방사선·항암·완화치료
- 반응으로 절제가 가능해지면 재평가

## 6. 예후 및 합병증
- **분화암 추적**: Tg 측정 시 항-Tg 항체 함께 해석, 경부 US로 국소 재발 평가
  - 전절제·RAI 후 저위험·우수 반응·Tg/US 음성: 진단적 전신스캔 일률 시행하지 않음
- **수술 합병증**: 부갑상샘 기능저하·반회후두신경 손상
  - 빠르게 커지는 목 부종·호흡곤란·목소리 변화: 혈종/기도 압박 의심, **즉시 기도·수술팀 평가**
  - 저칼슘 증상·쉰 목소리: 부갑상샘/후두신경 평가, 증상·검사에 따른 신속 교정·의뢰
- **갑상샘중독증 합병증**: 심부전·부정맥·주기적 마비·중독발작
