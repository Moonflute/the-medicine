# 갑상샘

## 공통 임상 접근
- 갑상샘 질환은 기능 이상, 염증성 질환, 결절·종양성 질환을 먼저 구분하고, 증상만으로 단정하지 않는다.
- 기능 이상이 의심되면 TSH와 유리 갑상샘호르몬을 임상 맥락과 함께 해석하며, 원인 확인은 항체·영상·약물력에 따라 진행한다.
- 결절 또는 종괴는 기능 이상 여부와 별개로 악성 위험 신호와 영상 소견을 평가한다.

## 먼저 배제할 상황
- 의식 변화·고열·심한 빈맥 또는 심부전이 동반된 중증 갑상샘중독증, 저체온·저환기·의식 저하가 동반된 중증 기능저하증은 긴급 평가한다.
- 빠르게 커지는 경부 종괴, 압박 증상, 쉰 목소리는 침습성 병변을 우선 평가한다.

## 하위 질환 감별 포인트
| 질환군 | 구분에 특히 유용한 단서 | 다음 확인 |
|---|---|---|
| 하시모토·무통성 산후 갑상샘염 | 자가면역 또는 산후 맥락과 기능 변화 | 항체, 시간 경과 |
| 그레이브스병·기능항진증·독성 주기 마비 | 지속적 중독증 또는 저칼륨성 근력저하 | 원인 감별과 심장·전해질 평가 |
| 기능저하증·무증상 기능저하증·병적 정상갑상샘증후군 | TSH-유리 T4 패턴과 급성 질환 맥락 | 약물·중증 질환·중추성 원인 |
| 아급성 갑상샘염 | 통증성 경부 증상과 염증 소견 | 시간 경과와 기능 변화 |
| 결절·유두암·여포암·속질암·역형성암 | 결절 영상과 성장·압박·전이 단서 | 초음파 기반 위험 평가 및 조직 진단 계획 |
