# 수술 체위와 안전 (Surgical Positioning)

## 체위의 구분
| 체위 | 형태 |
| --- | --- |
| Supine | 바로 누움 |
| Prone | 엎드림 |
| Lithotomy | 바로 누운 상태에서 다리를 지지해 벌림 |
| Trendelenburg | 수술대 전체를 기울여 머리를 낮춤 |
| Reverse Trendelenburg | 수술대 전체를 기울여 머리를 높임 |
| Semi-Fowler·Fowler | 몸통을 굴곡하여 상체를 올림 |

수술대 전체의 경사와 상체만 올리는 동작은 다르다. 명칭별 각도는 기관·용도에 따라 확인하며 그림의 형태를 먼저 판단한다.

## 목적과 안전
수술 부위 노출, 호흡·혈역학, 마취 접근과 환자의 관절·신경 위험을 함께 고려한다. 머리를 높인다고 흡인 위험이 없어지는 것은 아니다. 패딩·신체 정렬, 신경 신장·압박, 눈·피부 보호와 낙상 방지를 확인한다. 자세 변경 전후 기도·라인과 생리 반응을 재평가한다.
