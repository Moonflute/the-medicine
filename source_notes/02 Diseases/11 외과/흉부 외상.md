# 흉부 외상

## 먼저 생명을 위협하는 손상 확인

- 기도·호흡·순환을 평가하면서 긴장성 기흉, 대량 혈흉, 심장압전과 큰 혈관 손상을 먼저 찾는다.
- 불안정한 환자를 CT실로 보내기 전에 병상 초음파와 필요한 즉시 처치를 시행한다.
- 안정된 중증 외상에서는 조영 CT로 손상 범위를 확인한다.

## 손상별 구분

| 손상 | 핵심 단서 | 처치 방향 |
| --- | --- | --- |
| 긴장성 기흉 | 급격한 호흡·순환 악화, 한쪽 호흡음 감소 | 임상적으로 의심되면 영상 대기 없이 감압 후 흉관 |
| 개방성 기흉 | 가슴벽 결손으로 공기가 드나들고 한쪽 호흡음 감소 | 의료진의 임시 드레싱, 신속한 흉관 및 결손 복원 |
| 혈흉 | 호흡음 감소, 흉막강 혈액, 출혈성 쇼크 | 배액·수혈 및 지속 출혈에 대한 수술 평가 |
| 폐좌상 | 외상 뒤 저산소증·폐 실질 음영 | 산소화, 호흡 보조, 과도한 수액 회피 |
| 다발 늑골골절·동요흉 | 통증, 환기 저하, 흉벽 불안정 | 다중 진통·호흡 재활, 선택적 고정술 평가 |
| 심장압전 | 외상성 쇼크와 심낭액 | 긴급 수술적 처치 경로 |
| 기관·기관지 손상 | 지속 공기 누출, 피하기종, 폐 재팽창 실패 | 기관지내시경 및 흉부외과 평가 |

## 배액과 관찰을 구분

**안정 환자의 관찰·배액(WSES-AAST 2025)**

| 소견 | 선택 |
| --- | --- |
| 작은 기흉 ≤2 cm | 선택적으로 최소 24시간 관찰 |
| 혈흉 <300 mL | 선택적 관찰 가능 |
| 혈흉 300–500 mL | 호흡·출혈 추세·다른 손상으로 결정 |
| 혈흉 ≥500 mL | 배액 권고 |

- **즉시 처치**: 긴장성 기흉·혈역학 불안정·호흡 악화·지속 출혈. 불안정 환자의 혈흉은 양과 무관하게 배액·소생.
- **개방성 기흉**
  - 의료진: WSES-AAST는 3면 폐쇄 드레싱 후 흉관·가슴벽 결손 복원 제안
  - 일반 구조자: 공기를 가두는 밀봉 회피. 열린 채로 두거나 깨끗한 비밀폐·배기형 드레싱 사용 가능.
  - 모두 즉각 응급 대응. 덮은 뒤 호흡 악화 시 긴장성 기흉 의심.
- **수술 평가**: 다음 중 하나
  - 흉부 출혈로 혈역학 불안정
  - 흉관 출혈 **>1,500 mL/24시간**
  - 흉관 출혈 **>200 mL/hr가 3시간 지속**
  - 수치 미달이어도 임상 악화 시 기다리지 않음

## 후속 관리
- **호흡 합병증 예방**: 통증으로 인한 얕은 호흡은 무기폐·폐렴 위험 → 진통·기침/심호흡·조기 이동 병행
- **배액 후 재평가**: 잔류 혈흉·지속 누출 확인
- **늑골 고정술**: 동요흉·심한 전위·환기/진통 실패 등으로 선택
  - 외형만으로 삽관 여부를 결정하지 않음
