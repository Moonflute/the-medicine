# 외상

## 공통 접근

- 외상은 먼저 기도·호흡·순환과 대량 출혈 가능성을 평가하고, 손상 기전과 신체 진찰을 바탕으로 흉부·복부·골반·경부·비뇨생식기 손상을 병렬로 찾습니다.
- 혈역학적으로 불안정하거나 복막자극·신경학적 이상·골반 불안정이 있으면 손상 부위 확인보다 즉각적인 소생과 출혈 조절을 우선합니다.

## 공통 접근
- 이 범주의 하위 질환은 증상 경과, 침범 부위, 유발 요인 및 검사 패턴을 함께 비교합니다.
- 각 질환의 확진 기준과 처치는 아래 연결 문서에서 확인합니다.

## 하위 질환 감별 포인트
| 하위 질환 | 구분에 유용한 단서 |
| --- | --- |
| [[혈관 손상]] | 외상성 경동맥·대퇴동맥·신동맥 손상 |
| [[흉부 외상]] | 흉부 손상, 관통성 흉부손상, 심장 손상, 외상성 호흡부전 |
| [[관통상 복부외상 (Penetrating Abdominal Injury)]] | 복부 내로 관통성 물체(총상, 자상 등)가 침범하여 발생하는 외상 |
| [[간 손상 (Liver Injury)]] | 외부 충격(둔상 또는 관통상)이나 약물, 독소 등에 의해 간 실질이 손상되는 상태 |
| [[경부외상 (Cervical Trauma)]] | 경부(목) 부위에 발생하는 모든 외상성 손상을 의미하며, 해부학적 구조가 복잡하고 중요 혈관, 기도, 식도 등이 밀집되어 있어 치명적일 수 있음 |
| [[골반외상 (Pelvic Trauma)]] | 골반 고리(pelvic ring)의 구조적 파괴를 동반하는 고에너지 외상 |
| [[비장 손상 (Splenic Injury)]] | 복부 외상으로 인해 비장(spleen)의 실질이나 혈관이 손상된 상태 |
| [[둔상 복부외상 (Blunt Abdominal Trauma)]] | 외부의 둔력(blunt force)에 의해 복부 장기 및 구조물에 발생하는 비관통성 손상 |
| [[췌장 손상 (Pancreatic Injury)]] | 췌장에 가해진 외상성 손상으로, 복부 둔상이나 관통상에 의해 발생하며 진단과 치료가 지연될 경우 높은 이환율과 사망률을 보임 |
| [[신 손상 (Kidney Injury)]] | 급성 신손상(Acute Kidney Injury, AKI)은 신기능이 급격히 저하되어 체내에 수분, 질소 대사산물 등이 축적되는 증후군 |
