분과 : [[비뇨기과]]

## 1. 개요
- **정의:** 신장 실질에서 발생하는 악성 종양으로, 신세포암(Renal Cell Carcinoma, RCC)이 가장 흔함.
- **원인:** 흡연, 고혈압, 비만, 만성 신부전(투석 환자), 유전적 요인(VHL 증후군 등).
- **기전:** 주로 혈행성 전이(폐, 뼈, 간, 뇌)를 보임. 조직학적으로 투명세포암(Clear cell)이 가장 흔하며, 유두상(Papillary), 혐색소성(Chromophobe) 등이 있음.

## 2. 임상 양상 (Clinical Features)
- **초기**: 대개 무증상
- **진행 시 전형적 3징후**: 혈뇨·옆구리 통증·만져지는 옆구리 덩이
* **P/E:** 부종, 정계정맥류(좌측 신장암 시), 고혈압 등 확인.

## 3. 검사 (Lab & Imaging)
* **진단:** 복부 CT(조영 증강)가 표준 진단법. 초음파는 낭종과 고형 종양 감별에 유용.

## 4. 진단 (Diagnosis)
- **영상 진단**: 조영 증강 고형 종양이면 RCC 의심, 일부 양성 종양과 영상만으로 감별 어려움
  - 치료 계획에 따라 생검 또는 절제 조직으로 조직형 확인
- **전이 평가**: 흉부 CT 등 위험별 검사
  - 뼈 스캔은 일률적 병기검사로 시행하지 않고 관련 증상·검사 이상 시 고려

**TNM 병기(AJCC 8판)**:

| T분류 | 기준 |
| --- | --- |
| T1a / T1b | 콩팥 국한, 각각 ≤4 cm / >4–7 cm |
| T2a / T2b | 콩팥 국한, 각각 >7–10 cm / >10 cm |
| T3a | 콩팥정맥·분절정맥, 신우신배, 콩팥굴/콩팥주위 지방 침범; Gerota 근막 안쪽 |
| T3b / T3c | 하대정맥 혈전이 횡격막 아래 / 횡격막 위까지 도달하거나 하대정맥벽 침범 |
| T4 | Gerota 근막 바깥 침범; 동측 부신의 직접 침범 포함 |

| 병기군 | 기준 |
| --- | --- |
| I | T1 N0 M0 |
| II | T2 N0 M0 |
| III | T3 N0–1 M0 또는 T1–2 N1 M0 |
| IV | T4 M0 또는 모든 T/N의 M1 |

- **정맥 종양혈전**: T3 소견, 원격 전이와 구분
- **부신 병변**: 연속 직접 침윤과 떨어진 전이 구분
- **추가 기록**: 조직형·WHO/ISUP 등급·절제연. 전이성 약제 선택에는 IMDC 위험군 별도 적용

## 5. 치료
- **부분 신절제술**: 국소 **T1(≤7 cm)**에서 기술적으로 가능하면 우선 검토
  - 신보존을 ≤4 cm에만 제한하지 않음
  - 단일 신장·CKD에서는 보존 이득을 특히 평가
- **근치 신절제술**: 큰/복잡한 종양 등 부분 절제 불가 시 고려
- **능동감시·소작술**: 작은 신종괴 + 고령·허약·높은 경쟁 사망위험이면 논의
  - 소작 전 생검, 성장·증상·공격적 조직 소견 시 중재 전환
- **수술 후 보조 pembrolizumab**: clear-cell RCC의 KEYNOTE-564 해당 고위험군 검토
  - pT2 G4/육종양, pT3·pT4, pN+, 제한 전이 완전 절제 후 M1 NED
  - 모든 T1 완전 절제 환자에게 투여하지 않음
- **전이성**: 조직형·IMDC·치료 가능성에 따라 ICI + VEGFR-TKI 또는 nivolumab + ipilimumab 등
  - 전신 치료 필요 + 무증상 원발: 즉시 감축 신절제를 일률 시행하지 않음
  - IMDC 불량위험은 특히 피하고 약물 반응 후 재평가

## 6. 예후 및 합병증 (Prognosis)
* **예후:** 병기에 따라 상이함. T1기 5년 생존율은 90% 이상이나, 원격 전이 시 예후가 불량함.
