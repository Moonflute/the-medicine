분과 : [[비뇨기과]]

## 1. 개요
- **정의:** 방광 상피에서 발생하는 악성 종양으로, 90% 이상이 요로상피암(urothelial carcinoma)임.
- **원인:** 흡연(가장 중요, 위험도 2~6배), 화학물질 노출(염료, 고무, 석유 제품 등), 만성 방광 염증.
- **침윤 양상**: NMIBC는 배뇨근 침범이 없는 Ta·Tis·T1, MIBC는 근육층 이상 침범
  - 요로상피암의 유두상·상피내암(CIS) 경로 등을 고려하며, MIBC 전체를 편평상피화생 기원으로 설명하지 않음

## 2. 임상 양상 (Clinical Features)
* **CC:** 무통성 육안적 또는 현미경적 혈뇨
* **기타:** 빈뇨, 절박뇨, 골반 통증
* **P/E:** 직장수지검사(DRE)를 통해 방광 주위 침범 여부 확인

## 3. 검사 (Lab & Imaging)
* **진단적 검사:** 방광경(cystoscopy) 및 조직검사(biopsy)가 표준 진단법임.
* **영상 검사:** CT 또는 MRI를 통해 병기 결정(staging) 수행.
* **기타:** 소변 세포검사(urine cytology)를 보조적으로 활용함.

## 4. 진단 (Diagnosis)
* 방광경을 통한 시각적 확인 및 조직검사가 표준 진단법임.
* TNM 병기 체계에 따라 근침습 여부와 전이 정도를 평가함.

**침윤 깊이와 병기(AJCC 8판)**:

| T분류 | 침범 범위 |
| --- | --- |
| Ta / Tis | 비침윤 유두상암 / 편평한 상피내암(CIS) |
| T1 | 점막고유층 침윤, 배뇨근 침윤 없음 |
| T2a / T2b | 배뇨근 안쪽 절반 / 바깥쪽 절반 침윤 |
| T3 | 방광 주위 지방 침윤; a 현미경적, b 육안적 |
| T4a / T4b | 전립샘 기질·정낭·자궁·질 / 골반벽·복벽 침범 |

**Ta·Tis·T1은 비근침윤성(NMIBC), T2 이상은 근침윤성(MIBC)**이다. T1의 ‘침윤’을 근육 침윤으로 혼동하지 않는다. TURBT 검체에 배뇨근이 포함되었는지 확인한다.

| 병기군 | 기준 |
| --- | --- |
| 0a / 0is / I / II | N0 M0에서 각각 Ta / Tis / T1 / T2 |
| IIIA | T3–4a N0 또는 T1–4a N1, M0 |
| IIIB | T1–4a N2–3 M0 |
| IVA | T4b M0 또는 비국소 림프절 전이 M1a |
| IVB | 림프절 이외의 원격 전이 M1b |

- **N분류**: N1 진골반 단일 림프절, N2 진골반 다발, N3 총장골 림프절
- **CIS**: 고등급 병변, 병기 0이라고 저위험으로 취급하지 않음
- **NMIBC 위험군**: 등급·CIS·크기·다발성·재발 여부 추가

## 5. 치료 (Treatment)
**NMIBC(Ta·T1·CIS)**

- **시작**: 완전 TURBT·병리 위험 평가
  - T1·불완전 절제·근육층 미포함 등은 재TURBT 필요성 평가
- **저위험**: 천공·심한 출혈 없으면 **24시간 이내** 단회 방광내 항암제 고려
- **중간위험**: 반복 항암제 또는 **1년 BCG**
- **고위험**: **1–3년 BCG** 또는 조기 방광절제 논의
  - EAU 2026: 선별 BCG 미치료 고위험에서 BCG 유지 + sasanlimab·durvalumab의 이득/위험 논의 포함
- **매우 고위험·BCG-unresponsive**: 근치 방광절제 우선 논의
  - 충분한 BCG 후 고등급 Ta/T1이 **6개월 이내**, CIS가 **12개월 이내** 재발: 같은 BCG 반복 회피
  - 수술 불가·거부: 허가된 방광보존 치료·임상시험 검토

**MIBC(T2 이상)**

- **국소 치료**: 근치 방광절제 또는 선별 환자의 최대 TURBT + 동시 항암방사선 삼중치료
  - 방광보존: 국한 종양·양호한 방광기능·광범위 CIS 부재 등 평가
  - 지속·재발 침윤암: 구제 절제 검토
- **수술 전후 전신치료**
  - Cisplatin·면역치료 적합 **T2–T4a cN0–1 M0**: gemcitabine/cisplatin + durvalumab 검토
  - NIAGARA: **eGFR ≥40 mL/min**, 40–60에서는 분할 cisplatin 포함. 60만을 고정 배제값으로 사용하지 않음
  - Cisplatin 부적합: enfortumab vedotin(EV) + pembrolizumab도 EAU 2026 선택지
  - 청력·신경병증·심부전·전신 상태·국내 허가 함께 확인

**절제 불가·전이성**

- **일차 치료**: EV + pembrolizumab 등 적합한 병용
- **백금 항암 후 비진행**: avelumab 유지 검토
- **후속 치료**: 이전 노출·FGFR 등 표적 변이·장기 기능에 따라 결정

## 6. 예후 및 합병증 (Prognosis)
* NMIBC는 재발률이 높으나 생존율이 양호함.
  MIBC는 침습 깊이와 병기에 따라 예후가 결정되며, 전이 시 예후가 불량함.
