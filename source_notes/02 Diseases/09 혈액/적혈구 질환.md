# 적혈구 질환

## 공통 접근
- 빈혈은 평균적혈구용적(MCV), 망상적혈구 반응, 말초혈액도말을 함께 보아 **생산 저하**, **출혈**, **용혈**로 나눕니다. 철 상태, 비타민 B12·엽산, 염증 상태와 신장 기능은 흔한 생산 저하 원인을 구분하는 데 도움이 됩니다.
- 망상적혈구가 충분히 증가하지 않으면 골수 생산 문제를, 증가하면서 LDH·간접 빌리루빈 상승과 합토글로빈 저하가 있으면 용혈을 생각합니다. 도말 소견과 가족력은 유전성 원인을 좁히는 단서입니다.

## 먼저 구분할 위험 상황
- 급격한 빈혈, 황달·혈색소뇨, 호흡곤란 또는 흉통은 빠른 용혈이나 출혈을 우선 평가합니다.
- 범혈구감소증, 비정상 세포 또는 지속적인 거대적혈구증은 골수 질환·골수형성이상 증후군을 고려해야 하는 소견입니다.

## 놓치면 치료가 달라지는 분기
- **철결핍**: 빈혈 전에도 존재 가능
  - Ferritin은 염증 시 상승하므로 정상/상승만으로 배제하지 않고 TSAT·임상 맥락 확인
  - ASH 2026의 연령·임신·염증 등 대상별 역치 적용, 하나의 낮은 역치를 모두에게 쓰지 않음
- **소구성 빈혈**: 철결핍과 지중해빈혈을 가족력·RBC 수·도말·Hb 분석으로 구분
  - 철결핍 확인 없이 장기간 철 투여하지 않음
- **B12 결핍**: 정상 MCV·빈혈 부재만으로 배제하지 않음
  - 신경 이상·거대적혈모구성 빈혈 의심 시 결과 대기로 치료를 미루지 않음
  - B12 결핍 배제 전 엽산만 치료하지 않음
- **용혈 + 혈소판 감소·schistocyte**: TMA 신속 평가
  - DAT는 면역용혈 감별에 사용, 음성만으로 모두 배제하지 않음
- **PNH**: 용혈·비전형 부위 혈전·골수부전이 단서, 유세포로 확인
  - 범혈구감소는 AA·MDS 등 감별
- **철과부하**: 높은 ferritin만으로 유전성 혈색소침착증을 진단하지 않음
  - TSAT·유전자·필요 시 간 철 평가 후 사혈 결정
