# 림프구 질환

## 임상 경과와 세포 계열

현재 연결 범위는 주로 림프종이다. 림프절 비대가 모두 악성은 아니므로 감염·약물·자가면역 반응과 진행성 종괴를 구별한다. 혈액의 림프구 증가만으로 조직 림프종 아형을 확정하지 않는다.

| 범위 | 중요한 구별 |
| --- | --- |
| 호지킨 림프종 | 특징적인 병리·면역표현형; 다른 림프종과 치료 체계가 다름 |
| 공격적 성숙 B세포 림프종 | DLBCL·버킷 등, 빠른 증식; 분자·유전 정보가 치료에 영향 |
| 완만한 성숙 B세포 림프종 | 여포성·SLL 등; 무증상 일부는 관찰이 가능하지만 전환 위험 평가 |
| 림프모구성 림프종 | 전구세포 계열; ALL 계열 치료 접근 |
| T/NK세포 계열 | B세포 림프종과 다른 아형·치료; 조직 분류가 중요 |

과거 '버킷 유사' 같은 명칭은 최신 병리 분류와 일대일 대응하지 않을 수 있다. 기존 학습 링크를 보존하되 실제 진단은 형태·면역표현형·유전 소견을 통합한 최신 분류를 사용한다.

## 검체와 안전

절제 또는 충분한 조직 구조를 확보하는 생검이 중요하며 세침흡인만으로 완전한 아형 분류가 어려울 수 있다. 혈액검사, LDH·요산과 장기 기능, 아형에 맞는 영상·병기를 평가한다. 골수생검을 모든 림프종에 필수라고 일률 적용하지 않는다.

빠른 종괴 성장·기도/상대정맥 압박·신경 증상과 종양용해 위험은 응급 평가가 필요하다. 가능하면 치료 전 조직을 확보하되 생명을 위협하는 압박 등에서는 응급 처치를 우선한다. 림프구 질환이라는 공통 이름보다 아형·병기·환자 상태가 치료를 결정한다.
