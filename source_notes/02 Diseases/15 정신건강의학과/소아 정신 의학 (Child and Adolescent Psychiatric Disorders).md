# 소아 정신 의학

## 발달 수준과 기능의 평가
- **발달·기능**: 발달력, 언어·학습·사회적 상호작용, 수면·감각, 가정·학교 기능
- **정보 종합**: 보호자·학교·아동의 관찰을 비교하고 발달 단계에 맞는 행동과 지속적 기능 손상 구분
- **동반 평가**: 청각·시각 문제, 신체질환, 학대·외상·정신질환

| 범위 | 구별 포인트 |
| --- | --- |
| ADHD | 발달 수준에 부적절한 부주의·과잉행동/충동성, 여러 환경의 기능 손상 |
| 자폐 스펙트럼 | 사회적 의사소통·상호작용의 어려움과 제한적·반복적 양상 |
| 지적 장애 | 지적 기능과 적응 기능의 결함; IQ 숫자만으로 진단·중증도 결정 금지 |
| 학습·의사소통 장애 | 특정 학습·언어 영역의 어려움, 전반 발달·교육 기회와 구별 |
| 틱·뚜렛 | 운동·음성 틱의 양상과 지속 기간, 일상 기능 영향 |
| 애착·기분조절 장애 | 돌봄·발달 맥락과 증상의 지속성; 단순한 양육 평가로 진단하지 않음 |

## 검사와 치료
- **검사의 역할**: 척도·심리검사는 임상 평가를 보조; 단일 점수·지속수행검사만으로 ADHD 확진 불가
  - 뇌영상·유전자검사를 모든 아동에게 일률 시행하지 않음
  - 자폐는 단일 생물학적 검사 대신 발달·관찰 정보 종합
- **기본 지원**: 가족 교육, 학교·환경 조정, 행동·의사소통 지원
- **약물**: 진단·목표 증상에 맞추어 사용
  - ADHD: 성장·체중·맥박·혈압 추적
  - 자폐의 핵심 특성 자체를 항정신병약으로 일률 치료하지 않음
- **신속 전문 평가**: 자해·자살 위험, 급격한 퇴행·정신증, 의학적 불안정
