# 소아 정신 의학

## 발달 수준과 기능의 평가

발달력, 언어·학습·사회적 상호작용, 수면·감각 문제, 가정·학교 기능을 함께 평가한다. 보호자·학교·아동의 정보를 종합하고 발달 단계에 맞는 행동과 지속적인 기능 손상을 구분한다. 청각·시각 문제, 신체질환, 학대·외상과 동반 정신질환을 확인한다.

| 범위 | 구별 포인트 |
| --- | --- |
| ADHD | 발달 수준에 부적절한 부주의·과잉행동/충동성, 여러 환경의 기능 손상 |
| 자폐 스펙트럼 | 사회적 의사소통·상호작용의 어려움과 제한적·반복적 양상 |
| 지적 장애 | 지적 기능과 적응 기능의 결함; IQ 숫자만으로 진단·중증도 결정 금지 |
| 학습·의사소통 장애 | 특정 학습·언어 영역의 어려움, 전반 발달·교육 기회와 구별 |
| 틱·뚜렛 | 운동·음성 틱의 양상과 지속 기간, 일상 기능 영향 |
| 애착·기분조절 장애 | 돌봄·발달 맥락과 증상의 지속성; 단순한 양육 평가로 진단하지 않음 |

## 검사와 치료

척도·심리검사는 임상 평가를 보조하며 하나의 점수나 지속수행검사로 ADHD를 확진하지 않는다. 뇌영상·유전자검사도 모든 아동에게 일률적으로 시행하지 않는다. 자폐는 단일 생물학적 검사로 확진하는 질환이 아니며 발달·관찰 정보를 종합한다.

가족 교육, 환경·학교 조정, 행동·의사소통 지원을 기본으로 한다. 약물은 진단과 목표 증상에 맞춰 사용한다. ADHD 약물은 성장·체중·맥박·혈압 등을 추적하고, 자폐의 핵심 특성 자체를 항정신병약으로 일률 치료하지 않는다. 자해·자살 위험, 급격한 퇴행·정신증과 의학적 불안정은 신속한 전문 평가가 필요하다.
