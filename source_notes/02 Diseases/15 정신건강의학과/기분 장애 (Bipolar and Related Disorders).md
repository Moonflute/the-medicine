# 기분 장애

## 우울 증상보다 먼저 확인할 병력

현재 우울해 보여도 과거 조증·경조증이 있었는지 묻는다. 수면 욕구 감소, 과도한 활동·말수, 과대감, 충동적 지출·성적 행동과 기능 변화를 환자·가족에게 확인한다. 항우울제 관련 기분 상승, 물질·약물·갑상샘 질환도 평가한다.

## 삽화와 경과로 구분

| 상태 | 구분 포인트 | 치료 판단에 미치는 영향 |
| --- | --- | --- |
| 조증 | 뚜렷한 기능 손상·입원 필요 또는 정신병적 증상 | 양극성 I형 가능성, 급성 안전 관리 |
| 경조증 | 활동·기분 변화는 있지만 조증 수준의 심한 손상은 없음 | 주요우울삽화가 함께 있고 조증 병력이 없으면 II형 고려 |
| 주요우울삽화 | 우울·흥미 저하와 신체·인지 증상의 지속 | 자살 위험과 양극성 여부 확인 |
| 순환성 장애 | 역치 미만 기분 상승·우울이 장기간 반복 | 삽화 기간과 증상 없는 기간 확인 |
| 지속성 우울장애 | 만성적 우울 경과 | 장기간 기능 저하와 주요우울삽화 평가 |
| 정상 애도 | 상실과 관련된 정서 반응 | 애도 중에도 주요우울삽화·자살 위험이 동반될 수 있음 |

## 단계별 치료 원칙

- 급성 조증은 항정신병약과 필요 시 기분조절제를 사용하고 위험 행동·수면·수분 상태를 관리한다.
- 양극성 우울에는 해당 삽화에 근거가 있는 치료를 선택한다. 양극성 I형에서 항우울제 단독 치료를 피하고 혼재성 특징·급속순환을 확인한다.
- 단극성 우울은 중증도와 선호에 따라 심리치료·항우울제를 선택한다. 심한 자살 위험·정신병적 우울·긴급한 회복 필요성에서는 전문 평가와 ECT 등을 고려한다.
- 리튬 사용 시 혈중 농도, 신장·갑상샘 기능과 탈수·약물 상호작용을 점검한다. 유지 치료와 재발 징후 교육을 함께 한다.

## 최근 안전성 권고

NICE 2025 갱신은 발프로산의 생식·태아 위험과 사용 제한을 강조한다. 임신 가능성·임신 계획을 반드시 확인하고 해당 국가 허가·안전성 기준을 적용한다. 모든 기분 장애에 같은 약을 일괄 처방하지 않는다.
