## 1. 개요

- 이상운동질환은 떨림, 서동·경직, 근긴장이상, 불수의운동의 양상과 동반 신경학적 소견으로 분류한다.

## 2. 하위 질환 감별

- 안정 시 떨림·서동·경직은 파킨슨증을, 자세·동작 시 떨림은 본태성 떨림을, 특정 동작에서의 비정상 자세는 국소 근긴장이상을 우선 고려한다.

## 공통 접근
- 이 범주의 하위 질환은 증상 경과, 침범 부위, 유발 요인 및 검사 패턴을 함께 비교합니다.
- 각 질환의 확진 기준과 처치는 아래 연결 문서에서 확인합니다.

## 하위 질환 감별 포인트
| 하위 질환 | 구분에 유용한 단서 |
| --- | --- |
| [[본태성 떨림 (Essential tremor)]] | 가장 흔한 운동 질환 중 하나로, 주로 양측 손의 자세성(postural) 또는 활동성(kinetic) 떨림을 특징으로 하는 신경계 질환 |
| [[서경 (Writer's cramp)]] | 특정 작업(주로 글쓰기)을 수행할 때 손이나 팔에 발생하는 국소 근긴장이상증(Focal Dystonia) |
| [[파킨슨 증후군 (Parkinsonism)]] | 진전, 경직, 서동증, 자세 불안정 등 운동 증상을 특징으로 하는 신경퇴행성 질환군을 통칭함 |
| [[파킨슨 플러스 증후군 (Parkinson-plus syndrome)]] | 파킨슨 증후군(Parkinsonism)과 유사한 운동 증상을 보이나, 특이적인 임상적·병태생리학적 특징을 동반하는 신경 퇴행성 질환군. 비정형 파킨슨증(Atypical parkinsonism)이라고도 함 |
| [[헌팅턴병 (Huntington Disease)]] | 가족력과 진행성 불수의운동·성격 변화·집행기능 저하의 조합이 단서다 |
