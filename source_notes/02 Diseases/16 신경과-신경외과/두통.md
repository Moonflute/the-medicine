# 두통

## 먼저 확인할 이차성 위험

- **즉시 평가할 단서**: 벼락두통, 새 신경학적 결손·의식 변화, 발열·수막 자극
- **배경 위험**: 암·면역저하, 임신·산후의 새 두통, 외상
- **양상 변화**: 새 자세·운동 유발 두통
- 전형적 일차 두통이고 신경학적 진찰이 정상이면 안심만을 위한 일률적 영상검사는 시행하지 않음

| 양상 | 감별 포인트 |
| --- | --- |
| 편두통 | 박동성·중등도 이상, 활동 악화, 오심 또는 빛·소리 민감 |
| 긴장형두통 | 양측 압박성, 대개 경도·중등도, 일상 활동으로 뚜렷이 악화하지 않음 |
| 군발두통 | 극심한 편측 안와·관자 통증, 동측 자율신경 증상과 안절부절 |
| 혈관·종양 관련 | 급성 또는 진행성 경과, 신경 소견·전신 위험; 통증 형태만으로 배제 불가 |
| 자발적 두개내압 저하 | 기립 시 악화하고 누우면 호전하는 양상이 단서; 정상 CSF 압력도 가능 |

## 급성 치료와 예방
- **두통 일지**: 빈도·지속시간·동반 증상·급성 약물 사용일 기록
- **편두통 급성기**: 적응증·금기를 고려한 triptan·비오피오이드 진통제 등
- **군발두통 급성기**: 산소·빠른 triptan 제형; 일반 경구 진통제만 반복하지 않음
- **예방치료**: 빈도·장애 정도·환자 선호·동반질환으로 결정
- **약물과용두통**: 기존 두통 환자에서 **월 ≥15일 두통**과 다음 과용이 **3개월 초과** 지속할 때 평가
  - Triptan·opioid·복합진통제: **월 ≥10일**
  - 단순 진통제·NSAID: **월 ≥15일**
  - 과용 중단과 기존 두통 예방 계획 병행
- **자발적 두개내압 저하 의심**: 조영 뇌 MRI·척추 영상 평가
  - 개방압 확인만을 위한 LP 일률 시행은 피함
  - 원인·누출 위치·경과에 따라 경막외 혈액봉합술 등 전문 치료 검토
