# 척수 외상

## 초기 안정화와 신경학적 평가
- **안정화**: 기도·환기·출혈 평가, 적절한 척추 운동 제한
- **신경 평가**: 운동·감각·천수 보존을 ISNCSCI/ASIA로 기록, 손상 수준·완전성 판단
- **영상**: 성인 고위험 외상은 CT; 신경 이상·압박·인대/척수 손상 의심 시 MRI 추가
- **쇼크 감별**
  - 신경성 쇼크: 혈역학적 상태; 저혈압을 곧바로 단정하지 않고 출혈 등 다른 원인 배제
  - 척수 쇼크: 손상 아래 반사·근긴장이 일시적으로 저하되는 신경학적 상태

| 불완전 척수 증후군 | 특징적인 분포 |
| --- | --- |
| 중심 척수 | 대개 하지보다 상지 운동장애가 심함 |
| 전 척수 | 운동·통각·온도감각 손상, 상대적인 후주 감각 보존 |
| Brown-Sequard | 병변 동측 운동·진동·위치감각 저하와 반대쪽 통각·온도감각 저하 |
| 후 척수 | 진동·위치감각 장애와 감각성 실조가 중심 |

## 감압과 관류 관리
- **조기 감압**: 압박이 있는 급성 손상은 가능하면 **24시간 이내** 검토
- **MAP 관리(AO Spine/Praxis 2024)**
  - 하한 약 **75–80 mmHg**, 능동 증강 상한 약 **90–95 mmHg**
  - **3–7일** 유지 제안
  - 근거 확실성이 낮은 약한 권고로 출혈·심장 상태·부작용에 따라 개별화
  - 자발적 MAP 상승을 무조건 낮추라는 뜻은 아님
- **Steroid**: 고용량을 일률적 표준 처치로 사용하지 않음
- **합병증·재활**: 호흡 관리, 혈전·욕창 예방, 배뇨·배변 관리, 조기 재활
- **자율신경 반사 이상**: 상위 손상에서 새 심한 고혈압·두통 시 의심, 방광·장 등 유발 요인 신속 확인
