## 1. 개요
- **정의**: 혈관벽 염증·손상으로 조직 허혈·장기 손상을 일으키는 질환군
- **병태생리**: 면역복합체·ANCA·T세포 반응·육아종 형성 등이 혈관 손상 유발
  - 분절성 염증 가능, 치유 과정의 내막 비후·섬유화로 혈류 감소

| 분류 | 침범 부위·대표 질환 |
| --- | --- |
| 대혈관 | 대동맥·주요 분지: Takayasu, 거대세포동맥염(GCA) |
| 중혈관 | 주요 내장 혈관·분지: PAN, 가와사키병 |
| 소혈관 | 실질 내 혈관·모세혈관: ANCA 연관, 면역복합체 연관 혈관염 |
| 가변성 | 대·중·소혈관 모두 가능: 베체트병, 코간 증후군 |
| 단일장기 | 피부 혈관염, 원발성 CNS 혈관염 등 |
| 이차성 | SLE·RA·사르코이드증, HBV/HCV·매독, 종양·약물 등 |

- **병리 차이**
  - Takayasu·GCA: 대혈관 육아종성 염증
  - PAN: 중간 동맥의 괴사성 동맥염
  - GPA: 괴사성·육아종성 소혈관염
  - MPA: 육아종 없는 괴사성 소혈관염
  - EGPA: 호산구 침윤을 동반한 괴사성 혈관염
  - 피부 백혈구파괴성 혈관염·IgA 침착 혈관염도 소혈관 질환

## 2. 임상 양상
- **전신**: 발열·야간 발한·피로·체중 감소, 관절통·근육통
- **피부**: 자반·점상출혈·결절·궤양, 망상청피반
- **대혈관**: 상지 파행·맥박 소실·혈압 차이·잡음, 측두부 통증·턱 파행·시력 저하, PMR
- **중혈관**: 고혈압·신기능 저하, 식후 복통
- **소혈관**: 부비동염·기침·객혈, 신염(혈뇨·단백뇨·적혈구원주), 천식·호산구 증가, 다발성 단신경염

## 3. 검사
- **장기위협 우선 평가**: 혈뇨·적혈구원주·eGFR 저하, 객혈/저산소혈증, 신경염, 장허혈·시력 증상
- **혈액**: ESR/CRP, PR3-/MPO-ANCA, 보체·자가항체, 호산구, cryoglobulin·RF, 간염 혈청검사
  - ANCA는 보조 검사로 단독 확진 불가, 음성이어도 AAV 배제 불가
- **영상**: CT/MR 동맥조영술로 협착·폐쇄·동맥류 확인; 흉부 CT로 결절·공동·침윤 확인
- **생검**: 가능한 안전한 병변(신장·피부·폐 등)에서 시행
  - 혈관벽 염증·섬유소성 괴사·백혈구 파쇄 확인
  - GPA 신장: pauci-immune GN 가능
  - PAN: 장기 생검이 어려우면 동맥조영술의 내장 동맥류·폐색 활용; HBV 검사 포함
  - GCA: 측두동맥 생검에서 분절성 병변 고려
  - 모든 환자에서 가능하지 않으며, 장기위협 AAV의 치료를 생검 결과 대기 때문에 지연하지 않음

## 4. 진단
- **종합 진단**: 임상·항체·영상·조직을 통합; 연구 분류 기준은 임상 진단을 대체하지 않음
- **모방질환·이차 원인**: 약물·코카인, 감염성 심내막염·HBV/HCV·HIV, 악성종양, 면역복합체 질환 확인
  - 면역억제 전 감염 감별

| 질환 | 주요 감별 단서 |
| --- | --- |
| Takayasu | 젊은 여성, 상지 혈류 비대칭 |
| GCA | ≥50세 새 두통·턱 파행·측두동맥 이상·시력저하, PMR |
| PAN | 사구체신염·폐침범 없이 피부·관절·말초신경·신장·위장관 침범; 고혈압, 망상청피반·궤양·말단 경색, 복통·장허혈/천공, 다발성 단신경염·고환통; 적혈구원주 없는 소량 단백뇨·혈뇨 가능 |
| GPA | 상·하부 호흡기(부비동염·폐 공동), 신장·눈·피부·말초신경 침범; PR3/c-ANCA 흔함 |
| MPA | 괴사성 GN·폐 모세혈관염, 객혈·폐출혈·간질성폐질환; MPO-ANCA 흔하지만 음성 가능, 상기도 육아종 병변은 드묾 |
| EGPA | 천식·알레르기비염/부비동염, 호산구·IgE 증가, 폐 침윤·다발성 단신경염·자반; MPO/p-ANCA 양성일 수 있으나 필수 아님 |
| IgA 혈관염 | 비혈소판감소성 하지 자반과 복통·관절염·신장침범 또는 IgA 침착 생검 중 하나 이상을 함께 평가 |

소혈관염은 ANCA 연관(GPA·MPA·EGPA)과 비ANCA 연관(IgA 혈관염·cryoglobulinemia 등)을 구별한다.

## 5. 치료
- **장기·생명 위협 GPA/MPA**: 고용량 glucocorticoid + rituximab 또는 cyclophosphamide로 신속한 관해 유도
  - 신부전·폐출혈 등은 입원, 류마티스·신장내과 협진
  - 혈장교환은 선택된 상황에서 개별 검토
- **비장기위협 AAV·기타 혈관염**: 아형·침범 장기·재발 위험에 따라 스테로이드·면역조절 치료 선택
- **PAN**: 장기 침범·예후인자에 따라 스테로이드 단독 또는 cyclophosphamide 기반 관해 유도
  - HBV 관련이면 항바이러스 치료 함께 계획
- **EGPA**: 중증도에 따라 스테로이드 중심 치료, 중증 다장기 침범·불응성은 추가 면역억제
- **GCA의 시력 증상**: 지연 없이 즉시 glucocorticoid와 응급 평가
- **중혈관염의 장허혈**: 응급 평가
- **IgA 혈관염**: 대개 지지요법, 중증 장기 침범은 전문 평가
- **면역억제 안전관리**: 감염·예방접종·결핵/HBV 위험, 임신 계획·장기 기능 확인
  - PJP 예방·골 보호 검토
  - 관해 후 재발·감염·독성을 추적해 유지요법·감량 조정

## 6. 예후 및 합병증
- **예후**: 침범 장기·치료 반응에 따라 다름, 진단 지연 시 신부전·시력 상실 등 영구 손상 가능
- **질환 합병증**: 혈관 파열·혈전증, 허혈·괴사, CKD·심혈관 위험
- **면역억제 합병증**: 감염·기회감염, 저감마글로불린혈증, 골 손상·암 위험
- **장기 추적**: 관해 후에도 재발·장기 손상과 약물 독성을 함께 평가해 치료 강도 조절
