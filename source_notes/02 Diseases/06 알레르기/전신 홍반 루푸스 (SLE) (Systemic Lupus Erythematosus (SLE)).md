## 1. 개요
- **정의**: 자가항체·면역복합체가 조직·세포 손상을 일으키는 전신 자가면역질환
- **역학**: 여성에 호발(약 90%), 특히 가임기에 흔함
  - 2010년 국내 추정: 인구 10만 명당 발생률 2.5명·유병률 26.5명(해당 연도의 역사적 자료)
- **병태생리**: 유전 소인, 자외선·약물·감염, 여성호르몬(경구피임제·HRT 등)이 복합적으로 관여 → 핵 단백질·DNA에 대한 자가항체와 다장기 침범
- **항인지질증후군(APS)**: 자가항체 매개 후천성 응고항진 상태
  - 일차성 또는 SLE 등에 동반
  - 인지질 결합 단백질 등에 대한 자가항체가 내피·응고 경로를 활성화해 혈전 형성

## 2. 임상 양상
**장기별 임상 소견**

| 장기·범주 | 임상 소견 |
| --- | --- |
| 주요 증상 | 발열, 피부 발진, 관절통, 피로감. |
| 피부 | 나비 모양 발진(급성, 광과민성), 붉은 반점 및 고리 모양 발진(아급성), 원판상 발진(만성, 중심부 위축 및 경계부 비늘), 구강/비강 궤양, 비흉터성 탈모. |
| 관절 | 비침식성 관절염. |
| 신장(루푸스 신염) | 단백뇨(UPCR ≥ 500 mg/gCr), 혈뇨(RBC cast), 신기능 저하. |
| 심장/폐 | 심막염, 흉막염, 흉막삼출. |
| 신경계 | 섬망, 정신병적 증상, 발작 등 중추 및 말초신경계 증상. |
| 혈액 | 범혈구감소증(용혈성 빈혈, 백혈구감소증, 혈소판감소증 < 100,000/mm³). |
| 기타 | 레이노 현상, 혈관폐쇄(심근경색, 뇌졸중 위험 증가), 결막염, 각막염. |

**항인지질증후군 관련 증상:**

  - 혈전증: 정맥(DVT, PTE), 동맥(심근경색, 뇌졸중, PAD).
  - 산과적 이상: 반복적 유산/사산/조산, 전자간증, 자간증.
  - 기타: 편두통, 발작, 관절통, 그물울혈반(Livedo reticularis).

**약물 유발 루푸스·임신 관련 소견**

- **약물 유발 루푸스**: chlorpromazine, methyldopa, hydralazine, procainamide, isoniazid 등
  - 신장·중추신경 침범은 드물고 anti-histone이 흔함
- **임신**: 질환이 안정된 상태에서 계획, 고위험 산과 공동 관리
  - 산모 anti-Ro가 태반을 통과하면 신생아의 일시적 피부 루푸스, 드물게 영구적 심장 전도장애 가능

## 3. 검사
**자가항체·활성도**

- **ANA**: 선별검사; 반복 음성은 SLE 가능성을 낮춤
- **Anti-dsDNA·보체(C3/C4/CH50)**: dsDNA 상승·보체 저하는 특히 신염 활성과 연관 가능; 임상·소변 소견과 함께 해석
- **항체별 연관**
  - Anti-Sm: SLE 특이항체
  - Anti-RNP: 중복 결합조직질환 소견
  - Anti-Ro/SSA: Sjögren·아급성 피부루푸스·신생아루푸스
  - Anti-La/SSB: 흔히 anti-Ro와 동반
  - Anti-histone: 약물 유발 루푸스
- **ESR·CRP**: ESR만으로 활성도 판단하지 않음; CRP 상승 시 감염 감별
- **혈구·용혈**: 빈혈·백혈구/림프구/혈소판감소 확인, 약물·감염 감별
  - 직접 Coombs 양성만으로 용혈 확정 불가
  - 항혈소판항체는 혈소판감소의 유용한 확진 검사가 아님
- **신장**: 소변검사, 필요 시 생검(Class I–VI)

**항인지질항체(aPL)**

- **검사 대상**: 원인 불명 혈전증·특징적 태아손실 등에서 검토; 젊은 연령(예: 55세 미만)은 의심 단서이며 연령만으로 검사 여부를 결정하지 않음
- **검사 종류**: lupus anticoagulant(LA), anticardiolipin(aCL), anti-β2 glycoprotein I
- **지속성**: **≥12주 간격, 2회 이상** 확인
  - LA: 표준 응고검사 기준으로 양성 판정
  - 고전 APS 기준의 aCL: IgG/IgM **>40 GPL/MPL 또는 >99백분위수**
  - Anti-β2GPI: IgG/IgM **>99백분위수**

## 4. 진단
**SLE 분류 기준**

분류 기준은 임상 진단을 보조하며, 다른 원인과 장기 소견을 함께 판단한다.

- **1997 ACR**: 11항목 중 ≥4개
- **2012 SLICC**: 다음 중 하나
  - 임상 ≥1개·면역 ≥1개를 포함해 총 ≥4개
  - 생검으로 확인된 루푸스신염 + ANA 또는 anti-dsDNA 양성
- **SLICC 항목**
  - 임상: 급성/만성 피부 루푸스, 구강/비강 궤양, 비흉터성 탈모, ≥2개 관절 침범, 장막염, 신장·신경계 침범, 용혈성 빈혈·백혈구감소·혈소판감소
  - 면역: ANA, anti-dsDNA, anti-Sm, aPL, 보체 감소, 직접 Coombs 양성(용혈성 빈혈이 없는 경우)
- **2019 EULAR/ACR**: **ANA ≥1:80이 한 번 이상 확인**되어야 진입
  - **임상 항목 ≥1개 + 총점 ≥10점**
  - 영역별 최고 점수 하나만 합산, 각 소견이 동시에 나타날 필요는 없음
  - 더 가능성 높은 다른 원인이 있으면 해당 항목 제외

| 영역 | 소견과 점수 |
| --- | --- |
| 전신 | 발열 >38.3°C: 2 |
| 혈액 | 백혈구감소: 3 / 혈소판감소: 4 / 자가면역용혈: 4 |
| 신경정신 | 섬망: 2 / 정신병: 3 / 발작: 5 |
| 피부·점막 | 비흉터성 탈모: 2 / 구강궤양: 2 / 아급성 피부·원판상 루푸스: 4 / 급성 피부루푸스: 6 |
| 장막 | 삼출: 5 / 급성 심막염: 6 |
| 관절 | 관절 침범: 6 |
| 신장 | 단백뇨 >0.5 g/day: 4 / 생검 Class II·V: 8 / Class III·IV: 10 |
| aPL | 항인지질항체: 2 |
| 보체 | C3 또는 C4 저하: 3 / 둘 다 저하: 4 |
| SLE 특이항체 | Anti-Sm 또는 anti-dsDNA: 6 |

**APS·약물 유발 루푸스 감별**

- **고전 APS 분류(Sydney 2006)**: 임상 기준 ≥1개 + 지속적 검사실 기준 ≥1개, 다른 원인 평가
  - 객관적으로 확인된 동맥·정맥·소혈관 혈전증 ≥1회
  - 또는 아래 산과 기준 중 하나
    - 형태가 정상인 태아의 원인 불명 사망 **≥10주, ≥1회**
    - 중증 전자간증/자간증 또는 태반기능부전으로 정상 형태 신생아의 **<34주 조산 ≥1회**
    - 다른 해부·호르몬·염색체 원인 배제 후 **<10주 연속 자연유산 ≥3회**
  - 연구 분류 기준을 임상 진단·치료 결정과 동일하게 적용하지 않음
- **약물 유발 루푸스**: 원인약 중단 후 대체로 임상 호전, ANA는 **6–12개월** 양성 지속 가능

## 5. 치료
**기본 치료·강화 기준**

- **HCQ**: 금기가 없으면 지속 사용, 실제체중 기준 목표 **5 mg/kg/day**를 중심으로 망막·신장 위험과 질환 조절에 따라 조정
  - 시작 시 기저 안과 평가, 사용 중 원칙적으로 매년 OCT·FAF 감시
  - 유의한 위험인자가 없으면 첫 5년간 연례 감시를 유예할 수 있음(AAO 2025 개정); 일률적 6개월 간격 대신 위험도에 따라 결정
- **스테로이드**: 활성도·장기 침범에 맞춰 투여, 유지 prednisone **≤5 mg/day**, 가능하면 중단
- **치료 강화**: HCQ·국소 치료로 조절되지 않거나 스테로이드를 위 수준으로 감량하지 못하면 장기별 면역억제제·생물학제 추가
  - MMF·cyclophosphamide 등 조정; 신장·신경계 침범은 해당 전문과 협진
- **생활·예방**: 자외선 차단, 금연, 골건강, 예방접종

**약물별 주의**

- **NSAID**: 근골격 증상·경한 장막염·발열에 고려
  - 신혈류 감소·부종·단백뇨는 신염 악화와, 두통·어지럼·우울은 CNS flare와 감별
- **Cyclophosphamide**: 골수억제·생식선 독성·출혈성 방광염 설명
  - CBC·소변/혈뇨 감시, 충분한 수분과 필요 시 mesna
- **Azathioprine**: 위장관 증상, 골수억제, 과민반응성 간독성 감시

**aPL 양성의 혈전 예방**

- 지속성·고역가·다중 양성과 혈전/산과 병력에 따라 예방·항응고 필요성 판단
- 무증상 aPL 양성: 고위험 항체 프로파일·출혈 위험에 따라 aspirin 검토
- 모든 항체 양성 환자에게 일률적으로 항응고하지 않음

## 6. 예후 및 합병증
- 경과: 만성 재발성.
- 합병증: 루푸스 신염(Class IV 예후 불량), 감염, 심혈관 질환, 혈전증, 반복적 유산.
