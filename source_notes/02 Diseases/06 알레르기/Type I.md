# Type I

## 공통 임상 접근
- Type I 과민반응은 감작 후 재노출에 따른 즉시형 증상으로, 노출 시점과 피부·호흡기·순환기·위장관 침범을 구조적으로 확인한다.
- 유발 인자는 음식, 약물, 곤충독, 운동·온도·압박 같은 물리 자극까지 넓게 확인한다.
- 알레르기 비염·두드러기처럼 국소 증상인지, 여러 장기를 침범하는 전신 반응인지를 먼저 구분한다.

## 먼저 배제할 상황
- 기도 증상, 호흡곤란, 저혈압·실신 또는 지속적인 위장관 증상이 동반되면 아나필락시스로 우선 평가한다.

## 하위 질환 감별 포인트
| 질환군 | 구분에 특히 유용한 단서 | 다음 확인 |
|---|---|---|
| 아나필락시스·운동 유발 아나필락시스 | 급성 다장기 침범과 특정 노출·운동의 시간 관계 | 중증도와 유발 인자 |
| 두드러기·물리적 두드러기 | 일과성 팽진 및 특정 물리 자극 | 유발 자극과 지속 시간 |
| 유전성·후천성 혈관부종 | 반복적 깊은 부종, 두드러기 동반 여부 | 가족력·약물력·보체 평가 |
| 알레르기 비염 | 계절성 또는 지속적 비강·안구 증상 | 노출 양상과 동반 천식 |
| 음식·약물 알레르기 | 재현 가능한 섭취·투여 후 반응 | 정확한 노출 이력과 대체 원인 |
