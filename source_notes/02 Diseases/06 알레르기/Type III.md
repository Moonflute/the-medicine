# Type III

## 개요
- Type III는 알레르기 분과에서 함께 검토하는 하위 질환군입니다.
- 대표 질환: [[연쇄상구균 감염 후 사구체신염 (PSGN) (Post-Streptococcal Glomerulonephritis (PSGN))]], [[전신 홍반 루푸스 (SLE) (Systemic Lupus Erythematosus (SLE))]], [[혈관염 (Vasculitis)]], [[혈청병 (Serum Sickness)]]
- 세부 감별, 검사, 치료는 각 질환 문서에서 확인합니다.
