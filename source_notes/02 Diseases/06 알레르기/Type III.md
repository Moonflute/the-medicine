# Type III

## 면역복합체 침착의 판단

III형 반응은 항원·항체 복합체의 조직 침착과 보체 활성화가 중심이다. 노출과의 시간 관계, C3·C4, 피부·관절·신장 등 침범을 확인한다. 낮은 보체가 진단을 지지할 수 있지만 모든 면역복합체 질환에서 반드시 낮지는 않다.

| 범위 | 감별 포인트 |
| --- | --- |
| 혈청병 | 약물·이종 단백 노출 뒤 발열·발진·관절통; 실제 면역복합체 반응 |
| 혈청병 유사반응 | 임상 양상은 유사하지만 보체 소모·면역복합체 기전이 같지 않을 수 있음 |
| PSGN | 선행 연쇄상구균 감염 뒤 신염, 혈뇨·부종·고혈압과 보체 변화 |
| SLE 관련 | 다장기 자가면역 소견·항체와 장기 평가; 신염은 조직형에 따라 치료 |
| 혈관염 | 면역복합체성인지 ANCA 등 다른 기전인지 구별 |

## 장기 손상을 우선 평가

혈뇨·단백뇨·빠른 신기능 악화, 폐출혈, 신경 증상·허혈은 신속한 전문 평가가 필요하다. '혈관염' 전체가 III형은 아니며 ANCA 연관 소혈관염 등은 다른 기전과 검사·치료를 가진다.

PSGN은 고혈압·부종 관리와 남은 감염의 치료가 중요하다. 항생제가 이미 발생한 면역성 신염을 바로 되돌리는 치료는 아니다. SLE 신염은 소변·신기능을 추적하고 필요한 생검으로 유형·활성도를 확인해 KDIGO 2024 등 장기별 지침에 따라 치료한다. 혈청병은 원인 제거와 증상·중증도에 따른 치료를 시행하며 모든 III형 질환에 동일한 스테로이드 처방을 적용하지 않는다.
