# Type IV

## 공통 접근
- IV형 과민반응은 T세포 매개 지연반응입니다. 새 약물·접촉 항원 노출부터 발진까지의 시간, 점막 침범, 발열·호산구증가·장기 손상을 구분합니다.

## 먼저 구분할 위험 상황
- 점막 미란·표피 박리·전신 통증은 SJS/TEN을, 발열·얼굴 부종·호산구 증가·간/신장 침범은 DRESS를 우선 평가합니다.
