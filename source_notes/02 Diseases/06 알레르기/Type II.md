# Type II

## 공통 접근
- II형 과민반응은 세포 표면 또는 수용체에 대한 항체가 세포 파괴·기능 변화로 이어지는 틀입니다. 표적 장기와 항체가 파괴성인지 수용체 기능을 자극하는지 구분합니다.

## 먼저 구분할 위험 상황
- 급격한 빈혈·황달·혈색소뇨는 용혈을, 빈맥·체중 감소와 고열·의식 변화는 중증 갑상샘 과다 상태를 우선 평가합니다.
