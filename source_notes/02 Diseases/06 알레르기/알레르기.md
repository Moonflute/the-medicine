# 알레르기

## 과민반응의 기전과 임상 판단
- **병력**: 노출 물질·경로, 반응 시작 시간, 재노출, 침범 장기 확인
- **기전 해석**: 즉시형 증상이 모두 IgE 반응은 아님; 피부검사·특이 IgE 양성도 임상 반응 없이 감작만 의미할 수 있음
- **처치 판단**: 기전 분류는 원인·검사 선택에 활용, 응급 처치는 현재 중증도로 결정

| 기전 | 대표 양상 | 진단의 초점 |
| --- | --- | --- |
| Type I | IgE 매개 비만세포 활성화, 즉시형 음식·약물 반응 | 노출 후 재현성, 선택적 피부검사·특이 IgE |
| Type II | 세포·기저막 표적 항체, 세포 손상 또는 수용체 기능 변화 | 용혈·혈구 감소, 표적 장기 항체 |
| Type III | 면역복합체 관련 염증 | 보체·신장·피부·관절 침범 |
| Type IV | T세포 매개 지연 반응 | 지연 약물반응·접촉 피부염과 노출 시간 |

용혈·혈소판 감소나 지연 약물발진을 두드러기와 동일하게 치료하지 않는다. 급성 전신 반응에는 비IgE성 비만세포 활성화도 가능하다. 유전성 혈관부종 등 bradykinin 매개 부종은 Type I과 별개의 기전이다.

## 놓치면 위험한 양상

- **아나필락시스 의심**: 피부 발진이 없어도 기도·호흡·순환 장애에 따라 **대퇴 전외측 IM epinephrine 우선**
  - 검사를 기다리지 않으며 항히스타민제·스테로이드로 대체하지 않음
- **중증 약물반응 의심**: 피부 통증·점막 병변·박리·발열·간신장 손상은 SJS/TEN·DRESS 등 평가
  - 원인약 중단·전문 진료 연결, 일반적인 경구 재유발검사 적용 금지

## 검사와 재노출 관리

- **Tryptase**: 아나필락시스 급성기·기저치가 원인 평가에 도움; 정상이어도 배제 불가
- **약물 알레르기 표지 재평가**: 실제 반응·시간 관계 확인
  - 저위험 과거력: 전문적인 피부검사·유발검사 검토
  - 중증 지연 반응·고위험 즉시 반응: 별도 경로로 관리
- **예방 계획**: 위험도에 따라 회피, 응급 행동계획·자가주사 교육, 면역치료·예방 치료
- **기록**: 약명을 영구 금기로 남기기 전에 반응 유형·검증 여부를 구체적으로 기록
