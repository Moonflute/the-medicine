# 알레르기

## 공통 임상 접근
- 과민반응은 증상 발생 시간, 노출 경로, 재노출 여부, 장기 침범 양상을 함께 확인해 면역기전을 추정한다.
- 약물·음식·곤충독·수혈·감염·자가면역 질환 등 가능한 유발 인자와 이전 반응을 병력에서 구조적으로 확인한다.
- 면역기전 분류는 진단을 위한 틀이며, 실제 처치는 현재의 장기 침범과 중증도를 우선으로 결정한다.

## 먼저 배제할 상황
- 기도 증상, 호흡곤란, 저혈압, 지속적인 위장관 증상이 함께 나타나는 급성 반응은 아나필락시스 가능성을 먼저 평가한다.
- 광범위 점막 병변, 피부 통증·박리, 발열 또는 장기 침범이 있으면 중증 약물반응을 우선 배제한다.

## 하위 질환 감별 포인트
| 질환 | 구분에 특히 유용한 단서 | 다음 확인 |
|---|---|---|
| Type I | 노출 직후의 즉시 반응과 비만세포 매개 증상 | 유발 인자·아나필락시스 기준 |
| Type II | 세포 표면 또는 기저막 표적 항체와 연관 | 표적 장기, 용혈·세포손상 소견 |
| Type III | 면역복합체 침착과 다장기 염증 양상 | 보체, 신장·관절·피부 침범 |
| Type IV | 노출 후 지연되는 T세포 매개 염증 | 접촉·약물 노출과 피부·장기 양상 |
