# 흉수

## 검사 선택과 해석

- **초기 평가**: 병력·약물, 심부전/간경변/신질환, 암·결핵 위험과 흉부 초음파 종합
- **흉강천자**: 필요 시 초음파 유도
  - 의심 원인에 따라 단백·LDH·세포분획·배양·세포검사·pH·당·중성지방 선택
- **Light 기준**: 삼출액 분류의 출발점
  - 동시 채혈과 흉수에서 **다음 중 하나**면 삼출액. 흉수/혈청 단백 **>0.5**, 흉수/혈청 LDH **>0.6**, 흉수 LDH가 혈청 정상 상한의 **2/3 초과**
  - 이뇨제 사용 뒤 심부전 등 임상상이 여출액에 맞으면 혈청–흉수 알부민 차이 **>1.2 g/dL**가 위삼출액을 지지. 감염·악성 단서가 있으면 함께 평가
- **해석 주의**: 낮은 당은 감염·악성·결핵·류마티스성 흉막질환 등에서 가능; ADA·amylase·림프구 우세도 단독 확진 불가
- **심부전이 있어도 추가 평가**: 일측성 흉수·발열·흉막통·비전형 경과이면 감염·폐색전증·악성 확인

```flowchart
새로 확인된 흉수
> 초음파로 양·격벽 확인, 임상 원인과 안정성 평가
>> 전형적인 양측 울혈 + 위험 신호 없음 → 원인 치료 후 반응 확인
>> 원인 불명·일측·발열·흉막통·치료 불응 → 초음파 유도 천자
>>> Light 기준 모두 미충족 → 심부전·간경변·신질환 등 평가
>>> Light 기준 하나 이상 → 세포분획·pH·배양·세포검사를 원인에 맞게 해석
```

## 감별과 배액 판단

| 유형 | 단서 | 우선 판단 |
| --- | --- | --- |
| 부폐렴성·농흉 | 폐렴, 호중구 우세, 고름·격벽·낮은 pH | 항생제만으로 충분한지 또는 배액이 필요한지 |
| 결핵성 | 아급성 경과, 림프구 우세, 역학적 위험 | ADA를 보조적으로 사용하며 미생물·필요한 흉막 조직 검사로 확인 |
| 악성 | 재발성 삼출액, 흉막 결절·종양 병력 | 세포검사 음성으로 배제하지 않음. 필요하면 흉막 생검 |
| 암죽 | 흉관 손상·림프종·림프 흐름 장애 | 중성지방과 chylomicron 확인. 유백색 여부만으로 확정 불가 |
| 혈흉 | 외상·시술, 혈성 흉수 | 흉수 적혈구용적률이 말초혈액의 **≥50%**면 혈흉에 합당. 지연 채취 시 희석 가능 |

## BTS 2023의 중요한 기준

- **감염 의심·비농성 흉수**: pH 즉시 측정
  - **pH ≤7.2**: 안전하게 접근 가능한 양이면 흉관 배액
  - **7.2 < pH <7.4**: **LDH >900 IU/L**, 지속 발열·많은 흉수·낮은 당·CT 흉막 조영·초음파 격벽 등을 종합해 배액 고려
  - **pH ≥7.4**: 저위험 시사; 임상 악화 시 재평가
- **악성 흉수**: 증상·폐 재팽창·선호에 따라 유치 흉막 카테터 또는 pleurodesis
  - 비팽창폐: pleurodesis 성공 가능성 낮음
  - 무증상: 치료적 배액을 일률적으로 시행하지 않음
- **저산소증·패혈증·혈흉**: 원인 치료·안전한 배액 우선
