# 허혈성 심질환

## 공통 임상 접근
- 허혈성 흉통에서는 현재 증상이 급성 관상동맥증후군인지, 만성·안정적 허혈 양상인지부터 구분한다.
- 증상, 연속 심전도, 심근손상 표지자와 임상 위험도를 함께 해석하며, 비전형적 증상도 고위험군에서 과소평가하지 않는다.
- 죽상경화 위험요인과 기존 관상동맥질환은 모든 하위 질환의 사전확률을 바꾼다.

## 먼저 배제할 상황
- 지속·재발하는 흉통, 혈역학적 불안정, 새 허혈성 심전도 변화 또는 심근손상 표지자 상승은 급성 관상동맥증후군으로 즉시 평가한다.

## 하위 질환 감별 포인트
| 질환 | 구분에 특히 유용한 단서 | 다음 확인 |
|---|---|---|
| 불안정 협심증 | 새로 발생·악화·안정 시 흉통, 표지자 상승 없음 | 연속 심전도·표지자와 위험도 |
| NSTEMI | 허혈 증상과 심근손상 표지자 상승, ST 상승 없음 | 연속 심전도·표지자 추세 |
| STEMI | 지속 ST분절 상승 또는 동등한 급성 폐색 소견 | 즉시 재관류 경로 |
| 안정 협심증 | 예측 가능한 운동 유발 증상과 휴식 시 호전 | 임상 가능성과 비침습 평가 |
| 변이형 협심증 | 주로 안정 시 일시적 허혈 변화 | 발작 시 심전도와 유발 요인 |
| 우심실 경색 | 하벽 경색 맥락의 저혈압·우심실 침범 | 우측 흉부 유도와 혈역학 |
