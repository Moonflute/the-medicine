# 지방간

## 명칭과 원인의 구별

- **SLD**: 간 지방축적의 큰 범주
- **MASLD·MASH**: 대사 위험 동반 지방간과 그중 염증·간세포 손상 동반 형태
  - 과거 NAFLD·NASH에 대응하나 진단 정의가 완전히 같지는 않음
- **다른 원인**: 음주·대사 위험이 겹치는 MetALD, 알코올 관련 간질환 등 구분
- 기존 문서명·링크는 유지하며 임상 판단에는 새 명칭도 함께 사용

| 상태 | 평가의 중심 |
| --- | --- |
| 지방축적 | 영상 등으로 확인; 간효소 정상이라고 진행성 질환 배제 불가 |
| 지방간염 | 염증·간세포 손상과 섬유화; 지방량만으로 확진하지 않음 |
| 진행성 섬유화 | 간 관련 예후를 좌우; 비침습 평가·전문 진료 |
| 알코올 관련 | 실제 음주량·기간과 금단·영양 위험, 대사 요인 병존 |

## 섬유화 평가
- **고위험군(당뇨·비만 등)**: FIB-4로 1차 평가, 필요 시 탄성도·ELF 등 추가
- **2차 평가 기준**: 일반 성인 FIB-4 **≥1.3**에서 고려
  - **65세 초과**는 저위험 구분 문턱을 **2.0**으로 조정하는 접근
- **해석 주의**: 나이 영향이 커 젊은 성인·고령·급성 간손상에서 달리 해석. 한 수치만으로 간경변 확진 불가

## 치료의 변화
- **기본 관리**: 체중 감량·운동·식사 조절과 당뇨·심혈관 위험 관리
- **음주**: 실제 양을 평가하며 진행성 섬유화에서는 금주 중요
- **표적약**
  - Resmetirom: 허가된 지역의 비간경변성 MASH·유의한 섬유화에서 검토(EASL 2024)
  - Semaglutide: F2–F3 MASH의 선택·감시 기준 확인(AASLD 2025 개정)
  - 국내 허가·적응증을 확인하며 모든 단순 지방간·간경변에 확대하지 않음

간경변·진행성 질환은 문맥고혈압과 간암 감시 등 별도 관리가 필요하다.
