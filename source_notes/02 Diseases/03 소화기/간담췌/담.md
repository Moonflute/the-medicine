# 담

## 공통 임상 접근
- 담도 질환은 통증의 위치·시간 경과, 발열, 황달과 간기능 검사에서의 담즙정체 패턴을 함께 해석한다.
- 초음파를 출발점으로 하되, 폐쇄·합병증·종양이 의심되면 추가 단면영상과 내시경적 평가를 임상 맥락에 맞춰 사용한다.
- 결석성 질환, 감염·염증, 수술·시술 후 합병증, 종양성 폐쇄를 분리해 접근한다.

## 먼저 배제할 상황
- 발열·황달·우상복부 통증, 저혈압·의식 변화 또는 패혈증 징후는 급성 쓸개관염과 패혈증을 우선 평가한다.

## 하위 질환 감별 포인트
| 질환군 | 구분에 특히 유용한 단서 | 다음 확인 |
|---|---|---|
| 쓸개돌·쓸개관돌 | 산통 또는 폐쇄성 검사 이상 | 폐쇄·췌장염·감염 동반 여부 |
| 급성·만성 쓸개염 | 지속적 우상복부 통증·염증 소견 또는 반복 증상 | 초음파와 합병증 |
| 쓸개관염 | 감염 징후와 담도 폐쇄 | 중증도·배액 필요성 |
| 담즙 누출 | 수술·시술 후 통증·발열·배액 변화 | 영상과 누출 위치 |
| 담낭·담관 종양 | 진행성 황달·체중 감소·종괴 또는 협착 | 영상 기반 병기·조직 계획 |
| 선천성·용종성 병변 | 연령·선천성 병력 또는 우연 발견 | 영상 위험도와 추적 계획 |
