# 담도계 질환

## 폐쇄·염증·감염을 구분하는 접근

- **초기 평가**: 통증 지속 시간, 발열·황달, 백혈구/CRP와 bilirubin·ALP/GGT 확인. 초음파로 담낭 결석·벽·주변 액체와 담관 확장 평가
- **통증·염증의 구분**
  - 담도 산통: 일시적 폐쇄에 따른 통증
  - 급성 담낭염: 지속 통증, 국소 압통과 염증 소견
  - 황달·담즙정체가 두드러지면 총담관 결석·협착 평가
- **급성 담관염(TG18)**: 전신 염증 + 담즙정체 + 영상상 담관 병변이 확진 틀
  - Charcot 3징후가 모두 없어도 배제할 수 없음
  - 저혈압·의식 변화·장기부전이 있으면 중증 감염으로 접근

## 검사와 처치의 분기

- **총담관 결석 중간 위험**: MRCP/EUS 또는 수술 중 담관 평가. 단순 진단 목적의 ERCP는 피함
- **ERCP 직접 고려 고위험(ASGE 2019)**: 다음 중 하나
  - 영상에서 담관 결석 확인
  - 상행성 담관염
  - **bilirubin >4 mg/dL + 담관 확장** 동시 충족
- **담관염**: 항생제·소생과 담도 배액을 함께 계획
  - 일반적으로 **48시간 이내** 내시경 배액 제안(ASGE 2021)
  - 쇼크·장기부전 시 안정화와 긴급 배액을 병행해 더 빠른 원인 교정 고려
- **급성 결석성 담낭염**: 수술 가능하면 조기 복강경 담낭절제술
  - 가능한 한 빠르게, **입원 7일 이내이면서 증상 발생 10일 이내** 시행(WSES 2020)
  - 고위험과 수술 불가능을 구분하여 배액술 선택
- **수술 중 안전 확보**: critical view of safety가 기본
  - 일상적 IOC는 조건부 권고로 모든 상황에서 의무 시행을 뜻하지 않음(SAGES 2025)
  - 해부학이 불명확하거나 손상이 의심되면 영상과 안전한 대체 수술 전략 고려

## 감별 포인트

| 질환 | 구분할 단서 | 처치의 중심 |
| --- | --- | --- |
| 담석 산통 | 간헐적 통증, 뚜렷한 감염·장기부전 없음 | 증상성 결석의 수술 필요성 |
| 급성 담낭염 | 지속 통증·Murphy 징후·담낭 염증 | 조기 수술 또는 수술 불가 시 배액 |
| 총담관 결석 | 담즙정체·담관 확장 또는 결석 | 위험도에 따른 MRCP/EUS·결석 제거 |
| 담관염 | 감염과 담도 폐쇄 | 항생제와 배액 |
| 담즙 누출 | 수술 후 통증·발열·담즙성 배액 | 누출 위치, 액체저류 배액·담도 감압 |
| 종양성 폐쇄 | 진행성 황달·체중 감소·협착/종괴 | 병기와 절제 가능성의 다학제 평가 |

담낭 용종은 크기만으로 모든 환자에 같은 절제 기준을 적용하지 않는다. 성장, 형태, PSC 등 위험과 적용 지침을 함께 확인한다.
