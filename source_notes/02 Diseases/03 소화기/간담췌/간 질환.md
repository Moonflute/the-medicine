# 간 질환

## 공통 임상 접근
- 간 질환은 간세포 손상, 담즙정체, 합성 기능 저하, 문맥고혈압과 국소 병변을 구분해 접근한다.
- 증상·약물·알코올·대사 위험·바이러스 노출력과 간기능 검사 패턴, 영상, 필요 시 혈청학을 함께 해석한다.
- 복수, 황달, 출혈, 의식 변화는 질환명보다 간기능 저하와 합병증의 중증도를 먼저 평가하게 하는 단서다.

## 먼저 배제할 상황
- 급성 의식 변화·응고 이상을 동반한 간기능 저하, 토혈·흑색변, 발열을 동반한 복수, 급격한 황달·패혈증 징후는 긴급 평가한다.

## 하위 질환 감별 포인트
| 질환군 | 구분에 특히 유용한 단서 | 다음 확인 |
|---|---|---|
| 급성·만성 간염 | 노출력, 시간 경과와 간세포 손상 패턴 | 바이러스·자가면역·약물 평가 |
| 간경변·문맥고혈압 합병증 | 복수, 정맥류 출혈, 뇌병증 | 합성 기능과 감염·출혈 여부 |
| 지방간·알코올 관련 간질환 | 대사 위험 또는 음주력 | 섬유화·동반 질환 평가 |
| 국소 간 병변·간암 | 영상의 국소 병변과 기저 간질환 | 다상 영상과 종양 평가 |
| 혈관·침윤·감염성 간질환 | 통증·발열·혈관 위험 또는 면역저하 | 영상과 혈액·혈청학 검사 |

## 포함 질환
- 개별 간 질환의 진단·치료와 세부 감별은 하위 문서에서 확인한다.
