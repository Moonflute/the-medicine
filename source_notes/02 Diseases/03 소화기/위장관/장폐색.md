# 장폐색

## 폐색 위치와 허혈 여부

- 복통·구토·팽만·가스 및 대변 배출 감소가 있으면 기계적 폐색과 장마비를 구분한다.
- 수술력은 유착, 탈장은 감돈, 체중 감소·배변 변화는 대장 종양 가능성을 높인다.
- 부분 폐색에서는 변이나 가스가 일부 나올 수 있으므로 배출이 있다는 이유만으로 배제하지 않는다.

조영 CT는 폐색 지점·원인·닫힌 고리·허혈 소견을 평가하는 데 유용하다. 지속적인 심한 통증, 복막자극, 쇼크, 장벽 조영 감소나 천공은 즉각적인 외과 평가가 필요하다. 정상 젖산만으로 초기 장허혈을 배제할 수 없다.

| 질환 | 구분 단서 | 처치 판단 |
| --- | --- | --- |
| 유착성 소장 폐색 | 복부 수술력, 소장 확장과 전환점 | 교액·허혈·복막염 없을 때 비수술 치료 고려 |
| 탈장 관련 폐색 | 통증성 비환원성 탈장 | 감돈·교액 여부와 긴급 수술 |
| 대장 폐색 | 현저한 팽만, 종양·협착 | 원인·천공 위험·병기에 맞춘 감압·수술 |
| 구불창자 꼬임 | 현저한 팽만과 꼬임 영상 | 허혈·천공 여부에 따라 내시경 또는 수술 |

```flowchart
장폐색 의심 환자의 초기 분기
> 금식·수액·전해질 교정, 복부 진찰과 조영 CT
>> 복막염·교액·허혈·천공·폐쇄고리 → 항균제와 긴급 수술 평가
>> 합병증 없는 유착성 소장폐색 → 감압과 반복 진찰, 수용성 조영제 통과 평가
>>> 24시간에 대장으로 미도달하거나 악화 → 수술 필요성 재평가
>> 대장 폐색 → 종양·염전 등 원인별 감압/수술
>> 대장 확장이나 기계적 막힘 없음 → 약물·전해질, 급성 대장 가성폐쇄 평가
```

## 비수술 치료의 적용 범위
- **적용 대상**: 허혈·교액·복막염 없는 유착성 소장폐색 (Bologna)
- **처치**: 금식, 필요 시 위장관 감압, 수액·전해질 교정, 반복 평가
  - 수용성 조영제의 대장 도달 여부는 호전 가능성 판단에 도움
  - 소변량·흡인 위험·영양과 반복 복부 진찰 확인
- **기간**: 대개 **72시간**까지 시도 고려, 악화하면 기다리지 않음
- **적용 예외**: 모든 대장폐색·감돈 탈장·폐쇄고리에 확대 적용하지 않음

## 구불창자 꼬임

- **허혈·천공 없음**: 긴급 내시경 정복·감압, 점막 생존성 확인 (WSES 2023)
- **정복 실패·괴사·천공**: 수술
- **정복 성공 후**: 재발 위험이 높아 수술 적합 환자는 가능한 한 **같은 입원 중 구불창자 절제** 제안. 감압 후 귀가만으로 치료 완료하지 않음
