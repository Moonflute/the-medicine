# 위장관 출혈

## 위치보다 소생이 우선

기도·의식·혈역학, 지속 출혈, 항혈전제와 간질환을 먼저 평가한다. 초기 Hb가 정상이라고 급성 대량출혈을 배제하지 않는다. 수혈은 안정 환자의 제한적 전략을 기본으로 하되 진행 출혈·쇼크·심근허혈을 별도로 반영한다.

| 양상 | 위치 판단 | 다음 단계 |
| --- | --- | --- |
| 토혈·커피색 구토·흑색변 | 상부 가능성 | 소생 후 상부 내시경 |
| 불안정한 대량 혈변 | 상부도 가능 | 상부 원인을 놓치지 않고 지속 출혈 위치 확인 |
| 지속·혈역학적으로 의미 있는 혈변 | 하부 활동 출혈 | CTA로 위치 확인, 양성이면 신속 색전술 연계 |
| 안정된 간헐 혈변 | 대장·직장 | 적절한 장정결 후 대장내시경 |

## 내시경 시점과 재출혈

- **비정맥류 상부 출혈**: 소생 후 통상 **24시간 이내** 내시경
  - 궤양 지혈 후 고용량 PPI, 재출혈 시 반복 내시경 우선 검토. 실패하면 색전술·수술
- **하부 출혈**: 대부분 비응급 입원 내시경, 모든 환자에게 **24시간 이내** 긴급 검사를 강요하지 않음 (ACG 2023)
  - 진행하는 의미 있는 출혈은 CTA 활용. 위치 확인 없이 맹목적 수술로 진행하지 않음

### 상부·대장 내시경에서 출혈원을 못 찾았을 때

```flowchart
소장 출혈 의심 시 검사 선택
> 상·하부 내시경 결과와 장정결·관찰 범위 확인
>> 지속 대량 출혈·불안정 → 소생과 CTA, 혈관조영·색전팀 연계
>> 안정적이고 소장 출혈 의심 → 소장 캡슐내시경
>>> 현성 출혈 → 가능하면 출혈 후 48시간 이내
>>> 협착·폐색 위험 → 소장 CT/MR 또는 통과성 확인 뒤 캡슐 여부 결정
>>> 병소 확인 → 기구보조 소장내시경으로 확인·지혈/생검
```

- 첫 검사가 불충분하거나 상·하부 병소가 강하게 의심되면 해당 내시경을 다시 시행. 질이 충분한 검사를 캡슐 전 일률적으로 반복할 필요는 없음.
- 캡슐내시경 음성이고 출혈이 멎으면 Hb·철결핍 추적. 출혈·수혈 요구가 지속되면 소장 영상 또는 내시경 재평가.

## 정맥류와 약물

- **정맥류 의심**: 간경변 배경 토혈에서 혈관작용제·항생제·내시경 치료 병행
  - 소생 후 **12시간 이내** 내시경, 위치에 맞는 지혈 (Baveno VIII 2026)
- **식도정맥류/GOV1의 선제 TIPS**: 다음 중 **하나**에 해당하면 **72시간 이내, 이상적으로 24시간 미만** 경로로 평가
  - Child-Pugh **C 10–13점**
  - Child-Pugh **B >7점 + 초기 내시경 활동성 출혈**
  - 출혈 당시 **HVPG ≥20 mmHg**
- **TIPS 적용 예외**: GOV2·IGV1에 위 기준을 그대로 적용하지 않고 해부·출혈 위험별 별도 경로
- **항혈전제**: 심혈관 이차예방 약제·항응고제 중단/재개는 출혈·혈전 위험을 함께 판단, 무기한 중단하지 않음
- **FFP**: INR 정상화만을 위한 일률적 수혈은 권고하지 않음
