## 1. 개요
- 역학: 남성에서 약간 더 흔하며, 95%는 선암(adenocarcinoma). 40~50세 이후 발병률 급증
- 위험요인: 고령, 염증성 장질환(궤양성 대장염, 크론병), 가족력(FAP, HNPCC 등), 저섬유질/고지방/고단백 식단, 비만, 흡연, 음주
- 전이 경로: 직접 침윤, 림프성 전이, 혈행성 전이(간, 폐, 뼈), 신경주위 침윤
- 가족성 대장암
  - 가족성 선종성 용종증(FAP): 5번 염색체 APC 유전자 돌연변이(상염색체 우성), 전 대장에 수천 개의 용종 발생, 40세 이전 발병률 매우 높음, 치료는 전결장절제술
  - 유전성 비용종성 대장암(HNPCC, Lynch syndrome): DNA mismatch repair 유전자(hMSH2, hMLH1 등) 손상, MSI 발생, 근위부 결장에 호발, 난소·자궁·위암 동반 가능

## 2. 임상 양상
- 일반적 증상: 혈변, 배변 습관의 변화, 복부 종괴, 체중 감소, 피로, 빈혈
- 위치별 특징
  - 근위부(맹장, 상행결장): 빈혈, 대변 잠혈, 피로(대변이 액체 상태라 폐쇄 증상이 늦게 나타남)
  - 원위부(하행결장, S상결장, 직장): 변비, 복통, 혈변, 잔변감, 가는 변(대변이 단단해져 폐쇄 증상 빈번)
- 신체검사: 직장수지검사(DRE)로 종괴 확인, 직장 선반(rectal shelf, 복막 전이 시 직장-방광/자궁와에 만져지는 종괴) 확인

## 3. 검사
- 선별검사(평균 위험군): 45세부터 75세까지 시행. 기대여명이 10년 이상인 경우 권고.
- 선별검사 옵션:
  - 대장내시경: 10년 주기(표준).
  - 분변 기반 검사: 고감도 분변면역화학검사(FIT), 고감도 구아이아크 기반 분변잠혈검사(매년), 차세대 다중표적 분변 DNA 검사(mt-sDNA), 다중표적 분변 RNA 검사(mt-sRNA)(3년 주기).
  - 혈액 기반 검사: 선호되는 선별검사를 거부하거나 완료하지 못하는 경우에만 고려.
- 주의사항: 비대장내시경 선별검사에서 양성 결과가 나온 경우, 6개월 이내에 대장내시경을 통한 확진 및 후속 조치가 필수적임.
- 진단 및 병기 결정: 대장내시경(조직검사), 복부/흉부/골반 CT, MRI, PET, 내시경초음파(EUS).
- 바이오마커: CEA(수술 전후 및 재발 추적 관찰용, 선별검사 용도 아님).

## 4. 진단
- 대장 용종 분류
- 비종양성: 과증식성 용종, 염증성 용종
- 종양성: 선종(관상, 관상융모, 융모샘종), 암종
- 용종 치료 및 기준
- 내시경적 절제(EMR/ESD): 조직학적 확인 전 우선 절제
- 추가 수술 적응증: 점막하층 1/3 이상 침범, 저분화도(grade 3 이상), 림프혈관 침윤 존재 시

**TNM 병기 기준(AJCC 8판)**:

| 구분 | 기준 |
| --- | --- |
| Tis / T1 / T2 | 점막내암 / 점막하층 / 고유근층 침윤 |
| T3 / T4a / T4b | 고유근층 밖 주위조직 / 장측복막 관통 / 인접 장기·구조 직접 침범 |
| N1a / N1b / N1c | 림프절 1개 / 2–3개 / 림프절 전이 없이 주위조직 종양침착(tumor deposit) |
| N2a / N2b | 국소 림프절 4–6개 / ≥7개 전이 |
| M1a / M1b / M1c | 복막 전이 없이 원격 장기·부위 1곳 / ≥2곳 / 복막 전이(다른 전이 유무 무관) |

| 병기 | 조합 |
| --- | --- |
| 0 / I | Tis N0 M0 / T1–2 N0 M0 |
| IIA / IIB / IIC | T3 / T4a / T4b, 모두 N0 M0 |
| III | N1–2 또는 N1c, M0 |
| IVA / IVB / IVC | M1a / M1b / M1c |

**III기 보조항암의 위험 구분**은 T1–3N1과 T4 또는 N2를 나누어 본다. 이는 IIIA/B/C 세부 병기와 동일한 분류가 아니다. 직장암은 골반 MRI로 중직장근막과의 거리·EMVI·외측 림프절을 추가 평가하고, 치료 전 cTNM과 선행치료 후 ypTNM을 구분한다.

## 5. 치료
- 결장암: 수술적 절제(광범위 절제 및 림프절 곽청).
  3기(림프절 양성) 및 고위험 2기에서 보조 항암화학요법 시행
- 직장암

**직장암 국소 병기와 수술**:
- 골반 MRI에서 종양 위치, 절제연 위협, 괄약근·거근 침윤, 벽외혈관 침범과 림프절을 평가한다.
- 항문연 거리 하나만으로 수술 방법을 정하지 않고 음성 절제연과 괄약근 기능을 고려한다.

**국소 진행 직장암**:
- 하부 또는 MRI상 고위험이면 방사선과 전신 항암치료를 수술 전에 계획하는 총선행치료(TNT)를 고려한다.
- 일부 저위험은 선행 방사선 생략을 검토할 수 있고, dMMR/MSI-H는 면역치료 가능성을 별도로 평가한다.

- 전이성 대장암(Stage IV): 다학제 진료 필수.
  항암화학요법(5-FU, capecitabine, irinotecan, oxaliplatin 등) 및 표적치료제(bevacizumab, cetuximab 등) 사용.
  간 전이 시 절제 가능성 평가

**악성 대장폐색**:
- 천공 없는 안정적 좌측 폐쇄는 내시경 스텐트를 수술 가교 또는 완화 목적으로 선별 사용할 수 있다.
- 응급 절제·장루와 비교해 수술 목표·천공 위험·기관 시술 경험을 고려한다.

**2기 결장암 보조항암 기준**:
- T4는 보조치료를 적극 권고하며, 검사 림프절 <12개, 림프혈관/신경 침범, 장폐쇄·천공, 저분화 또는 고등급 tumor budding 등은 추가 위험요인이다.
- 위험요인 없는 2기에 일상적으로 보조항암을 시행하지 않는다.
- dMMR/MSI-H 2기에서는 fluoropyrimidine 단독을 통상 권하지 않으며, T4 등으로 치료가 필요하면 oxaliplatin 병합의 이득·독성을 논의한다.

**전이성 약제 분기**:
- MSI-H/dMMR이면 면역치료를 우선 평가한다.
- MSS/pMMR에서는 RAS/BRAF 등 분자형과 원발 위치를 반영하며, cetuximab/panitumumab은 RAS wild-type 여부를 확인한다.

간·폐 전이가 있어도 완전 절제/국소치료 가능성이 있으면 전신치료만으로 고정하지 않고 다학제에서 재평가한다.

## 6. 예후 및 합병증
- 예후: 병기에 따라 상이(1기 5년 생존율 약 90%, 원격 전이 시 13~18%)
- 합병증: 장폐색, 천공, 출혈, 전이
- 추적 관찰: 수술 후 1년 내 대장내시경, 이후 3년, 5년 주기.
  CEA 수치 및 영상 검사(CT/MRI)를 통해 재발 확인
