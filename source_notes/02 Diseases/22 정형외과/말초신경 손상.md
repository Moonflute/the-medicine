# 말초신경 손상

## 운동과 감각을 각각 기록

손상·정복·고정·수술 전후를 비교할 수 있도록 특정 근육의 운동과 감각 분포, 맥박·관류를 기록한다. 통증 때문에 움직이지 못하는 것과 신경 마비를 구분하고 관절·건·혈관 손상도 확인한다.

## 신경별 위치 추정

| 신경 | 대표 운동 소견 | 감각·추가 단서 |
| --- | --- | --- |
| 요골신경 | 손목·손가락 신전 저하 | 손등 첫째 물갈퀴 감각; 뒤뼈사이신경은 주로 운동 |
| 정중신경 | 엄지 맞섬 저하, 병변 위치에 따라 굴곡 약화 | 검지 끝 감각; 앞뼈사이신경은 감각 없이 OK 표시 약화 |
| 척골신경 | 손가락 벌림·모음 약화 | 새끼손가락 감각, Froment 징후 |
| 액와신경 | 어깨 벌림 약화 | 어깨 바깥 감각, 탈구 연관 |
| 총비골신경 | 발등 굽힘·가쪽 번짐 약화 | 발등 감각, 비골두 주변 손상 |
| 대퇴신경·상둔신경 | 각각 무릎 폄·엉덩관절 벌림 약화 | 대퇴신경은 앞넓적다리·안쪽 종아리 감각, 상둔신경은 주로 운동 |

감각 영역은 겹칠 수 있다. 신경근·신경얼기·여러 신경 손상과 구분하고 검사 하나로 손상 위치를 확정하지 않는다.

## 관찰과 긴급 의뢰를 구분

BOASt 2021은 신경 손상 동반 탈구의 신속한 정복과 반복 평가를 강조한다. 열린 상처·관통 손상과 신경 결손, 수술 중 확인한 손상, 수술·고정 후 새로 생기거나 진행하는 결손은 신속히 전문팀과 협의한다. 압박 붕대·깁스 문제와 구획증후군·혈관 손상을 확인한다. 모두 수개월 관찰부터 하는 것은 아니다.

## 검사와 회복 관리

신경전도·근전도는 위치·손상 정도·경과 평가에 유용하지만 급성 초기 검사가 정상 또는 불명확할 수 있다. 영상·전기생리 검사 시점은 임상 질문에 맞추고 필요한 수술 의뢰를 지연하지 않는다. 압박 해소, 관절 가동·부목·통증·감각 보호와 재활을 시행한다. Neurapraxia와 축삭 손상·완전 단절은 회복 전망·치료가 다르며 연속 진찰로 판단한다.
