# 소아 유전질환

## 표현형에서 검사 방향을 정하기

선천기형·발달지연·퇴행·성장 이상·가족력이 단서다. 임신·출생력, 3대 가족력, 성장 곡선과 기관별 이상을 정리한다. 이미 얻었던 기능을 잃는 퇴행은 단순한 발달 속도 차이로 설명하지 않는다.

## 특징을 함께 비교

| 질환 | 특히 유용한 단서 | 확인 방향 |
| --- | --- | --- |
| 레트 증후군 | 초기 발달 뒤 손 기능·언어 퇴행, 손 상동행동 | 임상 기준과 MECP2 검사 |
| 취약 X 증후군 | 발달·행동 문제, X 연관 가족력 | FMR1 CGG 반복 확장 검사 |
| 윌리엄스 증후군 | 대동맥판상부 협착, 특징적 발달 양상·고칼슘혈증 | 7q11.23 결실 검사 |
| 파타우 증후군 | 다지증·구순구개열·중추신경 및 심장 기형 | 13번 염색체 이상 확인 |
| 폼페병 | 영아 근긴장 저하·심근병증, 후기형은 근육·호흡 침범 | GAA 효소·유전자 검사 |
| 테이-삭스병 | 진행성 신경 퇴행·과도한 놀람 반응 | Hexosaminidase A 및 HEXA 검사 |
| 헐러 증후군 | 거친 얼굴, 골격·관절 이상, 각막 혼탁 | α-L-iduronidase 및 IDUA 검사 |
| 레쉬-니한 증후군 | 고요산혈증, 이상운동, 자해 행동 | HPRT1 관련 검사 |
| 하트넙병 | 광과민성 발진, 간헐적 신경 증상 | 중성 아미노산뇨와 SLC6A19 |
| 원발 섬모 운동 이상증 | 신생아 호흡 문제, 만성 습성 기침·중이염, 내장 역위 | 전문 검사 조합; 역위가 없어도 가능 |

## 검사 선택의 변화

ACMG 2021은 선천기형·발달지연·지적장애 아동에서 엑솜/유전체 검사를 1차 또는 2차로 고려하도록 권고한다. 그러나 일반 엑솜 검사가 모든 이상을 검출하지는 않는다. 반복 확장·염색체 구조 이상·효소 결핍이 의심되면 해당 검사를 선택하고 임상유전 전문팀과 해석한다. 의미 불명 변이만으로 확진하지 않는다.

## 치료와 상담

급성 대사 악화·저혈당·심폐 이상은 유전자 결과를 기다리지 않고 치료한다. 폼페병처럼 조기 질환 특이 치료가 중요한 경우 신속히 의뢰한다. 치료 가능성, 기관별 추적, 가족 검사·재발 위험과 발달 지원을 함께 계획한다.
