분과 : [[부인과]]

## 1. 개요
- **정의**: 자궁 내막에서 발생하는 악성 종양으로, 여성 생식기 암 중 가장 흔함.
- **원인**: 프로게스테론의 길항 작용이 없는 에스트로겐(Unopposed estrogen)에 대한 장기 노출 (비만, 당뇨, 호르몬 치료, 무배란 등).

- **기전**: 에스트로겐 자극 관련 증식증(EIN 등)·PTEN 등 변이를 거쳐 진행 가능; 분자 아형으로도 분류

## 2. 임상 양상 (Clinical Features)
* **CC**: 비정상 질 출혈 (폐경 후 출혈이 가장 흔함), 골반통, 자궁 비대.
* **P/E**: 초기에는 특이 소견이 없을 수 있음.

## 3. 검사 (Lab & Imaging)
- **진단**: 경질 초음파 후 자궁내막 생검(Endometrial biopsy) 시행.
- **병기 설정**: 수술적 병기 설정이 원칙 (자궁절제술, 양측 난소난관절제술, 림프절 절제술 등).
- **영상**: 전이 평가를 위해 CT, MRI 등 시행.

## 4. 진단 (Diagnosis)
- 선별 검사는 일반 인구에서 시행하지 않음.
- 조직학적 확진이 필수적이며, 수술 후 병리 결과를 통해 최종 병기 결정.

**FIGO 2023 병기**:

| 병기 | 구분 기준 |
| --- | --- |
| IA1 | 비공격적 조직형이 용종·자궁내막에 국한 |
| IA2 / IB | 비공격적 조직형, 근층 침윤 <50% / ≥50%, LVSI 없거나 국소적 |
| IA3 | 아래 조건을 모두 만족하는 저등급 자궁내막양암의 자궁·난소 동시 침범 |
| IC | 공격적 조직형이 용종·내막에만 국한, 근층 침윤 없음 |
| IIA / IIB | 비공격적 조직형의 자궁경부 기질 침윤 / 광범위 LVSI |
| IIC | 공격적 조직형에서 근층 침윤 있음 |
| IIIA1 / IIIA2 | 난소·난관 침범(IA3 제외) / 자궁 장막하층·장막 침범 |
| IIIB1 / IIIB2 | 질·자궁방조직 / 골반 복막 침범 |
| IIIC1 / IIIC2 | 골반 / 신혈관 높이 이하 대동맥주위 림프절 전이 |
| IVA / IVB / IVC | 방광·장 점막 / 골반 밖 복막 / 원격 장기 또는 신혈관보다 위 림프절 전이 |

- **IA3 조건**: 저등급 자궁내막양암, 근층 침윤 <50%, 광범위 LVSI 없음, 다른 전이 없음, 난소는 일측 국한이며 피막 침범·파열 없음.
- **조직형·LVSI**: 비공격적 조직형은 저등급(G1–2) 자궁내막양암이다. 고등급 자궁내막양암·장액성암·투명세포암 등은 공격적 조직형이다. FIGO 2023의 광범위 LVSI는 침범 혈관 ≥5개이다.
- **림프절**: IIIC의 미세전이는 i, 거대전이는 ii로 구분한다. 고립종양세포는 pN0(i+)로 기록한다. 자궁경부 선 침범만으로 IIA가 되지는 않는다.

**분자 병기 보정**

- 자궁체부·경부 국한 병원성 POLE 변이: IAm_POLEmut
- 같은 범위 + 근층 침윤 p53abn: IICm_p53abn
- MMRd·NSMP: 병기 변경 없음; III–IV도 분자형만으로 하향하지 않음

## 5. 치료
- **수술**: 자궁전절제·양측 난관난소절제·병기 평가
  - 림프절: 위험군에 따라 감시림프절 지도화, 모든 환자에게 골반/대동맥주위 절제하지 않음
- **보조치료**: 완전 절제 후 FIGO 2023 + POLE·MMR·p53·NSMP/ER 통합
  - 저위험: 병기 I–II 병적 POLE 변이, IA의 MMRd/저등급 ER 양성 NSMP 등은 무보조치료 추적
  - 중간 위험: 질 근접치료
  - 고중간 위험(광범위 LVSI·경부 기질 침윤 등): 골반 외부방사선
  - 근층 침윤 p53 이상·고위험 진행 병기: 항암+방사선 검토
  - ‘I기’만으로 보조치료를 생략하지 않음
- **가임력 보존**: 아래 조건 확인 후 LNG-IUD/고용량 progestin
  - 전문 병리상 grade 1 자궁내막양암, 근층 침윤·자궁외 병변 없음, 면밀한 추적 가능
  - 3–6개월마다 조직 반응 확인
  - 진행·무반응·임신 계획 완료: 자궁절제 권고
- **진행·재발**: 수술/방사선 근치 곤란 + 전신치료 필요
  - Carboplatin/paclitaxel + pembrolizumab 또는 dostarlimab → 면역 유지치료 검토
  - dMMR/MSI-H에서 이득이 특히 크며 pMMR도 대상 가능
  - 재발 후: 이전 면역치료·MMR·HR/HER2·진행 속도로 면역/표적/호르몬치료 선택

## 6. 예후 및 합병증 (Prognosis)
- 조기 발견 시 예후가 매우 좋음.
- 진행성 암의 경우 재발 위험이 있으며, 수술 후 정기적인 추적 관찰이 중요.
