## 1. 개요
- **정의**: 난소 상피 세포에서 기원하는 악성 종양으로, 전체 난소암의 90% 이상을 차지함
- **원인**: 배란 횟수 증가(초경이 빠르거나 폐경이 늦은 경우, 미산부 등)가 위험 요인이며, BRCA1/2 유전자 변이 등 유전적 요인이 중요함
- **기전**: 난관 상피 내 암종(STIC)에서 기원하는 경우가 많으며, 복막 파종 및 림프절 전이가 주된 전파 경로임

## 2. 임상 양상 (Clinical Features)
* **CC**: 초기에는 무증상이 많으며, 진행 시 복부 팽만, 복통, 소화 불량, 조기 포만감, 질 출혈 등이 나타남
* **P/E**: 복수, 난소 종괴 촉지

## 3. 검사 (Lab & Imaging)
- **종괴 평가**: 질식초음파·CA-125 보조 사용; 무증상 평균위험군의 일률적 선별검사는 아님
- **확진**: 영상·표지자를 참고하고 조직 확인
  - 선행항암 계획 시 원칙적으로 먼저 조직검사

## 4. 진단 (Diagnosis)
- 수술적 병기 설정(Surgical staging)이 필수적이며, 임신 중이라도 의심 시 시행함

**FIGO 난소·난관 병기(2014 체계)**:

| 병기 | 구분 기준 |
| --- | --- |
| IA / IB | 일측 / 양측 난소·난관 국한. 피막 보존, 표면 종양 없음, 복수·세척액 악성세포 없음 |
| IC1 / IC2 / IC3 | 수술 중 유출 / 수술 전 피막 파열 또는 표면 종양 / 복수·세척액 악성세포 |
| IIA / IIB | 자궁·난관·난소로 골반 내 확산 / 그 밖의 골반 복막조직 침범 |
| IIIA1 | 후복막 림프절만 전이: (i) 전이 병소 ≤10 mm, (ii) >10 mm |
| IIIA2 | 골반 밖 복막의 현미경적 전이, 림프절 전이 유무 무관 |
| IIIB / IIIC | 골반 밖 육안적 복막 전이의 최대 지름 ≤2 cm / >2 cm |
| IVA / IVB | 악성세포가 확인된 흉수 / 장기 실질·복강 밖 장기 또는 림프절 전이 |

- **전이 구분**: 간·비장 표면과 실질은 다름; 실질 전이는 IVB
- 단순 흉수만으로 IVA가 되지 않음
- 수술·병리·영상으로 병기 결정, 조직형·등급·잔존 종양 별도 기록

## 5. 치료
**초기 병기**: 병기설정 수술 후 조직형·등급으로 결정

- **관찰 가능**: 완전 병기설정 IA 저등급 장액성/저등급 자궁내막양, IA–IB 팽창성 점액성
- **항암 권고·검토**
  - 고등급 장액성·고등급 자궁내막양: I기라도 권고
  - II기: 조직형과 무관하게 보조 백금 항암 검토
- **경계성 종양**: 침윤성 암과 구분, 항암 자동 적용하지 않음

**III–IV기 수술·항암**

- **일차 종양감축**: 육안 완전 절제 가능 + 허용 가능한 수술 위험
- **선행항암**: 완전 절제 곤란 또는 수술 위험 높음 → 조직 확진 후 carboplatin/paclitaxel
  - 반응·안정병변: 4주기 이내 중간 종양감축 검토
  - 총 약 6주기 항암 완성
  - 치료 중 진행: 자동 수술하지 않고 진단·전신치료 재평가

**유지치료** (ASCO 2026)

1차 백금 항암에 완전/부분 반응한 진행성 고등급 암에 적용한다. 진행병변에 유지요법을 시작하지 않는다.

- **BRCA1/2 병적 변이**: olaparib·niraparib·rucaparib 검토
- **BRCA 변이 없음·HRD 양성**: niraparib·rucaparib 검토
- **이전 bevacizumab 병용 + BRCA 변이/HRD 양성**: olaparib + bevacizumab 선택 가능
- **BRCA 정상·HRD 음성**: ASCO 2026은 PARP 유지 비권고
  - 허용하는 다른 지침·국가는 이득·독성·승인 조건 개별 검토

**백금 저항성 재발**

- **MIRV**: 백금 종료 후 6개월 이내 진행 + FRα 고발현 + 이전 전신치료 1–3개
  - FRα 고발현: 검증 IHC에서 종양세포 ≥75%가 2+ 이상
  - 안과검사·예방 점안, 각막/시력 이상 시 보류·감량 기준 적용
- **Pembrolizumab + paclitaxel ± bevacizumab**: 성인, PD-L1 CPS ≥1, 이전 전신치료 1–2개(FDA 2026 승인)
- 국내 승인·급여 별도 확인

## 6. 예후 및 합병증 (Prognosis)
- **예후**: 진단 병기에 따라 생존 차이
- **CA-125 추적**: 수치 단독 상승만으로 바로 항암을 시작하는 생존 이득은 입증되지 않음
  - 수치 추세·증상, 필요한 영상으로 임상 재발 여부 판단
