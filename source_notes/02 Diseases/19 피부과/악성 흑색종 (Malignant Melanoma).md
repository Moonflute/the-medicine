분과 : [[피부과]]

## 1. 개요
- **정의**: 멜라닌 세포의 악성 변형으로 발생하는 피부암. 신경능선(neural crest) 유래 세포에서 기원하며, 피부 외에도 점막, 뇌, 위장관 등에서 발생 가능.
- **원인**: 자외선(UV) 노출, 가족력, 유전적 요인(CDKN2A, CDK4 등), 면역 저하 상태.

- **기전**: BRAF V600E 등 MAP kinase 경로 활성으로 증식, UV에 의한 DNA 손상 복구 실패

## 2. 임상 양상 (Clinical Features)
* **CC**: 무증상이 흔하나 가려움, 출혈, 궤양, 위성 병변 등이 동반될 수 있음.

- **ABCDE**: 비대칭(Asymmetry)·불규칙 경계(Border)·색조 변화(Color)·직경 >6 mm(Diameter)·크기/모양/색의 변화(Evolving)

**주요 분류**:

  - 표재확산 흑색종 (Superficial spreading melanoma): 가장 흔한 유형.
  - 결절 흑색종 (Nodular melanoma): 수직 성장만 하며 예후가 나쁨.
  - 악성 흑색점 흑색종 (Lentigo maligna melanoma): 고령의 안면부 호발.
  - 말단 흑색점 흑색종 (Acral lentiginous melanoma): 한국인에서 가장 흔한 유형.

## 3. 검사 (Lab & Imaging)
- **조직검사**: 전절제 생검 원칙, 필요 시 절개 생검
- **병기 평가**: AJCC 8판 TNM, Breslow 두께·궤양·림프절 전이 확인
- **영상**: 병기에 따라 PET-CT·뇌 MRI·림프절 초음파
- **분자검사**: BRAF V600E 등 표적치료 결정에 필요한 변이 확인

## 4. 진단 (Diagnosis)
* 임상적 ABCDE 평가 및 더모스코피(Dermoscopy)를 통한 선별.
* 조직병리 검사를 통한 확진 및 Breslow 두께 측정.

**피부 흑색종 AJCC 8판**:

| T분류 | Breslow 두께·궤양 |
| --- | --- |
| Tis | 표피 내에 국한된 상피내 병변 |
| T1a | <0.8 mm이고 궤양 없음 |
| T1b | <0.8 mm이며 궤양 있음, 또는 0.8–1.0 mm(궤양 유무 무관) |
| T2 / T3 / T4 | 각각 >1–2 mm / >2–4 mm / >4 mm |

T2–4는 궤양이 없으면 a, 있으면 b를 붙인다. Clark level을 Breslow 두께 대신 T분류에 사용하지 않는다.

| 병기군 | 기준 |
| --- | --- |
| 0 | Tis N0 M0 |
| I | 얇은 국소암(T1 또는 T2a), N0 M0 |
| IIA | T2b 또는 T3a, N0 M0 |
| IIB | T3b 또는 T4a, N0 M0 |
| IIC | T4b N0 M0 |
| III | 국소 림프절 또는 microsatellite·satellite·in-transit 전이, M0 |
| IV | 원격 전이 M1 |

- **임상병기(c)·병리병기(p) 구분**: T1b N0 M0는 임상 IB지만 병리 IA에 포함 가능
- **SLNB 결과**: N이 바뀌면 병기 재평가
- **III기 세분**: 전이 림프절 수·발견 방식·원발 T를 함께 적용

## 5. 치료
- **절제 경계(ESMO)**: Breslow 두께에 따라 결정
  - 상피내: **0.5 cm**
  - 침윤 두께 **≤2 mm: 1 cm**, **>2 mm: 2 cm**
  - 얼굴·말단은 기능과 병리 절제면 함께 고려
- **감시림프절생검(SLNB)**
  - **>1 mm + 임상 림프절 음성**: 권고
  - pT1b(0.8–1.0 mm 또는 <0.8 mm + 궤양): 이득·위험 논의
  - <0.8 mm + 무궤양: 통상 생략, 깊이 불명확 등 예외 평가
  - 양성이라고 예방적 완전 림프절절제를 자동 시행하지 않음
- **완전 절제 IIB/IIC·III기**: 재발 위험·면역 독성을 비교해 보조 anti-PD-1 논의
  - III기 **BRAF V600 변이**: BRAF/MEK 병용도 선택지
- **절제 가능 III기 + 임상/영상 림프절 전이**: 선행 면역치료 후 수술을 다학제로 검토
- **절제 불가 III·IV기**: anti-PD-1 기반 또는 BRAF V600 변이의 BRAF/MEK 병용
  - 종양 부담·증상·진행 속도·뇌전이에 따라 선택
  - 새 선행 요법의 국내 허가는 별도 확인

## 6. 예후 및 합병증 (Prognosis)
* **예후 인자**: Breslow 두께(침범 깊이), 궤양 유무, 림프절 전이 여부.
- **합병증**: 국소 재발, 림프절 전이, 원격 전이(폐, 간, 뇌 등).
