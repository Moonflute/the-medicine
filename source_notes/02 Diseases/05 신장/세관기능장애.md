# 세관기능장애

## 개요
- 세관기능장애는 신장 분과에서 함께 검토하는 하위 질환군입니다.
- 대표 질환: [[다낭성 콩팥 질환 (Polycystic Kidney Disease)]], [[리들 증후군 (Liddle Syndrome)]], [[바터 증후군 (Bartter Syndrome)]], [[지텔만 증후군 (Gitelman Syndrome)]], [[콩팥세관 산증 1형 (Renal Tubular Acidosis Type 1)]], [[콩팥세관 산증 2형 (Renal Tubular Acidosis Type 2)]]
- 세부 감별, 검사, 치료는 각 질환 문서에서 확인합니다.
