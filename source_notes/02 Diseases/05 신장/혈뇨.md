# 혈뇨

## 혈뇨 확인과 응급 판단

- **혈뇨 확인**: dipstick heme 양성은 소변 현미경 적혈구로 확인
  - 적혈구가 거의 없음: 혈색소뇨·미오글로빈뇨 감별
  - AUA/SUFU 정의: 적절히 채취한 한 검체에서 **≥3 RBC/HPF**
  - 월경·감염·일시적 원인: 원인 해결 후 재검
- **비뇨기 응급**: 혈괴에 의한 요폐 또는 지속 대량출혈
- **신장 평가를 서두를 소견**: 급격한 신기능 저하, 단백뇨·적혈구 원주, 고혈압·부종
- **평가 생략 금지**: 항응고제 복용·감염만으로 악성종양이나 구조적 원인 평가를 생략하지 않음

## 신장성과 요로성 혈뇨의 감별

| 단서 | 고려할 원인 | 추가 평가 |
| --- | --- | --- |
| 변형 적혈구·원주·단백뇨 | IgA 신병증 등 사구체염 | 신기능·단백뇨 정량, 필요 시 면역·신생검 |
| 가족력·청력·안과 이상 | COL4 관련 질환·Alport | 유전 및 신장 평가; 얕은 기저막이라고 무조건 양성 경과로 단정하지 않음 |
| 옆구리 산통 | 결석 | 결석·폐색·감염 평가 |
| 낭종성 신장·가족력 | 다낭성 콩팥 질환 | 영상·신기능 및 질환별 위험 평가 |
| 좌측 통증·골반 울혈 | Nutcracker syndrome | 증상·영상의 연관성을 확인하고 영상 소견만으로 확진하지 않음 |
| 무통성 육안혈뇨·흡연 등 | 요로 악성종양 | 비뇨기 위험 평가와 방광·상부요로 검사 |

**사구체성 단서가 있으면** 신장내과 평가를 병행한다. 단백뇨·eGFR 악화·활성 침사·전신질환이 생검 판단에 중요하다. 요로암 위험에 맞춘 비뇨기 평가도 진행한다.

## 현미경적 혈뇨의 위험도별 검사

| 악성종양 위험 | AUA/SUFU 2025 접근 |
| --- | --- |
| 낮음 또는 매우 낮음 | 즉시 방광경·영상보다 6개월 이내 요검사 재검 |
| 중간 | 방광경과 신장 초음파 |
| 높음 | 방광경과 상부요로 단면 영상; 금기 없으면 CT urography |

- **위험도 판단**: 적혈구 **3–10 / 11–25 / >25 RBC/HPF**, 흡연 **<10 / 10–30 / >30갑년**, 연령·성별·육안혈뇨 병력과 추가 위험인자를 종합
  - 낮은 위험은 저위험 조건을 모두 충족해야 함. 여성은 연령만으로 고위험에 분류하지 않음
- **재평가**: 초기 검사가 음성이어도 지속·재발 혈뇨, 새로운 육안혈뇨 또는 증상 발생 시 시행
