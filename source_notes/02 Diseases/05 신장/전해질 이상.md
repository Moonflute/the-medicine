# 전해질 이상

## 공통 접근
- 전해질 이상은 수치 자체보다 **증상·발병 속도·혈장 삼투압·체액 상태·소변 전해질**을 함께 해석합니다. 나트륨은 물 균형, 칼륨은 세포 이동·신장 배설·약물과 산-염기 상태를 중심으로 접근합니다.

## 먼저 구분할 위험 상황
- 경련·의식 변화가 동반된 심한 나트륨 이상, 근력 저하·심전도 변화가 동반된 칼륨 이상은 즉시 중증도를 확인합니다. 교정의 속도 역시 신경학적 합병증 위험과 연결됩니다.

## 하위 질환 감별 포인트
| 전해질 | 감별의 중심 | 연결 질환 |
| --- | --- | --- |
| 저나트륨 | 저삼투압 여부와 체액 상태·소변 농축을 먼저 확인 | [[저나트륨혈증 (Hyponatremia)]] |
| 고나트륨 | 자유수 결핍인지, 나트륨 획득인지와 갈증·소변 농축 능력을 확인 | [[고나트륨혈증 (Hypernatremia)]] |
| 저칼륨 | 위장관 손실, 신장 손실, 세포 내 이동을 산-염기·요중 K로 구분 | [[저칼륨혈증 (Hypokalemia)]] |
| 고칼륨 | 가성 고칼륨혈증, 세포 파괴·산증, 신장 배설 저하·약물을 구분 | [[고칼륨혈증 (Hyperkalemia)]] |
