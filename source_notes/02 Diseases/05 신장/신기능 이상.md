# 신기능 이상

## 공통 임상 접근
- 신기능 이상은 시간 경과를 통해 급성 손상, 회복 중인 손상, 만성 콩팥병을 구분하고 이전 크레아티닌·소변검사 기록을 찾는다.
- 체액 상태, 혈압, 약물·조영제 노출, 감염·쇼크, 요로 폐색 가능성을 동시에 평가한다.
- 소변검사·침사, 전해질·산염기 상태, 신장 영상은 원인 분류와 합병증 평가에 함께 사용한다.

## 먼저 배제할 상황
- 고칼륨혈증, 중증 산증, 폐부종·저산소증, 요독성 증상, 진행성 저혈압 또는 의심되는 양측 요로 폐색은 즉시 평가한다.

## 하위 질환 감별 포인트
| 질환 | 구분에 특히 유용한 단서 | 다음 확인 |
|---|---|---|
| 급성 콩팥 손상 | 짧은 기간의 신기능 변화 | 원인, 전해질·체액 합병증 |
| 만성 콩팥병 | 지속적인 신장 구조·기능 이상 | 만성도, 원인과 합병증 |
| 콩팥전 급성 콩팥 손상 | 관류 저하 병력·체액 손실 또는 저혈압 | 체액 상태와 반응 |
| 콩팥성 급성 콩팥 손상 | 침사 이상·신실질 손상 맥락 | 사구체·세관·간질 원인 |
| 콩팥후 급성 콩팥 손상 | 배뇨 증상·폐색 위험 또는 수신증 | 방광·요로 영상 |
