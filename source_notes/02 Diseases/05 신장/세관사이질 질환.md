# 세관사이질 질환

## 공통 접근
- 세관사이질 질환은 사구체성 혈뇨·단백뇨보다 급성 신손상, 농뇨·백혈구 원주, 약물·감염·전신질환 맥락이 두드러집니다. 최근 약물과 시간 관계를 확인합니다.

## 먼저 구분할 위험 상황
- 빠르게 악화되는 신기능, 핍뇨·고칼륨혈증·체액 과다, 발열·발진·호산구 증가를 동반한 약물 노출은 중증도와 알레르기성 원인을 우선 평가합니다.
