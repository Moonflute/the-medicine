# 항암 약물

## 주의해야 할 독성

| 약제·계열 | 대표 독성·확인 항목 |
| --- | --- |
| Cisplatin / carboplatin / oxaliplatin | 순서대로 신독성·저Mg/구토, 골수억제, 냉 자극 유발 말초 이상감각 |
| Doxorubicin 등 anthracycline | 누적 심장독성, 골수억제, 혈관외유출 손상 |
| Cyclophosphamide·ifosfamide | 출혈성 방광염. Ifosfamide는 뇌병증도 감시 |
| 5-FU·capecitabine / irinotecan | 점막염·설사, capecitabine 손발증후군 / irinotecan의 조기 콜린성 증상과 지연 설사 |
| Paclitaxel / vincristine | 말초신경병증·주입 과민반응 / 신경병증·변비와 장마비 |
| 면역관문억제제 | 장염, 간염, 폐렴, 내분비 이상 등. 호흡곤란·흉통·저혈압·심한 설사는 신속 평가 |

- **면역 이상반응**: 증상에 따라 감염·암 진행·다른 약제를 감별. Grade 2는 다수에서 투여 보류, Grade 3은 대개 보류와 고용량 스테로이드 검토. 심근염·신경계 이상·부신 위기는 낮은 등급이어도 긴급 평가
- **G-CSF 1차 예방**: 요법의 발열성 호중구감소증 위험 **약 ≥20%**. 그 미만이라도 고령·이전 발열성 호중구감소증·골수 침범 등 고위험이면 검토
  - **2차 예방**: 이전 주기에 호중구 합병증이 발생했고 감량·지연이 치료 성과를 해칠 수 있을 때
  - **Filgrastim**: 보통 세포독성 항암 종료 ≥24시간 뒤 **5 μg/kg/일**로 시작, ANC 및 프로토콜로 종료 결정
  - **Pegfilgrastim**: 성인 **6 mg 피하 주기당 1회**, 항암 종료 ≥24시간 뒤. 다음 항암과 간격은 제제 허가·요법·국내 급여 기준 확인

항체의 분류는 표적을 기준으로 본다. Bevacizumab은 VEGF, trastuzumab은 HER2를 표적하는 항체다.
