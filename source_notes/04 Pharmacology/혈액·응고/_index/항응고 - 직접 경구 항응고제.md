# 항응고 - 직접 경구 항응고제

> [!summary]
> 직접 경구 항응고제로, 와파린보다 다루기 단순한 편인 경구 항응고제 계열이다.
> 계통: `혈액·응고 > 항응고 > 직접 경구 항응고제`

## 기전 개요
- thrombin 또는 factor Xa를 직접 억제한다.

## 적응증
- 심방세동의 뇌졸중 예방
- 심부정맥혈전증
- 폐색전증

## 금기증
- 활동성 출혈
- 중증 신기능 저하 일부
- 기계판막

## 부작용
- 출혈
- 멍
- 위장관 출혈

## 특징
- 신기능, 반감기, 모니터링 필요성, 해독제 유무를 비교한다.
