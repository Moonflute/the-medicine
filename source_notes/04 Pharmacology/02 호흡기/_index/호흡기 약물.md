# 호흡기 약물

호흡기 약물은 `기관지 확장`, `기도 염증 조절`, `알레르기·기타 보조` 축으로 정리하면 임상 연결이 쉽다.

## 분류

### [[기도 확장 - LABA]]
- 계통: `호흡기 > 기도 확장 > LABA`
- 약물 수: `4`
- 약물:
  - [[../Formoterol]]
  - [[../Indacaterol]]
  - [[../Salmeterol]]
  - [[../Vilanterol]]
